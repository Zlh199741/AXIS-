# 剧本结构诊断审核技能

[技能说明]
    审核 script-structure-diagnosis-skill 的诊断报告产出，确保：
    1. 三幕式结构分析准确，占比判断合理
    2. 关键节点（激励事件/转折点/高潮等）识别无遗漏
    3. 改编可行性评估客观，建议可执行
    4. 诊断结论与原文实际内容一致

    本审核技能必须参考：
    1. skills/script-structure-diagnosis-skill/SKILL.md：了解诊断规范
    2. skills/compliance-review-skill/SKILL.md：合规检查
    3. tools/references/sensitive-word-dictionary.md：敏感词检测

    调用方 Agent：
    - agents/director.md：导演 Agent 执行审核
    - 小说分析阶段：由融合模块 chuanban-chaishu-skills 承担（无独立 agent 文件）

[审核流程]

    第一步：建立整体理解
        - 读取原始小说文本
        - 读取待审核的诊断报告
        - 明确审核立场：你的任务是找出问题，而非确认通过

    第二步：结构分析准确性审核
        | 检查项 | 标准 |
        |--------|------|
        | 叙事结构类型 | 判断是否准确（线性/多线/倒叙等） |
        | 三幕式占比 | 占比是否合理（25%/50%/25%浮动±10%） |
        | 章节划分 | 幕与章节的对应是否准确 |
        | 核心矛盾 | 外部/内部矛盾是否提炼准确 |

    第三步：关键节点验证
        | 节点 | 检查标准 |
        |------|---------|
        | 激励事件 | 是否真正打破平衡？位置是否合理？ |
        | 第一转折点 | 是否推动主角进入新世界？ |
        | 中点 | 是否有假胜利/假失败？ |
        | 第二转折点 | 是否推向最终对抗？ |
        | 高潮 | 是否为最高冲突点？ |
        | 结局 | 是否建立新平衡？ |

    第四步：改编可行性验证
        | 检查项 | 标准 |
        |--------|------|
        | 评分合理性 | 各维度评分是否有依据 |
        | 建议可行性 | 改编建议是否具体可执行 |
        | 难度评估 | 难度判断是否准确 |
        | 策略匹配 | 推荐策略是否与原文特性匹配 |

[评分表格式]

    三维评分规则（必须执行）：

    诊断准确性评分（0-100分）：
    □ 三幕式结构分析是否准确？（0-33分）
    □ 关键节点识别是否完整无遗漏？（0-33分）
    □ 核心矛盾提炼是否精准？（0-34分）

    改编评估质量评分（0-100分）：
    □ 各维度评分是否有原文依据？（0-33分）
    □ 改编建议是否具体可执行？（0-33分）
    □ 改编策略是否与原文特性匹配？（0-34分）

    报告完整性评分（0-100分）：
    □ 所有模板字段是否填写完整？（0-33分）
    □ 原文引用是否准确？（0-33分）
    □ 结论与分析是否逻辑自洽？（0-34分）

    通过标准（C级审核类，参考 skills/templates/quality-threshold-standard.md）：各项 ≥ 90分

[PASS/FAIL 标准]

    PASS 条件：
    - 三维评分各项 ≥ 95分
    - 关键节点无遗漏
    - 合规审核通过

    FAIL 条件（任一满足）：
    - 三幕式结构判断严重错误（如将第一幕错判为第二幕）
    - 遗漏2个以上关键节点
    - 改编建议与原文明显矛盾
    - 合规审核未通过

[诊断指南]

    Q: 三幕式占比判断不准？
    A: 检查第一幕是否在25%±10%处结束（激励事件→跨过门槛），第二幕是否占50%±10%（试炼→深渊），第三幕是否占25%±10%（觉醒→结局）。

    Q: 关键节点遗漏怎么办？
    A: 逐一对照9节点检查表（预示→失衡→越界→起伏→中点→深渊→暗夜→决战→结尾），标记每个节点在原文中的章节位置。

    Q: 改编建议太笼统？
    A: 每条建议必须包含：具体问题→影响范围→修改方向→参考案例。避免"建议加强节奏"这类空话。

    Q: 爽点密度计算有误？
    A: 重新逐章标记ABC爽点，确认权重（A×3+B×2+C×1），检查是否遗漏隐性爽点（如伏笔揭示、身份反转暗示）。

    Q: 诊断结论与原文不符？
    A: 回溯原文关键段落，逐条比对诊断报告中的引用是否准确，结论是否有原文依据支撑。

    Q: 角色弧光评估主观？
    A: 使用5阶段检查表（起点→触发→成长→转折→终点），每个阶段必须有原文事件对应，缺失阶段标注"缺失"而非主观猜测。

    Q: 多线叙事结构难以判断？
    A: 分别为每条叙事线独立诊断，再检查交汇点是否合理（通常在第5集和第8集）。

    Q: 改编可行性评分各维度权重如何确定？
    A: 按短剧优先级排序：爽点密度(30%)>节奏适配(25%)>角色弧光(20%)>场景集中度(15%)>叙事线性(10%)。

[常见审核案例]

    PASS案例：
    - 三幕式占比28%/47%/25%，在合理范围内
    - 9个关键节点全部识别，激励事件位于第1章末
    - 改编建议具体："第3-5章铺垫过长，建议合并为1集，将B级爽点提升为A级"
    - ABC爽点密度2.3/章，高于警告线

    FAIL案例：
    - 将第一转折点错误标注在全书70%处（应在25%处）
    - 遗漏"中点转折"节点，导致第二幕分析缺少核心支撑
    - 改编建议仅写"建议加快节奏"，无具体章节和操作方向
    - 爽点密度计算将C级爽点错标为A级，导致密度虚高

[术语表]

    | 术语 | 英文 | 定义 |
    |------|------|------|
    | 三幕式结构 | Three-Act Structure | 建置(25%)/对抗(50%)/解决(25%)的经典剧本结构 |
    | 激励事件 | Inciting Incident | 打破主角日常平衡的关键事件 |
    | 中点转折 | Midpoint | 全书50%处的重大转折，虚假胜利或虚假失败 |
    | 爽点密度 | Satisfaction Density | 每章/每万字的ABC爽点加权数量 |
    | 角色弧光 | Character Arc | 角色从初始状态到最终状态的变化轨迹 |
    | 节奏适配度 | Pacing Compatibility | 原文节奏与短剧3-10-60法则的匹配程度 |
    | 改编可行性 | Adaptation Feasibility | 原文适合改编为短剧的综合评估分数 |
    | 关键节点 | Key Plot Points | 推动叙事进程的不可或缺的情节点 |

[学习路径]

    📚 第一阶段：诊断基础 (1周)
    - 掌握三幕式结构识别方法
    - 练习关键节点标注
    - 熟悉ABC爽点分类标准

    📚 第二阶段：审核技巧 (1周)
    - 掌握诊断报告逐项比对方法
    - 学会识别诊断结论与原文的不一致
    - 练习改编建议可行性评估

    📚 第三阶段：案例分析 (1周)
    - 分析3个PASS案例和3个FAIL案例
    - 练习撰写审核报告
    - 掌握评分标准的一致性

    📚 第四阶段：实战应用 (持续)
    - 参与实际项目诊断审核
    - 积累常见问题模式库
    - 与script-structure-diagnosis-skill产出方协同优化
