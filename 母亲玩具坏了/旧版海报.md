## 海报A｜「妈妈，我要那个！」

**场景构思**：**极致仰拍 + 冲白过曝光感**。镜头贴在地面向正上方看，整个画面笼罩在一层**强烈的冷白过曝光晕**中——如同神降临时的"白光冲刷"感，母亲的象牙白西装在这种冲白光效下几乎和背后的白色光源融为一体，边缘泛光溢出如发光体。

场景是作家母亲的**巨型创作工作室**。母亲**背对镜头**站立，观众只看到她气场撼人的背影。仰拍透视严格准确——**近处（画面底部）：母亲的高跟鞋和小腿占据极大面积**，鞋底纹路清晰可见级别的近距离；**中段：腰身和西装收窄**；**远处（画面顶部）：肩线和头部在透视中变小但依然撑满画面宽度**——形成标准的近大远小锥形透视。她右手向前举起钢笔指向面前的男性全息影像。

**Q版司遥的视线焦点：看着母亲**——Q版坐在母亲右脚旁的手稿纸堆上，**不是看帅哥，而是仰头直视母亲的背影**，猫耳竖起，大眼里映着母亲象牙白西装背影的白色倒影，双手拉着母亲的裤腿下摆，小嘴张开是在喊"妈妈——！我要那个！"的撒娇。她的视线和身体语言全部指向母亲=**"我的全世界就是妈妈"**。

**作家身份环境元素（极致堆料）**：
- 地面近景：散落的手写手稿纸、红笔批注角色草图、揉皱废稿纸团、掉落的红色马克笔
- 远处墙面（仰拍中的"天空"）：巨型手稿证据墙——手稿页、角色线稿、剧情流程图、红蓝墨水连线、五男设计稿照片+红笔批注
- 画面左侧：工作台边缘入画——手稿小山、笔记本电脑、钢笔马克笔、咖啡杯、红色墨水瓶
- 天花板层：晾衣绳+木质夹子夹着角色设计稿如暗房晾照片
- 母亲手中：香槟金钢笔=命运的权杖

**画面张力**：冲白过曝让母亲背影如同从白光中降临的神 + 极致仰拍锥形透视的压迫 + 每寸空间堆满作家身份 + Q版不看帅哥只看妈妈="妈妈就是我的神"。

## 海报B｜「提线五将」

**场景构思**：**极致仰拍 + 冲白过曝 + 母亲背影**——与海报A形成统一视觉语言但换了核心动作。镜头贴地面向正上方看，冲白过曝光感笼罩全画面。

母亲**背对镜头**站立在画面上方，但这次她不是单手持笔——**双臂向左右两侧完全展开如十字架/交响乐指挥家**，十根修长手指微微弯曲，从每根指尖垂下多根极细金色发光丝线向画面下方扩散如金色瀑布。仰拍锥形透视严格准确——近处高跟鞋和小腿巨大，中段腰身收窄，远处展开的双臂和肩线在"天空"位置撑满画面如巨鹰展翅。金线从她十指向下延伸穿越整个画面空间——连接到画面中下方被悬吊的五个男性角色。

**五男傀儡**被金线悬吊在母亲双臂下方的半空中——从仰拍视角看他们悬浮在母亲和镜头之间的中间层，每人以不同姿态被线操控（冰棘十字架低头 / 焰牙空洞假笑 / 蔷薇跪地献礼 / 暗鸦挣扎挣不脱 / 残翼人偶站立）。他们在仰拍中身体也产生透视——脚部朝向镜头偏大，头部朝向母亲偏小。

**Q版司遥**在画面最前景最底部（镜头旁），坐在散落的手稿纸堆上，**仰头直视母亲背影**（不是看帅哥），左手拉着从母亲指尖垂下的一根金线在玩——像小孩拽着妈妈的衣角，完全不知道这根线的另一端正吊着一个男人的命运。右手指向某个被吊着的帅哥，小嘴喊"妈妈我要那个！"，猫耳竖起，星星眼，虎牙笑，天真到残忍。

**作家身份环境元素**：
- 地面近景（Q版脚边）：散落手稿纸、红笔批注角色草图、废稿纸团、掉落的红色马克笔
- 远处墙面（仰拍中的"天空"·母亲身后）：巨型手稿证据墙——手稿页、角色线稿、剧情流程图、红蓝墨水连线、五男设计稿照片+红笔删除线
- 画面侧边：工作台边缘入画——手稿小山、笔记本电脑、钢笔墨水瓶
- 天花板层：晾衣绳+夹子夹着角色设计稿

**画面张力**：极致仰拍母亲展翅背影如暗黑天使/傀儡之神 + 金线从十指如瀑布倾泻操控五个帅哥 + 冲白过曝让母亲融入白光如降临的神 + Q版在最底部拽着一根命运之线当玩具玩 + 每寸空间堆满作家身份——**冷酷的绝对掌控者**与**天真到残忍的无辜女儿**的极致反差。
