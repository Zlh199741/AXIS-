# 青山灵田计划人物资料

# 人物总览

- **主角**：沈禾，重生返乡，守着一座没人看好的荒山重新过日子。
- **核心家人**：周桂兰，沈禾奶奶，老屋和菜地都连着她的记忆。
- **事业搭档 / 情感线**：陆知远，云溪县农技站技术员，话少、较真、靠得住。
- **明面反派**：沈建国，沈禾二叔，嘴上说亲情，心里惦记荒山承包权。
- **商业反派**：赵明川，外来生鲜连锁区域经理，想把青山的货和牌子都握进合同里。
- **村庄配角**：李春桃、陈大山等村民，先看热闹，后来真正下场一起干。

## [idea][character][新增] 沈禾

# 角色类型

主角 / 女主 / 返乡创业者 / 重生种田经营核心

# 身份定位

二十八岁，前世在城市互联网公司熬到猝然倒下，再睁眼回到十年前。现在的她刚毕业回村，手里只有父亲留下的青山荒坡承包权和老屋继承权益。外人看她是没钱、没人、没经验的回村姑娘，她自己知道，未来的坑已经踩过一遍，掌心那点灵泉也许能让她把家守住。

# 一句话标签

**不再逃走，偏要把荒山种出活路的返乡女主。**

# 角色抓手

- **重生守家**：前世失去奶奶和老屋，这一世先守住家人和土地。
- **种田经营**：从菜地、摊位、订单做到自己的牌子，不急着一步登天。
- **清醒不圣母**：帮村民，但不让渡底线；合作可以，侵占不行。
- **慢热事业脑**：感情不抢戏，先把日子过稳。
- **外柔内硬**：说话温和，关键时刻能当众撕合同、拒绝压价。

# 视觉特征

- **外貌**：清瘦明亮，皮肤因下地逐渐晒出健康麦色，眼神干净但有锋芒。
- **发型**：前期低马尾配碎发，干活时用旧蓝布头巾扎起；后期品牌发布时盘起低发髻。
- **穿着**：旧白衬衫、洗旧牛仔裤、帆布鞋、围裙、袖套；重要场合穿亚麻衬衫和深色长裙。
- **标志性道具**：父亲留下的旧铜水瓢、红绳、记账本、帆布围裙。
- **标志性动作**：说话前先擦干手上的泥；遇到压迫时把账本摊开，用数据反击。
- **口头禅**：“地不会骗人。”

# 人物弧光

- **起点**：前世总觉得村庄代表落后、束缚和失败，所以一心往外跑。
- **转折点**：第一次靠自己种的菜换到钱，奶奶笑着说“这地养人”，她才重新看见土地的分量。
- **低谷**：灵泉秘密差点露馅，合作户动摇，奶奶又病倒，她一度想收拾箱子逃回老路。
- **觉醒**：她明白不能只守一个秘密，真正该守的是标准、品牌和大家都能受益的规矩。
- **终点**：成为青山生态农业主理人，把旧行李箱改成种子展示箱，真正留下。

# 初始缺陷

习惯用“离开”解决问题，不相信故乡装得下自己的未来。

# 终极觉醒

真正的出路不是远离根，而是把根重新养活。

# 金手指

- **掌心灵泉**：每日少量，可改良种子、水质、土壤和动植物状态。
- **未来记忆**：知道青山将进入生态农业与乡村旅游规划。
- **经营认知**：前世城市工作经历让她懂表格、合同、品牌、线上运营。

# 写作使用

她负责把事业、亲情、村庄群像和品牌线都串起来，后续所有大事件都要回到她的选择上。

## [idea][character][新增] 周桂兰

# 角色类型

核心家人 / 奶奶 / 情感锚点 / 土地记忆守护者

# 身份定位

七十岁，沈禾奶奶，青石村老住户。丈夫走得早，儿子沈长林也早年离世，她一个人守着老屋和沈家菜地。身上有老毛病，手脚却闲不住，节气、土性、水沟走向这些事都记得清清楚楚。

# 一句话标签

**把一生都熬进灶火和菜地里的乡村奶奶。**

# 角色抓手

- **温柔坚韧**：嘴上怕沈禾吃苦，转身还是给她留饭、烧水、补工具。
- **土地记忆**：哪块地原来种过什么、哪条水沟什么时候断的，她都记得。
- **情感锚点**：她的健康和笑容是沈禾重生后最大的目标。
- **传统智慧**：不懂合同和品牌，但懂节气、土性、人情。

# 视觉特征

- **外貌**：头发花白，背微驼，笑起来眼角皱纹很深。
- **穿着**：蓝布衫、黑布裤、旧围裙、布鞋。
- **标志性道具**：竹篮、针线笸箩、柴火灶旁的小板凳。
- **标志性动作**：听见院门响就擦手出来看；说正事时把围裙角攥紧。
- **口头禅**：“饭热着呢。”

# 人物弧光

- **起点**：担心沈禾留村没前途，容易被亲戚“自家人”话术动摇。
- **转折点**：亲眼看见沈禾靠菜地挣到第一笔钱，开始相信孙女。
- **低谷**：病倒后害怕自己拖累沈禾，主动提出别再折腾山。
- **终点**：坐在青山民宿院里，看着游客排队吃农家饭，承认沈禾真的把家守住了。

# 写作使用

她让“回家”这件事有了重量。只要奶奶还在，沈禾就没法再像前世那样说走就走。

## [idea][character][新增] 陆知远

# 角色类型

事业搭档 / 情感线男主 / 农技站技术员 / 理性验证者

# 身份定位

三十岁，云溪县农技站技术员，农学硕士毕业后回县里工作。平时跑土壤检测、病虫害防控和生态农业项目申报。性格克制，凡事要证据，不会因为同情谁就轻易站队。

# 一句话标签

**拿数据说话，也愿意陪她把地种明白的农技男主。**

# 角色抓手

- **理性专业**：凡事讲数据、检测、流程。
- **冷面热心**：表面说话直，实际每次关键节点都到场。
- **返乡同类**：也曾被人质疑“读那么多书回县里没出息”。
- **慢热守护**：不替沈禾做决定，只帮她把决定做得更稳。

# 视觉特征

- **外貌**：高瘦清冷，眉眼端正，常年下乡让肤色偏健康小麦色。
- **发型**：短发干净利落。
- **穿着**：浅灰工装衬衫、深色长裤、户外靴；随身背黑色检测包。
- **标志性道具**：土壤取样器、检测报告夹、钢笔、旧皮质笔记本。
- **标志性动作**：蹲下捻土、闻叶片、用笔在报告上圈重点。
- **口头禅**：“先看数据。”

# 人物弧光

- **起点**：只相信规范农业技术，对沈禾过快的种植成果保持怀疑。
- **转折点**：发现沈禾不是投机取巧，而是比谁都愿意记录、试验、复盘。
- **低谷**：外来资本质疑沈禾产品异常，他的检测报告被人恶意断章取义。
- **终点**：主动帮沈禾建立公开种植标准，让青山品牌摆脱“玄乎传闻”，能长久做下去。

# 写作使用

他负责把“太玄”的灵泉成果放进现实农业逻辑里：检测、改土、标准、申报。感情线也从这里长出来，不是突然心动，而是一次次并肩做事后的信任。

## [idea][character][新增] 沈建国

# 角色类型

反派 / 亲戚压迫者 / 熟人社会阻力

# 身份定位

沈禾二叔，村里小包工头，最会拿“都是一家人”压人。他提前从镇上饭局听到青山可能纳入生态农业试点，便想用两万块把沈禾家的荒山承包权拿走。

# 一句话标签

**披着亲情外衣抢地的二叔。**

# 核心特征

- **话术压迫**：总说“我是为你好”“女孩子种什么地”，句句都像替人打算。
- **熟人操控**：利用村里舆论让沈禾显得“不懂事”。
- **利益优先**：亲情只是工具，看到青山赚钱后立刻变脸。
- **镜像缺陷**：同样知道土地值钱，但只想占有，不愿经营。

# 视觉特征

- **外貌**：中年发福，笑时眼睛眯起，脸上常带油滑热络。
- **穿着**：短袖衬衫、西裤、皮鞋，腋下夹黑色公文包。
- **标志性道具**：转让合同、公文包、老式智能手机。
- **标志性动作**：说话时拍人肩膀，谈钱时压低声音。
- **口头禅**：“一家人，我还能害你？”

# 压迫点

- 低价收山，逼奶奶签字。
- 在村里散布沈禾“读书读傻了”“种地赔钱”的说法。
- 抢沈禾菜品客户，试图用低价劣质货搅乱市场。
- 后期与外来资本合作，试图证明沈禾产品有问题。

# 人物弧光

- **起点**：自信能靠亲情话术拿走青山。
- **转折点**：沈禾第一次当众拿出承包合同和账本，拒绝签字。
- **低谷**：看到青山品牌爆红后加倍嫉妒，转头和赵明川搅在一起。
- **结局设计**：因伪造合作授权、低价扰乱和违约行为被公开证据打脸，失去村民信任。

# 写作使用

前期所有“亲戚压人”的戏都可以落在他身上。他越想用亲情把荒山拿走，沈禾“守地”的决心就越清楚。

## [idea][character][新增] 赵明川

# 角色类型

商业反派 / 外来资本代表 / 品牌垄断者

# 身份定位

三十五岁，连锁生鲜品牌“鲜选仓”的区域经理。看出青山蔬果能卖高价后，拿出排他采购协议，想用渠道换走沈禾的产量、定价权和品牌使用权。被拒后，他转而抢相似品牌，再放出产品“好得不正常”的质疑。

# 一句话标签

**想用一份合同套住整座青山的资本经理。**

# 核心特征

- **精致压迫**：不吵不闹，用合同、渠道、流量和舆论压人。
- **利益计算**：认可沈禾能力，但更想吞下她的品牌。
- **体面反派**：外表礼貌，手段冷硬。
- **更高一层的对手**：他让冲突从村里亲戚吵架，变成渠道、商标和标准之争。

# 视觉特征

- **外貌**：西装笔挺，发型精致，眼神习惯审视别人价值。
- **穿着**：深灰西装、白衬衫、无明显品牌标识的商务腕表。
- **标志性道具**：平板电脑、电子合同、黑色商务车。
- **标志性动作**：谈判时推平板到对方面前；听到拒绝时轻敲桌面。
- **口头禅**：“市场不等人。”

# 压迫点

- 以渠道封锁威胁沈禾签排他协议。
- 抢注“青山灵田”相似商标。
- 引导质疑：沈禾家的菜为什么比别人好。
- 试图分化合作村民，让他们单独供货。

# 人物弧光

- **起点**：认为乡村创业者缺资本和渠道，必然会低头。
- **转折点**：沈禾用公开检测、订单数据和合作社模式挡住压价。
- **终点**：在品牌发布会上被反证打脸，不得不改以正常商业价格谈合作。

# 写作使用

中后期的商业压力主要由他带来。他逼沈禾意识到，地守住还不够，牌子、标准和合作社也得守住。

## [idea][character][新增] 李春桃

# 角色类型

配角 / 邻居婶子 / 村民观察者 / 舆论风向标

# 身份定位

四十五岁，沈家隔壁邻居，丈夫常年在外打工，她一个人照顾老人和孩子。嘴快、爱打听，心倒不坏。起初跟着村里人看笑话，后来第一个把自家菜地拿来按沈禾的标准试种。

# 一句话标签

**从看热闹到真入伙的嘴快邻居。**

# 核心特征

- **嘴快爱八卦**：村里消息传播器。
- **现实精明**：谁能让她挣到钱，她就服谁。
- **转向关键**：她从看热闹变成真入伙，其他村民才会跟着动心。

# 视觉特征

- **外貌**：圆脸，笑声大，动作麻利。
- **穿着**：碎花短袖、深色围裙、袖套。
- **标志性道具**：菜篮子、塑料账本夹、三轮车钥匙。
- **标志性动作**：一边择菜一边打听消息。
- **口头禅**：“真的假的？我可要亲眼看看。”

# 人物弧光

- **起点**：觉得沈禾城里娃种地不靠谱。
- **转折点**：尝到沈禾种的番茄，当场要买苗。
- **终点**：成为合作社第一批骨干，主动维护青山品牌口碑。

# 写作使用

她是村里的嘴，也是风向标。她一转向，其他看热闹的人才会真的动心。

## [idea][character][新增] 陈大山

# 角色类型

配角 / 退伍返乡青年 / 执行型帮手

# 身份定位

二十七岁，青石村返乡青年，做过物流和短途运输。家里有一辆小货车，起初靠零散活糊口，后来接下沈禾的蔬果配送线。

# 一句话标签

**把山货准时送进城的沉默行动派。**

# 核心特征

- **可靠守时**：送货从不拖延。
- **行动大于语言**：话少，干活快。
- **留下来的理由**：青山有了稳定活路后，他才真正决定留下。

# 视觉特征

- **外貌**：身材结实，肤色偏深，眼神直接。
- **穿着**：黑色短袖、工装裤、旧运动鞋。
- **标志性道具**：小货车、绑货绳、送货单。
- **标志性动作**：装车前反复检查筐子固定。
- **口头禅**：“几点送到？”

# 人物弧光

- **起点**：觉得村里没机会，准备再次外出打工。
- **转折点**：沈禾给出稳定配送订单和透明分成。
- **终点**：组织村里返乡青年做冷链与短视频运营，成了青山离不开的人手。

# 写作使用

他把青山的货送出去，也把“年轻人可以留村”的可能性带回来。

---

# 冲突关系

- **沈禾 vs 沈建国**：守地与夺地；劳动经营与投机占有。
- **沈禾 vs 赵明川**：品牌自主与资本垄断；长期标准与短期利润。
- **沈禾 vs 村民质疑**：年轻返乡者证明自己。
- **沈禾 + 周桂兰**：亲情修复，前世遗憾补偿。
- **沈禾 + 陆知远**：灵泉奇效与科学验证，互相试探到互相托底。
- **沈禾 + 李春桃 / 陈大山**：从单人创业到村庄协作。

---

# 使用前检查

- **主角**：身份、外貌、动作习惯、金手指和心路变化都已落点。
- **反派**：沈建国压亲情，赵明川压商业，两人不是同一种坏。
- **配角**：李春桃负责村里风向，陈大山负责配送和返乡青年线。
- **辨识度**：每个人都有能上画面的衣着、道具或动作。
- **主弧**：沈禾从想逃离故乡，到愿意把根重新扎回土地里。
