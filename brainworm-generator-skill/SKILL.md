# 脑洞生成器技能

## 技能说明

将一句话创意或故事点子，通过专业的编剧思维扩展为完整的短剧大纲。

核心功能：
1. 脑洞补全 - 世界观扩展、角色设定、冲突设计
2. 核心梗生成 - 核心卖点、情绪钩子、卡点设计
3. 人设生成 - 主角、反派、配角人设卡片
4. 故事卡生成 - 主线故事卡、支线故事卡
5. 集数规划 - 三段式情绪分布（集数根据内容密度动态规划）

## 核心执行原则

### 爆款短剧核心算法（3-10-60 情绪循环）

所有生成的集纲必须遵循：

- **前3秒钩子**：极致视觉奇观、肢体冲突、反常态画面
- **前10秒叙事**：快速交代人物关系、核心矛盾
- **1分钟爽点**：完整情绪释放（反派打脸、绝地反击）
- **卡点钩子**：截断在最高潮前0.5秒

### 绝对视觉化原则

- 禁止心理描写、内心独白
- 强制外化为肢体动作、微表情、物理交互

## 核心方法论

### 脑洞扩展五维模型

任何一句话创意都可从以下5个维度扩展为完整短剧概念：

| 维度 | 扩展方向 | 示例（"穿越到古代"） |
|------|---------|---------------------|
| **世界维度** | 时代背景+社会规则+势力分布 | 架空唐朝+科举制+四大家族 |
| **能力维度** | 金手指/系统+限制+成长路径 | 现代知识系统+每日3次+解锁新学科 |
| **冲突维度** | 核心矛盾+层层升级+终极对决 | 家族陷害→朝堂斗争→国运之战 |
| **人物维度** | 主角缺陷+反派镜像+CP化学反应 | 社恐书生+权谋太子+霸道公主 |
| **商业维度** | 核心爽点+情绪钩子+差异化卖点 | 知识碾压+打脸反转+穿越者视角 |

### 冲突设计三角模型

所有核心冲突必须同时满足三个条件：

```
         身份反差
        /        \
       /          \
生死危机 ——————— 信息差
```

- **身份反差**：主角外表与真实能力/身份的巨大反差（如废物→隐藏天才）
- **生死危机**：有切实的物理威胁或利益损失（非口头威胁）
- **信息差**：主角知道/拥有的信息与其他人不对称（制造期待感）

三者缺一则冲突力度不足，缺二则冲突无效。

## 工作流与执行步骤

### 第一步：点子解析

分析用户输入的原始点子，提取：
- 核心题材类型（对照 skills/genre-adaptive-skill/SKILL.md「§1.2 题材索引表」判定主/副题材；30+ 题材速查见下）
- 核心冲突元素（使用冲突三角模型验证）
- 预期受众定位（下沉市场/年轻女性/男频用户）
- 差异化潜力（与同题材竞品的区别点）

> **题材速查索引（30+，四大集群 · 对接 genre-adaptive 题材索引表）**：
> - 都市情感：豪门总裁·甜宠日常·职场逆袭·婚姻情感·亲子教育·婆媳家斗·都市重生
> - 玄幻修真：修仙升级·异界大陆·都市修仙·洪荒神话·系统玄幻·御兽·武道
> - 悬疑推理：破案解谜·惊悚恐怖·心理犯罪·无限流·游戏副本
> - 历史文化：古代宫斗·穿越历史·武侠江湖·民国有约·神话传说·种田经商
> 🔴 已建深度模板 8 类（豪门/玄幻/系统/悬疑/甜宠/末世/职场/古代宫斗）见 genre-adaptive-skill/genre-templates/；其余题材就近套用最相近模板 + 差异化元素。最低核心爽点条数以 genre-adaptive 索引表为准（每题材 ≥3 条）。

```

{设定的时代/社会背景}

### 核心规则
- 规则1：
- 规则2：
- 规则3：

### 势力分布
- 势力A：
- 势力B：
- 势力C：
```

### 第三步：金手指/系统设计

```

### 限制与代价
{使用限制、副作用、成长限制}

```

```
### 竞品对标（🔴 必填·三字段缺一不可）
- 对标作品：[同题材近期热门作品名 +（播放量/完播率，如有）]
- 差异化一句：[本作与对标作品的核心区别，一句话说清]
- 受众：[下沉市场 / 年轻女性 / 男频用户 / 其他，明确主受众]

- 卡点2：
```

```
- 转折点：
- 终点：

### 金手指

```

#### 反派人设

```
## [idea][character][新增] {反派 名}

### 身份定位
```

### 第六步：故事卡生成

#### 主线故事卡

```
## 故事卡：{主标题}

### 核心冲突
{核心矛盾}

### 目标
{主角目标}

### 关键转折
```

#### 支线故事卡（可选）

```
## 故事卡：{支线标题}

### 作用
{丰富世界观/情感线/制造误会}

### 与主线关系
{如何关联}
```

### 第七步：集数规划

三段式比例分布（总集数 N 动态，按前/中/后约各 1/3 切分，**不写死 1-10 集**，与系统动态集数一致）：

```
## 集数规划（总集数 N，按比例三段动态切分）

### 蓄能期（前 ~1/3，第 1 ~ 第 ⌈N/3⌉ 集）
- 首集：[3秒钩子 + 建人设]
- 过渡集：[核心冲突引入]
- 段末集：[首次爽点 + 段尾卡点]

### 加压期（中 ~1/3，第 ⌈N/3⌉+1 ~ 第 ⌈2N/3⌉ 集）
- [冲突升级 / 新势力介入 / 情感线发展]
- 段末集：[重大危机 + 强卡点]

### 升级期（后 ~1/3，第 ⌈2N/3⌉+1 ~ 第 N 集）
- [真相大白 / 终极对决]
- 终集：[大卡点收尾，截断在最高潮前0.5秒]
```

> 注：N 由内容密度决定（与系统动态集数一致）；三段比例约 1/3 : 1/3 : 1/3，集号随 N 等比缩放，禁止固定为 10 集。

## 与集纲生成的接口

brainworm-generator 完成后，将以下信息传递给 short-drama-architect：
- 世界观设定 → 集纲世界观
- 核心梗 → 集纲核心卖点
- 人设卡片 → 集纲人物设定
- 故事卡 → 集纲剧情设计
- 集数规划 → 集纲情绪分布

## 质量标准

- 世界观完整度：≥90%
- 人设标签化：每人设≥3个视觉标签
- 核心梗吸引力：3秒钩子必须有视觉冲击
- 集数节奏：三段式分布合理
- 视觉化程度：无心理描写

## 诊断指南

Q: 点子太简单怎么办？
A: 自动扩展，加入"金手指+系统+冲突"三角模型

Q: 人设不够标签化怎么办？
A: 加入视觉特征标签（着装、口头禅、标志性动作）

Q: 冲突不够强怎么办？
A: 引入"身份反差"+"生死危机"+"信息差"三重冲突
