# 电影级角色提案板技能

[技能说明]
    本技能负责生成"影视/动画项目开发用·角色提案板"级别的角色设定图（Pitch Board）。
    提案板是给导演 / 美术指导 / 制片 / 投资方 / 制作组看的"对外提案与对内拍板"视觉物，
    采用横版大画幅 16:9 + 中性灰提案板背景 + 不对称美术指导构图 + 6 区块固定布局。

    核心定位：把角色定义转化为一张"导演能直接拍板、投资方能直接看懂"的电影感提案板。

    🔴 2026-05-31 角色标准统一：电影级角色提案板为 AXIS **唯一角色标准**，取代三栏式纯白工业资产。
    与 AXIS 现有视觉技能的职责划分：
    - art-design-skill：角色概念设计、核心记忆点定义、T0级 Prompt 工程（上游），唯一产出 = 本提案板（character-prompts.md）
    - costume-prop-character-design-skill：3D 建模交付模型表（Model Sheet）等工业化落地，基底取自本提案板
    - 本技能（cinematic-character-pitch-board-skill）：角色唯一标准资产 = 横版16:9 中性灰六区块提案板，既供导演/投资方拍板，也作为后续分镜/Seedance/Kling 引用的一致性基底

    一句话边界：
    - 提案板（本技能）= 角色唯一标准资产，给"人"拍板 + 给后续分镜/Seedance/Kling 引用同用
    - 三栏式纯白工业资产已彻底废除（模板删除、校验器不再接受三栏式）；存量三栏式文件需回炉重生成为提案板
    - 同一角色各区块（A主视觉/B转面/C头部/D情绪/E服装）共享同一基底人物，五官/比例/发型/服装/配饰/道具严格一致

    [Stage Gate 流程位序 + 五问法口径 · 2026-05-31 更新]
    - 🔴 所有角色统一出电影级角色提案板（取代三栏式工业资产）→ 导演/美术指导拍板确认 → 通过后据其基底人物进入后续分镜/建模；提案板即唯一角色资产，不再另出三栏式工业资产。

[核心设计原则]

    六大全局视觉铁律（写入提示词时不得删减）：

    1. 一致性铁律 (Consistency First)
       - A/B/C/D 中所有角色视图必须为同一人
       - 五官比例、发型轮廓、皮肤色温、身材比例、服装款式、配饰位置、道具持握方式严格一致
       - 禁止任何角度的脸型偏移、年龄漂移、服装替换、配饰漂移
       - 同一角色各区块（A/B/C/D）必须共享同一基底人物（如有存量三栏式资产一并对齐）

    2. 真实材质铁律 (Real Material)
       - 皮肤须 PBR 物理材质（SSS 次表面散射 + 鼻梁下唇柔和高光 + 关节偷暖粉红）
       - 布料须 fabric fibers / weave / wrinkle 三重细节
       - 金属须真实反射但避免过亮高光；皮革须哑光颗粒纹 + 缝线细节
       - 🔴 影视级渲染必加（2026-05-31 新增·所有角色提案板含基础形象与变体均不得省略）：影视级游戏CG / 次世代3A质感 / 超写实PBR材质渲染 / 4K极致细节 / 柔光电影打光（低强度轮廓光勾边 + 发丝光透发 + 柔光镜柔化）/ 浅景深小景深焦外柔化

    3. 演员气质铁律 (Actor Presence)
       - 角色像"真实演员被镜头捕捉的瞬间"，不是平面摆拍模特
       - 微表情、肌肉张力、呼吸感、重心、肩颈姿态都要带真实人感

    4. 电影感铁律 (Cinematic Tone)
       - 色调克制、对比适中、留呼吸空间
       - 禁止高饱和网红美学、偶像化糖果美学、塑料蜡像感、冷白假人脸

    5. 画面洁净铁律 (Clean Frame)
       - 禁止文字水印 logo（标注层除外）、镜头 flare、散景光斑、漂浮粒子、噪点、胶片颗粒、随机微高光

    6. 职业版面铁律 (Pro Layout)
       - 所有标注（角色名/身高刻度/性格关键词/材质备注）清晰可读但不喧宾夺主
       - 字体锁定统一：印刷标注一律 Inter（西文/数字）+ 思源黑体 Source Han Sans（中文），手写手记一律 Caveat，严禁混入第三种字体

[执行流程]

    阶段0（步骤0）：视觉美学意图声明（五问法 · 强制前置）
        - 🔴 加载 skills/aesthetic-vision-skill/SKILL.md，完成五问法 Q1-Q5
        - 🔴 字段口径与 aesthetic-vision-skill §二·A「角色设计版」逐项对齐：Q1 目标情绪词 / Q2 视觉意象来源 / Q3 形状语言 / Q4 配色情绪声明 / Q5 世界观视觉位置
        - Q1 情绪词必须是具体情绪词（如「克制×隐忍×疲惫温柔」），禁止通用词（如「酷×帅×美」）
        - 🔴 落位口径（单一权威见 aesthetic-vision-skill §二）：五问法只写在「📐 视觉美学意图声明」人读 / 元数据区，禁止混入【中文描述段】/【English description block】生图正文
        - Q1-Q5 全部回答后方可进入第一步；本声明将被 review-skill 第7维度逆向溯源审核

    第一步：基底人物对齐
        - 读取上游 art-design-skill / costume-prop-character-design-skill 的角色定义
        - 若该角色已有既有资产（assets/prompts/character-prompts.md，含存量三栏式），必须以其为基底
        - 锁定核心字段：脸型 / 眼型 / 发型 / 肤色（HSB+HEX）/ 身高 / 体型 / 头身比 / 服装 / 配饰 / 道具 / 核心记忆点
        - 🔴 加载 skills/compliance-review-skill/SKILL.md 确认合规标准

    第二步：填写角色信息卡（输入区）
        - 按模板 templates/pitch-board-output-template.md 的角色信息卡 YAML 填满所有字段
        - HSB 色板 ≥4 色（每色含 H/S/B 与 #HEX）
        - 配饰/材质微距清单 4-6 件（作为 E 区块输入）

    第三步：6 区块固定版面设计（三列·双主块·三梯队）
        | 梯队 | 区块 | 位置/比例 | 内容 |
        |------|------|-----------|------|
        | — | 顶部细条 | 100% × 6% | 角色名 · 年龄 · 身高 · 风格方向 · 性格关键词 |
        | ① 主 | A 主视觉全身立像 | 左列·全高 24% × 94% | 85mm 全身立像 + 紧贴左缘金色身高刻度尺（双主块之一·竖向贯通全高） |
        | ① 主 | B 全身五视图 | 右列·上 48% × 54% | 正/3·4正侧/纯侧/3·4背/背，画面最大主块·双主块之一，底线 ±2-4% 错位 |
        | ② 参考 | D 情绪肖像 | 中列·上 28% × 50% | 50mm 中近景，中列上半，定情绪脸 |
        | ② 参考 | C 头部六视图 | 中列·下 28% × 44% | 正/3·4正侧/纯侧/低头/抬头/动态扭头（放大 1.15× 偏出网格） |
        | ③ 辅助 | F 美术备注与色板 | 右列·中横条 48% × 20% | HSB 色板（≥4色含HEX）+ 性格关键词 + 风格定位，堆叠于 B 之下 |
        | ③ 辅助 | E 服装配件拆解 | 右列·下横条 48% × 20% | 4-6 张 100mm 微距，每张 ±3° 旋转拍立得感，堆叠于 B 之下 |
        - 第一梯队 = A 全身立像（左列全高）+ B 全身五视图（右上最大主块），一竖一阔、分量最重，严禁把 B 压成扁条或把 A 截短；区块内部仅允许 ±2-5% 微错位，不得改占比与梯队

    第四步：背景与光源统一规格
        - 背景：中性灰提案板（#BEC1C4 至 #C7CACD 渐变 + 极轻微亚麻布纹/纸面纹理，无纯白无纯黑）
        - 光源：高调摄影棚柔光 5500-6000K 主光从右上 45° + 左侧低强度冷色补光，光比 2:1 至 3:1
        - A/B/C/D 四视觉区块共享同一光源方向与色温

    第五步：中英文提示词生成（T0标准）
        - 中文描述段：供 Nano Banana Pro / 即梦 直喂
        - 英文描述段：供 Midjourney v6 / Flux Pro 使用
        - 两段都必须完整覆盖 6 区块 + 全局风格前缀 + 画面洁净负面约束
        - 使用 tools/validators/pitch-board-validator.py 校验

    第六步：质量自检
        - 6 区块是否齐全？身高刻度尺是否存在？
        - 五官/比例/发型/服装/配饰在 A/B/C/D 是否一致？
        - HSB 色板是否 ≥4 色且含 HEX？
        - 背景是否为中性灰（非纯白/纯黑）？无场景元素？
        - 是否通过 pitch-board-validator.py 校验？

    第七步：Stage Gate（提案板审核门禁 · 强制）
        - 🔴 提案板必须经本技能配对审核 PASS + 导演 / 美术指导拍板确认后，方可据其基底人物进入后续 3D 建模 / 分镜 / Seedance·Kling 引用
        - 🔴 提案板未确认即进入下游 = 流程位序违规，下游产出作废重来
        - 确认放行后：提案板各区块与下游引用共享同一基底人物（五官/比例/发型/服装/配饰严格一致），由 pitch-board-review × art-direction-review 核对

[PASS/FAIL 标准]

    PASS 条件（必须全部满足）：
    - 6 区块齐全（顶部细条 / A / B / C / D / E / F）
    - A 区含身高刻度尺；B 区五视图齐全；C 区六视图齐全
    - HSB 色板 ≥4 色且含 HEX
    - 背景为中性灰（非纯白/纯黑），无场景元素
    - 中英文双段齐全
    - 五问法（阶段0）已完成且 Q1 为具体情绪词
    - 通过 pitch-board-validator.py 校验
    - 产出三维质量标准各项 ≥ 95分

    FAIL 条件（任一满足）：
    - 缺失任一版面区块（顶部细条/A/B/C/D/E/F）
    - 背景为纯白/纯黑或出现场景元素（卧室/办公室/医院等）
    - 五官/比例/发型/服装在 A/B/C/D 出现漂移
    - HSB 色板缺失或无 HEX
    - 五问法未完成 OR Q1 为通用词 OR 五问法混入中英文生图描述段正文
    - pitch-board-validator.py 未通过
    - 产出三维质量标准任一维度 < 95分

    📌 对照样例（各 1 句指引）：
    - ✅ PASS 样例：6 区块齐全、A 区有金色身高刻度尺、五问法写在「📐 视觉美学意图声明」人读区且 Q1=「克制×隐忍×疲惫温柔」、中英双段为纯画面描述且 A/B/C/D 同一人 → 三维各项 ≥95，放行进入第七步 Stage Gate。
    - ❌ FAIL 样例：背景出现卧室场景 + Q1 写「帅×酷×美」通用词 + 五问法被抄进 English description block 正文 → 同时命中「背景非中性灰 / Q1 通用词 / 五问混入生图段」三条，直接 FAIL 退回重做。

[产出三维质量标准]

    版面完整性评分（0-100分）：
    □ 6 区块是否齐全（顶部细条/A/B/C/D/E/F）？（0-33分）
    □ 身高刻度尺 + 五视图 + 头部六视图是否齐全？（0-33分）
    □ HSB 色板（≥4色含HEX）+ 材质微距（4-6件）是否齐全？（0-34分）

    一致性评分（0-100分）：
    □ 五官/眼型/发型在 A/B/C/D 是否一致？（0-33分）
    □ 服装/配饰/道具在 A/B 是否一致？（0-33分）
    □ 跨视图（A/B/C/D）基底是否一致？（如有存量资产一并对照）（0-34分）

    电影感与美术气质评分（0-100分）：
    □ 中性灰背景规格 + 统一光源是否达标？（0-33分）
    □ 不对称美术构图（非机械网格）+ 演员气质是否达标？（0-33分）

    通过标准（A+级视觉设计，参考 skills/templates/quality-threshold-standard.md v1.2）：各项 ≥ 95分
