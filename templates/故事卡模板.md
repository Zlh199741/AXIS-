# 故事卡模板

## 主线故事卡

```markdown
## 故事卡：[标题]

### 卡片ID
SC-001

### 类型
主线/支线

### 核心冲突
{一句话概括核心矛盾}

### 目标
- 主角目标：{主角想要达成什么}
- 主角困境：{主角面临什么阻碍}

### 障碍
- 内部障碍：{主角自身的问题/缺点}
- 外部障碍：{来自反派/环境的阻碍}
- 信息障碍：{主角不知道的关键信息}

### 关键转折点
1. 转折1：{事件描述}
2. 转折2：{事件描述}
3. 转折3：{事件描述}

### 爽点设计
- 预期爽点：{读者期待看到什么}
- 实际爽点：{如何超越预期}

### 卡点设计
- 卡点位置：{在哪一集}
- 卡点类型：悬念型/危机型/反转型
- 卡点描述：{截断在最高潮前0.5秒}

### 相关人物
- 主角：{角色名}
- 对手：{角色名}
- 参与者：{角色名}
```

## 支线故事卡

```markdown
## 故事卡：[标题]

### 卡片ID
SC-002

### 类型
支线

### 功能
丰富世界观/情感线/制造误会/提供助力

### 目的
{为什么需要这条支线}

### 与主线关系
{如何与主线交织}

### 关键节点
1. 节点1：{事件描述}
2. 节点2：{事件描述}

### 结局
{支线如何收束}
```
