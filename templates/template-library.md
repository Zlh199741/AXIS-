### 1.7 电影级角色提案板模板（Pitch Board）

> 用途：角色设定图唯一标准（2026-05-31 起取代三栏式工业资产）——横版大画幅 16:9 + 中性灰背景 + 6 区块固定布局，供导演/美术指导/制片/投资方与文生图同用。三栏式已删除、校验器不再接受三栏式；存量三栏式文件需回炉重生成为提案板。
> 权威模板（带占位符·可直接复制填空）：`skills/cinematic-character-pitch-board-skill/templates/pitch-board-output-template.md`
> 落地范例（4 角色 + 3 变体）：`不敢麻烦别人_动画改编/character-prompts-pitch-board.md`

```markdown
# 电影级角色提案板 - {项目名}

## 角色：{角色名}

### 📐 视觉美学意图声明（五问法 · 强制前置）
- Q1 情绪词（必须具体）：{情绪词×3}
- Q2 媒介 / Q3 形状语言 / Q4 配色情绪 / Q5 世界观位置

### 角色信息卡（YAML：年龄/身高/体型/风格方向/性格关键词/外貌/服装/场景气质）

### HSB 色板（≥4 色，每色含 H/S/B + #HEX）

### 配饰/材质微距清单（4-6 件）

### 【中文描述段】（Nano Banana Pro 直喂版）
顶部细条 + 区块A主视觉立像(+身高刻度尺) + 区块B五视图 + 区块C头部六视图 + 区块D情绪肖像 + 区块E服装拆解 + 区块F色板 + 统一光源 + 画面洁净负面约束

### 【English description block】
Top band + Zone A/B/C/D/E/F + unified lighting + clean-frame negatives

### 【画面洁净负面约束】

### T0 自检清单（版面完整性 / 一致性 / 材质 / 背景与画面洁净 / 美术指导气质）
```

> 校验：`python3 tools/validators/pitch-board-validator.py --file <提案板文件>`（软失败：文件不存在时 SKIP，不阻塞门禁）

## 二、模板使用指南

### 2.1 选择正确的模板

| 场景 | 使用模板 |
|------|----------|
| 导演分析输出 | 导演讲戏模板（增强版） |
| Seedance分镜 | 分镜脚本模板（Seedance） |
| Kling分镜 | 分镜脚本模板（Kling 3.0） |
| 审核报告 | 审核报告模板 |
| 周报 | 项目周报模板 |
| 交付 | 客户交付模板 |
| 角色对外提案板 | 电影级角色提案板模板（Pitch Board） |

### 2.2 模板定制

如有需要，可以在 `templates/custom/` 目录下创建自定义模板。
