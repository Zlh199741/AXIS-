# AXIS 三维质量标准通过阈值规范

> 版本: 1.2
> 创建日期: 2026-03-18
> 更新日期: 2026-05-30
> 说明: 各技能的三维质量标准通过阈值应根据技能特性差异化设定。v1.1: 视觉设计类统一提升至≥95分，审核类提升至≥95分以匹配实际执行标准。v1.2: 新增「生成自检线 vs 审核交付线」单一裁决规则，消除生成端92与审核端95被误读为双标、以及加权分/X制与三维评分冲突导致的"能生成必FAIL"循环

## 阈值分级标准

| 等级 | 阈值 | 适用技能类型 | 理由 |
|------|:----:|-------------|------|
| **S级（安全红线）** | **≥98分** | compliance-review-skill | 合规审核容错率极低，涉及法律/平台封禁风险 |
| **A+级（视觉设计）** | **≥95分** | 视觉设计类技能（服化道/道具/场景概念设计） | 视觉资产直接交付3D建模组，零偏差标准 |
| **A级（核心生产）** | **≥92分** | 生产类技能（分镜/导演/剧本/集纲） | 核心产出允许小幅优化空间，但整体质量必须达标 |
| **B级（辅助增强）** | **≥90分** | 辅助类技能（题材适配/故事卡/时长预测/双螺旋） | 辅助工具允许更多灵活度 |
| **C级（审核类）** | **≥95分** | 审核类技能的三维评分通过标准 | 审核是质量最后防线，三维评分必须与生产标准对齐 |

## 🔴 生成自检线 vs 审核交付线（消除「92↔95 双标」与「能生成必FAIL」循环）

> 2026-05-30 新增 v1.2：解决生成端（A级≥92）与配对审核端（C级≥95）长期被读成"互相打架"的问题。

- **生成类技能（A级）的「通过标准」分两条**：
  - ① **生成自检最低线 ≥92**：生成阶段自查达 92 即可进入审核，不阻断流程；
  - ② **交付/审核线 ≥95**：要通过配对 `*-review-skill` 与最终交付门禁，必须达到 ≥95。
  - 含义：**生成技能应以 ≥95 为实际目标**；92–94 = "可进入审核但需优化"，不视为冲突。
- **其它量纲技能的单一裁决**：脑洞用"加权总分"、时长预测用"110 制/70+加分"等内部分级**仅用于技能内部排序**；最终 PASS 一律以**三维评分对照本表等级**为唯一裁决（脑洞按核心生产 A 级；时长按辅助 B 级；其三维审核线仍为 C 级 ≥95）。
- **冲突即裁决规则**：任何"综合分 / 加权分 / X 制分"与"三维评分"结论不一致时，**以三维评分对照本表为准**，其余分数仅作参考。
- **桥接/结构类**（story-card-bridge / 双螺旋 / 结构诊断）：生成自检按 B 级 ≥90，配对审核三维按 C 级 ≥95；生成端的"戏剧节点/纠葛≥5/McKee 五节点"等硬性字段以配对 review 的强制项为准（生成端必须满足 review 的硬性项，避免系统性 FAIL）。

## 使用说明

各技能SKILL.md中的"通过标准"应引用本文件对应的阈值，而非硬编码≥95分。
格式示例：
```
通过标准：参考 skills/templates/quality-threshold-standard.md
- [维度1] ≥ [对应阈值]分
- [维度2] ≥ [对应阈值]分
```
