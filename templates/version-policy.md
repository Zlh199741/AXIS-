# AXIS 技能版本管理策略

> 创建日期: 2026-03-18

## 版本号规则

- 版本号反映**技能自身的迭代历史**，不要求全部统一
- 格式：`X.Y [描述]`，如 `3.0 全维度增强版`
- X = 大版本（结构性变更），Y = 小版本（内容增补）

## 当前版本分布

| 版本范围 | 技能数量 | 说明 |
|---------|:--------:|------|
| 1.0 | 1个 | 新建技能（costume-prop-character-design-review-skill） |
| 2.0 | 11个 | 第二批增强的审核技能 |
| 3.0 | 18个 | 全维度增强版（主力版本） |
| 4.0 | 1个 | art-design-skill（交叉自检融合版） |
| 5.0 | 2个 | compliance-review-skill、director-skill |
| 6.0 | 1个 | art-direction-review-skill |

## 版本升级时机

- **+0.1**：修复bug、调整阈值、术语修正
- **+1.0**：新增模块（如新增诊断指南/术语表/三维质量标准）
- 升级时必须在[版本信息]中注明更新内容和日期
