# AXIS 跨技能引用格式规范

> 版本: 1.0
> 创建日期: 2026-03-18
> 说明: 统一所有SKILL.md中的跨技能引用术语和格式

---

## 引用级别定义

| 级别 | 标准术语 | 含义 | 执行要求 |
|------|---------|------|---------|
| 🔴 **必须引用** | `必须引用` | 执行本技能前**必须**加载的外部资源 | 缺失即报错，不可跳过 |
| 🟡 **建议引用** | `建议引用` | 推荐加载以提升产出质量，但可跳过 | 有则更好，无则不阻塞 |
| ⚪ **可选引用** | `可选引用` | 特定场景下才需要的补充资源 | 仅在特定条件触发时加载 |

## 废弃术语映射表

以下术语已废弃，遇到时应替换为标准术语：

| 废弃术语 | 替换为 |
|---------|--------|
| `必须同步引用` | `必须引用` |
| `必须参考` | `必须引用` |
| `必须参考资源` | `必须引用` |
| `必调` | `必须引用`（放在上游技能列表中标注🔴） |
| `建议必调` | `建议引用`（放在上游技能列表中标注🟡） |
| `可选调用` | `可选引用` |
| `可选参考` | `可选引用` |

## 标准格式（[跨技能集成声明]区段）

```markdown
[跨技能集成声明]

    调用方 Agent：
    - agents/xxx.md：描述

    上游技能：
    - skills/xxx/SKILL.md：🔴 必须，描述
    - skills/yyy/SKILL.md：🟡 建议，描述
    - skills/zzz/SKILL.md：⚪ 可选，描述

    下游技能：
    - skills/xxx/SKILL.md：描述

    配对审核技能：
    - skills/xxx-review-skill/SKILL.md：描述

    必须引用：
    - skills/compliance-review-skill/SKILL.md：合规标准
    - tools/references/sensitive-word-dictionary.md：敏感词库
    - [其他必须资源]

    建议引用：
    - [建议但非必须的资源]

    可选引用：
    - [特定场景才需要的资源]
```

## 与[技能说明]中引用的关系

- `[技能说明]`中的"本技能必须参考"列表 = `[跨技能集成声明]`中"必须引用"列表的**子集或等同**
- 如果两处列表不同，以`[跨技能集成声明]`为准（更完整）
- 建议：`[技能说明]`中仅列出最关键的3-5个引用，完整列表放在`[跨技能集成声明]`中
