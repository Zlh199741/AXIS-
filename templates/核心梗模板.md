# 核心梗模板

## 核心梗基础信息

```markdown
## 核心梗：[标题]

### 类型
{豪门总裁/都市重生/玄幻修仙/系统流/甜宠/虐恋/职场/悬疑...}

### 一句话卖点
{一句话概括最核心的吸引力}

### 受众定位
- 主要受众：{下沉市场/年轻女性/职场人群/...}
- 年龄段：{18-25/25-35/35-45...}
- 爽点类型：{打脸/逆袭/甜/虐/爽}
```

## 核心卖点设计

```markdown
### 核心卖点

1. **卖点1**：{描述}
   - 视觉化呈现：{如何用画面表现}
   - 情绪触发点：{观众心理共鸣}

2. **卖点2**：{描述}
   - 视觉化呈现：{如何用画面表现}
   - 情绪触发点：{观众心理共鸣}

3. **卖点3**：{描述}
   - 视觉化呈现：{如何用画面表现}
   - 情绪触发点：{观众心理共鸣}
```

## 情绪钩子设计

```markdown
### 黄金3秒钩子

- 画面要求：{极致视觉奇观/肢体冲突/反常态画面}
- 具体描述：{开篇画面}
- 音效要求：{配合的音效}

### 前10秒叙事

- 人物关系：{快速展示}
- 核心矛盾：{冲突呈现}
- 站位展示：{对立关系}

### 1分钟爽点

- 爽点类型：{打脸/逆袭反转/武力镇压}
- 关键动作：{肢体动作描述}
- 情绪释放：{观众情绪峰值}
```

## 卡点设计

```markdown
### 阶段性卡点（第1至N-1集）

- 第1集卡点：{悬念设计}
- 第2集卡点：{悬念设计}
- ...
- 第N-1集卡点：{悬念设计}

### 跨章钩子（本章最后一集 — 性质：拖进下一章）

- 卡点类型：物理威胁+道德困境（答案留到下一章）
- 画面设计：{截断在最高潮前0.5秒}
- 期待感：{如何逼迫观众看下一章}
- 严禁：任何形式的章内情感闭合
```
