# 《我不是没事，我是不敢有事》AXIS场景提示词｜极致写实CG

**来源剧本**：`不敢麻烦别人_动画改编/我不是没事我是不敢有事_专业动画剧本.md`

**设计类型**：服化道设计 / 场景资产 / 场景叙事模板 v3.0 + v3.0.1 推荐字段

**用户确认风格**：极致写实CG

**全局场景风格前缀原则**：场景只写环境、空间、材质、光影、镜头，不写人物外貌、角色服装、人体比例；所有场景默认纯环境，绝对无人物。

**全局电影级氛围升级基线（2026-05-30 · 解决"八场景发闷、低饱和雷同"）**：在保留各场景既有焦段/构图/叙事动机/核心主体不变的前提下，统一注入电影感——
- ① 动机光分层：每场景以一盏可见 practical 实用光源（餐厅吊灯/电梯灯条/电脑屏幕/冷蓝月光/门缝光/床头灯）为光源逻辑核心，主光—辅光—轮廓光三层分明，明暗有层次而非均匀洗白。
- ② 中高反差电影光比：由"低反差克制"提到"中高反差"，亮部干净、暗部保留细节与色彩，体积感强。
- ③ 大气介质（物理成立处）：极淡空气介质——窗光丁达尔、晨昏尘光、夜里极淡雾感、暖灯光晕，给纵深与呼吸（克制、不满屏粒子）。
- ④ 色彩对位记忆点：每场景一个"冷里透暖 / 暖里压冷 / 一抹失衡色"的色彩对位钩子，让八场景彼此区分。
- ⑤ 电影质感：轻微各向异性高光、柔和光学边缘、真实景深焦外柔化，靠近电影摄影机成像，而非平板游戏CG。
- 🔴 不破坏：人物绝对无、核心主体不变、画面洁净负面约束仍生效。

**全局景别节奏升级（2026-05-30 · 解决"全是中景、景别单一"）**：每个场景出**一套三景别**而非单张——
- ① **定场镜**（wide establishing）：更广焦段交代空间情绪——压抑/孤立/被困场用 **14–20mm 大广角**拉压迫与渺小；治愈/温暖场用 **24–35mm 柔和全景**。
- ② **主景**：现有中景/中全景，交代空间布局（保留）。
- ③ **细节特写空镜**：**85–100mm**，给每个场景一个氛围记忆点物件（错菜盘/咖啡痕/键盘删除键/冷水杯/门缝光/温水杯等）。
- 焦段按场景情绪分配，不再千篇一律 35mm；三张共享同一空间/光源/色温/材质，仅景别与焦段不同；竖屏 9:16 构图。
