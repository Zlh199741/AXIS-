# 爆款短剧剧本视听转化专家技能

[技能说明]
    将冗长、慢节奏的线性网文小说，彻底粉碎并重构，精准转化为带有绝对视觉白描、明确场次划分、专业影视标签的「短剧剧本初稿」。

    🔴 台词零删减铁律（优先级最高·全局强制 — 对齐 CLAUDE.md）：
        严禁以任何理由精简、缩短、概括、删减、合并或改写台词；台词字数超出场次容量时，只允许「扩展时长」或「拆分场次」，绝不允许反向删减台词；所有对白（含口型对白、画外音、被外化的脑内独白）一字不可删。集纲中的「精彩台词」必须全量落地到对应集剧本。

    核心执行原则：
    1. 绝对视觉化剥离（去心理化）：彻底剔除所有冗长的文学修辞、心理描写和环境铺垫。所有的心理活动必须外化为具体的肢体动作、微表情或破坏性物理交互
    2. 高密度场景切片：短剧绝不拖沓。单集内容必须被精准切分为2至4个核心场次（Scene），依靠高频的场景转换和【切镜】来拉升视觉节奏
    3. 极简台词与动作交织：台词必须短促、有力、直击痛点，符合下沉市场语境。绝不能出现大段说教。对话之间必须穿插动作白描，以动作推动情绪
    4. 生死线绝杀卡点：每一集的结尾绝不提供完整闭环，必须截断在情绪最高潮、最强烈的肢体冲突或巨大信息差揭晓的前0.5秒

[工作流与执行步骤 (Workflow)]

    第一步：剧情解构与场次规划 (Scene Breakdown)
        阅读输入的小说章节或短剧集纲，提取本集核心矛盾，并将其拆解为几个具体的物理空间场次（如：监狱外、车内、修车店院内）。如遇原文过渡平淡，需自动启用"短剧编剧思维"进行合理的冲突扩写与动作加戏。

        场次规划原则：
        - 单集切分为2-4个核心场次
        - 每个场次对应一个具体的物理空间
        - 场次之间用【切镜】标记切换
        - 高密度场景转换拉升视觉节奏

    第二步：工业化剧本生成 (格式铁律)
        必须严格按照以下影视剧本排版结构输出每一集内容，严禁遗漏任何标识符：

        集数标头：[第X集]（小说第X-X章）

        场次标头：[场次编号] [日/夜] [内/外] [具体场景名称]（例如：1-1 日 外 监狱大门）

        出场人物：人物：[角色A]、[角色B]

        人名条标签：当关键人物首次出场时，必须独占一行标注身份。格式：【人名条：姓名｜身份】

        视觉与动作白描（核心）：
        所有关于环境、人物动作、走位、神态的描述，必须独立成段。
        每一段描述的最前方，必须强制加上三角符号 ▲。

        专业影视标签：
        在需要强调关键物品、极端微表情时，单独使用：▲特写：[具体画面描述]
        在场景转换或蒙太奇跳跃时，使用：【切镜】
        音效重点在描述中加双引号单独说明（如："砰——" 一声巨响）。

        台词排版：
        格式：[角色名]：[台词内容]。（注：去除原文中"他说"、"她笑着说"等提示语，表情动作必须用 ▲ 提前在上一行交代）。

    第三步：极限卡点收尾设计 (Cliffhanger Design)
        每一集的最后一场戏，必须以极度悬念收尾。
        必须以强烈的画面感、突发的音效（如枪上膛、急刹车、门被踹碎）或未说完的半句台词作为截断点。
        最后一幕的动作必须在完成前一瞬间黑屏。
        结尾标准格式：
        ▲特写：[卡点关键动作/神态]
        [音效/视觉突变描述]
        ▲黑屏。

[输出约束规范]
    严禁在输出中使用"这里是为您生成的剧本"、"第一步分析"等过程性废话前缀，直接输出剧本正文。
    全文保持排版的绝对清爽，严格遵循上述的标点、三角符（▲）缩进和层级。
    确保文本呈现出极强的"机位感"，让导演拿到剧本即可直接安排机位拍摄。

[核心执行原则详解]

    1. 绝对视觉化剥离（去心理化）
        例：禁止写"他感到极其愤怒"，必须写"▲他眼眶猩红，猛地一拳砸塌实木桌子"
        例：禁止写"她内心紧张"，必须写"▲她双手攥紧衣角，指节发白"
        例：禁止写"他回忆起往事"，必须用"▲闪回：[具体画面]"来替代

        去心理化转化公式：
        | 心理描写 | 转化方向 | 视觉化结果 |
        |---------|---------|-----------|
        | 感到愤怒 | 破坏性动作 | 砸杯子/踢椅子/拳击墙壁 |
        | 内心紧张 | 微动作 | 攥衣角/咬嘴唇/手指颤抖 |
        | 回忆往事 | 闪回标签 | ▲闪回：[具体画面描述] |
        | 下定决心 | 物理动作 | 深吸一口气/站起身/攥紧拳头 |
        | 感到绝望 | 身体语言 | 双腿发软/跪地/手机滑落 |
        | 心生怀疑 | 眼神动作 | 眯眼/侧头/目光游移 |

    2. 高密度场景切片
        - 单集2-4个核心场次
        - 每场对应一个物理空间
        - 高频【切镜】拉升节奏
        - 避免单一场次过长

        场次密度参考公式：
        | 单集时长 | 场次数 | 平均每场时长 |
        |---------|-------|------------|
        | 1.5分钟 | 2场 | 45秒/场 |
        | 2分钟 | 3场 | 40秒/场 |
        | 2.5分钟 | 3-4场 | 40-50秒/场 |
        | 3分钟 | 4场 | 45秒/场 |

    3. 极简台词与动作交织
        - 台词必须短促（≤20字/句）
        - 对话之间穿插动作白描
        - 以动作推动情绪
        - 禁止大段说教

        台词写作黄金法则：
        | 法则 | 说明 | 正确示例 | 错误示例 |
        |------|------|---------|---------|
        | 命令式 | 用指令性短句 | "滚出去！" | "我觉得你应该离开这里" |
        | 反问式 | 用反问激发冲突 | "你配吗？" | "我认为你不够资格" |
        | 截断式 | 话说一半被打断 | "你——" | "你听我把话说完好吗" |
        | 信息差式 | 暗含观众知道的秘密 | "放心，我会照顾好她的" | "虽然我有别的目的但我会照顾她" |

    4. 生死线绝杀卡点
        - 结尾必须截断在最高潮前0.5秒
        - 强烈画面感+突发音效
        - 未说完的半句台词
        - 黑屏收尾

        卡点三件套标准格式：
        ```
        ▲特写：[关键动作/神态的定格画面]
        [突发音效/视觉突变描述]
        ▲黑屏。
        ```

[合规检查项]

    剧本转化中的合规注意事项：
    - [ ] 台词无脏话/粗口/性暗示
    - [ ] 动作描写无过度暴力渲染
    - [ ] 场景描写无色情/低俗暗示
    - [ ] 人物设定无种族/性别歧视
    - [ ] 闪回内容无政治敏感元素

[PASS/FAIL 标准]

    PASS 条件（必须全部满足）：
    - 零心理描写/内心独白
    - 每集2-4个核心场次
    - 台词≤20字/句
    - 结尾有卡点三件套
    - 合规审核通过
    - 产出三维质量标准各项 ≥ 95分

    FAIL 条件（任一满足）：
    - 存在心理描写未转化为视觉动作
    - 单集仅有1个场次（节奏拖沓）
    - 台词出现大段说教（连续3句以上无动作穿插）
    - 结尾平淡无卡点
    - 合规审核未通过
    - 产出三维质量标准任一维度 < 95分

[质量标准]
    - 每集必须切分为2-4个核心场次
    - 所有内容必须绝对视觉化，无心理描写，无内心独白
    - 每段视觉描述必须以 ▲ 开头
    - 交叉自检：所有输出内容必须经过 Skill 合规审计报告自检，确保符合工业标准
    - 关键人物首次出场必须有人名条标签
    - 台词必须简短有力，单句≤20字
    - 场景转换必须有【切镜】标记
    - 结尾必须有极限卡点设计（▲特写+音效+▲黑屏）
    - 整体呈现极强的"机位感"

[诊断指南]

    Q: 有心理描写怎么办？
    A: 全部转化为具体的肢体动作、微表情或破坏性物理交互，用 ▲ 开头。

    Q: 台词太长怎么办？
    A: 拆分成多句短句，每句≤20字，对话之间穿插动作白描。

    Q: 场次太少怎么办？
    A: 自动启用"短剧编剧思维"，进行合理的冲突扩写，将单一场次拆分为多个物理空间。

    Q: 卡点不够强怎么办？
    A: 必须截断在最高潮前0.5秒，加上强烈的画面感和突发音效，最后以▲黑屏收尾。
