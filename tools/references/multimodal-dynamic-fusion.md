# 多模态动态融合系统

## 用途

扩展素材引用类型，支持动态视频参考提取、音频驱动视觉，实现更精准的动态效果生成。

---

## 一、素材类型扩展

### 1.1 现有类型（保留）

| 类型 | 语法 | 用途 |
|------|------|------|
| 静态图片 | @图片N | 角色形象、场景参考 |
| 视频参考 | @视频N | 整体动作参考 |

### 1.2 新增动态参考类型

#### 动态提取参考

| 类型 | 语法 | 用途 |
|------|------|------|
| 运镜提取 | @视频N[运镜] | 提取视频的镜头运动模式 |
| 速度提取 | @视频N[速度] | 提取运动速度曲线 |
| 时间伸缩 | @视频N[时间] | 提取时间伸缩效果 |

#### 部位提取参考

| 类型 | 语法 | 用途 |
|------|------|------|
| 前景提取 | @视频N[前景] | 提取视频前景元素 |
| 背景提取 | @视频N[背景] | 提取视频背景 |
| 主体提取 | @视频N[主体] | 提取主体动态 |

#### 音频驱动参考

| 类型 | 语法 | 用途 |
|------|------|------|
| BPM提取 | @音频N[BPM] | 提取节拍 |
| 频谱分析 | @音频N[频谱] | 提取频谱特征 |
| 情感曲线 | @音频N[情感] | 提取情感曲线 |

## 三、动态效果参数映射

### 3.1 视频动态 → 参数映射表

| 动态参考类型 | 提取参数 | Seedance映射 | Kling映射 |
|--------------|----------|--------------|-----------|
| @视频[运镜] | 方向、速度、加速度 | Dolly/Track参数 | 镜头运动描述 |
| @视频[速度] | Vmax、Vavg、曲线 | 运动模糊强度 | 时间伸缩 |
| @视频[前景] | blur、遮挡物 | 前景擦除 | 虚化前景 |
| @视频[背景] | 虚化程度、色调 | 背景氛围 | 场景融合 |
| @视频[主体] | 动态模糊、轮廓 | 主体清晰度 | 主体绑定 |

### 3.2 音频驱动 → 视觉映射表

| 音频参考类型 | 提取参数 | 视觉映射 |
|--------------|----------|----------|
| @音频[BPM] | 节拍点、时间戳 | 镜头切换点 |
| @音频[频谱] | 低/中/高频能量 | 色调/光效强度 |
| @音频[情感] | 情绪曲线 | 运镜节奏/景别 |

### 3.3 参数提取规则

```python
class DynamicReferenceExtractor:
    """动态参考提取器"""
    
    # 视频参数提取
    VIDEO_PARAMS = {
        "运镜": ["方向", "速度", "加速度", "轨迹"],
        "速度": ["Vmax", "Vavg", "峰值", "曲线类型"],
        "前景": ["模糊度", "遮挡物", "透明度"],
        "背景": ["虚化", "色调", "氛围"],
        "主体": ["轮廓", "动态模糊", "清晰度"]
    }
    
    # 音频参数提取
    AUDIO_PARAMS = {
        "BPM": ["节拍", "段落", "重拍"],
        "频谱": ["低频能量", "中频能量", "高频能量"],
        "情感": ["曲线", "强度", "变化率"]
    }
    
    def extract_video_params(self, video_ref: str) -> dict:
        """提取视频动态参数"""
        # 格式：@视频N[运镜]
        import re
        match = re.match(r'@视频(\d+)\[(\w+)\]', video_ref)
        
        if match:
            video_id = match.group(1)
            param_type = match.group(2)
            
            return {
                "video_id": video_id,
                "type": param_type,
                "params": self.VIDEO_PARAMS.get(param_type, [])
            }
        
        return {}
    
    def extract_audio_params(self, audio_ref: str) -> dict:
        """提取音频驱动参数"""
        # 格式：@音频N[BPM] 或 @音频N[情感]
        import re
        match = re.match(r'@音频(\d+)\[(\w+)\]', audio_ref)
        
        if match:
            audio_id = match.group(1)
            param_type = match.group(2)
            
            return {
                "audio_id": audio_id,
                "type": param_type,
                "params": self.AUDIO_PARAMS.get(param_type, [])
            }
        
        return {}
```

## 六、系统实现

### 6.1 融合处理器

```python
class MultimodalFusion:
    """多模态融合处理器"""
    
    def __init__(self):
        self.references = {
            "images": [],
            "videos": [],
            "audios": []
        }
    
    def parse_references(self, text: str) -> dict:
        """解析所有素材引用"""
        import re
        
        # 标准格式
        patterns = {
            "图片": r'@图片(\d+)',
            "视频": r'@视频(\d+)\[(\w+)\]',
            "音频": r'@音频(\d+)\[(\w+)\]',
            "主体": r'@主体\s+(\w+)',
            "音色": r'@音色\s+(\w+)'
        }
        
        results = {}
        for ref_type, pattern in patterns.items():
            matches = re.findall(pattern, text)
            results[ref_type] = matches
        
        return results
    
    def fuse(self, prompt: str) -> str:
        """执行融合"""
        refs = self.parse_references(prompt)
        
        # 1. 提取动态参考
        video_refs = refs.get("视频", [])
        for video_id, param_type in video_refs:
            # 应用动态参数
            prompt = self.apply_video_params(prompt, video_id, param_type)
        
        # 2. 应用音频驱动
        audio_refs = refs.get("音频", [])
        for audio_id, param_type in audio_refs:
            prompt = self.apply_audio_params(prompt, audio_id, param_type)
        
        # 3. 绑定主体
        subjects = refs.get("主体", [])
        for subject_name, image_ref in subjects:
            prompt = self.bind_subject(prompt, subject_name, image_ref)
        
        return prompt
    
    def apply_video_params(self, prompt, video_id, param_type):
        """应用视频动态参数"""
        # 实现动态参数应用逻辑
        return prompt
    
    def apply_audio_params(self, prompt, audio_id, param_type):
        """应用音频驱动参数"""
        # 实现音频驱动逻辑
        return prompt
    
    def bind_subject(self, prompt, subject_name, image_ref):
        """绑定主体"""
        # 实现主体绑定逻辑
        return prompt
```

## 八、预算影响

### 8.1 动态参考预算计算

| 引用类型 | 预算占用 | 说明 |
|----------|----------|------|
| @图片N | 1单位 | 静态图片 |
| @视频N | 3单位 | 视频参考 |
| @视频N[运镜] | 1单位 | 仅提取运镜参数 |
| @视频N[速度] | 1单位 | 仅提取速度参数 |
| @音频N | 1单位 | 音频参考 |
| @音频N[BPM] | 0.5单位 | 仅提取节拍 |

### 8.2 预算优化建议

```markdown
1. 优先使用@视频N[运镜]而非完整@视频N
   - 运镜提取：1单位
   - 完整视频：3单位

2. 仅需节拍时使用@音频N[BPM]
   - BPM提取：0.5单位
   - 完整音频：1单位

3. 相似动作可复用同一视频参考
   - @视频1[运镜] 可用于多个镜头
```
