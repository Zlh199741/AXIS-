## 第一部分：核心心法（底层逻辑）

> 必须遵循的三大铁律

### 1.1 Motivated Movement（动机驱动）

摄影机必须因为某个"动机"才移动：
- **角色动了** → 物理跟随（Tracking / Dolly Follow）
- **心理状态变了** → 心理推拉（Psychological Push-In）
- **揭示新信息** → 叙事引导（Reveal Shot）

> ⚠️ **禁止无动机运镜**：摄影机不能为了"酷"而乱动

### 1.2 The Z-Axis Rule（Z轴空间法）

- 业余运镜：X轴（左右）+ Y轴（上下）平移
- 好莱坞T0运镜：**极度依赖Z轴（纵深推拉）**
- 通过前景、中景、背景的相对运动（视差）创造立体感

### 1.3 Invisible Edit（隐形剪辑）

通过以下方式隐藏剪辑点，保持情绪连贯：
- 前景物体遮挡（Wipe）
- 快速甩摇（Whip Pan）
- 人物走向暗处

## 第二部分：T0级标志性运镜技能

### Skill 1: 斯皮尔伯格无痕长镜头（Spielberg Oner）

| 项目 | 内容 |
|------|------|
| **创始人** | 斯皮尔伯格 |
| **用途** | 对话场景、场景转换 |
| **操作要领** | 摄影机固定或缓慢移动，依靠演员走位改变景别 |
| **示例** | 两人全景对话，A走向镜头占据70%画面变成特写，然后转身离开带出新背景 |

**在 Seedance 中的应用**：
```markdown
【镜头1】**Long Take**，固定机位拍摄两人对话。A突然走向镜头，画面瞬间从全景变为近景压迫感特写。A转身离开，摄影机顺势跟摇...
```

### Skill 2: 芬奇式心理入侵推轨（Psychological Push-In）

| 项目 | 内容 |
|------|------|
| **创始人** | 大卫·芬奇（David Fincher） |
| **用途** | 角色意识到真相、做出重大决定 |
| **操作要领** | 使用 Dolly 配合长焦，匀速向角色面部推进 |
| **关键** | 必须是物理推进（Dolly），不能用变焦（Zoom）！ |

**T0级质感**：
- 变焦只是放大画面
- Dolly In 会改变透视关系，背景向两侧排开
- 产生"世界正在向角色压迫过来"的窒息感

**在 Seedance 中的应用**：
```markdown
【镜头2】**Dolly In (Psychological)**，使用长焦镜头，平滑、匀速向江辰面部推进。背景空间逐渐压缩，产生强烈的压迫感...
```
