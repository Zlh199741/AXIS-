## 五、违禁词检测与替换流程

### 5.1 自动检测流程
```
1. 编写提示词时，扫描全文
2. 匹配违禁词词典
3. 标记匹配项
4. 按替换建议替换
5. 再次扫描确认无遗漏
```

### 5.2 替换优先级
1. **直接删除**：无法替换的严重违禁词
2. **中性替换**：意思相近的中性词
3. **场景化替换**：根据剧情选择合适替换

### 5.3 替换示例
| 原始描述 | 问题 | 替换后 |
|----------|------|--------|
| 林辰嘴角流血 | 违禁 | 林辰紧咬下唇，衣领有红痕 |
| 他感到极其愤怒 | 禁止心理描写 | 他眼眶猩红，猛地一拳砸塌实木桌子 |
| 萧凡被斩首 | 严重违禁 | 萧凡战败（不展示具体死亡方式） |
| 君倾城衣衫褴褛春光外泄 | 低俗暗示 | 君倾城衣衫褴褛，略显狼狈 |

## 六、快速查询表

### 6.1 绝对禁止（触碰即违规）
```
恋童、兽交、分尸、碎尸、斩首、砍头、挖眼、掏心、剥皮、
凌迟、虐杀、酷刑、血祭、活人献祭、尸横遍野、内脏外露、
色情、淫秽、嫖娼、卖淫、性交易、乱伦、邪教仪式、恐怖袭击
```

### 6.2 建议替换（可保留但需修改）
```
暴力类：血液→水花、砍头→击倒、斩首→击败
低俗类：性感→时尚、诱惑→吸引、胸器→魅力
暗示类：暧昧低俗→暧昧、撩骚→交谈
心理类：愤怒→眼眶猩红、悲伤→泪流满面
```

## 七、六维一致性检查（补充）

在检测违禁词的同时，检查以下一致性：

| 维度 | 检查项 |
|------|--------|
| 人物一致 | 出现角色必须匹配角色信息库 |
| 时空一致 | 相邻分镜时间/地点/光线无缝衔接 |
| 物品一致 | 关键道具位置状态延续上一镜 |
| 动作连贯 | 新分镜起始动作承接上一镜结束状态 |
| 台词合规 | 仅当前说话角色有张嘴动作 |
| 敏感过滤 | 违禁词已替换为中性词 |
