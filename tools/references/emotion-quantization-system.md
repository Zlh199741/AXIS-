# 情感量化与视觉节奏系统

## 用途

将情绪强度量化为EII数值，实现现场音效节奏与视觉镜头的自动化对齐，提升视听同步质量；不生成、不引用背景音乐、BGM或音乐铺底。

---

## 一、情感强度量化体系

### 1.1 情感强度值（EII）定义

| EII范围 | 情绪标签 | 视觉表现 | 运镜特征 | 节奏特征 |
|---------|----------|----------|----------|----------|
| 0-20 | 低沉/绝望 | 暗调、低饱和、固定镜头 | 缓慢推拉 | 悠长留白 |
| 21-40 | 紧张/悬疑 | 冷调、阴影加重 | 晃动、跟拍 | 渐快 |
| 41-60 | 对抗/冲突 | 对比度增加 | 快速切镜 | 动接动 |
| 61-80 | 高潮/狂欢 | 高饱和、色彩爆发 | 极限特写 | 高频切换 |
| 81-100 | 释然/终局 | 收束、淡出 | 拉远镜头 | 静止 |

### 1.2 场景类型 → 情感曲线映射

#### 场景：危机逼近
```

T+0-2s: EII=20（平静）
T+2-5s: EII=40（悬念）压迫感渐起
T+5-8s: EII=65（紧张）节奏加快
T+8-10s: EII=85（危机）镜头晃动
T+10s: EII=100（截断）黑屏
```

#### 场景：温情回忆
```

T+3-8s: EII=50（回味）缓慢推近

T+12-15s: EII=15（结束）留白
```

#### 场景：激烈战斗
```

T+2-4s: EII=85（爆发）快切

```

## 二、视觉节奏同步协议

### 2.1 现场音效密度类型映射

| 音效密度段落 | 事件密度范围 | 视觉强度 | 镜头切换点 |
|----------|---------|----------|------------|
| 建立密度 | 80-100次/分钟 | 低 | 不切换 |
| 递进密度 | 100-120次/分钟 | 中 | 轻触发点 |
| 冲击密度 | 140-160次/分钟 | 高 | 强触发点 |
| 过渡密度 | 90-110次/分钟 | 过渡 | 不切换 |

### 2.2 同步标注格式

```markdown
[触发点同步]
现场音效节奏: @音频1（事件密度140次/分钟，冲击密度段落，禁止音乐铺底）

T+0s: 镜头1，建立场景 → 对齐建立密度段
T+3s: 镜头2，角色入场 → 对齐递进密度第1触发点
T+6s: 镜头3，冲突爆发 → 对齐冲击密度强触发点
T+10s: 镜头4，危机顶点 → 对齐冲击密度峰值触发点
```

### 2.3 自动生成逻辑

当提示词包含现场音效节奏引用时：
1. 解析现场音效特征（事件密度、段落）
2. 将镜头时长对齐到触发点
3. 在强触发点强制切换镜头

## 六、系统实现

### 6.1 EII计算函数

```python
class EmotionQuantizer:
    """情感量化器"""
    
    # 基础EII映射
    EMOTION_KEYWORDS = {
        "平静": 20, "温馨": 30, "紧张": 50, "悬疑": 45,
        "危机": 75, "绝望": 15, "愤怒": 70, "狂欢": 80, "释然": 35,
        "平静": 20, "温馨": 30, "紧张": 50, "悬疑": 45,
        "危机": 75, "绝望": 15, "愤怒": 70, "狂欢": 80, "释然": 35
    }
    
    # 场景元素调整
    SCENE_ADJUSTMENTS = {
        "黑暗": 10, "阴影": 10, "烛光": -10, "暖光": -10,
        "慢动作": 5, "快节奏": 15, "特写": 10, "全景": -10,
        "静音": 20, "高潮": 15
    }
    
    def calculate_eii(self, text: str) -> int:
        """计算文本的EII值"""
        eii = 50  # 默认值
        
        # 提取情绪关键词
        for keyword, base_value in self.EMOTION_KEYWORDS.items():
            if keyword in text:
                eii = base_value
        
        # 应用场景调整
        for element, adjustment in self.SCENE_ADJUSTMENTS.items():
            if element in text:
                eii += adjustment
        
        # 限制范围
        return max(0, min(100, eii))
    
    def generate_emotion_curve(self, shots: list, event_density: int = 120) -> list:
        """生成情感曲线"""
        curve = []
        current_time = 0
        
        for shot in shots:
            duration = shot.get("duration", 3)
            eii = self.calculate_eii(shot.get("description", ""))
            
            curve.append({
                "time": f"T+{current_time}s",
                "eii": eii,
                "description": shot.get("description", "")
            })
            
            current_time += duration
        
        return curve
```
