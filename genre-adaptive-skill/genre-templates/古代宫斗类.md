# 古代宫斗类 题材适配指南

## 题材标签
- 主分类：策略线驱动
- 副分类：权谋/情感
- 目标受众：18-40岁女性为主

## 核心满足点
1. **智力博弈快感**：以智取胜、步步为营
2. **权力翻盘**：从低位嫔妃到后宫之主
3. **人心算计**：识破阴谋、反将一军
4. **华丽视觉**：古装华服、宫殿美景

## 标志性场景
| 场景类型 | 描述 | 情绪 |
|---------|------|------|
| 入宫/选秀 | 初入后宫、暗流涌动 | 紧张+期待 |
| 宫斗陷害 | 被设计陷害/栽赃 | 紧张+愤怒 |
| 反击打脸 | 识破阴谋、当众揭穿 | 极致爽 |
| 帝后对手戏 | 帝王宠爱/疏远 | 甜/虐 |
| 晋封/降位 | 地位变化的关键节点 | 爽/虐 |
| 终极对决 | 与最终对手的终极博弈 | 燃+爽 |

## 专业术语
| 类型 | 术语 |
|------|------|
| 宫廷术语 | 嫔妃等级（答应/常在/贵人/嫔/妃/贵妃/皇后）、请安、侍寝 |
| 权谋术语 | 借刀杀人、以退为进、明修栈道暗度陈仓 |
| 服饰术语 | 凤冠霞帔、步摇、团花锦缎、云肩 |

## 视觉风格
| 维度 | 推荐 |
|------|------|
| 色调 | 正红+明黄+翠绿，传统中国色 |
| 光影 | 烛光暖色（宫殿内）、月光冷色（阴谋场景） |
| 运镜 | 稳定横移（宫殿长廊）、慢推（面部特写） |
| 特效 | 花瓣飘落、烛光摇曳、丝绸飘动 |
