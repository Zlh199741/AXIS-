# 末世生存类 题材适配指南

## 题材标签
- 主分类：力量线驱动
- 副分类：生存/冒险
- 目标受众：18-35岁男性为主

## 核心满足点
1. **生存危机的紧迫感**：资源争夺、怪物围攻
2. **实力成长爽感**：从普通人→末世强者
3. **人性博弈**：极端环境下的道德抉择
4. **团队/基地建设**：收集伙伴、建立避难所

## 标志性场景
| 场景类型 | 描述 | 情绪 |
|---------|------|------|
| 末世降临 | 灾变爆发、秩序崩塌 | 震惊+恐惧 |
| 首次觉醒 | 获得异能/变异 | 期待+燃 |
| 物资争夺 | 与其他幸存者争抢资源 | 紧张+愤怒 |
| 怪物围城 | 基地遭受大规模攻击 | 紧张+燃 |
| 人性抉择 | 救人vs自保的两难 | 虐心+纠结 |
| 等级跃迁 | 异能突破/装备升级 | 极致爽 |
