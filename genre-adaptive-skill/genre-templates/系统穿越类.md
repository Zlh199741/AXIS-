# 系统穿越类 题材适配指南

## 题材标签
- 主分类：成长线驱动
- 副分类：力量/策略
- 目标受众：18-35岁男女通吃

## 核心满足点
1. **信息差碾压**：预知未来/了解历史走向
2. **系统辅助爽感**：任务奖励、技能解锁、商城购买
3. **身份逆袭**：从底层快速崛起
4. **蝴蝶效应**：小改变引发大反转

## 标志性场景
| 场景类型 | 描述 | 情绪 |
|---------|------|------|
| 穿越降临 | 意外穿越+系统绑定 | 震惊+好奇 |
| 系统激活 | 面板弹出、任务发布 | 期待+兴奋 |
| 任务完成 | 奖励发放+能力获取 | 爽+满足 |
| 信息差打脸 | 预知结果→众人震惊 | 极致爽 |
| 系统惩罚 | 任务失败/违规惩罚 | 紧张+危机 |
| 系统升级 | 新功能解锁/权限提升 | 期待+燃 |
