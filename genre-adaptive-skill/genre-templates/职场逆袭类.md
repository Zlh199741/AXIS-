# 职场逆袭类 题材适配指南

## 题材标签
- 主分类：成长线驱动
- 副分类：商战/励志
- 目标受众：22-40岁男女通吃

## 核心满足点
1. **逆袭翻盘爽感**：从底层小职员到行业大佬
2. **打脸碾压**：打脸看不起自己的上司/同事
3. **能力展示**：关键时刻力挽狂澜
4. **公平正义**：惩罚职场霸凌/不公

## 标志性场景
| 场景类型 | 描述 | 情绪 |
|---------|------|------|
| 职场受辱 | 被上司打压/同事排挤 | 压抑+愤怒 |
| 能力初露 | 在关键项目中展现实力 | 期待+小爽 |
| 打脸反转 | 当众碾压曾经欺辱自己的人 | 极致爽 |
| 商战博弈 | 关键谈判/竞标/危机处理 | 紧张+燃 |
| 团队组建 | 收拢人才、建立团队 | 成就感 |
| 终极对决 | 与最终BOSS（老板/竞对）正面交锋 | 燃+爽 |

| 1 | 职场受辱+隐藏实力 | 7 |

| 5 | 团队组建+反击准备 | 7 |

| 10 | 终极打脸+新征程 | 10 |

## 专业术语
| 类型 | 术语 |
|------|------|
| 职场术语 | KPI、晋升、年终考核、述职、竞聘 |
| 商战术语 | 融资、收购、并购、对赌、IPO |
| 人际术语 | 站队、靠山、空降兵、嫡系、边缘化 |

## 视觉风格
| 维度 | 推荐 |
|------|------|
| 色调 | 冷灰蓝+暖金色对比（压抑vs逆袭） |
| 光影 | 写字楼冷光灯+逆袭时暖光 |
| 运镜 | 受辱时固定（无力感），逆袭时推+仰拍（力量感） |
| 特效 | 数据流、图表叠加（商战可视化） |
