# 豪门总裁类 题材适配指南

## 题材标签
- 主分类：情感线驱动
- 副分类：权谋/商战
- 目标受众：18-35岁女性为主

## 核心满足点
1. **身份反差爽感**：灰姑娘逆袭 / 隐藏身份揭露
2. **权力碾压快感**：总裁为女主撑腰、打脸恶人
3. **甜宠+虐恋交织**：极致甜蜜与误会虐心交替
4. **物质视觉冲击**：豪车、别墅、奢侈品、私人飞机

## 标志性场景
| 场景类型 | 描述 | 情绪 |
|---------|------|------|
| 初遇场景 | 身份悬殊的戏剧性相遇（碰撞/误会/替身） | 好奇+心动 |
| 打脸场景 | 总裁当众维护女主，打脸看不起她的人 | 极致爽感 |
| 虐心场景 | 误会导致分离/背叛假象 | 虐心+期待 |
| 身份揭露 | 女主/男主隐藏身份曝光 | 震惊+反转 |
| 豪门宴会 | 盛装出席，惊艳全场 | 视觉冲击+爽 |
| 商战对决 | 股权争夺/公司危机 | 紧张+燃 |
