# 悬疑推理类 题材适配指南

## 题材标签
- 主分类：悬疑线驱动
- 副分类：烧脑/反转
- 目标受众：20-40岁男女通吃

## 核心满足点
1. **智力优越感**：推理过程带来的满足
2. **反转震撼**：真相出人意料
3. **紧张窒息感**：危险逼近的压迫
4. **真相大白的释放**：长期悬念的解答

## 标志性场景
| 场景类型 | 描述 | 情绪 |
|---------|------|------|
| 案发现场 | 发现尸体/犯罪痕迹 | 震惊+恐惧 |
| 线索发现 | 关键证据浮出 | 好奇+兴奋 |
| 审讯对峙 | 嫌疑人与侦探交锋 | 紧张+智力碰撞 |
| 误导反转 | 以为找到真凶→推翻 | 震惊+好奇 |
| 危险逼近 | 主角/配角陷入险境 | 紧张+恐惧 |
| 真相揭露 | 终极反转+真凶现身 | 震撼+释放 |

## 专业术语
| 类型 | 术语 |
|------|------|
| 侦查术语 | 物证、指纹、DNA、不在场证明、作案动机 |
| 推理术语 | 密室、叙述性诡计、多重反转、红鲱鱼 |
| 心理术语 | 犯罪心理画像、微表情、反社会人格 |

## 视觉风格
| 维度 | 推荐 |
|------|------|
| 色调 | 冷色调（深蓝、墨绿），低饱和度 |
| 光影 | 硬光侧影、Film Noir风格、阴影遮面 |
| 运镜 | 手持微晃（不安感）、慢推（压迫感） |
| 特效 | 闪回叠影、画面扭曲、红色高光 |
