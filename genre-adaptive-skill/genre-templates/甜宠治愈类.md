# 甜宠治愈类 题材适配指南

## 题材标签
- 主分类：情感线驱动
- 副分类：日常/治愈
- 目标受众：16-30岁女性为主

## 核心满足点
1. **心动瞬间**：极致甜蜜互动
2. **安全感满足**：男主无条件宠爱
3. **日常治愈**：温馨生活细节
4. **CP互动**：发糖名场面

## 标志性场景
| 场景类型 | 描述 | 情绪 |
|---------|------|------|
| 心动瞬间 | 不经意间的对视/触碰 | 甜+心跳 |
| 壁咚/公主抱 | 经典肢体互动 | 甜+脸红 |
| 吃醋场景 | 因第三者产生醋意 | 甜+微虐 |
| 雨中/夜晚场景 | 浪漫氛围下的告白 | 甜+感动 |
| 同居日常 | 做饭/打闹/照顾 | 温馨+治愈 |
| 误会和好 | 小矛盾→甜蜜和好 | 微虐→甜 |
