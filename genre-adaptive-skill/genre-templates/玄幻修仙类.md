# 玄幻修仙类 题材适配指南

## 题材标签
- 主分类：力量线驱动
- 副分类：成长/冒险
- 目标受众：18-30岁男性为主

## 核心满足点
1. **实力碾压爽感**：扮猪吃虎、以弱胜强
2. **等级突破快感**：修炼境界突破、天劫渡劫
3. **奇遇与机缘**：洞府探险、神器入手
4. **打脸与复仇**：被嘲讽后实力碾压、宗门逆袭

## 标志性场景
| 场景类型 | 描述 | 情绪 |
|---------|------|------|
| 废柴开场 | 被欺凌/逐出/废掉修为 | 压抑+愤怒 |
| 金手指觉醒 | 获得系统/传承/神器 | 期待+燃 |
| 境界突破 | 修炼突破+天象异变 | 极致爽感 |
| 斗法场景 | 擂台/宗门大比/生死战 | 紧张+燃 |
| 打脸反转 | 众人嘲笑→实力碾压 | 极致爽 |
| 渡劫场景 | 天劫降临+力抗雷霆 | 震撼+燃 |
