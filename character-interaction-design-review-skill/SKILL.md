# 角色互动设计审核技能

[技能说明]
    审核 character-interaction-design-skill 的多角色互动场景设计产出，确保：
    1. 站位逻辑符合权力关系和叙事目的
    2. 视线交互设计合理，情绪传达准确
    3. 冲突动作可执行，不超出AI生成能力
    4. 群演调度清晰，不混乱
    5. 情感线互动与剧情一致

    本审核技能必须参考：
    1. skills/character-interaction-design-skill/SKILL.md：了解互动设计规范
    2. skills/visual-language-logic/SKILL.md：视听语言标准
    3. skills/compliance-review-skill/SKILL.md：合规检查
    4. skills/templates/quality-threshold-standard.md：通过阈值单一权威

[审核流程]

    第一步：站位逻辑审核
        | 检查项 | 标准 |
        |--------|------|
        | 权力关系 | 站位是否反映角色权力关系 |
        | 构图类型 | 三角/对称/对角线构图是否合理 |
        | 站位变化 | 变化是否有叙事动机驱动 |

    第二步：视线交互审核
        | 检查项 | 标准 |
        |--------|------|
        | 视线类型 | 直视/斜视/俯仰是否与情绪匹配 |
        | 视线变化 | 变化节奏是否服务于叙事 |
        | 轴线一致 | 视线方向是否遵守180度轴线 |

    第三步：冲突动作审核
        | 检查项 | 标准 |
        |--------|------|
        | 可执行性 | 动作是否在AI生成能力范围内 |
        | 情绪强度 | 动作强度是否与情绪匹配 |
        | 合规性 | 肢体冲突是否超出平台尺度 |

    第四步：群演调度审核（如有）
        | 检查项 | 标准 |
        |--------|------|
        | 位置清晰 | 群演位置是否有明确描述 |
        | 反应一致 | 群演反应是否与主角行动匹配 |
        | 数量合理 | 群演数量是否在AI可处理范围内 |

[评分表格式]

    三维评分规则（必须执行）：

    互动逻辑评分（0-100分）：
    □ 站位是否反映权力/情感关系？（0-33分）
    □ 视线交互是否合理传达情绪？（0-33分）
    □ 站位/视线变化是否有叙事驱动？（0-34分）

    可执行性评分（0-100分）：
    □ 冲突动作是否在AI生成能力内？（0-33分）
    □ 群演调度是否清晰可执行？（0-33分）
    □ 场景空间关系是否合理？（0-34分）

    叙事一致性评分（0-100分）：
    □ 互动设计是否与剧情一致？（0-33分）
    □ 情感线是否与角色关系匹配？（0-33分）
    □ 互动高潮是否与情绪节点对齐？（0-34分）

    🔴 亲密互动·性暗示构图专项评分（单列维度 — 仅当场景含 CP/暧昧/贴身/床戏 时强制评分，对接 compliance-review-skill）：
    □ 构图是否避免性暗示（无性器官/敏感部位特写、无挑逗体位、无情色凝视运镜）？（0-50分）
    □ 亲密尺度是否在平台允许范围内（以拥抱/牵手/额吻/搂肩为限）？（0-50分）
    专项判定：< 95分 → 合规一票否决 FAIL（回退重审），单独成关、不参与三维平均。

[PASS/FAIL 标准]

    PASS 条件：
    - 三维评分各项 ≥ 95分
    - 含亲密互动时，性暗示构图专项 ≥ 95分
    - 无轴线违规
    - 合规审核通过
    - 审核结论按[审核报告强制模板]完整输出

    FAIL 条件（任一满足）：
    - 站位与权力关系严重矛盾
    - 视线交互违反180度轴线且无叙事目的
    - 冲突动作超出平台尺度
    - 亲密互动性暗示构图专项 < 95分（合规一票否决）
    - 合规审核未通过

[诊断指南]

    Q: 站位与权力关系矛盾？
    A: 对照权力矩阵：画面中心偏上=主导，偏下=弱势，右侧=主动，左侧=被动。如果被压迫角色占据画面主导位置=站位与剧情矛盾=P0。

    Q: 视线交互违反轴线？
    A: 对话场景中，A看向画面右侧→B必须看向画面左侧（面对面）。如果两人都看向同一方向=轴线崩塌=P0。除非标注"刻意越轴"并说明叙事目的。

    Q: 冲突动作AI无法执行？
    A: 检查是否使用了AI友好替代方案：扇耳光→抬手+对方侧脸特写+音效；推倒→冲过去+撞到+踉跄；拥抱→跑向+张开手+画面定格。直接肢体接触动作=高崩坏风险。

    Q: 群演数量超出AI处理能力？
    A: Seedance/Kling单镜头建议：焦点人物≤3人，中景群演≤5人，背景群演用文字描述氛围即可。超过8个独立角色=AI无法稳定处理。

    Q: 情感线互动太平淡？
    A: 检查是否有情绪递进层次：靠近→接触→突破。单一层次的互动=缺乏张力。暧昧推拉必须有至少2个递进层次。

    Q: 站位变化没有叙事驱动？
    A: 每次站位变化必须对应一个叙事事件（权力逆转/关系突破/危机解除）。无理由的站位变化=调度混乱。

    Q: 误会场景设计不完整？
    A: 标准误会链：目睹异常→错误解读→情绪爆发→冲突升级→真相揭开。缺少任一环节=误会不可信。

    Q: 三角构图选择不当？
    A: 稳定三角=三方对峙/谈判；动态三角=追逐/转换；倒置三角=危机/压迫。构图类型与场景情绪不匹配=P1。

[常见审核案例]

    PASS案例：
    - 对峙场景：反派占画面中心偏上（主导），主角偏下（弱势），符合权力关系
    - 视线交互：A直视B(3点钟方向)→B回看A(9点钟方向)，180度轴线正确
    - 冲突动作使用AI替代：扇耳光→抬手特写→对方侧脸反应→"啪"音效
    - 群演设计：焦点2人+中景群演"众人惊恐后退"+背景"人群骚动"

    FAIL案例：
    - 被压迫的穷苦角色占据画面中心最大面积，权力矩阵完全反转
    - 对话中两人视线都朝画面右侧（越轴，空间关系崩塌）
    - 提示词直接写"两人激烈扭打在一起"，无AI替代方案
    - 要求画面中同时出现12个独立行动的角色，超出AI处理能力

[术语表]

    | 术语 | 英文 | 定义 |
    |------|------|------|
    | 权力矩阵 | Power Matrix | 通过画面占比和位置表达角色权力关系 |
    | 视线交互 | Gaze Interaction | 角色间通过视线传达情绪和关系 |
    | 三角构图 | Triangle Composition | 三个角色形成稳定/动态/倒置三角布局 |
    | AI友好替代 | AI-Friendly Alternative | 用表情/声音/影子替代直接肢体接触 |
    | 焦点人物法 | Focus Character Method | 群戏中只设计2-3个焦点人物的动作 |
    | 暧昧推拉 | Push-Pull Dynamic | 靠近→接触→突破的情感递进层次 |
    | 站位变化 | Blocking Change | 角色位置移动传达叙事信息 |
    | 情绪冲突矩阵 | Emotion Conflict Matrix | 角色情绪对抗的可视化模型 |
