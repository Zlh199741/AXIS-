# 脑洞扩展审核技能

[技能说明]
    审核脑洞扩展师在前期阶段的产出。审核员需要以批判性视角审视脑洞扩展结果，
    通过逐维度比对原始输入、脑内预演观众反应和市场吸引力、逐项评分的方式，
    确保世界观完整、核心概念有吸引力、角色可标签化、情绪循环有效、集纲规划合理。

    本审核技能必须参考：
    1. skills/brainworm-generator-skill/SKILL.md：了解脑洞扩展规范
    2. skills/genre-adaptive-skill/SKILL.md：确保题材适配性
    3. skills/compliance-review-skill/SKILL.md：合规检查
    4. skills/plot-psyche-double-helix-skill/SKILL.md：叙事结构验证
    5. tools/references/sensitive-word-dictionary.md：敏感词检测

[审核对象]
    brainworm-generator-skill 的产出文件，包括：
    - 世界观设定文档
    - 核心概念设计文档
    - 角色卡文档
    - 故事卡文档
    - 集纲规划文档

[审核流程]

    第一步：建立整体理解
        - 读取原始输入（用户提供的小说概念/题材/灵感）
        - 读取待审核的脑洞扩展全部产出
        - 明确审核立场：你的任务是找出问题，而非确认通过
        - 如有题材类型信息，加载 genre-adaptive-skill 对应题材指南

    第二步：世界观完整性审核
        - 检查世界观是否自洽（无逻辑矛盾）
        - 检查世界观是否足够独特（非模板化、有差异化卖点）
        - 检查世界观是否可视化（适合影视化呈现）
        - 检查世界观是否有"升级空间"（可扩展性）
        - 对照 plot-psyche-double-helix-skill 检查叙事结构是否健全

    第三步：核心概念吸引力审核
        - 检查核心概念的"卖点"是否明确（一句话能说清）
        - 检查情绪钩子是否有效（能触发好奇心/愤怒/期待）
        - 检查悬念设计是否合理（有来有回，不是空悬念）
        - 脑内预演：想象目标观众看到这个概念的第一反应
        - 竞品分析：与同题材热门作品对比差异化程度

    第四步：角色可标签化审核
        - 检查每个主要角色是否有"一句话标签"（如"废物逆袭"、"冷面王爷"）
        - 检查角色之间是否有足够的反差/冲突关系
        - 检查角色动机是否清晰且有共鸣点
        - 检查角色是否具备视觉辨识度（外观标签化）
        - 检查角色心因弧是否完整（缺陷→觉醒）

    第五步：情绪循环验证（3-10-60 法则）
        - 检查每个故事节点是否包含"3秒钩子"元素
        - 检查10秒内是否能快速建立人物关系和核心矛盾
        - 检查1分钟内是否有情绪释放点（爽点/反转/打脸）
        - 检查整体情绪节奏是否形成"递进-高潮-悬念"的循环
        - 检查卡点设计是否有效（截断在悬念最高点）

    第六步：集纲规划合理性审核
        - 检查集数分配是否合理（密度均匀，无注水）
        - 检查三段式情绪周期是否完整（蓄能期/加压期/升级期）
        - 检查每集是否有独立的核心冲突和爽点
        - 检查最终危机卡点是否足够强烈

    第七步：逐项评分并输出结果
        - 按照下方评分标准评分（6维加权分仅作内部参考与排序，不作为 PASS 裁决）
        - 🔴 PASS 唯一裁决：三维评分（剧情连贯性/商业吸引力/结构完整性）各项 ≥ 95分（C级审核类，参考 skills/templates/quality-threshold-standard.md）
        - 任一三维维度 < 95分 或 合规未通过 → FAIL + 问题清单

[审核维度与评分标准]

    1. 世界观完整性（权重：20%，满分 10 分）
        | 检查项 | 标准 |
        |--------|------|
        | 逻辑自洽 | 世界观内部无矛盾（力量体系/社会结构/历史背景） |
        | 独特性 | 非模板化，有差异化卖点 |
        | 可视化 | 适合影视化呈现，有强烈的画面感 |
        | 升级空间 | 可扩展至多季/多线叙事 |
        | 叙事结构 | 符合 plot-psyche-double-helix 的双螺旋结构 |

    2. 核心概念吸引力（权重：25%，满分 10 分）
        | 检查项 | 标准 |
        |--------|------|
        | 一句话卖点 | 能用一句话说清核心吸引力 |
        | 情绪钩子 | 能触发目标观众的好奇心/愤怒/期待 |
        | 悬念设计 | 有完整的悬念链，不是空悬念 |
        | 市场差异化 | 与同题材竞品有明显差异 |
        | 商业潜力 | 适合短视频平台传播（话题性/讨论度） |

    3. 角色可标签化（权重：20%，满分 10 分）
        | 检查项 | 标准 |
        |--------|------|
        | 标签清晰度 | 每个主角有"一句话标签" |
        | 角色反差 | 角色之间有足够的反差/冲突 |
        | 动机共鸣 | 角色动机有目标观众共鸣点 |
        | 视觉辨识度 | 角色外观有标签化视觉特征 |
        | 心因弧完整性 | 初始缺陷→终极觉醒的完整弧线 |

    4. 情绪循环有效性（权重：20%，满分 10 分）
        | 检查项 | 标准 |
        |--------|------|
        | 3秒钩子 | 每个节点有极致视觉冲击开场 |
        | 10秒叙事 | 快速建立人物关系和核心矛盾 |
        | 1分钟爽点 | 完整的情绪释放（打脸/反转/逆袭） |
        | 递进节奏 | 情绪强度逐集递进 |
        | 卡点质量 | 每集结尾截断在悬念最高点 |

    5. 集纲规划合理性（权重：10%，满分 10 分）
        | 检查项 | 标准 |
        |--------|------|
        | 内容密度 | 集数分配均匀，无注水集 |
        | 三段式周期 | 蓄能(前~1/3)/加压(中~1/3)/升级(后~1/3) 完整，按总集数比例切分，不写死集号 |
        | 独立冲突 | 每集有独立核心冲突 |
        | 终极危机 | 最后一集大卡点足够强烈 |

    6. 格式规范（权重：5%，满分 10 分）
        | 检查项 | 标准 |
        |--------|------|
        | 字段完整 | 世界观/概念/角色/故事/集纲全覆盖 |
        | 模板遵循 | 按 brainworm-generator-skill 输出模板格式 |
        | 排版清洁 | 无冗余内容，层次分明 |

[PASS/FAIL 标准]

    🔴 唯一裁决标准（引用 skills/templates/quality-threshold-standard.md「冲突即裁决规则」）：
    以三维评分对照阈值表（C级审核类 ≥95）为准；6维加权总分仅作内部参考，**不作为 PASS/FAIL 裁决**，
    任何加权分与三维评分结论不一致时一律以三维评分为准（消除"加权≥80"与"三维≥95"并存矛盾）。

    PASS 条件（必须全部满足）：
    - 三维评分各项 ≥ 95分（剧情连贯性/商业吸引力/结构完整性）
    - 合规审核通过

    FAIL 条件（任一满足）：
    - 三维评分任一维度 < 95分
    - 世界观存在严重逻辑矛盾
    - 核心概念无法用一句话说清
    - 角色缺乏标签化特征超过 2 个主角
    - 情绪循环三要素（3-10-60）任一完全缺失
    - 格式严重缺失（缺少核心字段超过 3 项）
    - 合规审核未通过

[输出模板]

    三维评分规则（必须执行）：
        剧情连贯性评分（0-100分）：
        □ 世界观与核心概念是否逻辑自洽？（0-33分）
        □ 角色动机与行为是否合理连贯？（0-33分）
        □ 情节转折点是否有足够铺垫？（0-34分）

        商业吸引力评分（0-100分）：
        □ 核心卖点是否足够吸引目标观众？（0-33分）
        □ 情绪循环（3-10-60）是否有效？（0-33分）
        □ 与竞品相比差异化程度如何？（0-34分）

        结构完整性评分（0-100分）：
        □ 所有必需字段是否齐全？（0-33分）
        □ 叙事结构（双螺旋）是否健全？（0-33分）
        □ 集纲规划（三段式情绪周期）是否合理？（0-34分）

        通过标准：
        - 剧情连贯性 ≥ 95分
        - 商业吸引力 ≥ 95分
        - 结构完整性 ≥ 95分
        - 任一维度低于95分 → 业务审核 FAIL

[诊断指南]

    | 问题类型 | 快速检查 | 修复方向 |
    |----------|----------|----------|
    | 世界观有矛盾 | 画出世界观逻辑图，检查因果链 | 找出矛盾节点，修复逻辑 |
    | 概念不吸引人 | 用一句话描述给测试用户 | 强化卖点，增加情绪钩子 |
    | 角色无标签 | 检查每个角色能否用4字概括 | 增加反差标签，强化视觉符号 |
    | 情绪循环缺失 | 检查3-10-60三要素覆盖率 | 补充缺失的钩子/叙事/爽点 |
    | 集纲注水 | 检查每集核心冲突是否独立 | 合并/替换弱集的内容 |
    | 题材不适配 | 对照 genre-adaptive-skill | 调整设定以符合题材惯例 |
    | 叙事结构不健全 | 对照 plot-psyche-double-helix | 补充心因弧/情节弧缺失部分 |
    | 格式不规范 | 对照输出模板检查 | 按模板修正格式 |
