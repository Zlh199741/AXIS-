# 服化道设计审核技能（融合工业级版）

[技能说明]
    审核服化道在阶段二的设计产出，包括人物设定提示词和场景环境提示词。导演需要以批判性视角审视服化道的产出，通过逐项比对导演清单、脑内预演文生图效果、逐项评分的方式，确保提示词质量真正达标，能让用户通过文生图工具生成准确的参考图。

    本审核技能融合工业级技术美术审核标准，增加以下审核维度：
    1. 五大设计铁律审核：辨识度、可信度、情绪优先、落地适配、技术实现
    2. 核心记忆点审核：检查是否有且仅有1个核心视觉记忆点
    3. 形状语言审核：检查形状语言是否与角色情绪匹配
    4. 避坑红线检查：检查是否有同质化、无逻辑、脱离场景等问题

    本审核技能可参考：
    1. resources/unified-audiovisual-language-library.md：获取精确的光影参数用于场景审核（第五层快速查询索引）
    2. tools/references/virtual-lighting-camera-library.md：获取灯光摄影机参数组合
    3. skills/art-design-skill/SKILL.md：了解工业级融合版设计规范
    4. 按需查阅（电影摄影三件套 — 审核光影规范块质量时参考）：
       - resources/电影摄影-主文件(技法+设备+工作流程).md（十大核心技法，审核光影规范是否专业合理）
       - resources/电影摄影-40+代表作视觉分析.md（代表作光影参数，比对场景光照方案）
       - resources/电影摄影-AI提示词库.md（8套打光方案标准，审核光影提示词质量）

    审核标准 = 电影级角色提案板（六区块·2026-05-31 唯一角色标准）：
    - 提案板：横版16:9 + 中性灰背景 + 顶部细条 + 区块A主视觉立像（+金色身高刻度尺）/ B全身5视图转面 / C头部6视图研究 / D情绪肖像 / E服装配件拆解(4-6张微距) / F HSB色板备注
    - 旧式「三栏式 / 4视图 / 8视图 / 4表情集」已彻底废除（校验器不再接受三栏式）；所有角色一律以提案板为准，遇旧三栏式产物判 FAIL 并回炉重生成为提案板

[审核对象]
    assets/prompts/character-prompts.md、assets/prompts/scene-prompts.md、assets/prompts/props-prompts.md 中本集新增内容；
    以及电影级角色提案板 character-prompts-pitch-board.md（主要角色标准交付物，若存在则一并审核）

[审核流程]

    第一步：建立整体理解
        - 读取导演分析产出（01-director-analysis.md）中的人物清单和场景清单
        - 读取待审核的服化道设计产出
        - 如有已有素材，读取了解上下文
        - 按标准标签语法筛选本集新增内容：`[epNN][character|scene][新增|变体|复用]`
        - 明确审核立场：你的任务是找出问题，而非确认通过

    第一步半：🔴 原文溯源回查（2026-03-24 新增 — 根因修复）
        - 读取 .agent-state.json 中的 novelFile 字段，获取原始小说文件路径
        - 读取原始小说文件（novel/ 目录下的 .txt 文件）
        - 对每个角色，在原文中搜索该角色的外观描写、性格描写、能力描写
        - 建立"原文角色画像"基线，作为后续审核的最终权威参照
        - 🔴 如果原文中有明确的外观描写但角色提示词中完全缺失 → 直接 FAIL
        - 🔴 如果原文中的关键特征（如种族特征、特殊标记、武器等）被遗漏 → 标记为必须修改
        - 运行自动化校验：`python tools/validators/novel-fidelity-checker.py <集数>` 并将报告附入审核结论

    第二步：逐项比对（三层比对：原文→导演→提示词）
        - 🔴 对每个人物：先对照原文描写，再对照导演人物清单中的外观关键词，最后检查服化道提示词是否完整覆盖两者
        - 🔴 对每个场景：先对照原文场景描写，再对照导演场景清单中的光线/色调/氛围描述，最后检查服化道提示词是否完整覆盖两者
        - 同时检查讲戏本中对同一人物/场景的具体描述，确保服化道提示词没有与讲戏本冲突
        - 🔴 新增检查维度：视频提示词中引用的角色外观是否与角色提示词一致（预检下游一致性）

    第三步：脑内预演
        - 对每个人物提示词：想象把这段文字丢进文生图工具（如即梦、Nano Banana Pro），生成出来的图会是什么样？
            - 生成的人物形象是否与导演心中的角色一致？
            - 是否有描述歧义可能导致生成结果偏离预期（如"清秀"可能被理解为女性化）？
            - 参考图的布局（特写+三视图）是否能清晰展示角色全貌？
        - 对每个场景提示词：想象把这段文字丢进文生图工具，生成出来的场景图是什么样？
            - 生成的场景氛围是否与导演讲戏本中该场景的情绪匹配？
            - 是否有关键视觉元素可能在生成中丢失（如"牌匾上的文字"在AI生成中经常出错）？
            - 空间布局是否清晰，不会生成混乱的构图？

    第四步：逐项评分
        按照下方验收清单，对每个人物和每个场景单独评分（1-10）

    第五步：输出结果
        - 🔴 校验报告前置门禁（先于评分判定）：产物必须附上对应自动化校验通过报告——
          角色 / 场景 / 道具产物（character-prompts.md / scene-prompts.md / props-prompts.md）须附 `python tools/validators/t0-validator.py` 通过报告；
          电影级角色提案板（character-prompts-pitch-board.md）须附 `python tools/validators/pitch-board-validator.py` 通过报告。
          **任一应附校验报告缺失或未通过 → 直接 FAIL，不进入评分。**
        - 计算所有人物评分和场景评分的总平均分
        - 平均分 ≥ 8 且无单项低于 6 → PASS
        - 平均分 < 8 或任一单项低于 6 → FAIL + 问题清单

[验收清单]

    工业级审核维度（新增）：
        □ 辨识度审核：检查提示词是否提炼了1个核心记忆点？该记忆点是否能3米外通过剪影识别？
        □ 可信度审核：检查造型是否基于「功能→结构→造型」逻辑？所有元素是否贴合角色人设？
        □ 情绪优先审核：检查形状语言、元素设计是否服务于角色情绪与叙事表达？
        □ 交叉自检审核：所有输出内容是否已通过 Skill 合规审计报告自检
        □ 落地适配审核：检查设计是否匹配短剧/动画/游戏的应用场景？
        □ 技术实现审核：检查是否考虑了PBR材质、拓扑约束的可实现性？

    避坑红线检查：
        □ 同质化检查：是否避免通用化、模板化设计？
        □ 无逻辑检查：是否有无功能支撑的造型堆砌？
        □ 脱离场景检查：是否避免脱离应用场景的纯自嗨设计？
        □ 过度堆砌检查：是否避免为炫技添加无意义细节？
        □ 多记忆点检查：是否避免试图实现多个亮点（应单点极致）？

    📐 五问法落位合规检查（口径见 aesthetic-vision-skill §二·单一权威）：
        □ 五问法（📐Q1-Q5）若出现，须位于产物的【人读层 / 元数据标注区】（如「📐 视觉美学意图声明」章节）→ 允许且推荐，不得据此扣分
        □ 🔴 五问法不得混入喂给生图模型的【中文描述段】/【英文描述段】正文 → 混入即该项 FAIL（生图正文须为纯画面描述）

    人物造型提示词（每个人物单独评分 1-10）
        评分维度：
        □ 与导演一致性：逐个对照导演人物清单中的外观关键词，提示词是否完整覆盖？有无遗漏或偏离？具体列出不一致的地方。
        □ 辨识度（脑内预演）：想象生成出来的图，这个角色能否一眼与其他角色区分开？如果是配角/路人，是否有足够的视觉差异化？
        □ 核心记忆点（工业级）：提示词中是否贯穿了1个核心视觉记忆点？能用一句话描述清楚吗？
        □ 形状语言（工业级）：提示词中体现的形状语言（圆/方/三角/S曲线/锯齿线）是否与角色情绪匹配？
        □ 描述精确性（脑内预演）：提示词中是否有歧义表达，可能导致文生图工具生成偏离预期的结果？具体指出哪句话可能有歧义。
        □ 细节完整性：面部、发型、体型、服装（款式/颜色/材质）、配饰、鞋子是否都有具体描述？缺哪个列出来。
        □ 风格匹配：提示词是否明确匹配项目的视觉风格（如 3D CG）？生成结果是否会偏向其他风格？
        □ 格式可执行：提案板六区块指令（16:9 + 中性灰背景 + 区块A主视觉+身高刻度尺 / B全身5视图转面 / C头部6视图 / D情绪肖像 / E服装拆解 / F HSB色板）是否清晰？能否直接复制到文生图工具使用？

        评分标准：
        - 9-10：提示词精准，脑内预演生成效果完全符合导演预期，无需修改
        - 7-8：基本到位，但有 1-2 处可能导致生成偏差的地方
        - 5-6：有明显的遗漏、偏离或歧义，需要修改
        - 1-4：提示词严重不足或与导演意图冲突

    场景环境提示词——宫格整体评分（1-10）
        说明：场景提示词采用宫格格式（≤9场景用3×3，10-12用3×4，13-16用4×4），每格一个场景。审核时先逐格检查，再整体评分。

        工业级维度（新增）：
        □ 空间逻辑：场景的空间布局是否合理？是否考虑了3D坐标锚点？
        □ 材质规范：场景中4种主要材质是否标注？材质描述是否具体可执行？

        逐格检查维度（每个格子/场景逐一检查）：
        □ 与导演一致性：该格场景是否对应导演场景清单中的某个场景？光线/色调/氛围描述是否完整覆盖？有无遗漏或偏离？
        □ 氛围传达（脑内预演）：想象生成出来的该格画面，氛围是否与导演讲戏本中该场景的情绪匹配？
        □ 空间清晰度（脑内预演）：该格描述的空间布局是否清晰？在宫格的小尺寸内是否能看清主要元素？
        □ 关键元素完整：导演讲戏本中提到的重要视觉元素是否在该格中有体现？

        宫格整体检查维度：
        □ 场景覆盖完整性：导演场景清单中的所有场景是否都在宫格中有对应格子？有无遗漏？
        □ 宫格规格正确性：场景数量与宫格规格是否匹配（≤9用3×3，10-12用3×4，13-16用4×4）？空格处理是否正确？
        □ 格间风格一致性（脑内预演）：想象生成出来的整张宫格图，所有格子的视觉风格是否统一？色彩体系是否协调？会不会出现某一格风格突兀？
        □ 风格匹配：整体是否明确匹配项目的视觉风格？
        □ 格式可执行：整段提示词能否直接复制到文生图工具生成一张完整的宫格图？

        评分标准：
        - 9-10：所有场景覆盖完整，逐格检查无问题，格间风格统一，脑内预演整张宫格图效果符合导演预期
        - 7-8：基本到位，但有 1-2 格存在氛围偏差或细节不足
        - 5-6：有明显的场景遗漏、格间风格不统一、或多格氛围偏离
        - 1-4：场景覆盖严重不全，或宫格格式错误

    跨集一致性（ep02+ 时检查，不评分）
        □ 复用素材是否正确标注为已有（不重复设计）？
        □ 变体素材是否标注了与原版的关联和差异？
        □ 新设计的角色/场景风格是否与已有素材协调？

    增强模式审核（启用高精度模式时额外检查）
        人物提示词增强内容：
        □ 材质与工艺细节块是否完整？（4种关键材质）
        □ 每种材质是否标注了材质名称和特性？
        □ 提案板六区块指令是否清晰？（区块A主视觉+身高刻度尺 / B全身5视图转面 / C头部6视图 / D情绪肖像 / E服装拆解 / F HSB色板）
        □ 高精度指令是否包含？（如 AAA game quality）

        场景提示词增强内容：
        □ 材质与工艺规范块是否完整？（4种主要材质）
        □ 光影规范块是否完整？（主光源、辅助光、光影逻辑）
        □ 每个场景格子是否标注了关键材质？
        □ 材质描述是否具体可执行？（如"红木材质，做旧处理"而非"木材"）

[输出规范]

    五维评分规则（工业级标准 - 必须执行）：
        剧情连贯性评分（0-100分）：
        □ 人物造型与角色设定是否一致？（0-33分）
        □ 造型变化是否有剧情铺垫？（0-33分）
        □ 人物外观是否与导演意图匹配？（0-34分）

        分镜连贯性评分（0-100分）：
        □ 镜头切换是否流畅自然？（0-33分）
        □ 镜头之间的空间关系是否合理？（0-33分）
        □ 视线匹配和轴线是否保持一致？（0-34分）

        场景完整性评分（0-100分）：
        □ 场景宫格是否覆盖所有需要的场景？（0-33分）
        □ 场景描述是否与导演场景清单一致？（0-33分）
        □ 格间风格是否统一协调？（0-34分）

        工业级审核评分（0-100分）：
        □ 辨识度：是否提炼了1个核心记忆点？（0-25分）
        □ 可信度：造型是否基于功能→结构→造型逻辑？（0-25分）
        □ 情绪优先：形状语言是否服务情绪表达？（0-25分）
        □ 交叉自检：是否已通过 Skill 合规审计报告自检？（0-25分）
        □ 避坑检查：是否有同质化/无逻辑/脱离场景问题？（0-25分）

        T0标准合规评分（0-100分）· 对齐电影级角色提案板（六区块·2026-05-31 唯一标准）：
        □ 横版16:9 + 中性灰提案板背景：是否含 "horizontal large-format 16:9" + "neutral gray #BEC1C4~#C7CACD"（非纯白/纯黑/无场景元素）？（0-20分）
        □ 六区块版面声明：是否含 顶部细条 + 区块A/B/C/D/E/F 完整？（0-20分）
        □ 主视觉 + 转面多视图：区块A 85mm全身立像（+金色身高刻度尺）+ 区块B 正/3·4正侧/纯侧/3·4背/背 五视图？（0-20分）
        □ 头部研究 + 情绪肖像 + 服装拆解 + 色板：区块C 头部6视图、区块D 情绪肖像、区块E 4-6张材质微距、区块F HSB色板（≥4色含HEX）？（0-20分）
        □ 渲染参数：是否包含 PBR / AO / SSS / UE5 / Octane 等参数（≥2项）？（0-20分）

        通过标准：
        - 剧情连贯性 ≥ 95分
        - 分镜连贯性 ≥ 95分
        - 场景完整性 ≥ 95分
        - 工业级审核 ≥ 95分
        - T0标准合规 ≥ 95分
        - 任一维度低于95分 → 业务审核 FAIL
        - 🔴 校验报告门禁：未附 t0-validator（角色/场景/道具）或 pitch-board-validator（提案板）通过报告 → 直接 FAIL（见审核流程第五步）

[诊断指南]

    如果在服化道审核过程中遇到问题，请用以下问题自我诊断：

    Q: 审核效率低？
    A: 先建立整体理解，再逐项比对，最后脑内预演。顺序不能乱。

    Q: 一致性检查不准确？
    A: 逐个对照导演清单中的外观关键词，检查是否有遗漏、偏离或矛盾。

    Q: 脑内预演效果不佳？
    A: 想象把提示词丢进文生图工具，生成结果是否与预期一致。

    Q: 场景宫格审核无从下手？
    A: 先逐格检查单个场景，再整体检查格间一致性。

    Q: 变体/复用标注混乱？
    A: 确认复用素材是否正确标注，变体是否标注了与原版的差异。

    Q: 增强模式审核遗漏项？
    A: 检查材质块（4种）、光影规范块、提案板六区块（区块A主视觉+身高刻度尺 / B全身5视图转面 / C头部6视图 / D情绪肖像 / E服装拆解 / F HSB色板）是否完整。

    Q: 评分标准不统一？
    A: 使用统一标准：9-10=无需修改，7-8=小问题，5-6=需大改，1-4=无法使用。

    Q: 输出格式不规范？
    A: 严格按照PASS/FAIL格式，确保修改优先级清晰。

[三维评分规则]

    设计质量评分（0-100分）：
    □ 辨识度/可信度/情绪感是否达标？（0-33分）
    □ 实操性/可行性是否通过？（0-33分）
    □ T0提示词是否可直接生成？（0-34分）

    一致性评分（0-100分）：
    □ 设计是否与导演要求一致？（0-33分）
    □ 多角色间风格是否统一？（0-33分）
    □ 设计是否与题材风格匹配？（0-34分）

    工业规格评分（0-100分）：
    □ 多视图是否齐全？（0-33分）
    □ 材质/PBR参数是否标注？（0-33分）
    □ 3D建模可行性是否验证？（0-34分）

    通过标准（C级审核类，参考 skills/templates/quality-threshold-standard.md）：各项 ≥ 90分
