# 视觉语言逻辑审核技能

[技能说明]
    审核 visual-language-logic 在导演讲戏本和分镜提示词中的应用产出，确保：
    1. 连贯性逻辑正确（轴线/视线/30度/动作匹配）
    2. 表现性逻辑合理（景别/角度/焦距/景深选择）
    3. AI视频适配性达标（运镜复杂度/转场/特效可行性）
    4. 镜头序列的叙事节奏合理

    本审核技能必须参考：
    1. skills/visual-language-logic/SKILL.md：了解25+视觉语法原则
    2. resources/unified-audiovisual-language-library.md：视听语言标准
    3. skills/compliance-review-skill/SKILL.md：合规检查
    4. 按需查阅（电影摄影三件套 — 审核光影叙事与色温对应关系时参考）：
       - resources/电影摄影-主文件(技法+设备+工作流程).md（色温/光比与情绪映射的技法规范）
       - resources/电影摄影-40+代表作视觉分析.md（代表作光影参数，验证色温K值与情绪是否匹配）

    调用方 Agent：
    - agents/director.md：导演 Agent 执行审核
    - agents/storyboard-artist.md：分镜师 Agent 自审

[审核边界划界 — 与 seedance-prompt-review-skill 分工（避免重复/漏审）]

    本 skill 与 seedance-prompt-review-skill 在视听语法上存在交叉。为消除「双重 FAIL」与「互相以为对方已查 → 漏审」，按下表明确分工：

    ① 本 skill 独审项（分镜 skill 不深查，本 skill 必须查）：
       - 25+ 视觉语法原则的「原理正确性」与「叙事增值」（库里肖夫效应、视觉母题、负空间/权力构图、焦段隐喻的语义层是否成立）
       - 镜头序列的蒙太奇逻辑、景别金字塔节奏（建置→解构→深入→高潮）的理论层评估
       - 导演讲戏本阶段（分镜生成之前）的视听语言应用质量
       - 光影叙事与情绪/色温(K值)的语义匹配是否成立

    ② 分镜 skill（seedance-prompt-review-skill）已覆盖项（本 skill 不重复深判，避免双重 FAIL）：
       - 机读层翻译审计 / 术语零残留（seedance-review 第二步B 独占）
       - Protocol A–F：零代词 / 视觉法医 / 防融图物理锚点 / 音效层（seedance-review 第二步G 独占）
       - 时长校验门禁（00-duration-sovereign-report.md，seedance-review 第二步H 独占）
       - 素材对应表 / @图片引用完整性（seedance-review 验收清单独占）
       - 单条 1–10 质量评分 + 剧情/分镜/场景三维连贯性（seedance-review 独占）

    ③ 交叉项（两边都查，口径必须一致；结论冲突时以分镜 skill 的「可执行性」为交付终判）：
       - 轴线原则 / 视线匹配 / 30度原则 / 屏幕方向一致性 / 景别变化 / 光影叙事
       - 本 skill 侧重「原理与叙事动机是否成立」；seedance-review 侧重「机读层是否可落地执行」
       - 同一问题不得两边各记一次 FAIL；以分镜 skill 终判为准，本 skill 仅在「原理性错误且无叙事目的」时独立判 FAIL

    🔴 台词零删减交叉项（与 CLAUDE.md「台词零删减铁律」一致 — 优先级最高）：
       - 审核声音设计（J-Cut / L-Cut / 声画对位 / 声音蒙太奇）时，严禁以「精简/删减/合并对白」作为优化节奏的手段
       - 台词字数超出某时间段容量时，只允许给出以下三类建议：① 扩展该段时长 ② 拆分为多个时间段 ③ 调整语速标注
       - 🔴 FAIL 条件：审核意见中出现「删减/合并/改写台词」类建议 → 该条审核意见作废 + 本 skill 输出判 FAIL（不得放行）

[审核流程]

    第一步：连贯性逻辑审核
        | 检查项 | 标准 |
        |--------|------|
        | 轴线原则 | 对话/对峙镜头是否保持180度轴线 |
        | 视线匹配 | 正反打视线方向是否正确 |
        | 30度规则 | 相邻镜头切换是否≥30度变化 |
        | 动作匹配 | 跨镜头动作是否连续不跳跃 |
        | 空间一致 | 环境元素是否前后一致 |

    第二步：表现性逻辑审核
        | 检查项 | 标准 |
        |--------|------|
        | 景别选择 | 景别是否服务于叙事目的 |
        | 角度含义 | 俯仰角度是否传达正确的权力/情绪关系 |
        | 景别变化 | 是否有远/中/近/特写的合理变化 |
        | 节奏控制 | 镜头时长是否与情绪强度匹配 |

    第三步：AI适配性审核
        | 检查项 | 标准 |
        |--------|------|
        | 运镜复杂度 | 运镜是否在AI生成能力范围内 |
        | 转场方式 | 转场是否使用AI支持的方式 |
        | 特效可行性 | 视觉效果是否可AI生成 |
        | 平台适配 | 是否适配目标平台（Seedance/Kling） |

    第四步：叙事节奏审核
        | 检查项 | 标准 |
        |--------|------|
        | 景别金字塔 | 是否遵循建置→解构→深入→高潮节奏 |
        | 呼吸感 | 是否有适当的视觉休息 |
        | 蒙太奇逻辑 | 多镜头段落是否有因果关系 |

[评分表格式]

    三维评分规则（必须执行）：

    视觉语法正确性评分（0-100分）：
    □ 连贯性逻辑（轴线/视线/30度）是否正确？（0-33分）
    □ 表现性逻辑（景别/角度）是否合理？（0-33分）
    □ 叙事节奏是否流畅？（0-34分）

    AI适配性评分（0-100分）：
    □ 运镜/转场是否在AI能力范围内？（0-33分）
    □ 特效描述是否可生成？（0-33分）
    □ 平台适配语法是否正确？（0-34分）

    专业深度评分（0-100分）：
    □ 视觉语法运用是否有创意？（0-33分）
    □ 镜头组合是否产生叙事增值？（0-33分）
    □ 是否避免了常见视觉语法错误？（0-34分）

    通过标准（C级审核类 — 阈值以 skills/templates/quality-threshold-standard.md 为唯一权威来源）：三维各项 ≥ 95分
    （说明：quality-threshold-standard.md 将所有 *-review-skill 三维评分通过线统一定为 C级 ≥95；本行与下方 [PASS/FAIL 标准] 的 95 阈值一致，禁止硬编码其它数值）

[PASS/FAIL 标准]

    PASS 条件：
    - 三维评分各项 ≥ 95分
    - 无轴线违规（除非有叙事目的）
    - 合规审核通过

    FAIL 条件（任一满足）：
    - 轴线严重违规且无叙事目的
    - 整段镜头序列无景别变化
    - 运镜全部超出AI生成能力
    - 合规审核未通过

[诊断指南]

    Q: 轴线违规判断标准？
    A: 检查对话/对峙场景中摄像机是否始终在两人连线同一侧。若越轴，必须标注叙事目的（如制造混乱感）。无目的越轴=FAIL。

    Q: 30度原则如何验证？
    A: 检查同一主体的连续两个镜头，机位角度变化是否≥30度。<30度会产生"跳帧"感，除非是刻意跳剪（需标注）。

    Q: 景别选择不当怎么识别？
    A: 对照金字塔法则：建置(全景)→解构(中景)→深入(过肩)→高潮(特写)。如果全程特写无建置=空间关系不明；全程全景无特写=情绪传达缺失。

    Q: AI运镜超出能力范围？
    A: Seedance支持：推/拉/摇/环绕/跟随。不支持：希区柯克变焦(Dolly Zoom)、精密纪实手持抖动、多轴复合运动。超出能力的运镜需简化或拆分。

    Q: 声音设计缺失怎么处理？
    A: 检查是否包含J-Cut/L-Cut标注。对话场景无声音设计=扣分。关键情绪转折处应有声画对位/声画分离设计。

    Q: 视线匹配错误如何定位？
    A: 检查"角色A看向画外→下一镜是否展示A看到的内容"。若缺失POV镜头且未标注"故意留悬念"=视线契约违约。

    Q: 节奏太平怎么诊断？
    A: 检查是否有"建立-打破"模式（短-短-短-长）。连续5个以上相同时长镜头=节奏疲劳，需插入变化。

    Q: 光影叙事与情绪矛盾？
    A: 暖光场景不应传达恐惧，冷光场景不应传达温馨。检查色温(K值)与情绪的对应关系。

[常见审核案例]

    PASS案例：
    - 对话场景严格遵守180度轴线，正反打视线方向正确
    - 全景→中景→特写遵循金字塔法则，节奏有明确起伏
    - 运镜均在Seedance/Kling能力范围内，无超纲要求
    - 声音设计完整：J-Cut用于悬念过渡，L-Cut用于情绪延续

    FAIL案例：
    - 对话场景两人都看向画面右侧（越轴导致空间崩塌）
    - 全集15条提示词全部使用中景，无景别变化
    - 要求"希区柯克推拉变焦+360度环绕+手持抖动"复合运镜，AI无法执行
    - 恐怖场景使用暖橘色调（3000K），与情绪严重矛盾

[术语表]

    | 术语 | 英文 | 定义 |
    |------|------|------|
    | 轴线原则 | 180-Degree Rule | 摄像机保持在角色连线同一侧 |
    | 30度原则 | 30-Degree Rule | 连续切镜角度变化≥30度 |
    | 金字塔法则 | Coverage Pyramid | 建置→解构→深入→高潮的景别递进 |
    | 视线匹配 | Eyeline Match | 角色看画外→下一镜展示看到的内容 |
    | 库里肖夫效应 | Kuleshov Effect | 通过反应镜头拼接产生新意义 |
    | 动接动 | Matching on Action | 动作进行中（70%处）切换镜头 |
    | 声画对位 | Audiovisual Counterpoint | 声音与画面表达相反情绪 |
    | 推拉变焦 | Dolly Zoom | 主体不变但背景透视扭曲的心理效果 |
    | 视觉母题 | Visual Motif | 贯穿全片的重复视觉元素 |
    | 负空间 | Negative Space | 画面中主体周围的空白区域 |

[学习路径]

    📚 第一阶段：连贯性审核 (1周)
    - 掌握轴线/视线/30度/屏幕方向四大连贯性原则
    - 练习识别越轴和视线匹配错误
    - 熟悉AI平台运镜能力边界

    📚 第二阶段：表现性审核 (1周)
    - 掌握景别选择与金字塔法则
    - 学会判断焦段隐喻是否与情绪匹配
    - 练习光影叙事审核

    📚 第三阶段：节奏与声音审核 (1周)
    - 掌握镜头时长与信息密度的关系
    - 学会识别节奏疲劳和"建立-打破"模式
    - 练习J-Cut/L-Cut/声画对位审核

    📚 第四阶段：综合实战 (持续)
    - 参与实际项目视听语言审核
    - 积累平台特定问题库
    - 掌握跨镜头连贯性整体评估

[合规检查项]

    视听语言审核中的合规注意事项：
    - [ ] 暴力场景是否使用留白逻辑（影子+反应镜头），避免直接暴力
    - [ ] 构图是否无歧视性暗示（如刻意矮化特定群体）
    - [ ] 色温对立不涉及政治敏感符号
    - [ ] 声音设计无违禁音效
    - [ ] 镜头语言无性暗示构图
