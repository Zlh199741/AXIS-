# 故事卡桥梁技能

## 技能说明

建立故事卡系统（McKee结构）与短剧集纲生成之间的桥梁，实现双向增强：

1. **正向增强**：在集纲生成中融入故事卡结构，提升剧情深度
2. **逆向增强**：集纲产出可反向输出为故事卡格式，供后续使用

## 核心原理

### 故事卡与集纲的对应关系

| 故事卡层级 | 集纲层级 | 说明 |
|-----------|---------|------|
| 幕 (Act) | 本章全集 | 完整故事 |
| 序列 (Sequence) | 动态集数段 | 情绪段落 |
| 事件 (Event) | 单集 | 核心冲突 |
| 节拍 (Beat) | 场景 | 镜头/动作 |

### 故事卡类型映射

| 故事卡类型 | 集纲应用 | 示例 |
|-----------|---------|------|
| 中故事卡 | 集线器主题 | 崛起之路、成长、爱情故事 |
| 小故事卡 | 单集爽点 | 装逼、打脸、英雄救美 |
| 戏剧卡 | 叙事技巧 | 信息差、反差、陷阱 |

### McKee 五节点强制字段（🔴 硬性字段 — 与 story-card-bridge-review-skill 强制项对齐）

> 依据 skills/templates/quality-threshold-standard.md v1.2「桥接/结构类」规则：生成端必须满足配对 review 的硬性项，避免系统性 FAIL。无论正向（故事卡→集纲）还是逆向（集纲→故事卡），产出都必须显式包含以下五节点，缺一即不合格：

| McKee 节点 | 强制字段要求 | 配对 review 判定 |
|-----------|-------------|-----------------|
| 激励事件 | 必须不可逆、迫使主角行动 | 缺失/可逆 → FAIL |
| 进展纠葛 | 数量 ≥5，且压力逐个升级 | <5 → P1 |
| 危机 | 必须为真正两难（两个选择都有重大代价） | 明显正确选择 → P0 |
| 高潮 | 必须由主角行动（选择/牺牲/觉醒）解决，禁止巧合/天降/外力 | 巧合解决 → P0 |
| 结局 | 必须建立新平衡 | 缺失 → FAIL |

## 工作流

### 方向一：故事卡 → 集纲

#### 输入
- 故事卡大纲（来自 剧本/故事卡/故事卡大纲.md）

#### 执行步骤

1. **解析故事卡结构**
   - 提取幕主题
   - 提取序列故事卡
   - 提取阶段目标

2. **映射到集纲**
   - 幕主题 → 整体故事梗概
   - 序列 → 集数分组（按三段式动态划分）
   - 事件 → 单集剧情
   - 节拍 → 场景/镜头

3. **融入3-10-60情绪循环**
   - 序列首集 → 3秒钩子强化
   - 序列中段 → 1分钟爽点
   - 序列末集 → 卡点钩子

4. **输出集纲**
   - 格式：short-drama-outline
   - 同时保留故事卡结构引用

#### 输出格式

```markdown
# {项目名} - 集纲

## 故事卡来源
- 幕故事卡：{幕故事卡}
- 序列故事卡：{序列列表}

## 宏观故事
{故事梗概}

## 集纲

### 前1/3集数（序列1：{序列故事卡.1}）
...

### 升级期（后1/3集数）（序列3：{序列故事卡.3}）
...
```

### 方向二：集纲 → 故事卡

#### 输入
- 集纲（short-drama-outline）

#### 执行步骤

1. **解析集纲结构**
   - 提取每集核心冲突
   - 提取情绪循环要素
   - 提取人物关系

2. **映射到故事卡**
   - 整体主题 → 幕故事卡
   - 集数分组 → 序列故事卡
   - 单集内容 → 事件/节拍

3. **补充戏剧卡**
   - 分析每集的叙事技巧
   - 标注使用的戏剧卡类型

4. **输出故事卡**
   - 格式：McKee结构
   - 包含转折点标注

#### 输出格式

```markdown
# {项目名} - 故事卡

## McKee 五节点（强制 — 缺一不合格）
- 激励事件：{不可逆事件，迫使主角行动}
- 进展纠葛：{≥5个，逐个升级}①… ②… ③… ④… ⑤…
- 危机：{真正两难，两个选择都有重大代价}
- 高潮：{由主角行动解决，非巧合}
- 结局：{建立新平衡}

## 幕故事卡
{幕主题}

## 序列故事卡

### 序列1（前1/3集数）
- 序列故事卡：{序列主题}
- 阶段目标：{目标描述}
- 序列戏剧卡：{使用的戏剧技巧}

### 序列2（中1/3集数）
...

## 事件结构

### 第1集
- 事件概要.1.1：{起因}→{转折}→{结果}
- 事件概要.1.2：...
- 转折点：{大/中/小}转折，{正面/负面}，{XX%}

### 第2集
...
```

- McKee 五节点强制字段齐全：激励事件 / 进展纠葛≥5 / 危机两难 / 高潮非巧合 / 结局新平衡（缺一不合格，与 story-card-bridge-review-skill 强制项对齐）

## 诊断指南

Q: 故事卡与集纲结构不匹配怎么办？
A: 以集纲为主，故事卡作为辅助参考

Q: 缺少转折点信息怎么办？
A: 基于集纲内容反向推导

Q: 如何保证差异化？
A: 在映射过程中加入创新元素

[PASS/FAIL 标准]

    PASS 条件（必须全部满足）：
    - 故事卡覆盖完整（100%）
    - 转折点标注清晰（大/中/小 + 方向 + 百分比）
    - 情绪循环完整（每集包含3秒钩子+1分钟爽点+卡点）
    - 产出三维质量标准各项 ≥ 95分

    FAIL 条件（任一满足）：
    - 故事卡覆盖率 < 80%
    - 转折点标注缺失 > 30%
    - 情绪循环严重不完整
    - 产出三维质量标准任一维度 < 95分

[产出三维质量标准]

    结构映射评分（0-100分）：
    □ 故事卡与集纲的对应关系是否正确？（0-33分）
    □ 转折点标注是否完整？（0-33分）
    □ 序列划分是否合理？（0-34分）

    情绪设计评分（0-100分）：
    □ 3-10-60情绪循环是否融入？（0-33分）
    □ 戏剧卡类型标注是否正确？（0-33分）
    □ 序列间情绪递进是否清晰？（0-34分）

    双向一致性评分（0-100分）：
    □ 正向映射（故事卡→集纲）是否完整？（0-33分）
    □ 逆向映射（集纲→故事卡）是否准确？（0-33分）
    □ 双向映射结果是否一致？（0-34分）

    通过标准（B级辅助增强，参考 skills/templates/quality-threshold-standard.md）：各项 ≥ 90分

[合规检查项]
