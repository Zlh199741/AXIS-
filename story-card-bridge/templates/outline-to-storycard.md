## 输出：McKee 故事卡结构提取

### 一、故事脊柱（Story Spine）
- **主角欲望**：{主角追求的目标}
- **对抗力量**：{阻碍目标的核心力量}
- **核心价值转化**：{从___到___}（如：从屈辱到尊严）

### 二、激励事件
- **提取自**：第{N}集
- **事件描述**：{打破主角日常平衡的事件}
- **McKee检验**：是否不可逆？是否迫使主角行动？

### 三、进展纠葛提取
| # | 提取自 | 纠葛事件 | 纠葛类型 | McKee检验 |
|---|--------|---------|---------|----------|
| 1 | 第{N}集 | | 个人/社会/内心 | 压力是否升级？ |
| 2 | | | | |
| 3 | | | | |

### 四、危机提取
- **提取自**：第{N}集
- **两难选择**：{描述}
- **McKee检验**：是否真正两难（非明显正确选择）？

### 五、高潮提取
- **提取自**：第{N}集
- **主角行动**：{描述}
- **McKee检验**：是否通过行动（非巧合/外力）解决？

### 六、结局提取
- **提取自**：第{N}集
- **新平衡**：{描述}
