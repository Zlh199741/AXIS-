# 剧本结构诊断技能

[技能说明]

    1. 爽点密度分析（ABC分析增强版）

## 二、爽点密度分析（ABC增强版）

### 2.1 ABC爽点定义
| 级别 | 爽点类型 | 描述 | 权重 |
|------|----------|------|------|
| A级 | 核心爽点 | 反派被打脸、绝地反击、身份反转 | 3 |
| B级 | 情绪爽点 | 误会解开、实力证明、情感突破 | 2 |
| C级 | 铺垫爽点 | 小胜利、小打脸、日常逆袭 | 1 |

### 2.2 密度计算公式
```
爽点密度 = (A×3 + B×2 + C×1) / 总章节数
理想值：≥ 2.0/章
警告值：< 1.0/章
```

### 2.3 爽点类型识别

**A类爽点标识词**：
- 打脸、反转、秒杀、碾压、揭露真相、身份曝光
- 绝地反击、以弱胜强、跨级挑战、复仇成功

**B类爽点标识词**：
- 误会解除、能力证明、突破、升级、表白成功
- 获得认可、化解危机、收货至宝

**C类爽点标识词**：
- 小胜利、日常、收获、结识新朋友、装备升级
- 学习新技能、获得信息

### 2.4 爽点分布分析
```
章节分布热力图：
0-10章：★★☆☆☆（铺垫期）
11-20章：★★★☆☆（积累期）
21-30章：★★★★☆（高潮期）
31-40章：★★★★★（爆发期）
```

## 三、节奏诊断（3-10-60适配度）

### 3.1 节奏问题识别

| 问题类型 | 表现 | 诊断标准 |
|----------|------|----------|
| 节奏拖沓 | 铺垫过长 | 单章有效信息 < 30% |
| 爽点延迟 | 爽点间隔过大 | 章节间隔 > 5章 |
| 高潮缺失 | 缺少情绪爆发 | 无A类爽点章节 > 30% |
| 卡点薄弱 | 悬念不足 | 章节结尾平淡率 > 50% |

### 3.2 3-10-60适配度评估

**前3秒钩子适配**：
- 检测每章开头3句话是否有强冲突
- 适配度 = 有冲突开头章节 / 总章节数
- 目标值：≥ 80%

**前10秒叙事适配**：
- 检测每章是否在10句话内进入主线
- 适配度 = 快速进入主线章节 / 总章节数
- 目标值：≥ 70%

**1分钟爽点适配**：
- 检测每章是否有明确的情绪释放点
- 适配度 = 有情绪释放章节 / 总章节数
- 目标值：≥ 60%

### 3.3 节奏曲线绘制

```
节奏强度曲线：
第1-5章：▁▂▃▄▅  (渐起)
第6-10章：▅▅▆▇█  (爬升)
第11-15章：█▇▆▅▅  (高潮)
第16-20章：▅▄▃▂▁  (回落)
```

## 四、角色弧光检查

### 4.1 主角弧光完整性

**检查维度**：
| 阶段 | 必需事件 | 缺失风险 |
|------|----------|----------|
| 起点 | 困境/缺陷 | 无成长动机 |
| 触发 | 转折事件 | 无变化契机 |
| 成长 | 挑战/学习 | 成长突兀 |
| 转折 | 重大危机 | 转折乏力 |
| 终点 | 目标达成 | 结局仓促 |

### 4.2 弧光评分标准
```
完整度 = (满足的阶段数 / 5) × 100%
优秀：≥ 80%
良好：60-79%
需改进：< 60%
```

### 4.3 反派弧光检查

**检查项**：
- 是否有明确动机
- 是否有压迫感展现
- 是否有失败倒计时
- 是否有人性复杂度

## 五、改编可行性评估

### 5.1 改编难度评分

| 维度 | 评分标准 | 分值 |
|------|----------|------|
| 爽点密度 | ≥2.0=易，<1.0=难 | 1-5 |
| 节奏适配 | 3-10-60适配度 | 1-5 |
| 角色弧光 | 弧光完整度 | 1-5 |
| 场景集中度 | 核心场景占比 | 1-5 |
| 叙事线性 | 线性/多线/碎片 | 1-5 |

**总分 = Σ(维度分)**
- 20-25分：⭐⭐⭐⭐⭐ 极易改编
- 15-19分：⭐⭐⭐⭐ 适合改编
- 10-14分：⭐⭐⭐ 需调整后改编
- 5-9分：⭐⭐ 较难改编
- 1-4分：⭐ 不建议直接改编

### 5.2 风险识别

| 风险类型 | 识别特征 | 应对建议 |
|----------|----------|----------|
| 节奏过慢 | 章节过长、铺垫过多 | 压缩/删除冗余内容 |
| 场景分散 | 场景切换频繁 | 合并/删减场景 |
| 人物过多 | 超过15个主要角色 | 精简/合并角色 |
| 设定复杂 | 世界观过于庞大 | 简化/聚焦核心设定 |
| 心理过多 | 内心描写占比 > 40% | 外化为动作/对话 |

## 七、诊断指南

Q: 爽点密度太低怎么办？
A: 识别低密度章节，合并小爽点为中爽点，增加打脸反转场景。

Q: 节奏适配度不高怎么办？
A: 增加开头冲突，压缩铺垫内容，每章设置情绪释放点。

Q: 角色弧光不完整怎么办？
A: 为缺失阶段添加关键事件，确保转折有足够铺垫。

Q: 改编可行性低怎么办？
A: 评估是否值得调整，或选择其他更适合改编的作品。

Q: 场景太分散怎么办？
A: 确定核心场景（占比 > 60%），合并/删除边缘场景。

[PASS/FAIL 标准]

    PASS 条件（必须全部满足）：
    - ABC爽点密度 ≥ 每万字3个A级爽点
    - 3-10-60节奏适配度 ≥ 70%
    - 角色弧完整度 ≥ 1条完整弧线
    - 诊断报告完整输出
    - 产出三维质量标准各项 ≥ 95分

    FAIL 条件（任一满足）：
    - A级爽点密度为0
    - 3-10-60适配度 < 50%
    - 角色弧完全缺失
    - 改编风险为“极高”且无替代方案
    - 产出三维质量标准任一维度 < 95分
