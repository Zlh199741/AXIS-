# Kling 2.6 提示词审核技能

[技能说明]
    审核分镜师在阶段三的 Kling 2.6 提示词产出。导演需要以批判性视角审视分镜师的产出，通过逐条比对导演讲戏本、脑内预演 Kling 生成效果、逐条评分的方式，确保提示词质量真正达标，能通过 Kling 2.6 生成符合导演意图的音画视频。

    本审核技能必须参考：
    1. skills/kling-3.0-prompt-review-skill/SKILL.md：了解 Kling 3.0 审核标准
    2. skills/seedance-storyboard-skill/templates/kling-prompt-template.md：了解 Kling 提示词产出规范
    3. resources/unified-audiovisual-language-library.md：确保视听语法一致性
    4. tools/references/sensitive-word-dictionary.md：敏感词检测
    5. 🔴 skills/seedance-storyboard-skill/translation-audit-rules.md：14条人读层→机读层翻译原则 + 翻译审计规范

[审核对象]
    outputs/<集数>/02-kling-prompts.md

[审核流程]

    第一步：建立整体理解
        - 读取导演讲戏本（01-director-analysis.md）
        - 读取角色提示词（assets/prompts/character-prompts.md）和场景提示词（assets/prompts/scene-prompts.md）
        - 读取待审核的 Kling 提示词产出
        - 明确审核立场：你的任务是找出问题，而非确认通过

    第二步：逐条比对
        - 对每条提示词，逐句对照导演讲戏本中对应剧情点的导演阐述
        - 找出导演阐述中有但提示词中被弱化、遗漏或表达偏离的地方
        - 找出分镜师自行添加的、导演阐述中没有的内容，判断是否合理
        - 记录所有偏差，无论大小

    第二步B：🔴🔴🔴 翻译审计检查（一票否决 — 必须在逐条评分之前执行）
        > ⛔ 一票否决规则：翻译审计任一 🔴 项不通过 → 整体直接 FAIL，无需进入后续评分。
        对照 translation-audit-rules.md 中的14条翻译原则，逐条检查机读层：
        - ☐ 术语零残留：机读层是否完全不包含任何专业术语？
          发现术语残留 → 🔴 必须 FAIL
        - ☐ 铟面坐标零残留：是否使用标准位置词汇而非钟面方位数字？
          发现铟面数字 → 🔴 必须 FAIL
        - ☐ 原则覆盖度：每条提示词是否至少使用了4条以上翻译原则？
        - ☐ 审计表存在性与准确性：是否附带翻译审计表且内容准确？
          缺失或不准确 → 🔴 必须 FAIL

    第二步C：🔴 跨产物语义一致性自动化校验（2026-03-24 新增 — 根因修复）
        - 🔴 运行：`python tools/validators/semantic-consistency-validator.py <集数>`
        - 脚本自动比对：导演戏本 vs Kling提示词（动作/情绪/时长覆盖率）+ 角色提示词 vs Kling提示词（引用角色定义一致性）
        - 🔴 脚本报告中有 critical 问题 → 该条直接 FAIL
        - 🟡 脚本报告中有 warning → 人工复核
        - 将脚本报告附入最终审核结论

    第二步D：🔴 原文溯源回查（2026-03-24 新增 — 根因修复）
        - 如果 novel/ 目录存在原文小说文件：运行 `python tools/validators/novel-fidelity-checker.py <集数>`
        - 🔴 角色行为与原文性格/能力矛盾 → 标记为必须修改

    第二步E：🔴 跨平台画镜 Protocol 合规审核（2026-04-10 新增）
        以下规则源自 seedance-storyboard-skill Protocol A/D/E，属跨平台通用铁律，Kling 同样适用。

        **Protocol A — 零代词**
        - ☐ 提示词是否完全无代词（他/她/它/男人/女人/主角/两人/他们）？
          发现任意代词 → 🔴 必须 FAIL
        - ☐ 关键道具是否用 @物品名 引用且描述了空间关系？
          道具未@或无空间关系 → 🟡 需补充

        **Protocol D — 视觉法医（禁止抽象词）**
        - ☐ 提示词是否完全无抽象情绪/氛围词（悲伤/震撼/紧张/压抑/磅礴/凝重等）？
          发现抽象词 → 🔴 必须 FAIL，标注位置并给出具象化替换建议
        - 替换方向：生理微反应（眼眶充血/嘴唇颤抖/手指攥紧）或环境具象（烛火摇曳/茶水波纹）

        **Protocol E — 防融图物理锚点**
        - ☐ 多角色同框场景是否使用物理锚点描述（角色部位+接触物+画面方位）？
          出现笼统描述（如"两人对峙""众人围观"）→ 🔴 必须 FAIL

        **台词完整保留**
        - ☐ 导演讲戏本/剧本中的台词是否 100% 原文保留？
          缺字/改字/合并 → 🔴 必须 FAIL

        判定规则：
        - 🔴 标记项任一命中 → 该条P直接 FAIL
        - 全部🟡累计 ≥ 3项 → 整体 FAIL
        - 本步骤须在脑内预演（第三步）之前完成

    第三步：脑内预演
        - 对每条提示词，想象它被送进 Kling 2.6 后，生成的视频和音频是什么样的
        - 判断：音画是否协同？语音/音效是否与画面动作匹配？
        - 判断：是否有描述方式可能导致 Kling 理解错误？
        - 判断：@引用的参考图加上提示词的动态描述，生成效果是否会自然？
        - 判断：音频设计是否合理？时长选择（5s/10s）是否匹配场景复杂度？

    第四步：逐条评分
        按照下方验收清单，对每条提示词评分（1-10）

    第五步：输出结果
        - 计算所有提示词的平均分
        - 平均分 ≥ 8 且无单项低于 6 → PASS
        - 平均分 < 8 或任一单项低于 6 → FAIL + 问题清单
        - 存在严重连贯性语法错误且非刻意设计 → 必须 FAIL

[验收清单]

    🔴 素材引用（强制评分项 — 缺失即FAIL）
        □ 角色引用：每条P的【主体】是否包含 `参考@图片N` 引用对应角色参考图？
        □ 场景引用：每条P的【场景】是否包含 `参考@图片N` 引用对应场景参考图？
        □ 完整性：是否为所有引用的素材建立了对应关系？
        □ 准确性：素材描述是否与 character-prompts.md / scene-prompts.md 一致？
        □ Kling 特点：Kling 使用单图生视频，每条提示词是否只引用了必要的参考图？
        ❌ 任何一条P缺少角色或场景@参考引用 → 直接判定该条不合格，必须补充

    音频设计检查（核心！逐项评分）
        □ 音频类型正确：根据场景选择合适的音频类型（对话/旁白/环境音/混合音效），禁止唱歌、说唱、BGM及任何可生成音乐内容
        □ 角色标签规范：是否使用 [角色名: 描述] 或 [角色名, 音色描述] 格式？
        □ 情绪标注：每个角色的台词是否标注了情绪？
        □ 音色描述：是否包含音色描述（沉稳男声/清脆女声等）？
        □ 多角色对话：
            - P1. 结构化命名：每个角色是否有唯一且一致的标签？
            - P2. 视觉锚定：是否先描述动作，再接台词？
            - P3. 音频细节：每个角色是否有独特的音色和情绪？
            - P4. 时序控制：是否使用"紧接着"、"这时候说话人切换"等连接词？
        □ 环境音效：场景是否有背景环境音？
        □ 动作音效：关键动作是否有音效标注？

    时长选择（评分项）
        □ 5s 场景：单一动作/快节奏场景是否选择 5s？
        □ 10s 场景：对话/复杂场景是否选择 10s？
        □ 时长与内容匹配：选择的时长是否能完整呈现内容？

    结构化标签（评分项）
        □ 【场景】标签：是否包含时间+光线+地点+空间布局？
        □ 【主体】标签：是否包含角色外观描述？
        □ 【音频】标签：是否包含角色+台词+情绪/音色？

    合规审核（核心检查！逐项必须通过）
        □ 政治敏感：无涉及领导人、敏感历史事件、领土争议等
        □ 黑道/犯罪：无展开描述黑社会、毒品、赌博、色情交易等犯罪细节
        □ 暴力血腥：无详细暴力手段、酷刑、肢解等过度渲染
        □ 软性色情（重点！）：
            - 无性侵、性骚扰、挑逗行为、脱衣勾引等
            - 无性暗示词汇
            - 无性癖好描写
            - 无性器官或性行为的直接/间接描写
        □ 低俗内容：
            - 无脏话/粗口
            - 无"黄赌毒"敏感词
            - 无低俗笑话或双关语
        □ 敏感题材处理：
            - 穿越/系统题材无政治敏感
            - 古代/宫廷题材无过度宫斗暴力
            - 黑道/帮派题材无展开犯罪细节
        □ 台词合规：角色台词无低俗内容，音频描述无违规内容
        □ 场景氛围：危险/暧昧/冲突场景无违规细节

    常见违规词汇对照检查（逐行扫描）：

[评分标准]

    每条提示词评分维度（每项 1-10 分）：

    1. 场景构建（10分）
        - 【场景】标签是否完整（时间、光线、地点、空间布局）
        - 场景描述是否与导演讲戏本一致

    2. 主体呈现（10分）
        - 【主体】标签是否清晰
        - 角色外观描述是否具体
        - @引用是否正确

    3. 音频设计（10分）
        - 音频类型选择是否合适
        - 角色标签、台词、情绪是否完整
        - 环境音效和动作音效是否恰当

    4. 音画协同（10分）
        - 语音节奏是否与画面动作匹配
        - 情绪表达是否一致
        - 时长选择是否合理

    5. 视听语言（10分）
        - 镜头类型和运动是否合理
        - 剪辑节奏是否流畅
        - 叙事是否连贯

    6. 平台规范（10分）
        - 是否遵循 Kling 2.6 提示词规范
        - 是否使用正确的结构化标签
        - 素材引用是否符合平台限制

[输出格式]

    三维评分规则（必须执行）：
        剧情连贯性评分（0-100分）：
        □ 提示词与导演讲戏本的核心情节是否完整对应？（0-33分）
        □ 人物行为动机是否合理连贯？（0-33分）
        □ 剧情转折点是否有足够铺垫？（0-34分）

        分镜连贯性评分（0-100分）：
        □ 镜头切换是否流畅自然？（0-33分）
        □ 镜头之间的空间关系是否合理？（0-33分）
        □ 视线匹配和轴线是否保持一致？（0-34分）

        场景完整性评分（0-100分）：
        □ 场景引用是否覆盖所有需要的场景？（0-33分）
        □ 场景描述是否与导演场景清单一致？（0-33分）
        □ 场景转换是否有逻辑支撑？（0-34分）

        通过标准：
        - 剧情连贯性 ≥ 95分
        - 分镜连贯性 ≥ 95分
        - 场景完整性 ≥ 95分
        - 任一维度低于95分 → 业务审核 FAIL
