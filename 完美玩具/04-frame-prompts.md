# 《完美玩具》分镜场景提示词｜五段结构版

**来源**：`03-text-storyboard.md` 16镜  
**用途**：分镜场景生成提示词，不是角色设定提示词。人物只作为空间占位、尺度关系和动作方向出现，角色外观调用角色资产文件。  
**固定五段结构**：场景空间 / 陈设道具 / 镜头构图 / 光影氛围 / 生成禁忌  
**全局空间轴**：前景猩红波斯地毯与冷金锁链 → 中景江烬跪位 / 三厘米触点 → 后景墨绿色丝绒王座与司遥 → 上方虚空代码层 / 银蓝UI权限面板。  
**全局禁忌**：无烟、无开放伤口、无真实血腥、无字幕水印、无乱码文字、无额外人物；左右关系不可翻转；破碎王冠项圈与冷金锁链不可消失。

---

## P01 开场锁链·暴君抬眸

### 镜001｜地面微距｜2s

1. **场景空间**：暗黑王座驯化厅的地面前景，猩红波斯地毯铺满画面，空间高度被压到极低，后方深黑墙板只作为模糊压迫背景。
2. **陈设道具**：冷金粗重锁链从画面左下拖入，椭圆链节压倒厚绒纤维，地毯被刮出连续深痕；左侧只露低矮烛台的一截暖边光。
3. **镜头构图**：100mm 贴地微距，镜头沿链条拖拽方向低速横移，画面不出现人物，只让锁链和地毯建立第一秒钩子。
4. **光影氛围**：猩红暗绒、冷金金属、深黑墙板；左侧暖烛光只擦链节上缘，顶部冷白窄光切出硬反光。
5. **生成禁忌**：禁止人物入镜、禁止烟、血、字幕、水印、乱码、额外道具；锁链必须有重量和压痕，不可轻飘。

### 镜002｜低机位中景｜2s

1. **场景空间**：镜头从前景地毯锁链推进到中景阴影跪位，再指向后景墨绿王座脚边，完整建立“地毯锁链 → 中景受控位 → 后景王座”的纵深轴。
2. **陈设道具**：冷金链节在地毯上形成连续受力线，破碎王冠项圈连接环作为锁链终点入画，后景墨绿王座脚边只露暗轮廓。
3. **镜头构图**：35mm 低机位中景，沿锁链方向快速上移；江烬只作为中景偏下跪位占位，角色外观调用角色资产，不在场景提示词内展开。
4. **光影氛围**：顶部冷白窄光切到项圈连接环与锁链硬面，左侧烛光退成边缘弱光，整体压出暗黑帝王驯化厅的冷硬秩序。
5. **生成禁忌**：禁止破坏前景到后景的锁链方向；禁止烟、开放伤口、字幕、水印、乱码；禁止把王座放到前景。

### 镜003｜面部中景｜0.5s

1. **场景空间**：暗黑王座厅中景局部，背景王座与墙板压成深黑阴影，只保留江烬肩颈占位与项圈所在的空间压力。
2. **陈设道具**：破碎王冠项圈冠齿、冷金连接环、撕裂布料边缘只作为场景关系道具出现；地毯与锁链方向隐约延续在下方。
3. **镜头构图**：85mm 中景局部，画面框住肩颈、下颌、项圈和半遮眼位，背景不抢焦点。
4. **光影氛围**：冷白窄光落在喉结、项圈边缘、下颌线，眼部上方保留睫毛阴影，整体是冷白与暗金属的压迫感。
5. **生成禁忌**：禁止怪物化、兽化、伤口化；禁止烟、血、字幕、水印、额外人物；背景不可明亮。

### 镜004｜中景硬停｜0.5s

1. **场景空间**：中景受控位与后景王座形成对峙，司遥不入镜，权力只通过后景墨绿王座轮廓、锁链方向和空间阴影存在。
2. **陈设道具**：破碎王冠项圈连接环与冷金锁链保持可见，后景墨绿丝绒王座高背只露暗色轮廓。
3. **镜头构图**：85mm 中景硬停，江烬抬眸占位在画面中下方，王座在后景中央偏上形成压制关系。
4. **光影氛围**：顶部冷白窄光命中眼位和项圈连接环，后景墨绿暗影压住空间，画面像被瞬间钉住。
5. **生成禁忌**：禁止司遥提前入镜；禁止烟、开放伤口、字幕、水印、乱码；禁止左右翻转锁链方向。

## P02 王座宣告·主仆阶级

### 镜005｜低位仰拍中景｜4s

1. **场景空间**：暗黑王座驯化厅后景中央，墨绿色丝绒王座占据上位空间，前景王座脚边与地毯形成低位仰视入口。
2. **陈设道具**：冷金高跟鞋、链端、墨绿丝绒王座、暗金扶手、祖母绿宝石反光、低矮烛台、厚重墨绿窗帘共同构成女帝级王座场。
3. **镜头构图**：35mm 低位仰拍，从王座脚边鞋尖与链端向上抬，司遥只作为后景王座上位占位，角色外观调用角色资产。
4. **光影氛围**：左侧烛火暖光擦过唇釉与暗金额冠边缘，顶部冷白光压出肩铠宝石冷反，墨绿、暗金、祖母绿形成高贵压迫。
5. **生成禁忌**：禁止偏离墨绿王座与女帝级仪式空间；禁止烟、字幕、水印、额外人物；禁止司遥惊慌或后退。

### 镜006｜王座中景｜5s

1. **场景空间**：王座中景锁定司遥所在的后景上位区，画面中心是王座、链端和手腕区域，下方空间暗示江烬受力位。
2. **陈设道具**：冷金锁链松弧绕过黑金链条手套，暗金扶手、墨绿丝绒椅背、烛台暖边光和厚窗帘保持原位。
3. **镜头构图**：50mm 稳定王座中景，轻微压近手腕链端与唇部方向；对白只作为配音，不生成画面文字。
4. **光影氛围**：暖烛光在红豆沙玻璃唇釉方向形成细反光，冷白顶光切手套链条，暖唇光与冷金链光对比。
5. **生成禁忌**：禁止对白字幕、文字气泡、乱码；禁止烟、额外人物、左右翻转；链条必须从王座上位区延伸向下方。

### 镜007｜链条中景｜5s

1. **场景空间**：画面以王座厅中轴的冷金锁链为主，连接后景司遥手腕与中景偏下江烬受控位。
2. **陈设道具**：冷金锁链从松弧变成绷直线，猩红地毯在链条下方被压暗，破碎王冠项圈连接环作为受力终点。
3. **镜头构图**：50mm 链条中景，沿绷紧锁链从司遥手腕切到江烬项圈方向，突出拉力传递。
4. **光影氛围**：冷白窄光沿锁链形成一条硬亮线，地毯暗红被压到低饱和，金属反光干净锋利。
5. **生成禁忌**：禁止锁链断开、消失或方向混乱；禁止烟、开放伤口、字幕、水印；人物不得脱离既定空间位置。

### 镜008｜交叉中景｜6s

1. **场景空间**：王座上位区、破碎王冠项圈细节区、司遥脚边链条区、江烬中下方视线区形成四点空间切换。
2. **陈设道具**：墨绿王座、暗金细链额冠反光、肩铠祖母绿、破碎王冠项圈连接环、冷金高跟鞋、猩红地毯链条共同构成阶级关系场。
3. **镜头构图**：85mm 交叉中景，切换王座、项圈连接环、鞋尖与链条、江烬抬眼方向；对白只作为配音，不生成字幕。
4. **光影氛围**：司遥所在王座区吃暖烛光，项圈和江烬眼位吃冷白顶光，暖金王座与冷白项圈形成权力切割。
5. **生成禁忌**：禁止字幕、文字气泡、乱码；禁止江烬低头臣服、司遥后退、烟、开放伤口、额外人物。

## P03 三厘米扑近·破碎王冠项圈拉扯

### 镜009｜中景突进｜4s

1. **场景空间**：暗黑王座厅三层空间被瞬间拉紧：前景猩红地毯与锁链，中景江烬冲出方向，后景墨绿王座稳定不动。
2. **陈设道具**：冷金锁链从弧形抖动迅速拉直，猩红地毯被脚掌与链条压出受力痕，后景王座、烛台、厚窗帘保持稳定。
3. **镜头构图**：35mm 中景突进，镜头轻微后撤以保留前景锁链、中景冲刺位、后景王座三层空间。
4. **光影氛围**：冷白顶光在眼位、破碎王冠项圈、锁链形成三处硬高光，墨绿王座压住后景，不被冲击打乱。
5. **生成禁忌**：禁止司遥惊慌后退；禁止江烬脱链；禁止烟、开放伤口、字幕、水印、额外人物；冲刺方向必须指向后景王座。

### 镜010｜中景硬停｜5s

1. **场景空间**：江烬被截停在司遥面前三厘米外，王座厅空间在近距离处形成危险压缩，后景王座仍是稳态权力源。
2. **陈设道具**：破碎王冠项圈前端连接环被冷金锁链拉住，司遥膝侧墨绿帝裍裙摆、冷金鞋尖、黑金手套边光保持不动。
3. **镜头构图**：50mm 中景硬停，前冲到极限后轻微震动再稳定，三厘米距离必须清晰可感。
4. **光影氛围**：项圈连接环吃冷白硬光，司遥膝侧与手套吃暖烛光边缘，冷白项圈与暖金指尖对撞。
5. **生成禁忌**：禁止触碰成功、脱链成功、司遥退缩；禁止偏离破碎王冠项圈的颈部道具、兽化、烟、血、字幕。

### 镜011｜面部中近景｜5s

1. **场景空间**：背景王座被压暗成权力阴影，画面焦点集中在中景三厘米边界内的江烬面部占位和项圈连接环。
2. **陈设道具**：破碎王冠项圈连接环、冷金锁链边缘、墨绿王座暗轮廓、猩红地毯低饱和背景保持空间连续。
3. **镜头构图**：85mm 面部中近景，静止锁住江烬面部与项圈，台词只作为配音，不生成字幕。
4. **光影氛围**：冷白窄光落在眼位、黑瞳、项圈连接环上，背景王座压暗，整体为暗黑金属冷调。
5. **生成禁忌**：禁止字幕、文字气泡、乱码；禁止失控乱吼、兽化、开放伤口、烟、额外人物。

### 镜012｜手部与破碎王冠项圈细节｜6s

1. **场景空间**：王座脚边的三厘米触点空间被放大，画面集中在司遥手套、项圈冠齿、江烬颈部边界和左侧烛火。
2. **陈设道具**：黑金链条手套、暗金细链、小型金属扣、破碎王冠项圈冷金冠齿、冷金锁链、背景墨绿王座虚化保留。
3. **镜头构图**：85mm 手部细节，慢速跟随指腹从冠齿滑向项圈下缘，最后停在触点，承接下一镜冻结。
4. **光影氛围**：暖烛光擦过黑金手套，冷白光切开项圈金属边，背景烛火逐渐僵住，暖金手套与冷黑项圈高反差。
5. **生成禁忌**：禁止情色化、伤口化、血腥化；触碰只表现权限测试和控制关系；禁止烟、字幕、水印、额外人物、偏离破碎王冠项圈的颈部道具。

## P04 时间冻结·隐藏设定

### 镜013｜冻结中景｜3s

1. **场景空间**：暗黑王座厅在三厘米触点处全空间冻结，前景锁链、中景触点、后景王座、左侧烛火同时停止。
2. **陈设道具**：冷金锁链悬在微抖前一刻，破碎王冠项圈下缘触点保留，地毯上方尘埃停在冷白光边缘，烛火火舌凝固。
3. **镜头构图**：35mm 冻结中景，镜头不移动，人物位置不改变，三厘米距离原样保留。
4. **光影氛围**：物理暖光瞬间失效，顶部冷白窄光衰减，银蓝系统光开始覆盖王座厅，冷白断停转银蓝冻结。
5. **生成禁忌**：禁止角色换位、距离改变、链条断裂；禁止烟、血、字幕、乱码、额外人物；冻结后不可新增动作。

### 镜014｜中景抬头｜4s

1. **场景空间**：王座厅从现实驯化空间转向上方权限层，司遥所在王座前中景与上方虚空代码层建立垂直轴线。
2. **陈设道具**：墨绿王座、破碎王冠项圈触点、冷金锁链、凝固烛火、银蓝系统光层同时存在，江烬冻结在画面下方。
3. **镜头构图**：50mm 中景抬头，从项圈触点缓慢上移到司遥眼位，再引向画面上方虚空层；画外音不生成字幕。
4. **光影氛围**：银蓝系统光从上方洒下，暗金额冠与肩铠祖母绿被压成冷反光，墨绿空间冻结。
5. **生成禁忌**：母亲不可出现实体；禁止字幕、文字气泡、乱码；司遥不可惊慌；江烬不可解冻或转移视线。

### 镜015｜UI细节｜4s

1. **场景空间**：上方虚空代码层覆盖王座厅，半透明UI面板悬在画面上方，中景保留司遥眼部反光，下方保留江烬冻结方向。
2. **陈设道具**：银蓝玻璃UI面板、不可读短线方块节点、红色隐藏条、墨绿王座暗轮廓、凝固烛火共同形成元宇宙权限层。
3. **镜头构图**：85mm UI细节，从司遥视线切到上方半透明面板，再切回眼睛反光；对白只作为配音。
4. **光影氛围**：银蓝面板向下投射矩形冷光，红色隐藏条成为唯一暖色焦点，银蓝代码光对撞警示红。
5. **生成禁忌**：除剧情指定【重度痴迷】外，UI不能生成可读文字、随机乱码、英文串；禁止字幕、水印、额外人物、烟。

### 镜016｜UI硬停→黑屏｜4s

1. **场景空间**：元宇宙权限层到黑屏标题空间的最终切换，前半保留王座厅上方UI红条，后半瞬间进入纯黑标题场。
2. **陈设道具**：半透明UI面板底部红色隐藏设定条、司遥眼部红色反光、江烬冻结视线、纯黑背景与主标题构成收尾道具层。
3. **镜头构图**：85mm UI红条硬停特写，随后瞬间切黑屏，主标题《完美玩具》砸入黑屏中央。
4. **光影氛围**：红色隐藏条是唯一暖色焦点，银蓝面板冷光迅速退场，最终转为纯黑与冷白标题冲击。
5. **生成禁忌**：UI除【重度痴迷】外不可读；禁止随机乱码、聊天气泡、额外字幕、水印；母亲不可出现实体；江烬不可解冻。
