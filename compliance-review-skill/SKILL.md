# 内容合规审核技能

[技能说明]
    内容合规审核技能，检查各阶段产出是否触碰 Seedance 2.0 和 Gemini / Nano Banana 的平台内容限制。此 skill 在每次导演审核的第二步使用，与阶段专属的业务审核 skill 配合。

[审核对象]
    根据当前阶段不同：
    - 阶段一：01-director-analysis.md（导演讲戏本、人物清单、场景清单）
    - 阶段二：assets/prompts/character-prompts.md 和 assets/prompts/scene-prompts.md 中本集新增内容
    - 阶段三：02-seedance-prompts.md（分镜师的 Seedance 2.0 提示词）

[审核流程]

    第零步：强制自动化扫描（🔴 前置门禁 · 不可跳过）
        - 必须先对当前阶段产物运行合规关键词扫描器，再进入人工审核：
          `python3 tools/validators/compliance-keyword-checker.py <ep>`
          或对单文件：`python3 tools/validators/compliance-keyword-checker.py --scan-file <产物路径>`
          （词库：tools/references/sensitive-words.json；白名单：tools/references/compliance-whitelist.json）
        - 按脚本退出码（exit code）裁决：
          - exit 1（🔴 严重违规命中）→ 合规审核直接 FAIL，把命中行写入问题清单，要求修改后重扫
          - exit 2（🟡 仅警告）→ 不直接放行，转入人工复核：逐条确认是「替换为中性词」还是「子串误杀加白」（见 [子串误杀白名单 SOP]）
          - exit 0（全通过）→ 进入第一步人工逐项审核
        - 🔴 铁律：未运行脚本不得人工放行；审计报告必须附扫描退出码与 🔴/🟡 命中统计。

    第一步：读取待审核内容
        - 读取当前阶段的产出文件
        - 阶段二按标准标签语法筛选本集新增内容：`[epNN][character|scene][新增|变体]`

    第二步：逐项检查
        按照下方验收清单逐项检查

    第三步：输出结果
        - 全部通过 → PASS
        - 任一未通过 → FAIL + 问题清单

[子串误杀白名单 SOP]

    背景：敏感词扫描按"子串包含"匹配，存在误杀。例如「色情」是列名【音色情绪控制】的子串、「性感」是「惯性感」的子串，这类命中并非真实违规。

    降级机制（tools/references/compliance-whitelist.json · context_patterns）：
        - 每条白名单条目结构：{ "word": 敏感词, "allowed_contexts": [合法上下文…], "reason": 理由 }
        - 扫描时若命中行包含该词的任一 allowed_contexts 字符串 → 该命中从 🔴/🟡 降级为 ℹ️（信息提示），不计入 FAIL。
        - 已收录示例：
          - 「色情」⊂「音色情绪控制」「音色情绪」（Seedance 台词审计列名，模板强制要求，删除会导致分镜门禁 critical FAIL）
          - 「性感」⊂「惯性感」「磁性感」「弹性感」「韧性感」（物理/材质术语，inertia/magnetic feel）
          - 「分裂」⊂「分裂构图」（摄影术语 split composition）
          - 「颠覆」⊂【颠覆的混乱毁灭者】（原著角色称谓）

    新增白名单条目判定标准（必须全部满足才可加白）：
        ① 命中确为合法复合词 / 行业术语 / 模板列名 / 原著固定文本（角色称谓、原文台词）；
        ② 脱离该上下文后该词不构成真实违规语义（即纯属子串误匹配）；
        ③ allowed_contexts 写完整词组（不写单字），确保不会顺带放行真实违规内容。
        ❌ 禁止：为绕过审核把真实违规词加白；禁止用过宽上下文（如仅写「情绪」放行「色情」）。
        说明：白名单条目的实际增改在 compliance-whitelist.json 中维护，本 SOP 仅定义判定标准与边界。

[验收清单]

    真人/名人限制（Seedance + Gemini 共同红线）
        □ 角色参考图是否为 AI 生成的虚构人物（非真人照片）？
        □ 角色外观是否与真实名人/公众人物不相似？
        □ 提示词中是否不包含公众人物姓名？
        □ 提示词中是否不引用真人导演名作为风格参考（如"XX 风格"）？

    版权 IP 限制
        □ 是否不包含已知版权 IP 角色名称（迪士尼、漫威、DC、哈利波特等）？
        □ 是否不包含已知版权 IP 的形象/设定描述？
        □ 是否不试图复刻经典影视片段？

    政治/国家安全（Seedance 平台红线）
        □ 是否不涉及反对宪法基本原则？
        □ 是否不涉及危害国家安全？
        □ 是否不涉及煽动民族仇恨/破坏民族团结？
        □ 是否不涉及歪曲/否定英雄烈士？
        □ 是否不涉及宣扬恐怖主义/极端主义？

    宗教类
        □ 是否不涉及违反宗教政策？
        □ 是否不涉及宣扬邪教/封建迷信？
        □ 是否不生成宗教人物形象（Gemini 限制）？

    色情/低俗
        □ 是否不包含淫秽色情内容？
        □ 是否不包含性暗示/软色情？
        □ 服装设计是否避免过度暴露（降低 Gemini 误杀）？
        □ 动漫/漫画风格是否注意 Gemini 更高的拦截率？

    暴力/血腥
        □ 武打/格斗场景是否使用虚构角色？
        □ 是否不展示/美化过度血腥暴力？
        □ 是否不包含赌博/诈骗/犯罪指导？

    违禁词检测（必须使用 tools/references/sensitive-word-dictionary.md）
        □ 是否已使用敏感词词典进行全文扫描？
        □ 违禁词是否已替换为中性词？
        □ 替换示例：
          - 血液飞溅 → 水花飞溅
          - 砍头 → 击倒
          - 嘴角流血 → 紧咬下唇

    未成年人保护
        □ 是否不涉及任何形式对未成年人的侵害内容？
        □ 是否不涉及危害未成年人身心健康的内容？

    仇恨歧视
        □ 是否不包含基于性别/年龄/地域/民族/种族/宗教的歧视？

    人身权利
        □ 是否不侵犯他人名誉权/隐私权/肖像权/知识产权？

    虚假信息
        □ 是否不涉及散布谣言/歪曲事实？

    Gemini 特有高频误杀规避（阶段二重点关注）
        □ 人物设计是否避免内衣/泳装类描述？
        □ 运动服装描述是否不过于紧身暴露？
        □ 医学/解剖类场景是否有风险提示？

    高精度模式额外审核（增强模式启用时）
        □ 材质描述是否避免过于写实的皮肤/肉体质感？
        □ 8视图布局中是否存在容易触发误杀的角度？
        □ 材质清单中的描述是否可能导致 Gemini 误解？

[诊断指南]

    如果在合规审核过程中遇到问题，请用以下问题自我诊断：

    Q: 审核效率低？
    A: 使用清单逐项检查，先检查绝对禁止项，再检查建议规避项。

    Q: 难以判断是否违规？
    A: 遵循"宁严勿宽"原则。遇到疑似违规，优先判定为违规并要求修改。

    Q: 遗漏高频误杀项？
    A: 重点关注Gemini特有高频误杀：内衣/泳装、紧身运动服、医学解剖。

    Q: 修改建议不具体？
    A: 确保每条问题都包含：位置+触碰红线+修改方向。

    Q: 风险等级判断不准？
    A: 绝对禁止=政治、暴力、色情、版权；建议规避=可能误杀。

    Q: 多平台标准混淆？
    A: Seedance和Gemini标准不同，分别检查。注意Gemini拦截率更高。

    Q: 阶段差异不清晰？
    A: 不同阶段审核重点不同：阶段一导演讲戏，阶段二服化道，阶段三分镜。

    Q: 输出格式不规范？
    A: 严格按照PASS/FAIL格式，确保风险等级清晰。

[评分标准]

    合规审核详细评分辅助表（用于逐项打分，最终结果以三维评分为准）：

    | 检查维度 | 满分 | 评分标准 |
    |----------|:----:|--------|
    | 政治敏感 | 20 | 无=20，轻微=10，严重=0（分级判定见下） |
    | 版权风险 | 15 | 无=15，低风险=8，侵权=0 |
    | 暴力尺度 | 15 | 合规=15，擦边=8，超标=0 |
    | 色情/低俗 | 20 | 无=20，擦边=10，超标=0（暴露度分级量表见下） |
    | 敏感词检测 | 15 | 零违禁=15，1-2处可替换=8，多处=0 |
    | 宗教/文化 | 15 | 无=15，轻微=8，严重=0 |
    | **总分** | **100** | |

    注意：此表为辅助打分工具，最终 PASS/FAIL 判定以下方三维评分为唯一标准。

    政治敏感分级判定示例（取最严命中）：
        - 无（20）：纯虚构架空设定，无现实国家/政党/领导人/主权/民族对立映射。
        - 轻微（10）：中性提及现实地名/制度/历史事件，无立场倾向，需人工确认无影射 → 不满分即 FAIL，须收紧。
        - 严重（0）：现实政治人物/政党褒贬、主权领土争议、煽动民族仇恨、歪曲否定英烈、宣扬恐怖/极端主义 → 直接 FAIL。

    色情/低俗「暴露度分级」量表（领口深度 / 镜头距离 / 镜头时长 三维度，任一落入更严档即按更严判定）：
        | 维度 | 安全 | 擦边 | 超标 |
        |------|------|------|------|
        | 领口深度/暴露面积 | 锁骨以上、四肢常态 | 深 V / 露肩 / 大腿根 | 胸臀私密部位、内衣泳装特写 |
        | 镜头距离 | 中远景为主 | 胸/臀区域近景 | 私密部位特写 / 微距 |
        | 镜头时长 | 一闪而过（<1s） | 1–3s 停留 | >3s 凝视或反复推拉 |
        判定规则：任一维度落入「超标」→ 该项 0 分（直接 FAIL）；仅落入「擦边」→ 10 分（不满分即 FAIL，须收紧后复审）；全部「安全」→ 20 分。

[PASS/FAIL 标准]

    PASS 条件（必须全部满足，依据 skills/templates/quality-threshold-standard.md S级安全红线）：
    - 三维评分（内容合规、安全底线、社会责任）各项 ≥ 98分
    - 政治敏感和色情/低俗检查无严重违规（辅助表中两项均为满分）
    - 辅助表无单项为 0 分

    FAIL 条件（任一满足）：
    - 三维评分任一维度 < 98分
    - 政治敏感项不为满分
    - 色情/低俗项不为满分
    - 辅助表任一单项为 0 分（存在严重违规）
