# 影视分镜脚本：《刀》

> 类型：3-5分钟社会议题反转短片
> 预估总时长：4分20秒（260s）
> 场景数：4个实景（家里饭桌/客厅/卧室、地铁车厢、公司茶水间）
> 主演：2人（老公、老婆）+ 1人画面内新闻出镜（女生）+ 2群演（同事）

---

## 技术约定

| 项目 | 规格 |
|------|------|
| 画幅 | 9:16 竖屏（短视频平台） |
| 主机位 | Sony FX3 / A7S3 |
| 辅机位 | iPhone 15 Pro（手机屏幕特写/POV） |
| 收音 | 领夹麦×2（老公、老婆）+ 机顶指向麦（环境音） |
| 色彩方案 | 家里暖黄 3200K / 地铁冷白 5600K / 手机屏幕冷蓝补光 |
| 剪辑节奏 | 前半段平均3-4s/镜，反转后加速至1.5-2s/镜，07场减速至5-8s/镜 |

## 声音设计备注

- **全片无配乐**。只用环境音+手机声+人声。配乐会削弱真实感。
- **手机提示音**是唯一的节奏工具：SC01-SC04越来越密集→SC05完全消失→SC07只剩一声震动。
- **油烟机嗡鸣**首尾呼应：SC01开头响→SC07"油烟机没响"= 日常被打碎。
- **耳鸣音**只用一次（SC05 #059-060），标记认知崩塌时刻。
