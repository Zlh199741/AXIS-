## 一、剧情梗概（100字内）

普通男人看到"救人男孩被骂活该"假新闻后义愤发评、转发人肉，三天持续加码。第三天真相反转：账号系伪造，女生无辜。他想删评道歉，却发现评论已被传播、私信已关闭。"你删掉了评论，但刀已经在别人手里了。"

## 五、P块拆分 — 导演讲戏本

### P01 开场·黑屏倒叙 | 时长：8s

**叙事功能**：倒叙钩子——用结果先行制造悬念

**情绪钩子**：
- 情绪标签：不安/悬疑
- 触发事件：男人沙哑声音的悔恨语气
- 表现手法：纯黑屏+声音驱动
- 钩子类型：悬念+倒叙

**导演阐述**：
开场1.5秒完全黑屏，只有男人画外音。声音处理：沙哑、带气声、极慢语速（约2字/秒），"我以为"之后有0.3s停顿，"在拿刀"气息外泄，"砍坏人"尾音微颤。这个语气必须是"已经知道答案的人在回顾"的质感，不是"正在愤怒"的质感。画面从黑渐亮1s：饭桌一角，暖黄光，汤碗热气升腾——这是"正常生活"的视觉锚。"三天前"字幕1.5s，白色宋体居中，黑底。

**剧本行号范围**：第18-28行（开场｜黑屏）

**人物**：
- 老公（画外音）

**场景**：黑屏 → 饭桌一角渐显

### P02 SC01-a 饭桌·假新闻冲击 | 时长：20s

**叙事功能**：冲突建置——假新闻点燃义愤

**情绪钩子**：
- 情绪标签：义愤/震惊
- 触发事件：看到"男孩救人身亡，被救女生疑似发文称其活该"
- 表现手法：手机屏幕新闻特写 + 老公脸色变化 + 评论区滚动
- 钩子类型：共情愤怒——观众和老公一起被点燃

**导演阐述**：
0-3s：搪瓷盘回锅肉特写（85mm俯15°），筷子夹起肉片——建置日常。老公脸从画面外入画。
3-6s：老公脸色突变，猛地把手机怼到画面前。"老婆！老婆你快来看！"——声音突然拔高。
6-9s：切老婆视角，正在解围裙，手上沾水。"又咋个了嘛？"——四川方言的日常感。
9-13s：手机屏幕特写（POV），新闻标题大字："男孩救人身亡，被救女生疑似发文称其活该。"评论区密密麻麻往上滚——CG评论流。
13-17s：老公义愤台词："你看嘛！救人的娃儿死了，被救的几个女的还说他活该？这是人说的话嗦？"——声音拔高，筷子搁碗边。
17-20s：老婆皱眉凑近看，"你先莫上头嘛。网上的事情，现在反转多得很。"——克制、理性的第一次警告。

**剧本行号范围**：第32-67行（01｜夜晚，家里饭桌 前半段）

**人物**：
- 老公：坐饭桌画面右侧，面朝左前方。穿普通家居T恤，短发。
- 老婆：画面左侧站厨房门口方向，面朝右方。正在解围裙，手上沾水。

**场景**：夜晚·家里饭桌——暖黄顶灯3200K + 右侧手机冷蓝光6500K

### P03 SC01-b 饭桌·发恶评 | 时长：18s

**叙事功能**：第一次出手——键盘侠的第一刀

**情绪钩子**：
- 情绪标签：义愤→快感
- 触发事件：发表恶评获得点赞
- 表现手法：手指打字特写 + 评论发送 + 点赞弹出
- 钩子类型：正义快感（危险的正反馈）

**导演阐述**：
0-4s：老公拒绝吃饭"吃啥子饭？我看到这种人，我气都气饱了！"——声音急促。老婆把饭碗推向他，他没接。
4-8s：低头点开评论框。手机屏幕冷光打在脸上——关键光影对比：上方暖黄灯光 vs 下方手机冷蓝光从下往上照亮脸部，形成"审判者/恶意"的光效。手指特写，一个字一个字敲。
8-11s：屏幕特写——评论内容逐字出现："你们不配活在这个世界上。"停两秒。又补："那个娃儿救你们，真是倒了八辈子霉。"
11-14s：老婆看到脸色变了："你这个话是不是说重了？"老公："重？她们说人家活该就不重？"
14-16s：直接点发送。手机震动。
16-18s：第一条点赞弹出——红色爱心。老公看着点赞，胸口那口气像顺了一点。低声："骂得轻了。"

**剧本行号范围**：第68-118行（01｜后半段）

**人物**：
- 老公：面部被手机冷光照亮，表情从愤怒→发送后微微释放
- 老婆：背景虚焦，表情从担忧→冷下来

**场景**：同SC01饭桌

### P04 SC02 地铁·转发人肉 | 时长：20s

**叙事功能**：升级——从评论到转发人肉，"只是转一下"

**情绪钩子**：
- 情绪标签：猎奇+加码
- 触发事件：人肉信息曝光 + 老婆微信被忽视
- 表现手法：地铁摇晃 + 手机刷屏 + 微信弹窗 + 转发
- 钩子类型：同温层共振——"终于有人懂我"

**导演阐述**：
0-3s：地铁车厢，人挤人。老公一手抓吊环一手刷手机。车厢摇晃，日光管5600K冷白光。
3-7s：手机屏幕特写（POV）："被救女生账号疑似曝光。"截图放大：头像、学校、评论、旧视频全被圈出来。评论区："长这样，一看就不是好东西。""地址有没有？""她妈妈开小卖部的，我找到了。"
7-10s：老公呼吸加重。老婆微信弹出："到公司没？莫再看那个了。人肉犯法的。"
10-13s：老公皱眉回复："我又没去她家。"两秒后补："我只是转一下。"老婆秒回："转也是在推她下去。"
13-16s：老公冷笑，退出聊天框。在转发框打字——屏幕特写："人肉她，让她一辈子抬不起头。"
16-18s：地铁到站，人流往外挤。老公低头点发送。
18-20s：评论弹出："哥们骂得好。""这种人就该被全网记住。""地址发我。"老公嘴角动了一下——"不是笑。是一种'终于有人懂我'的痛快。"

**剧本行号范围**：第121-200行（02｜第二天早上，地铁）

**人物**：
- 老公：地铁内，抓吊环，低头刷手机

**场景**：第二天早上·地铁车厢——5600K日光管冷白光 + 手机屏幕光

### P05 SC03 茶水间·合理化 | 时长：12s

**叙事功能**：合理化顶点——"苍蝇不叮无缝的蛋"

**情绪钩子**：
- 情绪标签：自我合理化/轻蔑
- 触发事件：同事质疑被一句话打回
- 表现手法：微波炉"叮" + 扒饭 + 金句对撞
- 钩子类型：认知闭环——观众开始产生不安

**导演阐述**：
0-3s：微波炉"叮"。老公扒着饭盒，手机立在旁边。
3-7s：同事乙："万一扒错了呢？"老公筷子往饭盒一戳："扒错了再道歉嘛。"扒一口饭，补一句："再说了，苍蝇不叮无缝的蛋。她要是真没问题，怕啥子？"
7-10s：旁边同事没说话。微波炉风扇嗡嗡响。
10-12s：手机屏幕特写——新评论跳动："她妈小卖部电话打爆了。""学校也接到举报了。""她把评论关了，心虚了。"老公眼神无迟疑，反而更硬。

**剧本行号范围**：第203-237行（03｜第二天中午，公司茶水间）

**人物**：
- 老公：扒饭盒
- 同事乙：功能性角色，一句质疑

**场景**：第二天中午·公司茶水间——混合光4500K，微波炉嗡鸣

### P06 SC04-a 家里·后果可视化 | 时长：15s

**叙事功能**：后果从线上蔓延到线下——小卖部停业、家庭受影响

**情绪钩子**：
- 情绪标签：对峙/防御
- 触发事件：老婆质疑"你确定是她吗？"
- 表现手法：小卖部停业视频 + 夫妻对话
- 钩子类型：危险信号加强——老婆的不安在升级

**导演阐述**：
0-3s：家里灯光偏黄（比SC01暗——暗示气氛下沉）。凉了的汤碗无热气。老公边喝汤边刷手机。
3-7s：手机屏幕：小卖部门口视频。门半关着，卷帘门上贴着手写纸"今日暂停营业"。评论："她妈不敢开门了。""活该。"
7-10s：老婆对面坐着看他："你看到没？人家屋头都被影响了。"老公："那也是她自己造成的。"
10-12s：老婆："你确定是她吗？"老公："她要不是，她关评论干啥子？"
12-15s：老婆："被几万人骂，哪个不怕？"老公抬头有点烦："你今天咋个回事？你老是帮她们说话。"

**剧本行号范围**：第240-280行（04｜前半段）

**人物**：
- 老公：坐饭桌画面右侧
- 老婆：对面坐着，声音变轻但目光锐利

**场景**：第二天晚上·家里饭桌——暖黄灯光变暗（比SC01暗30%）

### P07 SC04-b 家里·认知穿透 | 时长：18s

**叙事功能**：妻子的精准刺穿——全片最强认知穿透台词

**情绪钩子**：
- 情绪标签：穿透/逃避
- 触发事件：老婆说出"你是在等更多人证明你骂得对"
- 表现手法：夫妻对话的声音强弱对比
- 钩子类型：认知预穿透——为SC05的真相反转埋下最重的铺垫

**导演阐述**：
0-3s：老婆沉默两秒。"我不是帮她们。"看着他手机，声音很轻。
3-6s："我是怕你有一天发现，你骂错人了。"——这句台词的处理：声音轻、不带怒气、不带审判感——是"心疼你以后会后悔"的语气。
6-9s：老公笑了一声："骂错了我道歉嘛。"——轻飘飘的，像一粒米。可老婆脸色一下冷了。"你说得好轻巧哦。"
9-12s：老公没接话，继续刷。老婆看着他，忽然说——
12-15s：**"你不是在等真相。"** 老公手指停了一下。**"你是在等更多人证明你骂得对。"** ——这两句必须分开说，中间有1秒停顿。第一句让老公停下来，第二句钉进去。
15-18s：老公脸色僵住。几秒后，他把手机声音开得更大。像是故意不听。——这是逃避的肢体语言。

**剧本行号范围**：第281-325行（04｜后半段）

**人物**：
- 老公：从烦躁→僵住→逃避（开大手机音量）
- 老婆：从冷静→精准刺穿→眼看他逃避

**场景**：同SC04

### P08 SC05-a 卧室·热搜反转 | 时长：12s

**叙事功能**：真相反转——三条热搜击穿认知

**情绪钩子**：
- 情绪标签：震惊/恐惧
- 触发事件：热搜标题全变了
- 表现手法：黎明微光 + 手机屏幕 + 手指僵住
- 钩子类型：认知击穿——全片情绪转折点

**导演阐述**：
0-3s：天蒙蒙亮。闹钟还没响。老公闭眼摸手机——动作熟练，说明每天起床第一件事就是刷手机。
3-6s：点开热搜。手机屏幕特写（POV）。第一条："当事女生回应系他人冒充。"
6-9s：第二条："三名被救女生下跪哀悼。"第三条："辱骂救人者账号为假号。"
9-12s：老公手指僵在屏幕上。坐起来。呼吸变轻。——注意：不是大喘气，是突然"屏息"的反应。

**剧本行号范围**：第328-360行（05｜前半段）

**人物**：
- 老公：卧室，刚醒来

**场景**：第三天早上·卧室——天蒙蒙亮自然光4800K + 手机屏幕光为唯一强光源

### P09 SC05-b 灵堂·女生跪地 | 时长：18s

**叙事功能**：真相的"人形证据"——女生不是恶人，是被冒名的受害者

**情绪钩子**：
- 情绪标签：冲击/心碎
- 触发事件：灵堂视频 + 女生跪地痛哭 + 官方通报
- 表现手法：手机画面中的灵堂视频 + 女生哭到直不起腰
- 钩子类型：共情反转——观众和老公一起心碎

**导演阐述**：
0-4s：老公点开第一条视频。手机画面中：灵堂。白花。黑布。遗像。香火的烟慢慢往上飘。——每个元素给0.5-1s，让沉重感积累。
4-8s：手机画面中：那个被他骂了三天的女生，穿着洗得发白的校服外套，跪在地上。她瘦得厉害。肩膀一抽一抽。
8-11s：记者画外音："网上那些话，是你发的吗？"女生摇头。哭得说不出完整句子。"不是我……""我没有说过……""他救了我们……"
11-14s：她哭到直不起腰。旁边有人扶她，她手撑着地，又跪了回去。"我这辈子都还不起……"
14-16s：画面切到官方通报（字幕逐行出现）："网传账号为他人冒充。""辱骂截图系拼接伪造。""被网暴女生事发后一直在医院治疗，未发布相关言论。"
16-18s：老公脸上血色一点点退下去。耳朵嗡嗡响。"像地铁。像油烟机。像几万条评论一起压过来。"

**剧本行号范围**：第360-422行（05｜后半段）

**人物**：
- 老公：看手机视频，血色退去
- 女生（手机画面中）：穿旧校服跪地痛哭
- 记者（画外音）

**场景**：卧室 + 手机中灵堂画面（冷白顶光5500K + 香火暖光）

### P10 SC06-a 客厅·回看评论 | 时长：15s

**叙事功能**：面对自己的刀——每条评论都是证据

**情绪钩子**：
- 情绪标签：悔恨/恐惧
- 触发事件：回看5条评论 + 自己的截图上了网暴合集封面
- 表现手法：评论列表逐条回看 + 删除动画 + 新视频封面
- 钩子类型：反噬——施害者发现自己也成了被审判的对象

**导演阐述**：
0-3s：老公坐在饭桌边。手机放桌上，屏幕还亮着。点开评论记录。
3-7s：屏幕特写——五条评论逐条出现。第一条："你们不配活在这个世界上。"下面三千多赞。第二条："那个娃儿救你们，真是倒了八辈子霉。"第三条："人肉她，让她一辈子抬不起头。"下面有人回复："地址发我。"第四条："别装了，现在知道哭了？"第五条："这种人就该被全网记住。"
7-10s：他的手开始抖。点删除。删一条。又删一条。
10-13s：删到第三条停住——刷到新视频："这些人曾带头网暴当事女生。"封面第一张截图就是他的那句"人肉她，让她一辈子抬不起头。"
13-15s：他的头像被打了码。可那句话没有。

**剧本行号范围**：第425-483行（06｜前半段）

**人物**：
- 老公：手在抖

### P11 SC06-b 道歉无门 | 时长：15s

### P12 SC07-a "刀上全是好人的血" | 时长：20s

**叙事功能**：核心崩溃——全片高潮台词 + 妻子终极一刀

**情绪钩子**：
- 情绪标签：崩溃/心碎
- 触发事件：老公说出核心金句 + 老婆说"也是别人家的娃儿"
- 表现手法：极慢语速对话 + 沉默 + 眼泪
- 钩子类型：双重击穿——自我击穿（老公）+ 情感终击（老婆）

**导演阐述**：
0-3s：老婆从厨房出来，手里拿抹布。看见老公坐桌边一动不动。饭没吃。水没喝。手机扣在桌上。
3-5s："你今天咋个不看手机了？"——语气日常，但这句话有重量。
5-8s：老公没抬头。过了很久，把手机翻过来推到老婆面前。老婆看了一眼。什么都明白了。她没骂他。没说"我早说了吧"。只是轻轻把手机放回桌上。
8-11s：老公声音很哑："我昨天说，骂错了我道歉嘛。"笑了一下——那笑比哭还难看。"可我现在发现，我连道歉发给谁都找不到。"
11-14s：老公低头看自己的手——这双手昨天还在转发，前天还在打字，大前天还觉得自己站在正义那边。"我以为我在替好人说话。"眼眶慢慢红了。
14-16s：**"我以为我在拿刀砍坏人。"** 停住。喉咙像被堵住。**"结果回头一看……"** 一滴眼泪砸在桌面上。**"刀上全是好人的血。"**
16-18s：老婆看着他。声音很轻。却比骂他还疼。**"你们都说那个救人的娃儿可怜。"**
18-20s：老公没动。老婆继续："可被你们骂到跪都跪不稳的那个娃儿……"停一下，眼圈也红了。**"也是别人家的娃儿。"**

**剧本行号范围**：第535-630行（07｜前半段）

**人物**：
- 老公：一动不动 → 哑声说话 → 哭
- 老婆：拿抹布 → 沉默 → 轻声说出最狠的话 → 眼圈红

**场景**：第三天上午·家里饭桌——光线最暗的一场

### P13 SC07-b 终极推送·裂屏 | 时长：15s
