| 价值导向 | ✅ 正面——通过施害者视角的悔恨展现网暴的不可逆伤害 |

## 二、逐项合规检查

### 2.1 政治敏感

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 涉及政治人物/事件 | ✅ 无 | — |
| 涉及国家机关负面形象 | ✅ 无 | 官方通报以正面形式出现（辟谣、还原真相） |
| 涉及民族/宗教/领土争议 | ✅ 无 | — |

### 2.2 暴力/血腥

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 直接暴力画面 | ✅ 无 | 全片无物理暴力 |
| 血腥/恐怖画面 | ✅ 无 | — |
| 自残/自杀描写 | ⚠️ 需注意 | "她是不是不该被救"暗示被害者产生了活着的负罪感，属于间接心理伤害描写，但未描写任何自残/自杀行为 |
| 死亡描写 | ⚠️ 需注意 | 救人男孩已死亡（背景设定），灵堂画面（白花/黑布/遗像/香火）——但为叙事必要，展现的是悲伤与哀悼，非渲染死亡 |

**处理建议**：灵堂画面克制处理即可，不渲染遗体/死因细节。"她是不是不该被救"是终极情感冲击，保留但确保画面不直接展现自我伤害倾向。

### 2.3 色情/低俗

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 色情/擦边内容 | ✅ 无 | — |
| 低俗语言 | ✅ 无 | 方言口语自然，无粗俗脏话 |

### 2.4 网络暴力相关

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 是否美化网暴行为 | ✅ 否 | 老公的网暴行为在后半段被完整反噬，立场明确反对 |
| 是否传播人肉搜索方法 | ✅ 否 | 评论区内容点到即止（"地址有没有？""她妈妈开小卖部的"），不提供具体操作 |
| 是否煽动仇恨 | ⚠️ 需注意 | 前半段评论区恶评较多，但属于叙事功能（建置→反转），不构成煽动 |
| 隐私保护 | ✅ 合规 | 剧中明确展示"老公头像被打了码"，暗示平台/媒体有隐私处理 |

**处理建议**：评论区截图画面中的"地址""电话"等信息应做模糊处理或仅保留文字而非真实界面截图。

### 2.5 未成年人保护

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 涉及未成年人 | ⚠️ 间接涉及 | 女生穿校服（暗示学生/未成年人），是网暴被害者 |
| 对未成年人的保护态度 | ✅ 正面 | 全片立场明确同情保护被害者 |

**处理建议**：女生角色可设定为大学生或不明确年龄的年轻人，避免直接暗示未成年。如保留校服设定，确保叙事始终站在保护被害者立场。

### 2.6 方言使用

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 方言可理解性 | ✅ | 四川方言口语词（咋个/嘛/啥子/嗦/莫）均为高频词，全国基本可理解 |
| 是否需要字幕 | 建议 | 发布时建议配字幕确保可达性 |
