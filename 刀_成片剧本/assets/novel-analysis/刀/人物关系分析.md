# 人物关系分析：《刀》

> 源文件：成片版剧本_刀_定稿.md
> 类型：3-5分钟社会议题反转短片（1集）

## 角色清单

### 1. 老公（男主）

- **年龄**：三十多岁
- **职业**：普通上班族（坐地铁通勤、公司茶水间吃饭）
- **性格特征**：脾气直，容易被情绪带着走；自认正义感强，实则缺乏独立判断
- **语言特征**：四川方言口语（"咋个""嘛""啥子""嗦""莫"）
- **角色功能**：施害者视角主角——观众代入对象，完成从"正义键盘侠"到"施暴帮凶"的认知反转
- **情绪弧线**：义愤填膺 → 快感加码 → 自我合理化 → 真相击穿 → 悔恨无门 → 崩溃
- **关键台词**：
  - "骂得轻了。"（SC01，义愤高峰）
  - "扒错了再道歉嘛。"（SC03，合理化顶点）
  - "骂错了我道歉嘛。"（SC04，轻飘飘的承诺）
  - "我以为我在拿刀砍坏人。"（开场/SC07，核心隐喻）
  - "刀上全是好人的血。"（SC07，认知崩塌）

### 2. 老婆（女主）

- **年龄**：三十多岁
- **性格特征**：务实、清醒；不高声说教，但每句话精准刹车
- **角色功能**：理性之锚 / 观众良知代言——持续提出被忽视的警告，最终用"也是别人家的娃儿"完成情感致命一击
- **情绪弧线**：克制劝阻 → 沉默观望 → 精准刺穿 → 心疼落泪
- **关键台词**：
  - "网上的事情，现在反转多得很。"（SC01，第一次警告）
  - "转也是在推她下去。"（SC02，微信警告）
  - "你不是在等真相。你是在等更多人证明你骂得对。"（SC04，认知穿透）
  - "也是别人家的娃儿。"（SC07，情感终极一击）

### 3. 手机里的女生（被害者）

- **年龄**：学生（穿校服）
- **外观线索**：瘦，穿洗得发白的校服外套，肩膀一抽一抽
- **出场方式**：仅通过手机屏幕画面 / 新闻视频 / 灵堂视频出现，全片无实体出场
- **角色功能**：网暴被害者——被冒名、被全网误骂、被人肉、家庭受波及、灵堂跪地自证清白
- **关键台词**：
  - "不是我……"（SC05）
  - "我没有说过……"（SC05）
  - "他救了我们……"（SC05）
  - "我这辈子都还不起……"（SC05）
- **间接信息**（母亲转述）："她是不是不该被救。"（SC07终推送）

### 4. 功能性角色（无独立戏份）

- **同事乙**：茶水间发出质疑"万一扒错了呢？"，被老公一句话打回
- **记者画外音**：灵堂采访"网上那些话，是你发的吗？"
- **评论区众声**：匿名网暴参与者，承接老公的言论继续扩散

## 人物关系图谱

```
老公 ←──── 夫妻 ────→ 老婆
 │                        │
 │ [施害/转发/评论]        │ [劝阻/警告/刺穿]
 ↓                        ↓
手机里的女生 ←── 被冒名/网暴 ── 评论区匿名众
 │
 ↓
女生母亲（画外）── 发声："她是不是不该被救"
```

### 核心关系动力

| 关系 | 动力 | 转折点 |
|------|------|--------|
| 老公 → 老婆 | 听不进劝 → 被击穿 | SC04"你是在等更多人证明你骂得对" |
| 老公 → 女生 | 自认正义制裁 → 发现误伤无辜 | SC05 真相反转 |
| 老公 → 评论区 | 同温层共振"终于有人懂我" → 自己的话成了别人的刀 | SC06 删评无用 |
| 老婆 → 老公 | 克制劝阻 → 最后一刀"也是别人家的娃儿" | SC07 |

## 角色设计方向提示

| 角色 | 视觉方向 | 关键视觉锚 |
|------|---------|-----------|
| 老公 | 普通、接地气、不特别——让观众觉得"这就是我身边的人" | 微胖或中等身材、短发、T恤/格子衫、手机不离手 |
| 老婆 | 家常、温和但有锋芒 | 围裙→解围裙的过渡、手上沾水的细节、声音轻但目光锐利 |
| 女生 | 脆弱、年轻、让人心疼 | 洗旧校服、瘦弱、跪地哭泣 |
