# 时长预测与细节拆解技能

[技能说明]
    本技能在分镜编写阶段自动执行时长预测与叙事扩展。核心功能包括：
    1. 文本扫描：识别原著中所有关键叙事节拍（动作点、表情点、心理活动）
    2. 时长精算：预测基础时长和扩展时长
    3. 逐节拍细节拆解：将每个节拍拆解为多景别/多角度提示词
    4. 预测报告生成：输出完整的时长预测报告

    核心原则：忠于原文、细节拆解、视听丰盈

    本技能必须参考：
    1. skills/seedance-storyboard-skill/SKILL.md：分镜编写规范
    2. skills/director-skill/SKILL.md：导演讲戏本
    3. skills/compliance-review-skill/SKILL.md：合规标准

> 本技能整合为 AXIS 工作流的自动时长预测模块。

## 概述

**功能**：在分镜编写阶段自动执行时长预测与叙事扩展
**定位**：分镜师的前置工具，确保每个场景的提示词时长完全覆盖目标
**核心原则**：忠于原文、细节拆解、视听丰盈

## 核心参数矩阵

### 叙事保全率 (Narrative Fidelity, NF)

```
默认值：100% (Zero-Loss)
规则：禁止在未获得用户授权的情况下进行任何实质性剧情删减
算法：视听节拍 = 原始文本节拍 × (1 + 细节丰盈系数)
```

### 细节扩展系数 (Detail Expansion Factor, DEF)

```
针对"内容太少"的问题，不建议注水，而是通过叙事深挖丰富细节
示例：
  - "他走过草地" → 草地植物学纹理 + 主角皮鞋受力分析 + 风的流体力学 = 2分钟
  - "她哭了" → 眼眶泛红特写 → 泪光闪烁 → 泪水滑落 = 8秒
  - "他拿起刀" → 手指关节发白特写 → 刀柄纹理 → 刀刃寒光 = 10秒
```

### 信息密度转化 (Information Density Conversion, IDC)

```
即使是看似冗余的描写，也要转化为"世界观厚度"
确保原著的"含水量"被 1:1 转化为"视听氛围感"
```

## 叙事扩展方法

### 方法1：心理描写视听转化

```
每一行心理描写禁止删除，必须转化为：
  - 内心旁白
  - 环境氛围渲染
  - 瞳孔特写
  - 意识流蒙太奇

确保原著的"含水量"被 1:1 转化为"视听氛围感"
```

### 方法2：细节拆解扩展

```
当原文篇幅不足以覆盖目标时长时：

启动"逐节拍细节拆解"：
  - 将核心动作拆解为多景别镜头序列
  - 为情感变化添加微表情特写和环境渲染
  - 参考《黑客帝国》子弹时间或《言叶之庭》的细节呈现方式
```

### 方法3：视觉丰盈度增强

```
在保持原著叙事不变的前提下，通过视觉设计提升画面品质：

示例：
  - 在背景中添加高品质视觉细节（环境纹理、光影变化）
  - 运用专业光影设计（参考film-lighting-technique-skill）
  - 为情绪节点添加视觉渲染（色调变化、景深变化）
```

## 执行流程

### STEP 1: 叙事节拍扫描

```
输入：
  - 原始剧本/小说文本
  - 目标时长（如有）

执行：
  1. 识别原著中所有关键叙事节拍（动作点、表情点、心理活动）
  2. 统计原始节拍数量
  3. 评估忠实转化后的扩展倍率

输出：
  - 原始节拍数量
  - 关键叙事节拍清单
  - 预估扩展倍率
```

### STEP 2: 时长精算预测

```
输入：
  - 原始节拍数量
  - 细节丰盈系数（默认 2.0，可调整）
  - 目标时长（可选）

执行：
  1. 基础时长 = 原始节拍数量 × 平均节拍时长（默认 5秒）
  2. 扩张时长 = 基础时长 × 细节丰盈系数
  3. 校验：扩张时长 ≥ 目标时长？

输出：
  - 预测基础时长
  - 预测扩张时长
  - 需要补充的提示词数量
```

### STEP 3: 显微镜叙事拆解

```
输入：
  - 原始文本
  - 需要扩张的节拍点

执行：
  对每个节拍点进行"显微镜式"拆解：

  动作类：
    "他走进房间" →
      [5秒] 特写：皮鞋踩在地板上，鞋底与木纹摩擦
      [5秒] 中景：身体重心从右脚转移到左脚
      [5秒] 侧面：肩膀微微晃动保持平衡
      [8秒] 推镜：房间门缓缓打开，阳光从缝隙渗入

  心理类：
    "她感到绝望" →
      [5秒] 特写：眼眶微微泛红，泪水在眼眶中打转
      [5秒] 特写：嘴唇微微颤抖，深吸一口气
      [8秒] 近景：手指无力地松开，手机滑落
      [8秒] 俯拍：身体缓缓蹲下，蜷缩在角落

输出：
  - 拆解后的提示词清单
  - 每个提示词的预估时长
```

### STEP 4: 预测报告生成

> 🔴 **落盘路径（强制）**：本报告必须写入 `outputs/<集数>/00-duration-sovereign-report.md`，作为分镜编写与审核阶段的时长主权依据（编号 00 = 先于 01-director-analysis 的时长前置门禁），供 `seedance-prompt-review-skill`「第二步H 时长校验」与 `sovereign-duration-predictor-review-skill` 直接读取。

🔴 **报告头部必须带以下 YAML frontmatter（字段名固定，便于审核侧解析）**：

```yaml
---
NF: 100%              # 叙事保全率（默认100%）
扩展倍率: 2.0          # 扩展时长 ÷ 基础时长
原始节拍数: 0          # STEP1 统计的原始叙事节拍数量
基础时长: 0            # 秒；原始节拍数 × 平均节拍时长
扩展时长: 0            # 秒；基础时长 × 扩展倍率
最终预估时长: 0        # 秒；最终标定时长
目标时长: 0            # 秒；目标时长（无硬目标填 0）
---
```

报告正文：

```

**📌 文本概览:**
- 原始文本体量: [字数] 字
- 原始节拍数量: [N] 个
- 叙事保全率 (NF): 100%
- 扩展倍率: [X]倍

- 细节拆解: [哪些部分进行了逐节拍细节拆解]
- 视觉增强: [添加的光影/环境/氛围渲染]

```

### STEP 5: 段内密度校验（Segment Density Audit）

```
输入：
  - 分镜师编写的提示词（含时间段划分）

执行：
  对每条提示词中的每个时间段：
  1. 数该段内的节拍数 B（节拍定义见 director-skill）
     - 物理动作 = 1拍
     - 镜头运动 = 1拍
     - 短台词（≤10字）= 1拍；长台词（>10字）= 2拍
     - 表情/微动作 = 1拍
     - 同时发生合并为 1拍
  2. 算该段最大容量 Max = floor(段时长秒数 ÷ 2.5)
  3. 对白专项：口型台词 字数 × 0.4秒、画外音 字数 × 0.2秒（下限2秒）。🔴 此 0.4/0.2 是**密度校验保守预算**（与 beat-density-checker.py 的 DIALOGUE_CHAR_SECONDS=0.40 / BUBBLE_CHAR_SECONDS=0.20、AXIS-workflow-stages 对白密度表一致，故意偏慢以留足空间），**区别于** seedance-storyboard-skill 书写台词镜时用的"按戏型语速分档（慢3-4 / 日常默认4-5 / 快5-6 字/秒，以导演分析「节奏/语速档」字段为唯一权威）"——两套速率用途不同、不可互相套用
  4. 判定：
     - B ≤ Max 且对白时长达标 → ✅ PASS
     - B > Max 或对白时长不足 → ❌ FAIL，标记超密段

输出：
  - 每条P每段的节拍数 / 上限 / 通过状态
  - 超密段修复建议（拉长 / 拆段 / 移内容）
```

**示例输出**：
```
📊 段内密度校验报告 — P01

| 时间段 | 时长 | 节拍数 | 上限 | 对白需时 | 状态 |
|--------|------|--------|------|----------|------|
| 0-3s   | 4s   | 2      | 1    | 0s       | ❌ 超1拍 |
| 4-6s   | 3s   | 3      | 1    | 0s       | ❌ 超2拍 |
| 7-8s   | 2s   | 10     | 0    | 6.8s     | ❌ 严重超标 |

🔧 修复建议：
- P01总时长8秒不足以承载15拍内容，建议扩至15秒或拆为2条P
- 7-8秒段含2句对白（需6.8秒），必须独立为对白段
```

## 强制规则

### 避免实质性删减

```
优先通过视听语言转化解决节奏问题，而非直接删除内容

处理"节奏偏慢段落"的方式：
  ❌ 避免：直接删除
  ✅ 推荐：将其转化为风格化视听语言（氛围渲染/环境特写/蒙太奇）
```

### 细节为王

```
如果内容不够长，就用细节和画质去撑开时空
每个动作/表情/心理活动 = 至少 1 个独立提示词
```

### 原文优先

```
用户输入的原始文本是首要参考
市场适配是辅助参考
未经用户授权不应删减核心内容
```

[诊断指南]

    | 问题类型 | 快速检查 | 修复方向 |
    |----------|----------|----------|
    | 时长不足 | 计算总时长 vs 目标时长 | 执行显微镜拆解扩张 |
    | 节拍遗漏 | 逐行核对原始文本 | 补充遗漏节拍 |
    | 细节稀疏 | 每分钟提示词数<8 | 拆分动作+添加特写+环境 |
    | 心理描写未转化 | 搜索"感到/想到" | 转化为视听语言 |
    | 时长分配不均 | 检查每条4-15秒 | 拆分过长/合并过短 |
    | 段内密度溢出 | STEP 5 校验 B>Max | 拉长段时长/拆段/移内容至相邻段 |
    | 对白时长不足 | 口型 字数×0.4秒 / 画外音 字数×0.2秒 vs 段时长 | 为对白段独立分配足够时间 |
    | 扩张过度 | 细节是否有意义 | 确保每个细节服务叙事 |
