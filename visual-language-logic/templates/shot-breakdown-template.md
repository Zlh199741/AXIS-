## 视觉语法检查清单

### 连贯性逻辑
- [ ] 轴线原则：对话镜头组是否保持180度轴线
- [ ] 视线匹配：正反打视线方向是否正确
- [ ] 动作匹配：跨镜头动作是否连续
- [ ] 空间一致：环境元素是否前后一致

### 表现性逻辑
- [ ] 景别变化：是否有远/中/近/特写的合理变化
- [ ] 角度变化：每次切换至少30度变化
- [ ] 节奏控制：镜头时长是否符合情绪节奏
- [ ] 留白/呼吸：是否有适当的视觉休息

### AI视频适配
- [ ] 运镜复杂度：是否在AI生成能力范围内
- [ ] 转场方式：是否使用AI支持的转场
- [ ] 特效可行性：视觉效果是否可AI生成
