# 爆款短剧剧本审核技能

[技能说明]
    审核剧本转化专家（short-drama-scriptwriter-skill）产出的短剧剧本。
    审核员需以批判性视角审视剧本，通过验证去心理化原则、
    场次划分、专业标签规范、卡点设计等维度，确保剧本质量达标。

    本审核技能必须参考：
    1. skills/short-drama-scriptwriter-skill/SKILL.md：了解剧本生成规范
    2. skills/compliance-review-skill/SKILL.md：合规检查
    3. tools/references/sensitive-word-dictionary.md：敏感词检测
    4. resources/unified-audiovisual-language-library.md：视听语言标准

[审核流程]

    第一步：建立整体理解
        - 读取上游集纲（权威路径：assets/outline/{chXX}-outline.md）
        - 读取待审核剧本（权威路径：assets/novel/{chXX}-script.md）
        - 明确审核立场：找出问题而非确认通过

    第二步：绝对视觉化验证（核心）
        逐行扫描：
        - 是否存在心理描写（"他感到愤怒"、"她内心纠结"等）？
        - 是否存在内心独白？
        - 是否存在抽象情感描述（"极度愤怒"、"异常悲痛"等）？
        - 所有心理活动是否已外化为具体肢体动作/微表情/物理交互？
        常见违规示例：
        ❌ "他感到极其愤怒" → ✅ "▲他眼眶猩红，猛地一拳砸塌实木桌子"
        ❌ "她内心紧张" → ✅ "▲她双手攥紧衣角，指节发白"
        ❌ "他回忆起往事" → ✅ "▲闪回：[具体画面]"

        去心理化分级标准（生成端 short-drama-scriptwriter-skill 与本审核端统一口径）：
        - 🔴 P0（0 容忍）：内心独白 / 上帝视角 / "他心想·她暗想·回忆起·原来·感到"等不可拍摄词汇 → 出现任一处即 FAIL
        - 🟡 P1（限量）：抽象情感形容词（"极度愤怒""异常悲痛"）未配套外化动作 → ≤3处记🟡建议优化并要求外化，>3处即 FAIL

    第二步半：台词忠实度审计（🔴 台词零删减铁律 — 全局优先级最高）
        对照上游集纲（assets/outline/{chXX}-outline.md）的"精彩台词"逐句 diff：
        - 集纲中的每一句台词（含口型对白、画外音、脑内独白）是否在剧本中被完整保留？
        - 是否存在被精简 / 缩短 / 概括 / 删减 / 合并 / 改写的台词？
        - 仅允许"扩写"（补语气、穿插动作），严禁任何形式的反向删减。
        判定：
        - 发现任一句台词被删减/精简/合并/改写 → 🔴 P0 FAIL（全集回退重审）
        - 台词容量超时只允许「扩展时长 / 拆分时间段 / 调整语速标注」三种处理，严禁删词

    第三步：场次划分审核
        - 每集是否切分为2-4个核心场次？
        - 场次标头是否完整（编号+日/夜+内/外+场景名）？
        - 出场人物是否标注清晰？
        - 人名条标签是否规范（【人名条：姓名｜身份】）？

    第四步：专业标签审核
        必须包含的标签：
        - ▲ [动作描述]：动作白描
        - ▲特写：[画面描述]：特写镜头
        - 【切镜】：场景转换
        - "[音效]"：音效标注
        - ▲黑屏。：卡点收尾

    第五步：卡点收尾审核
        - 每集结尾是否截断在最高潮前0.5秒？
        - 是否使用"特写+音效+黑屏"三件套？
        - 最后一幕动作是否在完成前一瞬间黑屏？

    第六步：台词与节奏审核
        - 台词是否短促有力（≤20字/句）？
        - 对话之间是否穿插动作白描？
        - 是否避免大段说教？
        - 整体是否有"机位感"？

    第七步：逐项评分并输出结果

[审核维度与评分标准]

    | 审核项 | 权重 | 5分 | 3分 | 1分 |
    |--------|:----:|-----|-----|-----|
    | 绝对视觉化 | 25% | 零P0+零P1 | 零P0+P1≤3处 | 出现P0 或 P1>3处 |
    | 场次划分 | 15% | 2-4场/集，标头完整 | 基本完整 | 混乱缺失 |
    | 专业标签 | 15% | 全部标签规范使用 | 缺少1-2项 | 严重缺失 |
    | 场景切片 | 10% | 高密度，节奏紧凑 | 中等密度 | 拖沓单调 |
    | 卡点收尾 | 20% | 三件套完整+极致悬念 | 有悬念但不够极致 | 平淡收尾 |
    | 台词质量 | 10% | 短促有力+动作交织 | 基本达标 | 冗长说教 |
    | 格式排版 | 5% | 绝对清爽专业 | 基本规范 | 混乱 |

[PASS/FAIL 标准]

    PASS 条件（全部满足）：
    - 绝对视觉化：零 P0（心理描写/内心独白），P1（抽象情感未外化）≤3处
    - 台词忠实度：对照集纲零删减（无删减/精简/合并/改写）
    - 场次划分：每集2-4个场次，标头完整
    - 专业标签：核心标签完整使用
    - 卡点收尾：每集有卡点，使用三件套
    - 综合评分 ≥ 4.0
    - 三维评分各项 ≥ 95分（审核类 C 级，引用 skills/templates/quality-threshold-standard.md v1.2）

    FAIL 条件（任一满足）：
    - 🔴 出现任一处 P0 心理描写/内心独白（0 容忍）；或 P1 抽象情感未外化 >3处
    - 🔴 台词被删减/精简/合并/改写（违反台词零删减铁律 → 全集回退重审）
    - 场次划分混乱或缺失
    - 核心标签缺失超过2项
    - 卡点收尾缺失
    - 综合评分 < 3.0
    - 三维评分任一维度 < 95分

[输出模板]

    三维评分规则（必须执行）：
        剧情连贯性评分（0-100分）：
        □ 剧本与集纲核心情节是否完整对应？（0-33分）
        □ 人物行为动机是否合理连贯？（0-33分）
        □ 剧情转折点是否有足够铺垫？（0-34分）

        分镜连贯性评分（0-100分）：
        □ 场景切换是否流畅自然？（0-33分）
        □ 场景之间空间关系是否合理？（0-33分）
        □ 视线匹配和轴线是否一致？（0-34分）

        场景完整性评分（0-100分）：
        □ 场景覆盖所有需要的地点？（0-33分）
        □ 场景描述与导演清单一致？（0-33分）
        □ 场景转换有逻辑支撑？（0-34分）

        通过标准（审核类 C 级，引用 skills/templates/quality-threshold-standard.md v1.2）：各项 ≥ 95分

[诊断指南]

    | 问题 | 检查 | 修复 |
    |------|------|------|
    | 有心理描写 | 搜索"感到/内心/心想" | 转化为动作▲ |
    | 台词太长 | 检查单句字数 | 拆分≤20字/句 |
    | 场次太少 | 检查每集场次数 | 拆分为2-4个场次 |
    | 卡点无力 | 检查结尾三件套 | 特写+音效+▲黑屏。 |
    | 标签缺失 | 搜索▲/【切镜】 | 补充缺失标签 |
    | 排版混乱 | 检查缩进/层级 | 按模板修正 |

[术语表]

    | 术语 | 英文 | 定义 |
    |------|------|------|
    | 绝对视觉化 | Absolute Visualization | 剔除所有心理描写，外化为动作 |
    | 动作白描 | Action Line | 用▲开头的物理动作描述 |
    | 场次 | Scene | 一个连续时空内的叙事单元 |
    | 人名条 | Name Slug | 角色首次出场的身份标注 |
    | 切镜 | Cut | 场景转换标记 |
    | 卡点三件套 | Cliffhanger Triple | 特写+音效+黑屏的收尾组合 |
    | 机位感 | Camera-Ready | 导演可直接按剧本安排拍摄 |
    | 去心理化 | De-Psychologize | 将心理描写转化为物理动作 |
