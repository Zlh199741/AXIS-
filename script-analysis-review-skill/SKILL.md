# 导演分析审核技能

[技能说明]
    审核导演在阶段一的分析产出，包括导演讲戏本、人物清单和场景清单。这是导演的自审环节，要求导演以批判性视角审视自己的产出，通过逐行比对原始剧本、脑内预演画面效果、逐项评分的方式，确保讲戏质量真正达标，而非仅确认格式完整。

    本审核技能融合：
    1. 爆款短剧质量检查：确保商业吸引力
    2. 视听语言逻辑检查：参考 resources/unified-audiovisual-language-library.md 确保专业性
    3. 微表情标签库：检查导演讲戏是否使用可拍摄的动作/表情
    4. 敏感词检测：参考 tools/references/sensitive-word-dictionary.md
    5. 可选：需要复杂视听分析时，可参考 skills/visual-language-logic/SKILL.md
    - 绝对客观视角：检查是否有内心独白/上帝视角
    - 物理动作 > 心理描写：检查情绪是否通过动作传达
    - 黄金3秒钩子：检查每个剧情点开篇是否有强视觉冲击
    - 情绪高潮点：检查剧情点中段是否推向情绪高潮
    - 卡点钩子：检查结尾是否停留在危机/悬念边缘
    - 标签化人设：检查人物外观是否有视觉反差标签
    - 极致台词节奏：检查台词是否≤20字/句

[审核对象]
    outputs/<集数>/01-director-analysis.md

[审核流程]

    第一步：建立整体理解
        - 读取权威剧本/集纲输入源（按优先级）：
          ① 剧本：assets/novel/{chXX}-script.md
          ② 原始剧本/小说：novel/第N集.txt（或 novel/novel.txt）
          ③ 集纲：assets/outline/{chXX}-outline.md
        - 读取待审核的导演分析产出（outputs/<集数>/01-director-analysis.md）
        - 明确审核立场：你的任务是找出问题，而非确认通过

    第二步：逐行比对
        - 逐行读原始剧本，逐个读讲戏本中的剧情点
        - 找出剧本中有但讲戏本中被弱化、遗漏或表达偏离的地方
        - 记录所有偏差，无论大小

    第三步：脑内预演
        - 对每个剧情点，想象一个导演拿着这段讲戏去指导拍摄，画面会是什么样？
        - 判断：讲戏中的描述是否足够具体，让拍摄团队不需要再问"你到底要什么效果"？
        - 判断：讲戏描述拍出来的画面，是否准确传达了原始剧本的情绪和意图？

    第四步：逐项评分
        按照下方验收清单，对每个剧情点评分（1-10），并对人物清单、场景清单整体评分

    第五步：输出结果
        - 集纲模块完整性校验任一项缺失 → 直接 FAIL（硬门禁，先于评分）
        - 计算所有剧情点的平均分
        - 平均分 ≥ 8 且无单项低于 6 → PASS
        - 平均分 < 8 或任一单项低于 6 → FAIL + 问题清单

[验收清单]

    集纲模块完整性校验（🔴 硬门禁 — 对齐 director-skill「集纲模块强制阻断规则」，缺项先于评分直接 FAIL）
        检查 01-director-analysis.md 文件顶部"集纲模块"五项是否齐全：
        □ 故事梗概（一句话标题≤50字 + 故事梗概≤150字 — 与 short-drama-architect 标准一致）→ 缺失 FAIL
        □ 前三秒钩子（黄金3秒，强视觉冲击/悬念动作）→ 缺失 FAIL
        □ 前十秒叙事（钩子引发的后果 + 人物应激）→ 缺失 FAIL
        □ 一分钟核心情绪点（情绪高潮）→ 缺失 FAIL
        □ 卡点钩子（悬念收尾）→ 缺失 FAIL
        □ 每个 P 的情绪钩子设计块 + 叙事功能标签 是否齐全 → 缺失 FAIL
        □ 🆕 每个 P 的【节奏/语速档】字段（慢 3–4 / 日常 4–5 / 快 5–6 字/秒 + 判定依据）是否齐全，整集骨架是否有【A4 本集节奏基调】→ 缺失 FAIL（分镜将无戏份依据、只能凭空猜语速→拖沓/赶）。同P内情绪跳档句是否标了覆盖。
        判定：任一项缺失 → 业务审核直接 FAIL（拒绝进入评分），与 director-skill T0 铁则一致

    爆款短剧质量检查（整体评估，不单独评分，FAIL时记录问题）
        □ 绝对客观视角：导演阐述中是否有"他心想"、"他回忆起"、"原来在几年"等内心独白/上帝视角？如有，列出具体位置。
        □ 物理动作 > 心理描写：情绪是否通过具体动作传达？是否有抽象描述如"表现疲惫"、"内心愤怒"需要转化为动作？
        □ 黄金3秒钩子：每个剧情点的开篇是否有强视觉冲击动作/情绪定格/悬念展示？列出缺失钩子的剧情点。
        □ 前10秒叙事：钩子引发后果和人物应激反应是否快速展示？是否有拖沓铺垫？
        □ 情绪高潮点：剧情点中段是否推向情绪高潮（绝对压制/惊天反转/极致欺辱）？列出缺乏高潮的剧情点。
        □ 卡点钩子：剧情点结尾是否停留在危机/悬念边缘？是否有平稳结束缺乏期待感的？
        □ 标签化人设：人物清单中是否包含视觉标签（身份/穿着/表情特征）？标签是否具有反差感？
        □ 极致台词节奏：台词是否≤20字/句？是否有过于冗长的台词？

    剧情拆解（整体评估，不单独评分）
        □ 逐行比对：原始剧本中的每一个场景转换、每一句台词、每一个动作指示，是否都有对应的剧情点覆盖？列出遗漏项。
        □ 叙事完整性：每个剧情点是否是一个完整的叙事段落？是否有段落被不必要地拆散（如蒙太奇序列被拆成多个独立剧情点）？
        □ 合并检查：服务于同一叙事目的的相邻段落是否应合并？指出具体是哪些。
        □ 拆分检查：是否有段落包含两个独立的叙事目的，应拆分？指出具体是哪个。
        □ 时长合理性：每个段落的内容密度与建议时长（4-15s）是否匹配？

    导演讲戏质量（每个剧情点单独评分 1-10）
        评分维度：
        □ 画面感（脑内预演）：闭上眼读这段讲戏，你脑中能浮现出清晰、连贯的画面吗？如果有模糊的地方，具体是哪句话不够清晰？
        □ 动作链完整性：人物从 A 状态到 B 状态的物理动作是否有完整的过渡？是否存在"跳跃"——上一秒在做 X，下一秒突然在做 Y，中间缺少衔接？
        □ 节拍密度：每个连续镜头内的节拍密度是否合理（1 拍 ≈ 2.5 秒）？多镜头段落的节拍是否合理分配在各镜头中？
        □ 头尾安全区：Seedance 生成的前 0.5s 和后 0.5s 是否避开了关键内容？
        □ 镜头可执行性：单镜头段落——镜头运动是否能连续实现？多镜头段落——每组镜头各自是否可执行，切换方式是否清晰？
        □ 光影具体性：光线描述是否具体到方向、色温、强度？"光线柔和"不够具体，"灰蓝色的清晨微光从左侧单窗斜射入室内"才够具体。
        □ 情绪传达：这段讲戏是否准确传达了原始剧本中该场景的核心情绪？如果有偏差，指出原始剧本的情绪是什么，讲戏传达的情绪变成了什么。
        □ 衔接自然：与前一个和后一个剧情点之间，画面空间、时间、情绪是否能自然过渡？如果不能，指出断裂点。

        评分标准：
        - 9-10：讲戏精准，脑内预演画面清晰完整，无需修改
        - 7-8：基本到位，但有 1-2 处可以更具体或更准确的地方
        - 5-6：有明显的模糊、跳跃或偏离，需要修改
        - 1-4：讲戏严重不足，无法指导拍摄

    人物清单（整体评分 1-10）
        □ 筛选合理性：人物清单是否只包含需要参考图的角色？检查以下两点：
            - 应列入的角色是否遗漏：本集出现 2+ 个剧情点的人物、预计后续集数复现的人物，是否都在清单中？
            - 应排除的角色是否误入：本集只出现 1 次且不会再出场的群演/一次性配角（如路人、围观群众），是否被错误地列入了清单？
        □ 群演描述充分性：不在清单中的群演/一次性配角，在讲戏本的导演阐述中是否有足够具体的外观描述？分镜师能否据此直接在提示词中用文字描写？（如"尖脸眯缝眼的白袍学员"够具体，"一个路人"不够具体）
        □ 外观可设计性：对清单中每个人物的外观关键词，判断服化道设计师是否能据此画出一个明确的形象？哪些人物的描述过于模糊？
        □ 一致性：人物清单中的外观描述与讲戏本中对同一人物的描述是否矛盾？

    视听语言逻辑（整体评估，不单独评分，FAIL时记录问题）
        □ 轴线原则：对话/对峙/共同关注点的镜头组是否保持屏幕空间一致？越轴是否有叙事目的？
        □ 屏幕方向一致性：同一连续动作的运动方向与视线方向是否一致？
        □ 30度原则：同一主体的连续切镜，机位变化是否足够明显？
        □ 视线匹配：给出角色看向画外的反应后，是否补充了"他看到了什么"或"故意留悬念"？
        □ 库里肖夫效应：是否用反应镜头传达情绪，而非在一个镜头里讲完所有事？
        □ 动接动/静接静：镜头切换时机是否符合节奏逻辑？
        □ 因果逻辑：关键镜头是否遵循原因→结果或结果→原因（悬念）？
        □ 光影叙事：光线是否服务于情绪表达？（暖光=安全/冷光=危险，伦勃朗光=秘密）
        □ 焦段选择：是否体现了广角/长焦的心理隐喻？
        □ 声音设计：是否有J-Cut/L-Cut的描述？声画对位是否有目的？

    场景清单（整体评分 1-10）
        □ 完整性比对：逐个检查剧情点中出现的场景，是否全部出现在场景清单中？列出遗漏的场景。
        □ 环境可设计性：对每个场景的光线/色调/氛围描述，判断服化道设计师是否能据此生成一张场景参考图？哪些场景的描述过于笼统？
        □ 一致性：场景清单中的描述与讲戏本中对同一场景的描述是否矛盾？

    元数据一致性（不评分，仅检查）
        □ 每个剧情点的"人物"字段是否与人物清单匹配？
        □ 每个剧情点的"场景"字段是否与场景清单匹配？

[输出规范]

    三维评分规则（必须执行）：
        剧情连贯性评分（0-100分）：
        □ 剧本与讲戏本的核心情节是否完整对应？（0-33分）
        □ 人物行为动机是否合理连贯？（0-33分）
        □ 剧情转折点是否有足够铺垫？（0-34分）

        分镜连贯性评分（0-100分）：
        □ 镜头切换是否流畅自然？（0-33分）
        □ 镜头之间的空间关系是否合理？（0-33分）
        □ 视线匹配和轴线是否保持一致？（0-34分）

        场景完整性评分（0-100分）：
        □ 场景清单是否覆盖所有剧情点需要的场景？（0-33分）
        □ 场景描述是否与讲戏本中的场景描述一致？（0-33分）
        □ 场景转换是否有逻辑支撑？（0-34分）

        通过标准：
        - 剧情连贯性 ≥ 95分
        - 分镜连贯性 ≥ 95分
        - 场景完整性 ≥ 95分
        - 任一维度低于95分 → 业务审核 FAIL

[诊断指南]

    | 问题类型 | 快速检查 |
    |----------|----------|
    | 审核立场不客观 | 明确目标是"找出问题"而非"确认通过" |
    | 逐行比对效率低 | 使用表格工具辅助，先读剧本再读讲戏本 |
    | 脑内预演不准确 | 尝试用一句话描述画面，描述不出即问题所在 |
    | 评分标准不统一 | 9-10=无需修改，7-8=小修小补，5-6=需大改 |
    | 遗漏视听语言问题 | 使用视听语言检查清单逐项验证 |
    | 遗漏爆款质量问题 | 使用爆款质量检查清单逐项验证 |
    | 问题描述不具体 | 使用"位置+当前问题+修改方向"结构 |
    | 人物/场景清单不准 | 检查筛选标准：是否出现2+次、后续是否复用 |

[学习路径]

    📚 第一阶段：审核意识建立 (1周)
    - 理解审核立场：找出问题而非确认通过
    - 练习逐行比对技巧
    - 练习脑内预演

    📚 第二阶段：评分标准掌握 (1周)
    - 掌握8个评分维度的标准
