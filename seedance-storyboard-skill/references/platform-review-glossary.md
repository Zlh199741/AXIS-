## 八、运镜工具箱（T0级心法+10大技能）

### 8.1 核心心法（三大铁律）

1. **Motivated Movement**：运镜必须有动机（角色动/心理变/揭示信息）
2. **Z-Axis Rule**：依赖Z轴纵深创造立体感
3. **Invisible Edit**：通过遮挡/甩摇/走向暗处隐藏剪辑点

## 九、平台约束（T0强制）

### 9.1 Seedance 2.0 约束

| 输入类型 | 数量上限 | 格式 | 大小限制 |
|---------|---------|------|----------|
| 图片 | ≤9张 | jpeg/png/webp/bmp/tiff/gif | 每张<30MB |
| 视频 | ≤3个 | mp4/mov | 每个<50MB，总时长2-15s |
| 音频 | ≤3个 | mp3/wav | 每个<15MB，总时长≤15s |
| **总文件** | **≤12个** | - | - |
| 生成时长 | 4-15秒 | - | - |
| 分镜数量 | ≥10条/集 | - | - |

### 9.2 Kling 2.6 约束
- 图片：≤1张
- 时长：5s/10s
- 音频：内置（音画同出）

### 9.3 Kling 3.0 约束
- 图片：≤1张
- 时长：3s/5s/10s/15s
- 音频：内置（音画同出）
- 智能分镜：支持「镜头1、镜头2」
- 主体参考：支持@主体绑定

## 十一、分镜密度公式（T0强制）

```
分镜数量 = round(字数 / 1000 × 12)
误差范围：±5%

| 字数 | 分镜数(±5%) |
|------|-------------|
| 1000字 | 12个(11~13) |
| 2000字 | 24个(23~25) |
| 3000字 | 36个(34~38) |
| 5000字 | 60个(57~63) |
```

## 十三、审核评分体系

### 评分维度（9维度T0标准）

| 维度 | 说明 |
|------|------|
| 忠实度 | 逐句比对导演阐述 |
| 画面还原 | 脑内预演效果 |
| 动作可执行 | 节拍密度合理性 |
| 镜头可实现 | 物理矛盾检查 |
| 视听语法 | 轴线/视线/30度/视线钩子/物理动力学 |
| 平台适配 | Seedance/Kling友好度 |
| 音频设计 | J-Cut/L-Cut/人声锚定/现场音效 |
| 情绪准确 | 氛围传达/情感熵 |
| 连贯性 | 镜头间衔接/空间一致性 |

### 通过标准
- 9维度评分：平均分 ≥ 8 且无单项低于 6
- 产出三维质量标准：各项 ≥ 95分
- 合规审核：全通过
- 注意：9维度评分为逐条提示词的详细打分工具，产出三维质量标准为整体判定标准，两者必须同时满足

## 十四、诊断指南

| 问题 | 诊断 | 解决方案 |
|------|------|----------|
| 提示词超平台限制 | 检查单条素材数量 | 拆分剧情点或减少引用 |
| AI生成动作不自然 | 检查节拍密度 | 1拍≈2.5秒 |
| 角色镜头间不一致 | 检查@引用锚点 | 避免重复描写长相 |
| 空间关系混乱 | 检查3D坐标系 | 确保时钟方向一致 |
| 视线方向错误 | 检查Eye-line锁死 | 180度原则 |
| 光影氛围不统一 | 检查光源/色温 | 每条明确标注 |
| 群演处理不当 | 检查@引用 | 不在character-prompts.md中的人物用文字描述 |
| 敏感内容违规 | 扫描违禁词表 | 逐行检查替换 |
