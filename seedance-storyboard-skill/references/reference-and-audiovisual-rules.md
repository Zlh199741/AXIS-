## 四、@引用语法规范（T0标准）

### 4.1 基础语法
```markdown
@图片1、@图片2...    # 最多9张
@视频1、@视频2...    # 最多3个
@音频1、@音频2...    # 最多3个
```

### 4.2 用途指定格式

| 用途 | 写法 |
|------|------|
| 首帧 | @图片1 作为首帧 |
| 尾帧 | @图片2 作为尾帧 |
| 人物形象 | 参考 @图片1 的人物形象 |
| 场景 | 场景参考 @图片3 |
| 运镜 | 参考 @视频1 的运镜效果 |
| 动作 | 参考 @视频1 的动作编排 |
| 特效 | 完全参考 @视频1 的特效和转场 |
| 人声/现场音效 | @音频1 仅做人声音色锚定或现场音效参考，禁止任何可生成音乐内容（背景音乐、BGM、音乐铺底等） |
| 音效 | 音效参考 @视频3 的音效 |

### 4.3 场景宫格处理
- scene-prompts.md 九宫格必须**逐格独立编号**
- 禁止整张九宫格作为单一@图片引用

### 4.4 角色锚定协议（跨提示词一致性保障）

当同一角色出现在多条提示词中时，必须使用角色锚定协议确保视觉一致性：

**素材对应表中增加角色锚定表**：
```markdown
## 角色锚定表

| 锚定ID | 角色名 | 视觉锚定 | 核心特征锁定 | 贯穿提示词 |
|--------|-------|---------|-------------|-----------|
| A1 | 江辰 | @图片1 | 黑发束冠、剑眉、右额疤痕 | P01-P12 |
| A2 | 崔云绣 | @图片2 | 银白长发、冰蓝瞳孔、清冷气质 | P03-P10 |
```

**机读层锚定写法**：
```
❌ 弱锚定：以@图片1为主角...
✅ 强锚定：以@图片1中的江辰（黑发束冠、剑眉）为主角...
           全程保持江辰的发型、面部疤痕与@图片1一致。
```

**锚定规则**：
- 每条提示词引用角色时，必须写 `@图片N中的[角色名]` 而非仅 `@图片N`
- 角色首次出现时，括号内补充 **2-3个核心视觉特征**（发型、标志性特征）
- 跨提示词复现时，至少重复 **1个核心特征** 作为锚定提示
- 角色锚定表中的"贯穿提示词"列用于审核时检查一致性

### 4.5 素材优先级权重（Asset Priority Weighting）

多个@引用同时存在时，模型不知道优先听谁的。必须使用权重语义关键词明确优先级：

| 权重级别 | 关键词 | 含义 | 示例 |
|---------|-------|------|------|
| 🔴 强制 | "以...为准" / "完全参考" | 模型必须严格遵循 | "角色形象以@图片1为准" |
| 🟡 主要 | "参考...的风格" / "参考...的方式" | 大方向遵循，允许微调 | "运镜方式参考@视频1" |
| 🟢 辅助 | "氛围接近" / "风格类似" | 仅作灵感参考 | "色调氛围接近@图片3" |

**权重写法示例**：
```
❌ 无权重：以@图片1中的角色为主角，场景参考@图片2，参考@视频1的运镜方式。

✅ 有权重：以@图片1中的江辰为主角（角色形象以@图片1为准），
           场景氛围参考@图片2但以文字描述为主，
           运镜节奏完全参考@视频1。
```

**冲突解决规则**：
- 当文字描述与@引用冲突时，**文字描述优先**（模型更容易理解文字指令）
- 当多个@引用之间冲突时，**编号越小优先级越高**（@图片1 > @图片2）
- 素材总数推荐 **5-8个**，超过8个时必须明确标注每个素材的权重级别

### 4.6 零代词铁律 + 引用双轨制（2026-04-10 新增）

> 来源增强：画镜平台 Protocol A（2026-04-03）

**🔴 零代词铁律（强制）**：机读层正文中绝对禁止使用代词，一律替换为 @角色名：

| 禁用词 | 正确替换 |
|--------|----------|
| 他/她/它 | 写出 @角色名 |
| 男人/女人 | 写出 @角色名 |
| 主角/配角 | 写出 @角色名 |
| 两人/他们/她们 | 分别写出 @角色A 与 @角色B |

🔴 **FAIL条件**：机读层出现任意禁用代词 → 直接判定 FAIL，全部替换为@角色名后重新自检。

**@名称空格强制规则**：所有 @角色名 / @场景名 / @物品名 前后必须保留空格：
- ✅ 正确：` @陈恩义 走到 @破旧书案 前`
- ❌ 错误：`@陈恩义走到@破旧书案前`（紧贴，导致@识别失败）
- ❌ 错误：`@陈恩义，抬起头`（@名称紧贴标点）
- ❌ 错误：`（@陈恩义）`（括号内紧贴，必须写成 `（ @陈恩义 ）`）

**引用双轨制**：机读层的不同位置使用不同引用格式：

| 位置 | 格式 | 示例 |
|------|------|------|
| 时间轴正文（时间段描述中） | 语义名称 `@角色名` | ` @陈恩义 转头看向 @小阳 ` |
| 参考行（机读层尾部素材引用） | 编号+语义 `@图片N 用途（ @语义名 ）` | `@图片1 角色形象（ @陈恩义 ）` |

**@物品名引用规则**：关键道具必须用 @物品名 引用，并描述与角色/场景的空间关系：
- ✅ ` @陈恩义 右手握住 @魂铃 ，铃身锈迹在烛光下泛出暗红光泽`
- ❌ `陈恩义拿着铃铛`（道具未@，未描述空间关系）

## 五、视听语言逻辑（T0强制）

### 5.1 连贯性语法

| 原则 | 定义 | 打破条件 |
|------|------|----------|
| **轴线原则** | 对话/对峙镜头组保持屏幕空间一致 | 制造混乱/超自然感 |
| **屏幕方向一致性** | 连续动作方向保持一致 | 中性镜头重置 |
| **30度原则** | 连续切镜头位变化≥30度 | 有意制造跳帧 |
| **视线匹配** | 反应后补充POV或留悬念 | 故意留悬念 |
| **视线钩子** | 焦点中心重合度误差<5% | - |

### 5.2 蒙太奇逻辑

| 技巧 | 公式 | 应用 |
|------|------|------|
| 库里肖夫效应 | 中性表情+客体=新情绪 | 反应镜头 |
| 动接动 | 动作70%处切换 | 流畅剪辑 |
| 因果逻辑 | 原因→结果/结果→原因 | 悬念/顺叙 |
| J-Cut | 声先画 | 悬念/平滑过渡 |
| L-Cut | 画先声 | 情绪连贯 |
| 声画对位 | 声音与画面相反 | 讽刺/反差 |

### 5.3 焦段隐喻

| 焦段 | 心理隐喻 |
|------|----------|
| 广角(<35mm) | 夸大前景、拉伸纵深，喜剧/恐惧/速度感 |
| 标准(35-70mm) | 客观叙述，无特殊心理暗示 |
| 长焦(>85mm) | 压缩空间、隔离角色，孤独/窒息感 |

### 5.4 光影叙事

| 光源 | 效果 | 适用情绪 |
|------|------|----------|
| 暖光 | 安全/温馨/怀旧 | 积极场景 |
| 冷光 | 危险/孤独/冷酷 | 危机场景 |
| 伦勃朗光 | 明暗对照，三角光区 | 秘密/双重人格 |
| 色温对立 | 冷暖对比制造冲突 | 对抗场景 |
| 顶光 | 眼窝阴影 | 神秘/压迫/恐怖 |
| 正侧光 | 半脸明暗 | 复杂/双面人格 |
| 逆光 | 轮廓剪影 | 温暖/浪漫/救赎 |
| 硬光 | 边缘锋利 | 紧张/冲突 |

## 六、空间坐标与视线规则（T0强制）

### 6.1 3D坐标系建立

```markdown
空间坐标锚点：
- 原点：[场景固定物体，如柜台、床、书案]
- 方向基准：[如门=6点钟方向，窗=3点钟方向]
- 角色坐标：
  - 角色A：位于X点钟方向，距原点Y米
  - 角色B：位于X点钟方向，距原点Y米
```

### 6.2 视线对焦规则

```markdown
视线对焦（Eye-line）：
- 角色A视线看向X点钟方向（看向角色B）
- 角色B视线看向Y点钟方向（回看角色A）
- 180度锁死：[是/否]
- 越轴处理：[如需越轴，标注"【越轴】"并说明叙事目的]
```

### 6.3 越轴处理规范
- 越轴必须有叙事目的
- 必须标注【越轴】
- 越轴后需中性镜头重置轴线

### 6.4 防融图物理锚点构句公式（多角色同框必用 — 2026-04-10 新增）

> 来源增强：画镜平台 Protocol E（2026-04-03）

**适用场景**：两个或以上角色同框、对话、对峙、接触时，必须使用此公式构造时间段中的角色关系描述。

**核心句式（强制套用）**：

`[@角色A + 身体姿态 + 物理支撑面/阻隔物] + [空间距离/相对动作] + [@角色B + 身体姿态 + 物理支撑面/阻隔物]`

**执行规则**：
- 角色姿态禁止笼统词（坐在/躺着/站着），必须写清**身体部位与接触物**（如"后背贴住木制床头背板"、"手肘压在石桌边缘"）
- 空间关系必须**可量化**（如"隔着一张方桌"、"距 @角色B 半步"、"肩线几乎贴近"）
- 两主体距离很近时，必须加入**物理阻隔防止融图**（如"隔着桌角"、"单手撑墙形成阻隔"）

**改写示例**：

| 错误写法 ❌ | 正确写法 ✅ |
|---|---|
| `@陈恩义 坐在椅子上` | `@陈恩义 后背死死贴着木椅靠背，双手搭在扶手边缘` |
| `@小阳 凑近陈恩义` | `@小阳 双脚站在地板上，上半身前倾俯身凑近，与 @陈恩义 之间隔着床沿阻隔` |
| `两人对视` | `@角色A 视线越过方桌桌角锁定 @角色B ，双方相距约一步，中间有桌面形成物理分隔` |

**🔴 FAIL条件**：多角色同框时间段出现"两人对视/坐在一起/站在旁边/并肩而立"等笼统描述 → 直接判定该时间段 FAIL，必须改写为含身体姿态+物理锚点的完整句式。
