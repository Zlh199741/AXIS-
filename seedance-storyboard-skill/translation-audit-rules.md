# 成品用词转换参考 · 14条原则

> 🔴 2026-06-08 方向C 定位变更：分镜改为**单层成品**后，"人读层→机读层翻译"与"每条P必附翻译审计表"的**流程已废除**。本文件保留为**写/审单层成品时的用词转换对照**——下文各表"人读层 | 机读层翻译"两列，按"❌ 技术/规划写法 | ✅ 成品自然语言写法"理解即可。

> **核心原理**：Seedance 2.0 / Kling 是视频生成模型。机读层采用 **70% 自然语言画面描述 + 30% 专业影视词汇** 结构，将所有设计意图翻译为模型能执行的具体画面描述，同时保留模型可直接执行的影视词汇作为30%配额。不可执行的纯技术参数（24mm、J-Cut标签、伦勃朗光、180度法则等）仍须翻译为自然语言。
>
> **机读层70/30结构说明**：
>
> | 类别 | 占比 | 含义 | 示例 |
> |---|---|---|---|
> | **自然语言画面描述** | **70%** | 具体可感知的场景/动作/光影/音效 | "冷白月光从左侧斜照，将她的脸切成半明半暗" |
> | **专业影视词汇（可执行）** | **30%** | 模型能直接执行的镜头语言词汇 | "广角镜头"、"特写"、"切极近特写"、"手持跟拍"、"仰拍" |
>
> **✅ 允许使用（计入30%配额）**：广角镜头、长焦镜头、特写、极近特写、中景、近景、全景、推镜、拉镜、切镜、仰拍、俯拍、手持跟拍、景深、虚化、定格、慢镜头、逆光、轮廓光、顶光、侧光、低调光、高调光、柔光、硬光、散射光、冷色调、暖色调、胶片质感、柯达胶片质感、电影质感、暗角、光晕、镜头光晕、动态模糊
>
> **🔴 仍须翻译（不可执行参数）**：mm数值（24mm/85mm）、J-Cut/L-Cut标签、伦勃朗光、蝶形光、180度法则、库里肖夫效应、丁达尔效应、f-stop数值、钟面方位、ECU/MS等英文缩写
>
> **适用范围**：所有 Seedance 2.0 / Kling 2.6 / Kling 3.0 提示词的机读层编写和审核。
>
> **标准示范**：
> - `outputs/ep01/02-seedance-prompts.md`（EP01 全12条翻译审计完成）
> - `outputs/ep02/02-seedance-prompts-EP01标准示范版.md`（EP02 全12条翻译审计完成）
>

> **🧭 为什么这样规定（实证依据 · 2026-06-07 核对官方页+社区指南；2026-06-08 修订：补回"抽象情绪词"边界，消除"看不懂术语"通杀措辞）**
>
> ⚠️ **先分清两类，绝不可混为一谈**（本节最易被误读处）：
>
> - **(A) 抽象情绪 / 心理词**（"她很伤心"、"温柔地"、"紧张地说"、"压迫感"、"电影感"）→ **Seedance 真·读不懂**。这是本项目**核心铁律**，依据见 `Seedance_2.0_情绪与语气提示词写法手册` 开篇与 `Seedance_2.0_微表情物理描述素材库_100组` ——摄影机只能拍到情绪的**身体表演**，拍不到"情绪"本身，故必须物理化为**面部肌肉指令（微表情）+ 发声方式公式**。🔴 这一类的理由就是"模型读不懂"，**不得改写或否定这个表述**。
> - **(B) 影视技术术语 / 参数**（焦段mm、运镜、景深、光名、剪辑关系）→ **不是读不懂**。Seedance 对运镜（推/拉/摇/移/环绕）、景深、虚化、逆光、特写等**能识别并执行**（官方页与多份指南确认 dolly/pan/tilt/rack focus/depth of field "register meaningfully"）。这一类要翻译/规避，是**另外的工程理由**，分四小类：
>
>   1. **数值技术参数（mm焦段 / f光圈 / ISO / fps）→ 翻译为视觉结果**：理由是**不可控 + 官方明确不建议**，而非模型不识。官方指南解读警告："Use rhythmic descriptions, not technical specs… 别写 24fps / f2.8 / ISO800 / 85mm"。
>   2. **跨镜剪辑关系（J-Cut / L-Cut / 库里肖夫效应 / 180度法则）→ 拆成时间分段**：理由是**单条文生视频物理上做不出"剪辑关系"**（一次只生成一段连续画面），与"懂不懂"无关。
>   3. **命名光法（伦勃朗光 / 蝶形光 / 丁达尔效应）→ 描述光向+明暗**：理由是**描述性写法命中率更高**；官方指南同样偏好"光从左侧45度打、半脸明暗"而回避 Rembrandt / rim light。
>   4. **英文运镜词（Dolly 等）/ 英文景别缩写（ECU/MS）→ 用中文等价词**：理由是**机读层强制中文输出**（火山引擎官方中文指令即"推/拉/摇/移/环绕/跟随"），属语言统一选择，**不是模型不认识英文运镜**。
>
> 附：时间段记号用 `0·X秒：` 而非 `00:00·00:03` —— 分段式时间轴（timeline prompting）本身是 Seedance 推荐技巧，AXIS 正是采用之，仅为规避特定记号的截断风险（见附件④禁忌符号表），**并非否定该技术**。
>
> 一句话：**(A) 抽象情绪词 = 真读不懂 → 物理化；(B) 技术术语/参数 = 读得懂，但为"可控性 + 单条可执行性 + 中文统一"而翻译。** 两者理由不同，审核话术须**分开表述**：既不得用"Seedance 看不懂术语"一句通杀（会误伤 B 类），也不得反过来否定"抽象情绪词读不懂"这条铁律（A 类）。

## 一、14条翻译原则

> **与70/30规则的关系**：以下14条原则说明如何将**不可执行技术参数**翻译为自然语言。凡已列入核心原理"✅ 允许使用"清单的影视词汇（广角镜头/特写/仰拍/推镜/切镜/手持跟拍/慢镜头/虚化等），**无需按本原则转换，直接保留并计入30%配额即可**。各受影响原则内部标注了 `✅30%可直接使用` 提示。

### 原则① 焦段→空间效果

**规则**：不写 mm 数字，写焦段产生的**视觉结果**。✅30%可直接使用：`广角镜头` / `长焦镜头` / `中景` / `近景` / `全景` 等焦段/景别词汇本身可保留，mm数值仍须删除。

| 人读层 | 机读层翻译 |
|---|---|
| `广角24mm，拉伸纵深` | `广角镜头从教室后方拍向讲台方向——拉伸纵深夸大空间` |
| `广角28mm手持` | `画面晃动如手持跟拍，视角宽广` |
| `长焦85mm压缩空间` | `长焦镜头将前景人物和背景人群压缩进同一平面` |
| `长焦隔离角色` | `长焦将她从嘈杂的人群中隔离出来` |
| `标准50mm客观叙述` | `中景，正面平视拍摄` |

---

### 原则② 角度→镜头物理位置

**规则**：不写角度的**心理象征含义**（如"渺小感""权力感"）。✅30%可直接使用：`仰拍` / `俯拍` 词汇本身可保留，但需补充镜头的物理位置描述（如"极低角度贴地仰拍"而非仅写"仰拍"）。

| 人读层 | 机读层翻译 |
|---|---|
| `高空俯拍（渺小感）` | `镜头从画面顶部高处向下拍摄，角色在画面中央显得渺小` |
| `低角度仰拍（暗示扭转）` | `镜头从地面高度向上拍摄，身影从下方延伸向天花板` |
| `平视（客观）` | `镜头与人物视线平齐` |
| `过肩镜头` | `从角色A肩后拍向角色B，A的背影占画面左三分之一` |
| `主观视角POV` | `主角眼中所见——[具体画面]` |

---

### 原则③ 坐标→画面位置 + 标准位置词汇

**规则**：不写钟面数字，写"画面左/右/近景/远景/深处"。

| 人读层 | 机读层翻译 |
|---|---|
| `原点=讲台，6点钟=学生区` | `画面近景是学生区，画面远景是讲台` |
| `角色A在3点钟方向距2米` | `角色A站在画面右侧，距角色B约两米` |
| `面朝12点钟（教学楼）` | `面朝画面深处方向（教学楼）` |
| `180度锁死` | `保持180度轴线一致——A始终在画面右侧，B始终在画面左侧` |
| `视线：全部→6点钟` | `五十双眼眶齐齐盯住画面前景方向（门口）` |

**标准位置词汇表**（P.词汇）：
- `画面左侧` / `画面右侧` / `画面中央`
- `画面前景` / `画面中景` / `画面远景`
- `画面深处` / `画面顶部` / `画面底部`
- `面朝画面深处方向` / `面朝画面前景方向`
- `画面偏左` / `画面偏右`

### 原则④ 光影→光源方向 + 效果

**规则**：不写专业光名，写"光从哪里来、照到哪里、产生什么明暗"。

|---|---|
| `伦勃朗光` | `灯光从左侧45度打在脸上，半边脸明半边暗` |
| `蝶形光` | `光源从正上方略偏前照射面部，鼻下形成对称蝶形阴影` |

| `逆光（轮廓）` | `光源在角色身后，角色变为暗色剪影，边缘勾勒出金色轮廓光` |
| `体积光` | `粉笔灰在光柱中翻涌形成白色鬼雾` |
| `闪烁光` | `荧光灯忽明忽暗，每隔1-2秒闪烁一次` |

| `低调光（low-key）` | `画面大面积深黑，仅一束窄光照亮角色面部局部，其余沉入黑暗` |

### 原则⑤ 剪辑→时间分段结构

**规则**：蒙太奇不写术语名称，通过**分段方式和描述节奏**体现。

| 人读层 | 机读层翻译 |
|---|---|
| `正反打` | 时间段1：`中景A说话` → 时间段2：`镜头切到B的中近景反应` |
| `库里肖夫效应` | Shot A和Shot B放在**不同时间段**，中间不加解释 |
| `J-Cut（声先画）` | 上一条音效行末尾加入本条声音，或本条开头"声音先于画面0.3秒渗入" |
| `L-Cut（画先声）` | 本条音效行末尾注明"[某声音]延续至下一镜" |
| `硬切` | 时间段之间不写过渡词，直接换段落 |
| `骤然切黑` | `画面骤然切黑。纯黑。绝对寂静。` |
| `画面定格` | `画面定格在[具体画面描述]` 作为时间段最后一句 |

### 原则⑥ 声音→音效行写法 + 情绪弧线

**规则**：J-Cut/L-Cut 不写名称，在音效行中**跨条安排声音**或**标注延续**。

| 人读层 | 机读层翻译 |
|---|---|
| `J-Cut` | `[声音]先于画面0.3秒渗入` |
| `L-Cut` | 音效行末尾注明`[某声音]延续至下一镜` |
| `声音留白` | `绝对寂静N秒` 或 `所有声音骤停` |
| `主观听觉` | `从[角色]主观听觉——声音模糊失真如隔了一层水` |
| `声音特写` | `[某声音]清晰放大，压过其他一切声音` |
| `声音情绪弧线` | `低频嗡鸣→渐强→骤然切换为尖锐嚎叫` |

### 原则⑦ 叙事→描述控制

**规则**：信息隐藏/角色盲区不用术语，用**主动限制描述范围**的写法。

| 人读层 | 机读层翻译 |
|---|---|
| `信息隐藏` | `画面不揭示[内容]，仅展示[可见动作]` |
| `角色盲区` | `她背对学生看不到这一切——但观众可以看到` |
| `悬念截断` | `画面在[关键动作]的一瞬间骤然切黑` |
| `伏笔暗示` | `声音暗示[某事]仍在，故事未完` |

---

### 原则⑧ 运镜→物理运动描述

**规则**：英文运镜名（Dolly/Arc Shot/Pan/Whip Pan等）仍须翻译为物理运动描述。✅30%可直接使用：`推镜` / `拉镜` / `切镜` / `手持跟拍` 等中文运镜词汇可直接保留（计入配额），但需配合具体运动轨迹描述。

| 人读层 | 机读层翻译 |
|---|---|
| `Dolly Push-In（心理入侵）` | `镜头匀速向角色面部推进至中近景` |
| `Dolly Follow（跟拍）` | `长焦镜头从身后跟拍` |
| `Arc Shot（环绕）` | `镜头从角色背后缓慢环绕至她的侧面` |
| `Handheld（手持）` | `画面保留微小的重心偏移和晃动，如手持跟拍` |
| `快速Dolly Out` | `镜头从特写快速拉远到中近景` |
| `爆点轻震` | `画面剧烈晃动一瞬` 或 `画面微微抖动（声波震感）` |

#### ⑧附 有机运动修饰（去AI感·强制）

> **核心问题**：AI生成的镜头运动是数学插值曲线——匀速、零抖、零漂移、零过冲——过度完美反而暴露AI痕迹。真实摄影画面包含光学物理和人-机交互产生的微小"不完美"，人眼虽不逐一察觉，但潜意识据此判断画面真实性。

**规则**：机读层每条运镜描述**必须附带 ≥1 个有机运动修饰**，将数学完美运动转化为带有物理惯性和人体操控痕迹的有机运动。

| 运镜动作 | 有机运动修饰（每条运镜必选 ≥1 个） |
|---------|-------------------------------|
| 推镜/拉镜 | `推进到位时微微过冲后回稳` / `起步有短暂加速段` / `推进中画面重心略向一侧偏移后修正` |
| 横摇/跟拍 | `角色停步时镜头惯性微过冲后稳住` / `跟拍中与主体距离有微小波动` / `水平方向重心轻微漂移` |
| 手持 | `画面随呼吸节奏垂直方向轻微起伏` / `水平重心不规则缓慢漂移` / `步伐带来周期性微震` |
| 固定机位 | `画面重心极缓慢地微幅漂移` / `非绝对静止，保留微风级轻微振动` |
| 变焦 | `变焦到位后有微小回弹` / `变焦过程中画面边缘轻微缩放呼吸` |
| 升降/吊臂 | `到极限位置轻微回弹` / `升降过程中水平轴微偏` |
| 环绕 | `环绕轨迹非完美圆弧，有轻微距离波动` / `环绕到位前减速段画面微漂` |

**翻译对照**：

| ❌ 纯数学描述（AI感） | ✅ 有机运动描述（去AI感） |
|---|---|
| `镜头缓慢推向面部特写` | `镜头缓慢推向面部特写，到位时微微过冲后回稳` |
| `镜头跟随角色向右平移` | `镜头跟随角色向右平移，角色停步时镜头惯性微过冲后稳住` |
| `镜头静止，前景清晰` | `镜头近似静止，画面重心极缓慢地微幅漂移，前景清晰` |
| `镜头从高处向下俯瞰` | `镜头从高处向下俯瞰，下降过程中水平轴微偏后修正` |

### 原则⑨ 介质→可见现象

**规则**：大气介质不写专业名（体积光/丁达尔效应），写**微粒在光线中的具体表现**。

| 人读层 | 机读层翻译 |
|---|---|
| `体积光（粉笔灰）` | `细小的粉笔灰微粒在每一道冷蓝光柱中沉浮翻涌如鬼雾` |
| `丁达尔效应` | `阳光从窗户缝隙射入，在尘埃中形成可见的金色光束` |

## 二、翻译审计规范

### 2.1 翻译审计表格式（必做）

> 🔴 **强制：前验格式，禁止后验自检。**

### 2.5 角色一致性铁律（主角与变体）

**核心规则**：同一角色的主角形象与其任何**变体**（换装、年龄变化/回忆闪回、受伤状态、异化/变身等）之间，机读层必须明确说明**视觉锚点**以保持核心一致性。

**三类核心视觉锚点（每条变体镜头至少覆盖2项）**：

| 锚点类型 | 说明 | 写法示例 |
|---------|------|---------|
| **面部特征锚点** | 角色最核心的辨识面部特征 | "同一张清瘦脸庞，双眼皮明显" / "下颌线相同" |
| **标志性色彩/材质** | 不随变体改变的颜色标识 | "始终保持黑色长发" / "标志性的红色围巾" |
| **独特身体标记** | 疤痕/胎记/纹身/体型比例 | "左眼下方月牙形疤痕" / "右手虎口纹身" |

**机读层变体写法规范**：

```
[变体描述]（核心锚点：[锚点1] + [锚点2] 与主角一致）
```

示例：
- `年幼版小阳（约10岁，清瘦脸庞与双眼皮特征与成年主角一致，身穿旧校服）`
- `受伤版陈恩义（左脸有血痕，但清冷眼神与刀削轮廓线与主角基础形象一致）`
- `回忆版父亲（年轻约25岁，皮肤粗糙与高颧骨特征与当前版本一致，短发）`

**🔴 FAIL 条件**：

| 违规表现 | 判定 |
|---------|------|
| 角色变体出现（换装/时间跳跃/状态变化）但机读层无任何核心锚点描述 | 🔴 FAIL |
| 变体描述与主角描述的核心特征矛盾（如主角双眼皮，变体写成细长单眼皮） | 🔴 FAIL |
| 有@图片的角色在变体镜头中未引用@图片且无文字锚点补充 | 🔴 FAIL |

**✅ 100%覆盖检查清单（角色一致性）**：
- [ ] 本P中角色是否为变体（换装/年龄/状态变化）？
- [ ] 若是 → 机读层第一句是否包含"核心锚点：...与主角一致"的描述？
- [ ] 变体描述的核心特征是否与素材对应表/@图片定义无矛盾？
