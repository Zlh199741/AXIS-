# 动作导演增强模块

## 模块定位

本模块是 Seedance 分镜编写技能的**动作戏增强组件**。当导演分析阶段识别出战斗/动作场面时，自动启用本模块进行分镜编写。

---

## 触发条件

当剧情点包含以下特征时，启用动作导演增强模块：

| 特征类型 | 关键词 |
|----------|--------|
| 战斗类 | 打斗、格斗、比武、攻击、防守、反击、杀手、刺客 |
| 冲突类 | 冲突、对峙、追赶、拦截、压制、爆发 |
| 特效类 | 释放技能、催动内力、真气外放、魔法、能量冲击 |
| 物理类 | 撞击、摔投、拳脚、武器交锋 |

---

## 核心逻辑

### 1. 时间逻辑（节奏控制）

#### 快节奏战斗序列（ Explosive Pace）
- **镜头序列**：特写(0.8s) → 近景(1s) → 中景(1.2s) → 全景(0.5s)
- **关键词**：动态模糊、高速运动、快切、短时
- **视听映射**：对应维度三"神经劫持" - 物理丢帧策略

#### 慢镜头特写序列（Slow Motion）
- **镜头序列**：全景(3s) → 中景(4s) → 近景(5s) → 特写(6s)
- **关键词**：时长递增、景别聚焦、情感沉淀、留白
- **视听映射**：对应维度六"情感熵" - 时间弹性

#### 快慢结合序列（Mixed Pace）
- **节奏设计**：快 → 慢 → 快 或 慢 → 快 → 慢
- **关键词**：极静转化极动、变速对冲、节奏张弛交替
- **视听映射**：对应呼吸波形剪辑

### 2. 空间逻辑（转场设计）

#### 镜头间转场

| 转场类型 | 关键词 | 使用场景 |
|----------|--------|----------|
| 淡入淡出 | 转场:淡入淡出 | 同一场景内的情绪延续 |
| 叠化 | 转场:叠化、交叉溶解 | 场景切换、时间流逝 |
| 硬切 | 硬切、瞬间切换 | 突发冲击、视觉暴击 |
| 运动匹配 | 运动延续、视角连贯 | 同一主体不同角度 |

#### 视角连续性规则

- **方向一致**：上一镜头角色向右移动，下一镜头继续向右
- **高度匹配**：相邻镜头视线高度保持一致
- **构图关联**：通过共享元素或空间关系连接镜头

#### 环境过渡

当场景转换时（如 宗门大殿 → 后山竹林）：
- 添加：`转场:叠化 + 环境过渡:从红墙黛瓦到翠绿竹林`

### 3. 三角色协作

| 角色 | 职责 | 输出 |
|------|------|------|
| 动作导演 | 设计物理可信的动作链 | 动作链描述 |
| 摄影指导 | 将节奏参数转化为具体镜头运动 | 镜头序列设计 |
| 硬核小说家 | 使用具象动词和感官语言 | 叙事描述 |

---

## 输入参数

从导演分析阶段获取以下参数：

1. **Start Frame（起始帧）**：初始姿态、攻防双方设置、力量来源、环境
2. **End Frame（结束帧）**：冲击反馈、着点、伤害、破坏
3. **Combat Style（战斗风格）**：
   - 武侠气功（Wuxia/Qi）
   - 科幻机甲（Sci-Fi Mecha）
   - 写实格斗（Realistic MMA）
   - 奇幻魔法（Fantasy Magic）
   - 忍者迅捷（Ninja/Speed）
   - 暴力美学（Violent Aesthetic）
4. **Core Move（核心招式）**：标志性攻击名称
5. **Pace Focus（节奏焦点）**：极速爆发/慢镜特写/快慢结合

### 🔴 动作因果链验证机制（v2.0 新增）

#### 因果链公式

每个动作必须满足 **因→果→果的因** 三段验证：

```
[前置状态] → [动作执行] → [物理结果] → [后续状态]
     ↑            ↑            ↑            ↑
  角色姿态     力量来源     反馈合理性   下一动作前提
```

#### 因果合理性校验表（🔴 每条动作链必须逐行校验）

| 校验维度 | 校验问题 | 不合格示例 | 合格示例 |
|----------|----------|------------|----------|
| 力量来源 | 攻击的力量从哪来？ | 站立不动直接击飞对方10米 | 腰马合一蓄力→拳风凛冽→对方击退5米 |
| 姿态连续 | 上一个动作结束后身体处于什么姿态？ | 刚倒地→下一帧站着出招 | 刚倒地→单膝撑地→借力弹起→出招 |
| 防御响应 | 被攻击方在攻击到达前有无反应？ | A出拳→B直接被打飞（B是木桩？） | A出拳→B侧身闪避/横剑格挡→仍被余力击退 |
| 蓄力-威力匹配 | 蓄力时长与攻击威力是否成正比？ | 0.3秒蓄力→毁天灭地 | 3秒蓄力→L3级环境破坏 |
| 伤害累积 | 受伤后战斗力是否受影响？ | 吐血三次→依然满血战斗 | 吐血三次→动作变慢/招式变形/呼吸急促 |
| 环境交互 | 场景破坏是否影响后续动作？ | 地面崩裂→角色仍在原地站稳 | 地面崩裂→角色借碎石跳跃/失去平衡 |

#### 蓄力-威力量化对照

| 蓄力时长 | 最大合理威力 | 环境破坏上限 | 击退距离上限 |
|----------|-------------|-------------|-------------|
| 0-0.5s | 普通一击 | L1 轻微 | 1-2米 |
| 0.5-1s | 重击 | L1-L2 | 3-5米 |
| 1-2s | 强力技能 | L2-L3 | 5-10米 |
| 2-4s | 大招释放 | L3-L4 | 10-30米 |
| 4s+ | 终极必杀 | L4-L5 | 30米+/击穿场景 |

### 🔴 多人战斗轴线管理系统（v2.0 新增）

#### 轴线分级

```
主轴线（Master Axis）
  ├── 核心对抗双方的连线（如 A vs B）
  ├── 整场战斗的空间参考基准
  └── 除非叙事需要，永远不越此轴
  
子轴线（Sub Axis）
  ├── 其他参与者与主轴线的关系线
  ├── 可在子轴线内自由运镜
  └── 切回主轴线时必须有"桥接镜头"
```

#### 多人站位管理（钟面坐标系）

以场景中心为圆心，用钟面方向标注每个角色位置：

```
        12点（北）
         |
9点 ----+---- 3点
         |
        6点（南）

示例（三人战）：
A = 10点方向（左侧偏上）
B = 2点方向（右侧偏上）→ A-B 为主轴线
C = 6点方向（下方）→ C-A / C-B 为子轴线
```

#### 越轴规则（🔴 铁律）

| 越轴条件 | 处理方式 | 示例 |
|----------|----------|------|
| 角色穿越画面 | 用角色运动带领观众越轴 | A从左冲向右，经过B身旁，轴线自然翻转 |
| 中性镜头桥接 | 插入正面/俯拍等轴线中性角度 | 俯拍全景→新轴线角度 |
| 环绕运镜 | 摄影机绕角色移动完成越轴 | 环绕A的面部从左到右，新轴线建立 |
| ❌ 硬切越轴 | **禁止**——除非刻意制造眩晕/混乱感 | 仅用于"失控混战"等特殊叙事 |

#### 多人战斗镜头切换规则

```
规则1：每次切换视角，必须先给"新视角主体"一个建立镜头
规则2：3人战斗 → 最多同时追踪2条轴线
规则3：4人以上 → 必须分组（2v2、1v多），每组独立轴线
规则4：混战场景 → 锁定一个POV角色，其他人相对他运动
规则5：切回主角视角时，用"视线匹配"衔接（主角看向→看到的内容）
```

### 🔴 动作戏情绪曲线系统（v2.0 新增）

#### 战斗四幕结构

每场动作戏（无论几条P）必须设计完整情绪弧线：

```
情绪强度
  ▲
  │        ③逆转点
  │       ╱ ╲
  │      ╱   ╲  ④决杀
  │     ╱     ╲╱╲
  │  ②胶着    　  ╲
  │  ╱              ╲  ⑤余波
  │╱                 ╲___
  ①试探
  └──────────────────────► 时间
```

| 阶段 | 情绪目标 | 节奏 | 镜头特征 | 持续比例 |
|------|----------|------|----------|----------|
| ①试探 | 紧张、克制 | 慢→中 | 全景/中景交替，稳定运镜 | 15-20% |
| ②胶着 | 焦灼、拉锯 | 中→快 | 快切、过肩镜头、近景 | 25-30% |
| ③逆转 | 震撼、意外 | 急停/慢镜 | 特写+时间冻结+越轴冲击 | 15-20% |
| ④决杀 | 爽快、释放 | 极快→骤停 | 快切combo→定格特写 | 20-25% |
| ⑤余波 | 沉淀、震撼 | 慢 | 全景拉远、空镜、残留特效 | 10-15% |

#### 情绪钩子对接（桥接 director-skill 钩子学）

| director-skill 钩子 | 动作戏对应 | 融合方式 |
|---------------------|-----------|----------|
| 黄金3秒 | ①试探开篇 | 用"危机一击"或"杀意释放"作为开篇冲击 |
| 前10秒叙事 | ①试探→②胶着过渡 | 快速交代力量对比和核心矛盾 |
| 1分钟高潮 | ③逆转+④决杀 | 战斗的情绪顶点必须对齐全片高潮 |
| 卡点钩子 | ⑤余波末尾 | 胜负已分但留下更大悬念/代价揭示 |

#### 单条P的微情绪曲线

当动作戏只占1条P时，压缩为三段式：
```
蓄势（20%）→ 爆发（60%）→ 回响（20%）
```

### 🔴 打击感强制调用协议（v2.0 新增）

编写动作戏提示词时，**每一次攻击命中**必须从以下四维度各选至少一项写入提示词：

```
🥊 打击感四维强制调用
├── [视觉] 从4.1表中选：命中火花/冲击波/粒子效果/画面震动 中至少1项
├── [物理] 从4.2表中选：击退距离/倒地方式/墙壁撞击/地面摩擦 中至少1项
├── [时间] 从4.3表中选：子弹时间/停顿帧/特效残留 中至少1项
└── [角色] 从4.4表中选：受击者的反应动作 至少1项
```

#### 打击感速查卡（写入提示词时直接套用）

| 攻击等级 | 视觉反馈 | 物理反馈 | 时间反馈 | 角色反应 |
|----------|----------|----------|----------|----------|
| 轻击 | 金色火花 | 击退1米 | 无特殊 | 痛苦表情 |
| 中击 | 冲击波(环形) | 击退3-5米+地面摩擦 | 停顿1帧 | 咬牙硬撑 |
| 重击 | 粒子效果(碎片) | 击退5-10米+墙壁撞击 | 子弹时间0.5s | 口喷鲜血 |
| 必杀 | 画面强烈震动+冲击波 | 击穿墙壁/击退10米+ | 子弹时间1-2s+停顿3帧 | 惨叫+倒地 |
| 终极 | 全屏白光/粒子爆炸 | 地面崩裂/山体滑坡 | 子弹时间2s+特效残留3s | 灰飞烟灭/昏迷 |

#### 提示词写入格式

```
...拳头命中对方胸口，金色火花迸溅（视觉），对方身体向后滑出三米，
双脚在地面划出两道深痕（物理），命中瞬间画面微微停滞（时间），
对方面部扭曲，牙关紧咬强撑不倒（角色反应）...
```

### 🔴 跨P动作连贯性检查协议（v2.0 新增）

当连续多条P构成同一场战斗时，必须执行以下检查：

#### 跨P状态传递表（🔴 每场战斗必填）

```markdown
| 检查项 | P0X结尾状态 | P0(X+1)开头状态 | 是否一致 |
|--------|-------------|-----------------|----------|
| 角色姿态 | [如：单膝跪地] | [必须延续或合理过渡] | ✅/❌ |
| 角色位置 | [如：3点钟方向5米处] | [必须延续] | ✅/❌ |
| 伤势累积 | [如：左臂受伤+吐血1次] | [必须体现] | ✅/❌ |
| 场景破坏 | [如：地面L2破坏] | [破坏不能消失] | ✅/❌ |
| 武器/法宝状态 | [如：剑已折断] | [不能突然恢复] | ✅/❌ |
| 能量/体力 | [如：真气消耗70%] | [后续招式威力应下降] | ✅/❌ |
| 天气/光线 | [如：乌云密布] | [必须延续] | ✅/❌ |
| 情绪阶段 | [如：②胶着→③逆转] | [接续③逆转] | ✅/❌ |
```

#### 跨P衔接技法

| 衔接方式 | 描述 | 适用场景 |
|----------|------|----------|
| 动作接力 | P结尾A出拳 → 下一P开头拳头命中 | 攻击跨P |
| 视线桥接 | P结尾A看向远处 → 下一P展示A看到的内容 | 视角转换 |
| 声音先导 | P结尾留下环境音（如剑鸣） → 下一P从该声音展开 | J-Cut跨P |
| 状态延续 | P结尾角色喘息 → 下一P开头仍在喘息中 | 体力衰竭 |
| 环境锚定 | P结尾聚焦破碎的柱子 → 下一P从同一柱子旁展开 | 空间连续 |

| 空间撕裂/虚空效果 | ⭐ | ⭐ | ⭐⭐ | 简化为光效+扭曲 |
| 精细面部微表情 | ⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐ | Seedance/Kling 3.0 优先 |
| 快速切换（<0.5s/镜头） | ❌ | ❌ | ❌ | 单条P不做快切，后期剪辑实现 |
| 慢动作/子弹时间 | ⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐ | 直接生成，天然适合AI |

#### AI不友好动作的替代策略

| AI难以生成的动作 | 替代方案 |
|-----------------|----------|
| 多人混战快切 | → 分解为多条P，每条锁定单一视角 |
| 复杂连招combo | → 用"蓄力→命中结果"跳过中间过程 |
| 精确武器碰撞 | → 用特写+火花暗示碰撞，不拍碰撞瞬间 |
| 法天象地巨型法相 | → 用远景剪影+光芒暗示，不拍清晰全身 |
| 多角色同步动作 | → 分条P各拍一人，后期交叉剪辑 |
| 快速位移（闪现） | → 用残影+目的地出现，省略移动过程 |

## 执行流程

### 步骤1：识别动作戏类型

分析导演阐述，判断是否为动作戏，提取：
- 战斗风格
- 核心招式
- 节奏模式
- 🆕 **情绪阶段**：本条P处于战斗四幕的哪个阶段？
- 🆕 **AI可行性预判**：涉及的动作是否AI友好？

### 步骤2：设计动作链 + 因果验证

将核心招式转化为物理动作序列：
1. 预备动作（蓄力）
2. 释放动作（攻击）
3. 命中反馈（效果）
4. 结束姿态（结果）

🆕 **必须执行**：用"因果合理性校验表"逐行验证动作链的每个环节。

### 步骤3：确定镜头序列 + 轴线管理

根据节奏模式选择模板：
- 快节奏 → Template A
- 慢节奏 → Template B
- 混合节奏 → Template C

🆕 **多人战斗**：标注主轴线/子轴线，确认越轴是否合规。

### 步骤4：映射视听语言 + 打击感调用

将动作设计映射到统一视听语言库：
- 时间逻辑 → T0标准维度
- 空间逻辑 → 转场设计
- 物理参数 → 动态模糊/阻尼

🆕 **每次命中**：必须执行"打击感四维强制调用"，从视觉/物理/时间/角色反应各选至少1项。

### 步骤5：生成Seedance提示词

按照动作戏专用模板输出，融合：
- 素材引用
- 空间坐标
- 动作序列
- 镜头切换
- 音效标注
- 🆕 打击感四维描述
- 🆕 AI可行性评级标注

### 🆕 步骤6：跨P连贯性检查

如果本条P与前/后P属于同一场战斗：
- 填写"跨P状态传递表"
- 确认姿态/位置/伤势/场景破坏/武器状态/能量/天气/情绪阶段全部一致
- 选择合适的"跨P衔接技法"

### 🆕 步骤7：情绪曲线校验

对照"战斗四幕结构"，确认：
- 本条P处于哪个情绪阶段
- 节奏/镜头特征是否与该阶段匹配
- 整场战斗的情绪弧线是否完整

## 增强篇：东方神话与战斗动作系统

### 一、东方神话物理法则（仙侠/玄幻专属）

#### 1.1 元素化位移
- **定义**：允许人物在移动时解体为黑雾/流光/剑气，攻击时瞬间凝聚实体
- **参考**：钟馗化雾、仙剑御剑
- **视觉表现**：
  - 黑雾形态：黑色烟尘翻滚、侵蚀路径
  - 流光形态：金色/银色光芒拖尾
  - 剑气形态：白色剑光分离

#### 1.2 法天象地
- **定义**：允许召唤巨大的元神/法相在身后同步攻击
- **效果**：极大vs极小对比，产生视觉压迫感
- **应用场景**：
  - 身后法相升起 → 主角显得渺小但气势强大
  - 巨人之身 → 压迫感

#### 1.3 虚实转化
- **定义**：实体与虚影之间的转换
- **表现**：
  - 虚影：半透明、飘忽不定
  - 实体：完全凝实、有实体光影

#### 1.4 灵气化形
- **定义**：真气外放具象化
- **颜色分类**：
  - 金色：神圣、正义、高贵
  - 血色：暴虐、嗜血、邪恶
  - 黑色：魔道、腐蚀、诡异
  - 白色：纯净、浩然、正气
  - 青色：清新、自然、木系

#### 1.5 虚空撕裂
- **定义**：空间裂缝效果
- **表现**：
  - 空间扭曲、裂纹蔓延
  - 能量喷涌、光芒绽放
  - 吞噬效果、引力扭曲

0-3s [潜伏]：俯拍，月光穿过竹林缝隙，黑影蛰伏在竹叶阴影中，仅见双眼微光闪烁（静止长镜头）
3-5s [突袭]：黑影化为残影暴起，三道残影同时出现在不同位置，苦无脱手飞出"嗖——"（极速跟拍）
5-7s [交锋]：目标拔刀格挡，苦无撞击刀面火花迸溅"当——"，忍者已绕至身后（环绕快速跟拍）
7-9s [追逐]：目标转身挥刀扑空，忍者踩竹尖借力跳跃，竹竿弯曲弹回（仰拍追踪）
9-11s [致命一击]：忍者从上方俯冲，短刀直刺"噗——"，命中瞬间画面冻结0.8s（视觉），目标身体前倾（物理），血雾在月光下呈银色（时间），目标瞳孔涣散（角色）
11-13s [脱离]：忍者单手撑地翻身后撤，收刀入鞘，身后竹叶纷纷断落
13-15s [消失]：薄雾涌起，忍者身形渐淡消散于雾中，仅留一片竹叶缓缓落地

【因果链验证】
潜伏蛰伏(速度蓄力) → 残影突袭(爆发力释放) → 竹尖借力(轻功合理) → 俯冲一击(重力加速) ✅

【战斗动作库调用】

出招：苦无投掷、短刀突刺、连环暗器

### 十四、混合风格战斗协议（v3.0 新增）

#### 🔴 混合战斗触发条件

当同一场战斗中出现以下情况时，启用混合风格协议：
- 同一角色在战斗中切换战斗方式（如：法师用完魔力后拔剑肉搏）
- 不同风格的角色对战（如：忍者 vs 武侠剑客）
- 场景转换导致风格切换（如：机甲被毁→驾驶员跳出→近身格斗）
- 剧情要求风格融合（如：赛博忍者、魔法武侠）

#### 风格切换桥接规则

| 切换类型 | 桥接方式 | 持续时长 | 示例 |
|----------|---------|---------|------|
| 渐变切换 | 用1-2秒过渡镜头展示风格变化 | 1-2s | 法师魔力耗尽→法杖断裂→拔出匕首（奇幻→写实） |
| 突变切换 | 用硬切+冲击感标记风格转变 | 0.3-0.5s | 机甲爆炸→驾驶员弹射→落地翻滚（科幻→写实） |
| 融合并行 | 两种风格同时存在，各占画面一部分 | 持续 | 忍者用忍术+武侠用剑法，交叉剪辑 |
| 升级切换 | 战斗升级导致风格进化 | 1-3s | 普通格斗→角色觉醒→释放内力（写实→武侠） |

#### 混合战斗子系统调用规则

```
规则1：主风格占比 ≥ 60%，副风格占比 ≤ 40%
规则2：动作词库可混合调用，但每条P内只用一个风格的打击感参数
规则3：音效库可叠加（如忍者暗器音+武侠剑鸣音）
规则4：情绪曲线使用主风格的曲线模型
规则5：AI可行性评级取两种风格中较低的那个
规则6：风格切换点必须有明确的叙事触发（不能无理由切换）
```

### 十五、体力/资源消耗曲线系统（v3.0 新增）

#### 设计目的

确保长时间战斗中角色的体力、能量、伤势随时间推移合理变化，避免"永动机式战斗"。

#### 消耗-表现对照表（🔴 每条P必须参照）

| 资源剩余 | 角色状态 | 动作表现 | 提示词必须体现 |
|----------|---------|---------|--------------|
| 100-80% | 全盛 | 动作流畅有力、招式完整 | 正常描写 |
| 80-60% | 轻微疲劳 | 偶尔喘息、汗水增多 | "额头汗珠""呼吸微促" |
| 60-40% | 明显消耗 | 动作变慢、防御出现破绽 | "动作迟缓""防御不及" |
| 40-20% | 危险状态 | 招式变形、无法使用大招 | "摇摇欲坠""强撑站立" |
| 20-0% | 极限 | 仅能做基本动作、随时可能倒下 | "视线模糊""单膝跪地" |
| 0% | 耗尽 | 无法继续战斗 | "瘫倒在地""意识模糊" |

#### 体力消耗与因果链联动

```
蓄力-威力对照表 + 体力消耗 = 实际威力

示例：
- 角色体力100%，蓄力2s → 大招威力100% → L3破坏
- 角色体力40%，蓄力2s → 大招威力50-60% → L2破坏（因体力不足减弱）
- 角色体力20%，蓄力2s → 大招失败/半途中断 → L1或无破坏
```

#### 跨P体力传递规则（🔴 铁律）

1. **体力只降不升**（除非剧情明确有恢复手段）
2. **每条P结尾必须标注当前体力百分比**
3. **下一条P开头体力 ≤ 上一条P结尾体力**
4. **体力低于40%时，必须在提示词中体现疲劳**
5. **体力低于20%时，禁止使用S级以上大招**
