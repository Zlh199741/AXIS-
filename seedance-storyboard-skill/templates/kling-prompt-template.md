## P01 [剧情标题]

**音画设计**：
- 声音类型：[对话/旁白/环境音/混合音效；禁止唱歌、说唱、BGM及任何可生成音乐内容]
- 角色音色：[音色描述，如"沉稳男声"、"清脆女声"]
- 情绪氛围：[紧张/温馨/悬疑等]
- 时长：5s / 10s

**Kling 2.6 提示词**：
```
【场景】[场景描述，包含时间、光线、地点]
【主体】[角色外观描述，参考@图片1]
【音频】[角色@音色名称]"[台词内容]"[情绪描述]
背景叠加[环境音效]，镜头为[镜头类型]拍摄。

[完整叙事描述：场景环境、主体动作、运镜、音频细节]
```

**重要**：以下信息必须全部包含在 Kling 提示词中：

1. **场景构建**：
   - 【场景】：时间、光线、地点、空间布局
   - 【主体】：角色外观描述
   - 明确画面与音频的配合

2. **音频设计**（Kling 核心）：
   - 【音频】：角色标签 + 台词 + 情绪/音色
   - 环境音效：场景背景音
   - 物体/动作音效：如脚步声、碰撞声

3. **多角色对话规范**（P1-P4原则）：
   - P1. 结构化命名：每个角色使用唯一标签如 [角色A: 描述]
   - P2. 视觉锚定：先描述动作，后接台词
   - P3. 音频细节：为每个角色赋予独特音色和情绪标签
   - P4. 时序控制：使用"紧接着"、"这时候说话人切换"等连接词

4. **镜头运动**：
   - 镜头类型：近景/中景/远景/特写
   - 镜头运动：推进/拉远/环绕/跟拍
   - 与音频节奏配合

5. **时长选择**：
   - 5s：适合单一动作/快节奏场景
   - 10s：适合对话/复杂场景

**Kling 2.6 提示词模板**：

```
【场景】[场景描述，时间+光线+地点+空间布局]
【主体】[角色描述，如"穿黑色西装的男子"，参考@图片1]
【音频】[角色@音色]"[台词]"[情绪] / [环境音效] / [动作音效]

[完整叙事描述：
- 画面内容：场景环境、角色动作、表情变化
- 运镜：镜头类型和运动方式
- 音频：对话内容、现场音效、环境音；禁止任何可生成音乐内容
- 氛围：情绪基调、节奏]
```

## Kling 2.6 vs Seedance 2.0 对比

| 特性 | Kling 2.6 | Seedance 2.0 |
|------|-----------|--------------|
| 音画同步 | ✅ 音画同出（一次生成） | ❌ 需单独生成音频 |
| 素材引用 | @图片参考（视觉） | @图片/@音频（需分别生成） |
| 提示词结构 | 【场景】【主体】【音频】 | 叙事式描述 |
| 音频类型 | 对话/音效/环境音 | 需单独描述 |
| 时长限制 | 5s / 10s | 无固定限制 |
| 音色控制 | 支持 @音色名 | 无此功能 |
| 输出格式 | 结构化标签 | 自由叙事 |

## 音频写作规则（来自 Kling 官方手册）

| 类型 | 写作要点 |
|------|---------|
| 对话（单角色） | 角色标签 + 句子 + 情绪 + 语速 + 音色 |
| 对话（多角色） | 使用唯一标签，如 [A角色]"句子" [B角色]"句子" |
| 禁用项 | 禁止唱歌、说唱、纯音乐、BGM及任何可生成音乐内容 |
| 音效 | 声音来源 + 状态 + 拟声词 |
| 环境音 | 场景 + 声音元素 + 空间混响 |
| 现场音效节奏 | 声音来源 + 节奏密度 + 空间混响；禁止纯音乐/BGM |
