**T0视听语言设计**：
- 镜头关系：[轴线/越轴/视线匹配]
- 剪辑节奏：[动接动/静接静/冲击剪辑/呼吸节奏]

- 原点：[场景固定物体]
- 方向基准：[如门=6点钟方向]
- 角色坐标：[角色A位于(0,0,0)]

**时长**：5s / 10s

**Kling 2.6 提示词**：
```
【场景】[场景描述，时间+光线+地点+空间布局]
【主体】[角色描述，参考@图片1]

## 二、T0工业级输出规范

### 2.1 必须包含的T0要素

| 要素 | 说明 |
|------|------|
| 空间坐标锚点 | 原点+方向基准+角色坐标 |
| 视线对焦 | Eye-line锁死/越轴标注 |
| T0视听语言 | 物理动力学/构图权力/神经劫持 |
| 声音设计 | J-Cut/L-Cut/声画对位 |

### 2.2 音频写作规则

|| 类型 | 写作要点 |
|------|---------|
| 对话（单角色） | 角色标签 + 句子 + 情绪 + 语速 + 音色 |
| 对话（多角色） | 使用唯一标签，如 [A角色]"句子" [B角色]"句子" |
| 禁用项 | 禁止唱歌、说唱、纯音乐、BGM及任何可生成音乐内容 |
| 音效 | 声音来源 + 状态 + 拟声词 |
| 环境音 | 场景 + 声音元素 + 空间混响 |
| 现场音效节奏 | 声音来源 + 节奏密度 + 空间混响；禁止纯音乐/BGM |

### 2.3 尾缀规范（必加）
```
1.视频画面禁止出现任何字幕、文字、标题或水印；2.视频不要有背景音乐，仅保留人声和动作音效；3.禁止出现任何文字气泡、对话气泡、聊天气泡或漫画式对白框。
```
### 2.4 🔴 翻译审计要求（新增 2026-03-19）
- 每条提示词必须按 `translation-audit-rules.md` 中的14条原则翻译
- 每条提示词必须附带「📐 翻译审计」表（格式如下）：
```markdown
#### 📐 翻译审计（P[XX]共使用[N]条原则）
| 机读层原文 | 使用原则 | 人读层设计来源 |
|---|---|---|
| `[具体短语]` | [原则编号]→[翻译方向] | `[对应设计意图]` |
```
- 机读层不得包含任何专业术语，空间描述禁止钟面方位数字
- 标准示范：🟢 `outputs/ep01/02-seedance-prompts.md`（**增强版，优先参考**）/ `outputs/ep02/02-seedance-prompts-EP01标准示范版.md`

## 三、Kling 2.6 vs Seedance 2.0 对比

|| 特性 | Kling 2.6 | Seedance 2.0 |
|------|-----------|--------------|
| 音画同步 | ✅ 音画同出（一次生成） | ❌ 需单独生成音频 |
| 素材引用 | @图片参考（视觉） | @图片/@音频（需分别生成） |
| 提示词结构 | 【场景】【主体】【音频】 | 叙事式描述 |
| 音频类型 | 对话/音效/环境音 | 需单独描述 |
| 时长限制 | 5s / 10s | 4-15秒 |
| 音色控制 | 支持 @音色名 | 无此功能 |
| 输出格式 | 结构化标签 | 自由叙事 |
| T0标准 | 视听语言/空间坐标/视线对焦 | 视听语言/空间坐标/视线对焦 |
