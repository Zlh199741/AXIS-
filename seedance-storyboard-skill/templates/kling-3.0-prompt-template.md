## 一、Kling 3.0 五大新特性（必须融入T0标准）

### 1.1 智能分镜（T0增强）
- 使用「镜头1、镜头2」标记触发自动分镜
- 支持正反打、台词跨分镜、画外音
- 无需繁琐后期，一次生成即是成熟影像叙事
- 支持「智能分镜」与「自定义分镜」两种模式

### 1.2 主体参考（T0增强）
- 绑定画面特定元素，确保主角始终如一
- 镜头推拉摇移，主体也能清晰稳定
- 视觉主体 + 音色双重一致
- 使用 @主体 标签绑定已创建的主体

### 1.3 全能音画（T0增强）
- 支持**三人以上**多角色指代
- 支持多语种：中、英、日、韩、西
- 支持方言：粤语、四川话、东北口音、英式/美式/印度口音
- 支持多语混说

### 1.4 原生级文字（T0增强）
- 精准保留原图中的招牌、字幕、标识
- 生成全新文字内容时字迹清晰

### 1.5 15秒超长生成（T0增强）
- 支持 **3-15秒** 灵活时长
- 复杂叙事选 10-15s，单一场景 5s
