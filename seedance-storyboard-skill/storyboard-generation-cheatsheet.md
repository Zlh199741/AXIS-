## 🔴🔴 零·机读层唯一权威格式（最高优先级 — 2026-05-31）

**机读层（🎬 提示词）唯一合法格式 = 自然语言格式**（本速查表 + SKILL.md + 审核 skill 同一口径）：
1. 每条 P 机读层**第一行** = `[Global Spatial Anchor: ...]`（空间锚点GSA）。
2. 画面 = 70% 自然语言 + 30% 可执行影视词；时间段 `0·Xs秒：`（推荐 `·`，`0-Xs秒：` 兼容）。
3. 台词内联进秒数段（见"台词内联唯一模板"）；音效写独立 `音效层：`；素材用 `参考@图片N`。
4. 🔴 **GSA 跨片引用禁令（P8 — 2026-06-06 新增）**：机读层逐条独立喂模型、模型对其它 P 零记忆，故 GSA 内禁止任何跨片文字引用（`承接PXX`/`承接PXX终态`/`同PXX结束位置`/`同一坐位`/`匹配剪辑承接PXX`/`承接P15画面淡出`等）→ 出现即 FAIL。"继承上一P结束态"须改写为**本P绝对站位重述**（左/右/上/下＋距离＋视线＋道具在场＋开关态环境）；画面级同坐位/同构图靠**首帧承接**（把上一条尾帧或构图定格作参考图）实现；跨片衔接叙事意图只写导演分析（`01-director-analysis.md`：连续性约束/衔接设计/起幅落幅），不进分镜文件。（`陈屿 终态在画面右前方` 这类**本镜内**终态位置合法。）
5. 🔴 **视频单元 + 镜头切换 + 接点分镜图（2026-06-09 修订）**：原子生成单元＝**一个视频(一次生成)＝≤15s**，🔴 **视频内部可含多个镜头切换**（模型一次生成完成，短剧快剪常态，不得因切得多判 FAIL）。镜头要**快**：1–4s/镜，一个 15s 视频可装 4–6 镜（旧"单镜=一次生成/5–8s"已废）。**拆视频唯一硬线＝15s**：视频总长 >15s 才拆 Pxa/Pxb，**视频之间**用 @分镜图承接（基础数据照传 + 变动数据做成 @分镜图：原画质尾帧→改新站位→喂下一视频，同机位复用，台词镜必配图）。台词镜时长=字数÷语速(**按戏型选档:慢戏3–4/日常4–5/快戏5–6字/秒**,见SKILL.md,严禁一刀切3–4字/秒把快戏拖懒;小动作叠说话不另计)。**FAIL**：单视频 >15s 未拆 / 用慢档把快戏拖沓。详见 SKILL.md 同名段 + `references/stitching-and-shot-handoff.md`。

🔴 **附件④的 6 层堆栈（`[GLOBAL]`等）/ 小蔡 6 字段（焦段mm/光圈f/英文运镜）/ `00:00·00:03` / `{}`台词 / `<>`音效嵌行 / `@image_N` —— 全部仅供人读层与帧规划层，严禁进机读层。** 机读层出现以上任一 → FAIL。
⚠️ `[Global Spatial Anchor:]`（机读层首行）≠ 附件④的 `[GLOBAL]`（人读层标签），勿混。

## 二、每条P的强制四要素

> 🔴 2026-06-08 方向C 单层：9维度/情绪钩子等设计思考归导演分析（`01-director-analysis.md`），不在分镜文件重写。每条P成品落地以下可执行要素：

| 要素 | 单层成品（机读层）必须包含 |
|---|---|
| **空间锚点** | 首行 `[Global Spatial Anchor: ...]`；正文画面位置词（左/右/上方/下方/中央/深处），有人物必说明其画面位置 |
| **镜头语言** | 🔴 每段点名景别（特写/近景/中景/全景）＋点名且具体的运镜（缓推/横摇/手持跟拍；禁 mm/f 数字、禁英文运镜） |
| **情绪物理化** | 微表情（面部肌肉）＋发声方式；禁"她很伤心/温柔地/压迫感"等抽象词 |
| **台词** | 逐字源剧本原文（零删减）；口型/画外音/系统声绑定人声锚定ID＋音色参数 |
| **节奏** | 时间段 `0·Xs秒：`，总长与标题时长一致；按节拍分配，禁均分 |
| **声音/负面** | 独立音效层（无BGM）；尾缀禁文字/字幕/水印＋无背景音乐 |

违反"情绪物理化 / 台词逐字 / 运镜点名 / 空间锚点" → 该条P直接FAIL

## 三、平台格式规范

### Seedance 2.0
- 语言：**必须中文**，禁止英文提示词
- 结构（方向C 单层）：分镜文件＝🎬单层成品；导演思考（9维度/情绪钩子/讲戏）在 `outputs/<ep>/01-director-analysis.md`，不在分镜文件重写
- 成品**分级字数上限（P4 — 2026-05-31）**：无台词P ≤700 / 含台词P ≤1100 / 情绪长镜·多台词P ≤1300。🔴 台词字数不计入门禁、永不因字数删台词，超限优先删修饰词或拆P。
- 尾缀：`1.视频画面禁止出现任何字幕、文字、标题或水印；2.视频不要有背景音乐，仅保留人声和动作音效；3.禁止出现任何文字气泡、对话气泡、聊天气泡或漫画式对白框。`
- 🔴 方向C：原"每条P必附 📐翻译审计表"**已废除**（单层无翻译步骤）
- 🔵 **文件头推荐两个章节（方向C：已从 FAIL 降为推荐/warning，缺失不再阻断）**：
  1. `## 素材引用表`：每个素材必须用 `参考@图片N` 格式列出（❌ 禁止用 `# 素材清单：` 注释格式）
  2. `## 单条提示词预算表`：每条P一行，含 `预算通过 ✅`，末行含 `总文件数：N条`
  - 正确示例：`| 参考@图片1 | 角色 | 小白龙 |`
  - 错误示例：`# 素材清单：@图片1=小白龙`（此格式不被验证器识别）
- 🔴 **机读层每个 `@图片N` 必须紧跟角色名/场景名（❌ 裸号禁止出现）**：
  - ✅ 正确：`孙悟空（@图片2）` / `小白龙（@图片1）` / `南天门（@图片8）`
  - ❌ 错误：`取经团队（@图片2、@图片1、@图片6）`（三个号都没有名字）
  - ❌ 错误：`白色道袍的少年（@图片1）`（描述了但没有角色名）
- 🔴 **场景 @图片N 视角对齐规则（2026-04-06 增补）**：
  - `scene-prompts.md` 主视觉 = 通用外观参考，锚定**风格/色彩/建筑**
  - 每个场景的 `# P块分镜视角变体` = 对应 P 块实际摄影机角度的专用参考图
  - **使用优先级**：P块对应的视角变体 > 主视觉（若无视角变体则用主视觉+文字补全角度）
  - ✅ 正确：P01 使用「灵山顶广场 P01视角（极高处俯视）」变体
  - ❌ 错误：P01 直接引用主视觉（平视构图），然后期望视频模型推断正确角度
  - 镜头角度**必须在文字提示词中明确写出**，不依赖参考图暗示

## 五B、台词零删减铁律（2026-04-28 新增 — 优先级最高）

## 七B、画镜 Protocol A-F 速查（2026-04-10 新增）

> 来源：`seedance-storyboard-skill/SKILL.md` 第五步 + Section 4.6 + Section 6.4
> 详细规则查阅 SKILL.md 全文，此处为生成阶段速查

### Protocol A — 零代词 + @引用

- 机读层**严禁**：他/她/它/男人/女人/主角/两人/他们 → 全部替换为 `@角色名`
- 所有 `@角色名` / `@场景名` / `@物品名` **前后必须有空格**
- 关键道具用 `@物品名` 引用并描述空间关系

### Protocol B — 六维饱满（每时间段 ≥6/8 项）

| # | 维度 | 速查关键词 |
|---|------|-----------|
| 1 | 运镜 | 景别+运镜类型+速度 |
| 2 | 光影 | 光源方向+色温+明暗分割 |
| 3 | 环境细节 | 空间纵深+建筑/自然细节 |
| 4 | 材质质感 | 布料/金属/皮肤/石材触感 |
| 5 | 粒子动态 | 风/雾/灰尘/花瓣/雨丝/烟气 |
| 6 | 主体动作 | 具体部位动作+动作推进 |
| 7 | 面部锚点 | 微表情+生理反应+身体接触点 |
| 8 | 声音层 | 乐层+音效层（对白嵌入秒数段内，不在音效行） |

- 覆盖 <6 项 → 该时间段 FAIL

### Protocol C — 内容密度 + 时长真实

- 密度公式：镜头数 / 字数 x 100 = 2~4
- 时长按实际发生估算：静态2-3s / 简单动作2-3s / 短台词3-4s / 中台词4-6s / 长台词6-10s
- 3s 内容标 6s → FAIL

### Protocol C+ — 🔴 段内节拍密度门禁（每条P每段必检）

**公式**：`段内最大节拍数 = floor(该段时长秒数 ÷ 2.5)`

| 段时长 | 最大节拍数 | 能做什么 |
|--------|-----------|---------|
| 2s | 0 | 仅留白/定格 |
| 3s | 1 | 1个动作或1句短台词 |
| 5s | 2 | 1个动作+1次运镜 |
| 8s | 3 | 1组连贯动作+1次运镜 |

**对白铁律**：`口型对白 字数 × 0.4秒 / 画外音 字数 × 0.2秒`（下限2秒；与 sovereign-duration-predictor 及 SKILL 统一），两句对白不可同段（除非段时长 ≥ 两句之和 + 1秒）
**情绪转折**：每次转折 ≥ 2秒，不可与对白压缩同段

节拍数 > 上限 或 对白时长不足 → ❌ 该段 FAIL，必须拉长/拆段/移内容
详见 SKILL.md 7.3.1

### Protocol D — 视觉法医（禁止抽象词）

- 机读层严禁："悲伤/震撼/紧张/压抑/磅礴" 等抽象情绪词
- 强制替换为生理微反应（眼眶充血/嘴唇颤抖/手指攥紧）或环境具象（烛火摇曳/茶水波纹）
- 出现抽象词 → FAIL

### Protocol E — 防融图物理锚点（多角色同框必用）

- 句式：`@A [身体部位] [接触动词] @B 的 [身体部位]，@A 位于画面[方位]，@B 位于画面[方位]`
- 必须明确：谁/碰哪里/谁在哪 → 缺任一要素 → FAIL

### Protocol F — 无背景音乐与人声音色情绪控制（2026-05-19更新）

```
音效层：0秒衣袂摩擦声 + 3秒脚步回声 + 8秒门轴轻响。禁止任何可生成音乐内容（背景音乐、BGM、音乐铺底等）。
```
- 每条 P 的机读层必须含 `音效层`，未含 → FAIL
- Seedance 方案 B：不要背景音乐；出现任何可生成音乐内容（背景音乐、BGM、音乐铺底、弦乐/古筝铺底等）→ FAIL
- 🆕 **台词内联唯一模板（P3 — 2026-05-31 固化，全P强制同一句式，字段顺序不可变）**：
  `X·Y秒：…画面铺底+主体动作…参考@图片N [角色名]开口[口型对白/画外音/脑内独白]——"[源剧本原文，逐字不删]"（人声锚定V[n]；固定音色[年龄感+明暗+颗粒+气息位置]；语速[n]字/秒；音量[高/中/低]；气息[平稳/收住/短促]；尾音[收住/下压/上扬/发颤]；停顿[如有]）`
  - 🔴 "气声说出：…""低沉地说：…"等自由写法不合规 → 必须改为本模板
- 同一角色/旁白/系统声跨P保持同一声音ID和固定音色锚点；情绪只能通过语速、停顿、音量、气息、尾音变化表达
- `音效层` 只写环境音、动作音、特殊音效；出现人声锚定/音色情绪参数 → FAIL
- 🆕 **时间段分隔符（P2 — 2026-05-31）**：推荐中点 `·`（`0·2秒：`）规避 `-` 截断风险；`0-2秒：` 向后兼容，新产出优先 `·`。

### Protocol G — 有机运动审计（去AI感·Anti-AI Uncanny）

- 机读层每条运镜描述**必须包含 ≥1 个有机运动修饰**（详见 `translation-audit-rules.md` 原则⑧附）
- 🔴 **禁止纯数学运镜描述**：`镜头缓慢推向` / `镜头匀速移动到` / `镜头平稳横移` → 这些无物理惯性的表述暴露AI生成痕迹
- ✅ **强制替换为有机运动**：必须附带过冲回稳 / 起停惯性 / 重心漂移 / 呼吸起伏 / 距离微波动等修饰
- 有机运动强度按场景类型自动适配（查阅各场景模板的 `镜头质感` 字段）：
  - 情感戏 → 极低（三脚架+微幅漂移）
  - 悬疑/惊悚 → 中（手持+呼吸绑定）
  - 动作戏 → 高（肩扛+步伐震动+惯性过冲）
  - 空镜/群戏 → 低（轨道+接缝微震+起停惯性）
  - POV主观 → 最高（全量有机修饰）
- 全条运镜均为纯数学描述、无任何有机修饰 → **FAIL**

### 台词完整保留铁律

- 来源剧本中的台词必须 **100% 原文保留**，禁止缩写/改写/合并
- 缺字/改字/合并 → FAIL

### Protocol H — 🔴 台词完整性审计（每条P必检）

来源剧本中的台词 = 机读层中的台词，逐句对照：

| 检查项 | FAIL条件 |
|--------|---------|
| 遗漏 | 来源剧本有的台词，机读层找不到 |
| 篡改 | 台词措辞被改写（哪怕一个字） |
| 张冠李戴 | 说话人与来源剧本/导演分析不一致 |
| 未标注 | 创作添加的台词未标注 `[创作添加]` |

**强制输出**：每条P必须输出 `🎭 台词审计表`（无台词标"本条无台词 ✅"）
详见 SKILL.md 7.6

### Protocol C+ 补充 — ⏱ 密度/容量（方向C：表已降级，不再强制输出）

> 🔴 方向C：`⏱ 密度校验表` 不再强制输出（与翻译审计表一同废除）。台词容量靠**台词零删减铁律**保证——
> 字数超时段容量时只许**扩时长或拆P**，绝不删台词。节拍密度的确定性校验在 `beat-density-checker.py`（脚本，非手填表）。

### 时间段写法顺序（禁止颠倒）

1. **镜头信息** `(景别/运镜/速度)` → 开头必写
2. **环境光影** `@场景名 + 光照 + 空间 + 材质 + 粒子` → 先建立空间
3. **角色动作** `@角色名 + 动作 + 微表情 + 姿态 + 锚点` → 再写人物
4. **道具交互** `@物品名 + 空间关系` → 最后写物件
- 角色动作开头无环境铺底 → FAIL
