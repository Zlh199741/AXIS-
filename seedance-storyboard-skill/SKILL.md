## 🔴🔴 零·机读层唯一权威格式声明（最高优先级 — 2026-05-31 新增）

> **本声明用于一次性终结"双模板矛盾"。生成方、审核方、任何协作 Agent 在写/审机读层前必须先读本节。**

**机读层（🎬 Seedance 提示词）唯一合法格式 = 自然语言格式（本 SKILL.md / storyboard-generation-cheatsheet.md / seedance-prompt-review-skill 共同规定的格式）**，要点：

1. 每条 P 机读层**第一行**＝ `[Global Spatial Anchor: ...]`（空间锚点GSA，详见本文「场景站位锁定铁律」）。
2. 画面描述＝ **70% 自然语言 + 30% 可执行影视词**；时间段用 `0·Xs秒：`（推荐 `·`）或 `0-Xs秒：`（兼容）。
3. 台词内联进对应秒数段（人声锚定写法，见「台词内联唯一模板」）；音效写独立 `音效层：` 行；素材用 `参考@图片N`。

🔴 **附件④（`Seedance_2.0_核心技能速查手册_6层堆栈_6字段…`）的 6 层堆栈（`[GLOBAL]/[FIXED RULES]/[SCENE]/[RHYTHM CURVE]/[TIME AXIS]/[NEGATIVE CONSTRAINTS]`）、小蔡 6 字段（焦段mm/光圈f/英文运镜术语）、`00:00·00:03` 时间码、`{}`台词、`<>`音效嵌行、`@image_N` —— 全部仅供「人读层 / 帧规划层」使用，严禁进入机读层。** 机读层若出现 `[GLOBAL]`、`焦段：85mm`、`f/2.0`、`Dolly`、`00:00·00:03`、`@image_N` 等 → 直接判 FAIL。

> ⚠️ 命名防混淆：机读层首行的 `[Global Spatial Anchor:]`（空间锚点GSA）与附件④人读层标签 `[GLOBAL]` **不是同一个东西**，不可互相替换。

> 🧭 **为什么禁这些（实证依据）**：上述机读层禁项（`焦段85mm`/`f2.0`/`Dolly`/`00:00`时间码/`@image_N` 等）都属**技术术语/参数类**——禁它们**不是因为"Seedance 看不懂"**（它能识别运镜/景深/逆光等），而是为**可控性 + 单条可执行性 + 中文统一**：数值参数不可控且官方不建议、剪辑关系单条文生视频不可执行、命名光法描述化命中率更高、英文运镜词改中文。
> ⚠️ **但要分清**：抽象情绪/心理词（"她很伤心"/"温柔地"）则**确属 Seedance 读不懂**（核心铁律），必须物理化为微表情+发声方式——这条**不可否定**。两类理由勿混。详见 `translation-audit-rules.md`「核心原理 · 为什么这样规定」(A)(B) 两类。

## 一、核心方法论（第一性原则）

### 1.1 五大核心原则

| 原则 | 定义 | 应用 |
|------|------|------|
| **导演意图优先** | 提示词是导演意图的技术翻译 | 逐句对照导演阐述 |
| **叙事描述式** | 用完整段落描述，像写电影脚本 | 禁止关键词堆叠 |
| **参考图已见** | 不重复静态内容，专注"变化" | 动作、运动、情绪转变 |
| **一条一段叙事** | 每条提示词=一次生成任务=完整叙事 | 多镜头但叙事连续 |
| **节拍密度约束** | 1拍≈2.5秒，动作太密会糊/跳/不自然 | 每个连续镜头内约束 |

### 1.2 T0工业级标准体系

本技能融合**好莱坞29条视听语言工业标准**：

```
维度一：物理动力学（3条）
├── 1. 预备与后效：预备帧:动作帧:后效帧=3:1:2
├── 2. 重力债：落地重心下沉位移需达到身高2%
└── 3. 动力传导：切镜前后速度矢量保持

维度二：构图与权力（3条）
├── 4. 负空间压制：主体置于15%画框角落
├── 5. 权力夹角：仰拍5°=崇拜，45°+=极端压迫
└── 6. 几何母题：核心形状贯穿微观与宏观

维度三：神经劫持（5条）
├── 7. 视线钩子：焦点中心重合度误差<5%
├── 8. 呼吸节奏：紧凑按24-12-6-3帧递减
├── 9. 物理丢帧：撞击瞬间删除中间2帧
├── 28. 视角契约：角色睁眼/看向画外→下一镜必须POV（18-24mm人眼视野）
└── 29. 视角切换呼吸：客观→主观→客观三明治结构，主观段2-4秒，配合声音层变化

维度四：语义与深度（3条）
├── 10. Z轴深度经营：前景/中景/远景四层
├── 11. 视听对位：声音与画面相反
└── 12. 符号关联：形状相似性跨越时空

维度五：生物本能（3条）
├── 13. 生理同步：过曝引导眯眼
├── 14. 重力补偿：阻尼效果0.8
└── 15. 恐怖谷畸变：眼部:嘴部=1:9

维度六：情感熵（3条）
├── 16. 环境熵增：杂质密度每分钟增加15%
├── 17. 时间弹性：恐惧0.1秒拆解多组镜头
└── 18. 通感模拟：高频音效8000Hz+

维度七：意志延伸（3条）
├── 19. 虚无主义空镜：极动后极静
├── 20. 视觉病毒：物理错误仅占<1%
└── 21. 观测者效应：模拟心搏率微抖动

维度八：神格化（3条）
├── 22. 光源霸权：主光控制情绪
├── 23. 静默核弹：无声胜有声
└── 24. 递归投影：画面内画面

维度九：非人境（3条）
├── 25. 视觉残影：动作残留
├── 26. 因果倒置：结果先于原因
└── 27. 无我之镜：第一人称极限
```

### 第一步半：素材对应表预构建（🔴 必做 — 写任何P之前必须完成 — 2026-04-10 新增）

> 🔴 **铁律：禁止在素材对应表未完成之前开始写任何一条P的提示词。**
> 素材对应表必须覆盖本集**所有P**出现的所有有图资产，而非边写边加。

**执行方法**：

1. **先扫描来源剧本，再对照导演讲戏本**，列出本集所有P中出现的全部元素：
   - **具名角色**：逐P列出场景中出现的每一个角色
   - **场景环境**：逐P列出对应的主场景（老屋/坟地/村口小路等）
   - **关键道具**：逐P列出有专属参考图的道具（如竹刀/魂铃等）

2. **逐项比对** `character-prompts.md` / `scene-prompts.md` / `props-prompts.md`，确认每个元素是否有对应当前集的参考图：

   | 元素 | 有参考图 | 无参考图 |
   |------|---------|---------|
   | 角色 | 分配 @图片X，用途写"参考@图片X的[角色名]形象" | 标记"文字描述替代"，不分配编号 |
   | 场景 | 分配 @图片X，用途写"[场景名]环境参考" | 标记"文字描述替代" |
   | 道具 | 分配 @图片X，用途写"[道具名]外观参考" | 标记"文字描述替代" |

3. **将有图资产全部写入文件头部的素材对应表**，无参考图的元素在对应P中用文字描述

4. **同步填写单条提示词预算表**：列出**所有P**（P01-1到PXX-X）的图片/视频/音频/总文件数，禁止只列部分P

> 🔴 **违反此步骤（素材对应表缺项 / 单条预算表不完整）→ 直接判定整个文件 FAIL，必须补齐后重新审核**

### 第二步：逐条判断场景类型 → 路由到对应模板

对来源剧本中的每个剧情点逐行覆盖，再参考导演讲戏本判断场景类型，按以下**优先级从高到低**依次匹配，**命中即停**：

```
┌─ 判断1：是否为动作戏？
│  触发词：战斗/格斗/冲突/追逐/释放技能/打斗/对峙出招/武器碰撞
│  → 命中 → 模板3.2 动作戏增强模板（打点架构版）
│           ⚠️ 进入模板前必须确认双轴：
│             · 风格代号（SCI科幻/WUX武侠/MOD写实/FAN奇幻）
│             · 节奏模式（HEAVY重击/RUSH连击/CHASE追逐）
│           未确认双轴 → 禁止生成，必须先从来源剧本、导演讲戏本或用户描述中提取
│
├─ 判断2：是否为多角色对话？（≥3人同场有台词）
│  触发词：三人及以上角色同时在场且各有台词/多人争论/圆桌讨论/审问
│  → 命中 → 模板3.4 多角色对话增强模板
│
├─ 判断3：是否为情感高潮？
│  触发词：哭泣/崩溃/告白/离别/死亡/回忆触动/沉默对视/情绪爆发
│  → 命中 → 模板3.5 情感对话增强模板
│
├─ 判断4：是否为悬疑/惊悚？
│  触发词：恐惧/未知威胁/黑暗/独处听到异响/追踪/偷窥/惊吓/诡异
│  → 命中 → 模板3.6 悬疑/惊悚增强模板
│
├─ 判断5：是否为回忆/闪回？
│  触发词：回忆/闪回/往事/幼年/过去的自己/梦境/时间跳转/触景生情
│  → 命中 → 模板3.7 回忆/闪回增强模板
│
├─ 判断6：是否为群戏/大场面？
│  触发词：大军/人群/集会/战场全景/数百人/万人/仪式/阅兵/混战
│  → 命中 → 模板3.8 群戏/大场面增强模板
│
├─ 判断7：是否适用高效生成模式？
│  触发条件：有明确首尾帧 / 有运镜参考视频 / 需要音效节拍卡点 / 视频延长接力
│  → 命中 → 模板3.3 对应子模式（A/B/C/D/E）
│
└─ 以上均未命中
   → 默认 → 模板3.1 标准叙事模板
```

**复合场景处理**：一个剧情点可能同时触发多个类型（如"回忆中的战斗"），此时：
- **主模板**：取优先级最高的命中项作为主模板骨架
- **辅模板**：将次优先级模板的核心元素融入主模板
- 示例："回忆中的战斗" → 主模板=3.7回忆/闪回（色调切换+进出方式），回忆段内容使用3.2动作戏（高燃节拍+动作链）

**场景类型标注**（必做）：每条 P 块开头（`## P0X` 标题下、`### 🎬 Seedance 提示词` 块之前）必须标注所用模板：
```
> ⚡ 场景类型：[动作戏/多角色对话/情感高潮/悬疑惊悚/回忆闪回/群戏大场面/标准叙事]
> 使用模板：3.X [模板名称]
```

**🔴 角色资产完整性检查（必做 — 2026-04-10 新增）**

在编写每条P之前，逐条确认该P中出现的**每一个具名角色**是否在 `character-prompts.md` 中有对应的当前集参考图：

| 检查项 | 规则 | 违规处理 |
|--------|------|---------|
| 角色有参考图 | 在素材对应表中分配独立 @图片编号，@图片用途必须写"参考@图片X的[角色名]形象" | 正常编写 |
| 角色无参考图（缺失上游资产） | 机读层**只能用文字描述该角色外貌**，禁止借用其他角色的 @图片 | 必须在P开头注明"[角色名]无参考图，以文字描述替代" |
| 用角色A的 @图片给角色B的场景当"情绪参考" | 🔴 **绝对禁止** — 即使标注"情绪参考基准"也不允许 | 直接判定该条P FAIL，必须删除错误引用改为文字描述 |

> **根本原则**：@图片X 在 Seedance 中是强视觉锚点，模型会把该图的面孔/体型作为画面中人物的生成依据。任何跨角色引用都会导致人物面孔错乱，无论意图是"情绪参考"还是其他目的。

按模板格式输出（详见第三部分）

**🔴 单层成品必含要素铁律（T0级强制 — 2026-06-08 方向C 改写；原"两层四要素铁律"作废）**

> 🔴 **方向C：分镜文件＝单层「官方对齐」成品。** 导演的 9维度 / 情绪钩子 / 空间与视线
> 分析等**设计思考**，在导演分析阶段产出于 `outputs/<ep>/01-director-analysis.md`，
> **不在分镜文件内重写**（不再有 in-file 人读层＋翻译审计）。分镜文件只交付"可直接
> 喂 Seedance 的成品提示词"，每条 P 必须把设计**落地**为以下可执行要素：

| 要素 | 机读层（单层成品）必须包含 |
|---|---|
| **空间锚点** | 首行 `[Global Spatial Anchor: ...]`；正文出现画面位置词（左/右/上方/下方/中央/深处），有人物必说明其画面位置 |
| **镜头语言** | 🔴 每个时间段**点名景别**（特写/近景/中景/全景等）＋**点名且具体的运镜**（缓推/横摇/手持跟拍等中文词；官方要求"具体"——写"缓慢推近"而非"镜头移动"；🔴 禁 mm/f 数字、禁英文运镜词）；🆕 相邻时间段/相邻P景别**避免相邻级直切**，优先跨级（如中景→特写，跳过近景），降低拼接跳切感 |
| **情绪物理化** | 抽象情绪一律物理化为微表情（面部肌肉指令）＋发声方式，🔴 禁"她很伤心/温柔地/压迫感"等抽象词（查附件②③④素材库） |
| **台词** | 逐字源剧本原文（零删减铁律）；口型/画外音/系统声段落绑定人声锚定ID＋音色参数（守跨P音色一致） |
| **节奏** | 时间段标注（`0·Xs秒：` 格式），总长与标题时长一致；时长按动作节拍分配，禁均分；🆕 每条P**首段或末段优先安排一个"动作衔接、无台词"的气口**（小停顿），给跨P拼接留接口 |
| **声音/负面** | 独立音效层（仅人声/环境/动作音，无BGM）；尾缀含"禁文字/字幕/水印"＋"无背景音乐" |

> 🔴 违反"情绪物理化 / 台词逐字 / 运镜点名 / 空间锚点" → 该条P直接判定 FAIL。
> 🔴 9维度标签、情绪钩子4行结构等**分析框架属导演分析阶段产物**，不要求出现在分镜成品里。

**🔴 场景站位锁定铁律（Global Spatial Anchor — 2026-04-22 新增）**

每条P块机读层**第一行**必须为 `[Global Spatial Anchor: ...]`（空间锚点GSA）空间锚点，锁定本P角色的空间拓扑状态，解决Seedance跨P生成时角色站位随机翻转问题。

> ⚠️ **命名防混淆（P1）**：机读层首行 token 固定写英文 `[Global Spatial Anchor:]`（中文别称"空间锚点GSA"，仅口头/文档使用）。它与附件④人读层标签 `[GLOBAL]` 完全不同，机读层严禁出现 `[GLOBAL]`。（保留英文 token 是为兼容 `_gsa_injector.py` 与全部存量产物，不做破坏性重命名。）

| 情况 | 处理方式 |
|------|----------|
| 首P / 新场景首P | 从来源剧本与导演讲戏本提取初始空间状态，独立建立基线 |
| 同场景连续P | 用本P绝对站位**重写**上一P结束时的空间状态（位置变化则更新）；🔴 禁止写"承接PXX/同PXX结束位置"等跨片引用（模型对其它P零记忆） |
| 场景切换P | 写"新场景 — [场景名]"后清零重建新场景基线 |

**GSA白名单**（只写这些）：画面位置（左/右/前/后）、相对距离、高低关系、视线朝向、门/出口状态、道具在场状态

**🆕 GSA环境状态继承槽（P5 — 2026-05-31 新增，可选写入）**：允许追加**纯开关态的环境连续性状态**（不写描述性形容词），用于跨P继承关键环境变化，字段固定为：
- `环境状态：空调[关/已启动]；灯光[暖灯/冷白光已铺/熄]；温度感[闷热/转凉]；音环境[风扇低速/电话接通/静]`
- 只允许写"开/关/已启动/已铺/已熄"这类**状态值**，禁止写"柔和地洒下""压迫感"等描述/情绪词（那些仍进时间段正文）。

**GSA黑名单**（禁止写入）：外貌细节、服装、灯光的描述性渲染、特效、情绪形容词、动态动词、🔴 跨P文字引用（承接PXX / 承接PXX终态 / 同PXX结束位置 / 同一坐位 / 匹配剪辑承接PXX）（只记**本P**终态位置 + 上述开关态环境状态）

**格式**：`[Global Spatial Anchor: @角色A 画面左侧，面朝右方；@角色B 画面右侧，面朝左方；场景锚点：[固定参照物]；环境状态：空调已启动、冷白光已铺]`

> 🆕 **多角色联动重述（拼接方法论吸收）**：当一个角色的位置/姿态在本P发生变化（如由坐变站），同框其他角色的**位置/朝向/视线**若会被动改变，必须在本P GSA 里**一并重述**（如"A站起→B需抬头、视线上移"），而不只更新主角。理由同 GSA 总则：模型对其它P零记忆，联动状态不显式写出就会丢。

> 🔴 FAIL条件：P块机读层开头缺少 `[Global Spatial Anchor: ...]` → 直接判定 FAIL
> 🔴 FAIL条件（P8 — 2026-06-06 新增）：GSA 内出现跨P文字引用（`承接PXX`/`承接PXX终态`/`同PXX结束位置`/`同一坐位`/`匹配剪辑承接PXX`）→ 直接判定 FAIL。机读层逐条独立喂模型、对其它P零记忆；"继承上一P终态"须改写为**本P绝对站位重述**，画面级同坐位/同构图靠**首帧承接**（上一条尾帧/构图定格作参考图）实现，跨片衔接叙事意图只写导演分析（`outputs/<ep>/01-director-analysis.md`），不进分镜文件。（`陈屿 终态在画面右前方` 这类**本镜内**终态位置合法，不在禁止之列。）
> 🆕 **首帧承接的边界（防误读 · 拼接方法论吸收）**：首帧承接 = 借上一条尾帧让**新镜头**保持人物/空间一致，**不是**用于伪造"同一连续镜头"的连贯运镜——AI 对参考图是「分解→重新生成」而非复制，把尾帧当首帧硬拼连续运镜必然产生肉眼可见跳切。因此**连续单镜头不交给模型跨P续接，跨P一律按切镜处理**（换景别/换角度，见铁律表"镜头语言"行的景别跨级）。
> 详细规范见 `tools/references/spatial-continuity-checker.md`

> 🔴🆕 **视频单元 + 镜头切换 + 接点分镜图（2026-06-09 修订 · 撤销错误的"一次生成=一个镜头"）**——正确模型如下：
> - **原子生成单元 = 一个视频（一次生成）= ≤15s 上限**。🔴 **一个视频内部可以包含多个镜头切换**（模型一次生成就能切多个镜头）——这正是短剧快剪的常态，不是缺陷。
> - 🔴 **镜头要快**：视频内部**快切常见 1–4s/镜**，一个 15s 视频可装 **4–6 个镜头**；别为凑时长把单镜拖长（旧"单 P 5–8s 下限"已废）。
> - 🔴 **拆视频的唯一硬线 = 15s**：一个视频（含其内部所有镜头）总长 **≤15s**；**超过 15s 才拆成下一个视频**（如 `P03a` / `P03b`）。**视频内部的镜头切换不用拆、不用 @分镜图**（模型一次生成完成）。
> - 🔴 **接点（仅视频与视频之间）靠 @分镜图驱动**（AI 对上一个视频零记忆）：**基础数据**（人物/场景设定图·不变）照传；**变动数据**（站位/朝向/动作进度）在视频接点处**做成 @分镜图**——抓上一视频**原画质**尾帧（勿用截图压缩）→ 改出新站位（如"女生站起→对面母亲抬头"）→ 喂下一视频首帧；**同机位可复用同一 @分镜**；🔴 **台词镜必配图，只写台词靠抽卡＝死路**。详见 `references/stitching-and-shot-handoff.md`。
> - 📌 **书写**：一个 `## PXX` = 一个视频（≤15s），内部用 `0·Xs秒` 时间段写各镜头/动作 beat；总长 >15s 时拆 `## PXXa` / `## PXXb`（与真实 ep01 文件 P01a/P01b 一致）。
> - 🔴 **台词镜时长 ≥ 台词字数 ÷ 语速 + 0.5s 留白**（台词零删减铁律——时长被台词撑出来，说不完就加段/延长/拆下一视频，绝不缩台词）。
> - ✅ 总时长靠多视频累加，仍满足「每集≥10条 / round(字数/1000×12)」。
> - 🔴 **FAIL 条件**：① 单个视频（P）总时长 >15s 未拆 → 拆成 Pxa/Pxb；② 为凑时长把镜头拖长致节奏拖沓 → 压缩或加镜头切换。**🔴 一个视频内部含多个镜头切换是合规的，不得因"镜头多/切得快"判 FAIL。**

**🆕 时间段分隔符规范（P2 — 2026-05-31 新增）**：
- 机读层时间段**推荐用中点 `·`**：`0·2秒：` `6·10秒：`，规避 Seedance 对 `-` / `——` 的截断风险（见附件④禁忌符号表）。
- 旧式 `0-2秒：` 仍**向后兼容**（校验器双接受），但新产出一律优先 `·`。
- 时长总和、密度校验等口径不变，仅分隔符变化。

每个时间段（`0-Xs：...` 格式）必须同时覆盖以下 **8项饱满信息中的≥6项**，严禁写"角色走过来说话"式空句：

| # | 维度 | 说明 | 判断标准 |
|---|---|---|---|
| ① | **镜头信息** | 景别+运镜方式+速度 | 有景别词（特写/中景/全景）+ 运镜词（推/拉/摇/跟/固定） |
| ② | **场景空间** | 前景/中景/后景或空间纵深 | 至少两层空间描述 |
| ③ | **光影变化** | 光源方向、色温、明暗变化 | 至少包含：光源方向 + 明暗效果二选一；电影级质感场景需额外包含色温描述或环境光响应 |

| ⑥ | **粒子动态** | 风/雾/灰尘/花瓣/雨丝/烟气/光尘/水波 | 有动态漂浮或流动元素 |

**附加硬规则**：
- 每时间段至少出现 **1个环境细节 + 1个材质细节 + 1个动态元素 + 1个身体锚点**
- 超过 4 秒的时间段必须有**动作推进、运镜推进或光影变化**，禁止画面静止发呆
- 情绪转化为**生理微反应**（充血/颤抖/汗珠/眼眶发红），禁止直接写"悲伤""震撼"等抽象词
- 🔴 覆盖项 < 6项 → 该时间段直接判定 FAIL，补写后重新检查

| 震撼/感动/激动 | 物理交互：手指无意识抠紧衣角/话本滑落/水杯在手中微微晃动 |
| 紧张/恐惧/不安 | 生理表现：额头汗珠/喘息加速/美人尖抗起/唇色发白 |
| 氛围压抑/凝重 | 环境具象：烛火剧烈摇曳/窗缝寒风卷起纸页/茶水表面细微波纹 |
| 气势磅礴/威压 | 空间压迫：角色投影覆盖对方全身/仰拍低角度让角色占据画面上方三分之一 |

**微表情递进链要求**：情绪爆点、沉默对视、崩溃、反击前静止、反派变脸、告白/离别等演技镜头，必须从增强模块选择清洗后的微表情物理描述，按“起始反应 → 中段升级 → 终点状态”写成连续递进，不允许只写“表情复杂/情绪爆发/眼神压迫”。

🔴 **FAIL条件**：机读层出现上述禁止写法中的抽象词 → 直接判定 FAIL，替换为对应的具象化描述后重新自检。

**🔴 时间段写法顺序规则**

> 来源增强：画镜平台时间段描述规则（2026-04-03）

每个时间段必须按以下顺序书写，禁止跳过或颠倒：

1. **镜头信息**：`(景别/运镜/速度)` → 开头必写
2. **环境与光影**：`@场景名 + 光照氛围 + 空间纵深 + 材质 + 粒子动态` → 先建立空间
3. **角色动作**：`@角色名 + 动作 + 微表情 + 身体姿态 + 物理锚点` → 再写人物
4. **道具交互**：`@物品名 + 与角色/场景的空间关系` → 最后写物件

**模板**：`X-Y秒：(景别/运镜/速度) @场景名 [光影+环境+材质+粒子]，@角色名 [动作+微表情+姿态+锚点]，@物品名 [空间关系]`

🔴 **FAIL条件**：时间段以角色动作开头而无环境光影铺底 → 判定顺序违规，重写该时间段。

**时间段时长估算标准**（🔴 严禁虚标，按实际发生时长估算；也**严禁偏慢拖沓**）：

🔴🔴 **台词镜时长 = 台词字数 ÷ 语速 + 留白**。语速**按戏型分档，严禁一刀切**（旧版统一 3–4字/秒会把快戏拖懒）：

🔴🔴 **戏型/语速档的唯一权威来源 = `01-director-analysis.md` 每个 P 的「节奏/语速档」字段（+ 整集骨架 A4 基调）。分镜阶段直接读取该字段、严禁自行重判戏份。** 若导演分析缺该字段 → 回退导演阶段补，不在分镜层凭空猜。

| 戏型 | 语速 | 适用 |
|---|---|---|
| 慢戏 | 3–4字/秒 | 悲情/压迫/临终/郑重宣告/独白 |
| **日常对话（默认）** | **4–5字/秒** | 普通叙事、室友/家常/铺垫对话 |
| 快戏 | 5–6字/秒 | 争吵/搞笑/激动/打快、快节奏短剧 |

🔴 **两条防拖铁律**：
- **留白**：慢戏每句 +0.3–0.5s；**快戏紧切，可不留白或用 L-cut 声音叠化**，别每句硬加 0.5s。
- **动作叠说话**：小动作（揉眼/拍粉/坐起/递物）**边说边做、不另计时间**；只有"无台词的纯动作"才单独占时长。

| 内容类型 | 合理时长 |
|---|---|
| 静态画面/环境空镜 | 2-3s |
| 简单动作（转头/抬手/推门） | 2-3s |
| **台词镜** | **字数 ÷ 语速（选戏型档）+ 留白**；>60字必须拆多段 |
| 复杂连续动作 | 4-6s |
| 瞬间事件 | 1-2s（不要拖） |

📌 例：15 字**日常对话**按 4.5 字/秒 → 15÷4.5 ≈ **3.3s**（而非慢戏档 3.5字/秒 的 ~4.8s）。同一句话，选错档差近 1.5s——逐镜累积就是全片拖沓的根源。

**🔴 内容密度细节保真（Protocol C）**

> 来源增强：画镜平台 Protocol C（2026-04-03）

**密度基准**：每 100 字剧本原文 ≈ **2-4 个分镜条目**；1000 字 ≈ 8-15 条。

**细节展开强制规则（严禁压缩）**：

| 原文类型 | 强制拆分规则 |
|---|---|
| **环境描写** | 拆成光影、材质、空间纵深、天气粒子、物件摆放，分别写入时间段 |
| **角色动作** | 每个独立动作一个时间段，禁止压缩"推门+环顾+走到桌前"为一段 |
| **心理活动** | 转化为微表情时间段（眼神变化/嘴唇颤动/手指攥紧），禁止保留抽象心理词 |
| **对话场景** | 每句台词一个时间段；重要对话必须补充**听者反应时间段** |
| **氛围渲染** | 比喻意象转化为具体画面（"空气凝固"→霜花、雾气、烛火摇曳） |

**🔴 严禁**：❌ 3-4句原文压缩为1段 ❌ 跳过环境/心理描写 ❌ 用省略号代替画面

**密度自检公式**：`分镜条目数 ÷ 原文字数 × 100` 结果应在 **2-4** 范围内；逐句对照原文，每句描写必须有对应时间段。

**🔴 无背景音乐与人声音色情绪控制标注规范（Protocol F — 2026-05-19更新）**

> 来源增强：画镜平台 Protocol F（2026-04-03）

Seedance 视频提示词采用方案 B：**不要背景音乐**。机读层只允许写人声与画面内音效，禁止把任何可生成音乐内容（背景音乐、BGM、音乐铺底、弦乐/古筝铺底等）写入可生成声音内容。有台词、旁白或系统声的P必须绑定人声锚定ID，保证同一角色/同一来源跨P保持同一音色。

| 层级 | 内容要求 | 示例 |
|---|---|---|
| **人声** | 角色台词、旁白、系统声音必须嵌入对应秒数段正文，不写进音效行；必须标注人声锚定ID、固定音色、语速、音量、气息、尾音 | `5-6秒：参考@图片N 叶锋开口口型对白——"走。"（人声锚定V1；音色保持青年男声、低亮度、少气声；语速3字/秒；音量中低；尾音收住）` |
| **音效层** | 环境音+动作音+特殊音效，标注各自时间点；不得含任何可生成音乐内容 | `0秒脚步声 + 7秒碎裂声 + 12秒风声` |

> **⚠️ 对白/独白规则（2026-05-19更新）**：角色台词、系统声音、旁白等人声内容**不在音效行写**，必须嵌入对应的秒数时间段正文内（如 `5-6秒：...叶锋开口口型对白——"xxx"（人声锚定V1；音色保持...；语速...；音量...；气息...；尾音...）`）。音效行只写音效层，不写任何可生成音乐内容，不写音色情绪控制。

**音色情绪控制硬规则**：
- 同一角色/同一旁白/同一系统声在全片使用同一声音ID（如 V1/V2/Vsys），不得每条P临时换音色。
- `固定音色锚点`必须包含声线年龄感、明暗度、颗粒感、气息位置四类信息，例如“青年女声、偏冷、少颗粒、口腔前部发声”。
- 情绪变化只能通过语速、停顿、音量、气息、尾音处理表达，例如“语速从4字/秒降到2.5字/秒、音量压低、吸气变短、尾音收住”。
- 禁止用“悲伤地/愤怒地/温柔地”替代具体声音参数；这类抽象词必须拆成可听见的人声参数。
- 禁止把音色情绪控制写入 `音效层`；`音效层`只写环境音、动作音、特殊音效。

**🆕 台词内联唯一模板（P3 — 2026-05-31 固化，全P强制套用同一句式）**：

```
X·Y秒：……（画面铺底+主体动作）……参考@图片N [角色名]开口[口型对白/画外音/脑内独白]——"[源剧本原文台词，逐字不改不删]"（人声锚定V[n]；固定音色[年龄感+明暗+颗粒+气息位置]；语速[n]字/秒；音量[高/中/低]；气息[平稳/收住/短促]；尾音[收住/下压/上扬/发颤]；停顿[如有，标位置]）
```

- 字段顺序固定：`承载方式 → 台词原文 → 人声锚定ID → 固定音色 → 语速 → 音量 → 气息 → 尾音 →（停顿）`，不得增删字段或换序。
- 台词原文必须 100% 逐字保留（台词零删减铁律）；情绪只通过上述参数表达。
- 🔴 旧的"气声说出：…""低沉地说：…"等自由写法一律不合规，必须改为本模板。

**改写对比**：
- ❌ 旧写法（禁止）：`音效：...｜[对白层] @陈恩义（6-9秒，低沉）：走。`
- ❌ 旧写法（禁止）：`音效：0-5秒古筝轻拨作为音乐铺底→10-15秒弦乐渐弱｜音效层：0秒微风拂过花瓣沙沙声 + 3秒脚步声`
- ❌ 旧写法（禁止）：`4·6秒：…气声说出："今天好热啊。"`（缺人声锚定字段，自由写法）
- ✅ 新写法（音效行）：`音效层：0秒微风拂过花瓣沙沙声 + 3秒脚步声 + 12秒衣料摩擦声`
- ✅ 新写法（对白内联唯一模板）：`6·9秒：…参考@图片N 陈恩义开口口型对白——"走。"（人声锚定V1；固定音色青年男声、低亮度、少颗粒、口腔前部发声；语速2字/秒；音量低；气息平稳；尾音收住）`

**🔴 FAIL条件**：机读层缺少音效层；出现背景音乐保留、BGM、配乐铺底、音乐铺底等可生成音乐内容；有台词/旁白/系统声但缺人声锚定ID、固定音色或语速/音量/气息/尾音参数；同一角色跨P声音ID不一致 → 判定声音层 FAIL，补写后重新自检。

**🔴 台词完整保留铁律（台词零删减 — 优先级最高）**

- 分镜提示词中的台词必须**100% 保留剧本原文**，严禁概括、删减、合并或改写
- 每句原文台词必须对应独立时间段，禁止将多句台词压缩到同一时间段
- **严禁以"时长不足/语速过快/密度超标"为理由精简台词**——台词字数超出时间段容量时，**只允许扩展时长或拆分时间段**，绝不允许反向删减台词
- 所有对白类型（口型对白、画外音对白、脑内独白）均受此铁律保护，一字不可删
- AI 审核/建议阶段**不得建议精简台词**，只允许建议：① 扩展时间段时长 ② 拆分为多个时间段 ③ 调整语速标注
- 🔴 FAIL条件：台词与剧本原文不一致（缺字/改字/合并/精简） → 直接判定该条P FAIL + 全集回退重审

| ⑥ | **焦段空间效果** | 导演分析中的焦段选择（广角畸变/长焦压缩/微距细节）是否落地为视觉效果描述？ | 一般覆盖良好 |
| ⑦ | **时长与节奏** | 导演分析中的时长是否与单层成品时间段总长一致？剪辑节奏（单镜头/快切）是否在叙事结构中体现？ | 时长一般一致，但"单镜头不切"的要求可能在多段叙事中被隐式违反 |
| ⑧ | **🔴 @图片引用完整性（2026-04-10 新增）** | 本P画面中出现的每一个具名角色/主场景/关键道具，凡在素材对应表中有对应@图片的，是否在机读层第一句全部引用？ | 角色在场景中出现但@图片未引用（如小阳跟随奔跑却只引用了陈恩义的@图片） |

**逐P @图片引用完整性自检三步法（⑧维度专项）**：

1. 列出本P（对照导演分析/源剧本）**画面内**出现的具名元素清单（角色/场景/道具）
2. 逐项对照素材对应表，确认是否有对应@图片
3. 确认机读层第一句已引用所有有图元素，无图元素已用文字描述

| 元素状态 | 正确处理方式 | 常见错误 |
|---------|------------|---------|
| 画面内出现 + 有@图片 | 机读层第一句必须引用 | 只引用主角忘引配角/场景 |
| 画面内出现 + 无@图片 | 机读层第一句用文字描述外貌 | 完全不描述/用别人@图片代替 |
| 仅声音出现（不在画面内） | 无需引用@图片 | — |
| 仅台词提及（未出场） | 无需引用@图片 | — |

🔴 **角色一致性检查（变体镜头专项 — 2026-04-10 新增）**：

> 同一角色的主角形象与其任何变体（换装/年龄变化/回忆闪回/受伤状态/异化）之间，机读层必须明确说明**视觉锚点保持核心一致**。

**变体识别标志**（出现以下任意一项 → 触发角色一致性检查）：
- 时间跳跃（回忆/闪回/年幼/年老）
- 服装/装备变化（换装、不同场景服饰）
- 状态变化（受伤、异化、变身、死亡状态）

**三类核心视觉锚点（变体镜头至少覆盖2项）**：

| 锚点类型 | 说明 | 写法示例 |
|---------|------|---------|
| **面部特征** | 角色最核心的辨识面部特征 | "同一张清瘦脸庞，双眼皮明显" / "下颌线相同" |
| **标志性色彩/材质** | 不随变体改变的颜色标识 | "始终保持黑色长发" / "标志性红色围巾" |
| **独特身体标记** | 疤痕/胎记/纹身/体型比例 | "左眼下方月牙形疤痕" / "右手虎口纹身" |

**机读层写法规范**：`[变体描述]（核心锚点：[锚点1] + [锚点2] 与主角一致）`

示例：
- `年幼版小阳（约10岁，清瘦脸庞与双眼皮特征与成年主角一致，身穿旧校服）`
- `受伤版陈恩义（左脸血痕，但清冷眼神与刀削轮廓线与主角基础形象一致）`

**🔴 FAIL条件**：
- 变体镜头无任何核心锚点描述 → 🔴 FAIL
- 变体描述与主角核心特征矛盾 → 🔴 FAIL
- 有@图片的角色在变体镜头中既未引用@图片，又无文字锚点补充 → 🔴 FAIL

详细规范见 `translation-audit-rules.md` 2.5节。

**第四步：来源剧本 + 导演意图完整性自检（🔴 四类高发遗漏场景）**

先回到来源剧本逐行确认原文载荷，再对照导演讲戏本检查以下4类易漏场景：

1. **括号内联技术标注**
   - 扫描来源剧本与导演分析中所有括号`（）`内的技术指令：J-Cut / L-Cut / 镜头焦段 / 声音设计
   - ✅ 每一个括号标注都必须在机读层或翻译审计表中有对应处理
   - ⚠️ 常见漏项：同一段落中的第二个J-Cut / L-Cut（第一个往往被处理，第二个易遗漏）

2. **景别+动作的绑定关系**
   - 扫描来源剧本与导演分析中"特写/中景/全景/长焦+动作"的组合表达
   - ✅ 景别指令必须与动作一同保留，不得只保留动作丢弃景别
   - ⚠️ 常见漏项："特写[身体部位]的[动作]"——身体部位特写消失，仅剩动作描述

3. **L-Cut跨镜信息传递**
   - 当导演原文标注L-Cut时，该声音信息属于**当前条结尾+下一条开头**
   - ✅ 当前条写完L-Cut后，必须在下一条机读层开场写入对应接收（衔接设计记于导演分析）
   - ⚠️ 常见漏项：当前条有L-Cut标注，下一条开头直接从新声音开始，跨镜延续完全断裂

4. **具体内容被泛化替换**
   - 来源剧本或导演分析若含具体播报内容（电子音播报"XXX"）/ 具体台词内容（角色喊"XXX"）
   - ✅ 机读层必须保留具体内容，不得抽象为"播报声""嚎叫声""控诉声"
   - ⚠️ 常见原因：对模型能力不确定，主动把具体内容替换成泛化描述，导致导演意图丢失

- ⚠️ 任一检查未通过 → 回到对应条目修正机读层 → 重新对照来源剧本原文与导演分析确认

- 全部 PASS → 钩子退出码 0 → commit 正常进行

**首次安装**（仓库克隆后只需执行一次）：

```bash
./.githooks/install.sh
```

执行后会设置 `git config core.hooksPath .githooks`，把项目级钩子目录指向 `.githooks/`。

**紧急旁路**（仅限确实知道自己在做什么的紧急情况）：

```bash
git commit --no-verify
```

⚠️ 任何使用 `--no-verify` 提交的产物在审核侧将被认定为"未经校验产物"，必须补跑校验器+提交补丁后才能进入剪辑流程。

**与第七步的关系**：

| 阶段 | 触发点 | 关卡 | 是否可绕过 |
|------|-------|------|---------|
| 写作阶段 | 文件保存/标记完成 | 第七步 7.1-7.6（产出侧 Skill 关卡） | 取决于自觉，可被绕过 |
| 提交阶段 | `git commit` | 第七步 7.7（Git 钩子关卡） | 仅 `--no-verify` 可旁路 |
| 审核阶段 | 进入 review skill | 第一步半（审核侧 Skill 关卡） | 取决于审核员尽责度 |

> **三道关卡叠加**：产出侧（自觉）+ 提交侧（强制硬卡）+ 审核侧（尽责验证），构成校验门禁的完整三道防线。

### 3.0 素材预算最佳实践（🔴 重要）

根据社区实测验证，Seedance 2.0 的素材分配经验法则：
- **图片：3-5张最佳**。1-2张锁角色，1-2张定场景/风格，多了反而互相干扰
- **视频：1-2段最佳**。一段定运镜，一段定动作节奏。3段容易冲突
- **音频：仅允许人声或现场音效参考**。Seedance 不要背景音乐，禁止任何可生成音乐内容（背景音乐、BGM、音乐铺底等）参考
- **推荐配置：4-7个文件**（角色图×2 + 场景图×1 + 运镜视频×1 + 可选人声/音效参考×1）
- **避免堆满12个文件**，素材太多会让模型"困惑"，不知道该优先听谁的

### 零代词铁律（速查）

- 机读层**绝对禁止**代词：他/她/它/男人/女人/主角/配角/两人/他们/她们
- 一律替换为 `@角色名`，前后必须保留空格
- 出现任意禁用代词 → 直接 FAIL

### 防融图物理锚点（速查）

- 多角色同框时**禁止**笼统描述（两人对视/坐在一起/站在旁边/并肩而立）
- **必须**使用：`[@角色A + 身体姿态 + 物理支撑面] + [空间距离] + [@角色B + 身体姿态 + 物理支撑面]`
- 近距离必须加入**物理阻隔**（桌角/床沿/墙面）防止融图

### 节拍密度校验（速查）

- 1拍 ≈ 2.5秒，段内最大节拍数 = `floor(段时长 / 2.5)`
- 口型台词最低时长 = `字数 x 0.4秒`（下限2秒）；画外音最低时长 = `字数 x 0.2秒`
- **两句对白不可塞入同一段**（除非段时长 ≥ 两句之和 + 1秒缓冲）
- 每条P编写完成后**必须输出密度校验表**（紧跟翻译审计表之后）

### 台词审计铁律（速查）

- 100%原文保留，禁止缩写/改写/合并/替换
- 说话人锁定，禁止张冠李戴
- 来源剧本N句 = 机读层N句，零遗漏
- 每条P编写完成后**必须输出台词审计表**（紧跟密度校验表之后）
