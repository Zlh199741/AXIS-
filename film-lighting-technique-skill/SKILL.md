# 电影质感光源技巧技能

[技能说明]
    本技能提供电影级质感的光源运用逻辑和结构化模板，适用于：
    1. 生图提示词：人物肖像、场景氛围的灯光设计
    2. Seedance 视频提示词：动态镜头的光影变化设计
    3. 服化道场景提示词：场景布光的基础氛围设定

    核心方法：将抽象的"电影质感"转化为可执行的8种光源技巧 + 标准化模板

---

## 一、八大核心光源技巧

### 1. 顶光照明 (Top Light)

| 要素 | 描述 |
|------|------|
| 光源位置 | 正上方，垂直于头顶 |
| 光影效果 | 眼窝处形成阴影，制造压迫感 |
| 适用情绪 | 神秘、压迫、恐怖、审讯 |
| 关键词 | 顶光照明、眼窝阴影 |

**Prompt模板**：
```
[景别]，[人物]在[场景]中。
对[人物]使用顶光照明，光源垂直在头顶，在眼窝处形成阴影。
画面营造[神秘/压迫]的感觉。电影级画面，超真实质感。
```

---

### 2. 正侧光 (Side Light / 3/4 Light)

| 要素 | 描述 |
|------|------|
| 光源位置 | 人物左侧或右侧 90° |
| 光影效果 | 脸部一半清晰，一半处在阴影中 |
| 适用情绪 | 神秘、复杂、压抑、双面人格 |
| 关键词 | 正侧光、一半清晰一半阴影 |

**Prompt模板**：
```
[景别]，[人物]在[场景]中。
主光源在人物[左/右]侧，以正侧光的形式打在人物上。
人物的[左/右]边脸清晰，[另一侧]脸处在阴影中。
画面采用[黑白色调/冷色调]，气氛[压抑/神秘]。电影级画面，超真实质感。
```

---

### 3. 逆光 / 轮廓光 (Back Light / Rim Light)

| 要素 | 描述 |
|------|------|
| 光源位置 | 人物后方 |
| 光影效果 | 勾勒金色轮廓，形成人物剪影 |
| 适用情绪 | 温暖、浪漫、梦幻、救赎 |
| 关键词 | 逆光、金色轮廓、人物剪影 |

**Prompt模板**：
```
[时间/场景]下，[人物]在[场景]中。
[夕阳/月光/灯光]逆光照射[人物]，形成人物剪影。
勾勒出[人物]发光/金色/银色的轮廓。画面整体[昏暗/柔和/梦幻]。
电影级画面，超真实质感。
```

---

### 4. 伦勃朗光 (Rembrandt Lighting)

| 要素 | 描述 |
|------|------|
| 光源位置 | 侧上方 45° |
| 光影效果 | 鼻翼阴影在面颊形成三角形光区 |
| 适用情绪 | 戏剧性、深沉、思考、神秘 |
| 关键词 | 伦勃朗光、三角光区 |

**Prompt模板**：
```
[景别]，[人物]在[背景]中沉思/思考。
对人物脸部使用伦勃朗光照明，光源在侧上方45°。
在面颊形成标志性的三角形光区。近景/特写。
电影级画面，超真实质感。
```

---

### 5. 硬光 (Hard Light)

| 要素 | 描述 |
|------|------|
| 光源特性 | 直接光源，无柔化 |
| 光影效果 | 阴影边缘锋利，明暗对比大 |
| 适用情绪 | 危险、压迫、冷酷、硬汉 |
| 关键词 | 硬光、质感硬朗、阴影边缘锋利 |

**Prompt模板**：
```
[场景描述]。[时间]。
对[人物]使用硬光照明，光线质感硬朗。
阴影边缘锋利，明暗对比大，画面偏[冷/暖]色调。
凸显出[危险/压迫/冷酷]的氛围。[景别]。电影级画面，超真实质感。
```

---

### 6. 丁达尔效应 (Tyndall Effect)

| 要素 | 描述 |
|------|------|
| 光源条件 | 光线穿过烟雾/尘埃/水汽 |
| 光影效果 | 显现出光的路径和体积，形成三角形光束 |
| 适用情绪 | 神圣、神秘、戏剧性、史诗感 |
| 关键词 | 丁达尔效应、光的路径、光的体积 |

**Prompt模板**：
```
[场景描述]。[时间]。
光线从[窗户/门/缝隙]照进[场景]，出现丁达尔效应。
显现出[三角形/长条形]的体积，以[形状]照亮[区域]。
[光效描述]。画面明暗对比强烈。电影级画面，超真实质感。
```

---

### 7. 黑色电影风格 (Film Noir)

| 要素 | 描述 |
|------|------|
| 光源特性 | 单一光源，低调光 (Low Key) |
| 光影效果 | 浓厚阴影，明暗对比强烈 |
| 适用情绪 | 悬疑、阴谋、犯罪、神秘 |
| 关键词 | 黑色电影风格、Film Noir、侧顶光 |

**Prompt模板**：
```
[场景描述]。[时间]。
光照使用黑色电影风格（Film Noir）。
对人物使用[侧顶光/单一光源]照明。
投射出浓厚的人物阴影。画面昏暗，光影对比强烈。
营造出[悬疑/阴谋]的感觉。[景别]。电影级画面，超真实质感。
```

---

### 8. 黄金时刻 / 蓝调时刻 (Golden Hour / Blue Hour)

| 类型 | 时间 | 光线特点 | 适用情绪 |
|------|------|----------|----------|
| 黄金时刻 | 日落时分 | 柔和、温暖、逆光 | 温暖、浪漫、梦幻、告别 |
| 蓝调时刻 | 日落后20-40分钟 | 冷蓝、偏暗 | 忧郁、孤独、冷静、失落 |

**Prompt模板 - 黄金时刻**：
```
[场景]。[时间]正好是落日时刻/黄金时刻。
[光源]光线[柔和/温暖/逆光]，逆光勾勒出人物轮廓。
画面整体[昏暗/柔和/梦幻]。[色调描述]。
电影级画面，超真实质感。
```

**Prompt模板 - 蓝调时刻**：
```
[场景]。[时间]正好是落日后的蓝调时刻。
整个画面色调偏冷，呈现出[蓝色/紫色]的冷调。
[光源描述]，[低调照明]。营造出[忧郁/冷静/孤独]的氛围。
[景别]，[人物]在画面中显得[渺小/失落]。电影级画面，超真实质感。
```

## 三、标准化模板公式

### 公式1：人物照明模板

```
[景别]，[人物]在[场景]中。
对[人物]使用[光源类型]照明，[光源位置]在[方向]。
[光影效果描述]。
画面[色调/氛围]。电影级画面，超真实质感。
```

### 公式2：场景氛围模板

```
[场景描述]。[时间]。
[光源类型]从[方向]照进[场景]。
[特殊光效描述]。画面明暗对比[强度]。
电影级画面，超真实质感。
```

### 公式3：情绪化光影模板

```
[光源类型] + [精确位置/方向] + [具体光影效果] + [情绪关键词] + "电影级画面，超真实质感"
```

### 4. 实际项目运用案例（ep02）

**场景提示词中的光源设计**：
```
**时间与光线**：夜晚，外面的天色已经完全暗下来，房间里没有任何自然光源，
全部依靠室内烛光照明。房间内的光线明暗交替，烛火摇曳产生的阴影在墙壁
和家具上不断移动，营造出一种不安定的感觉。主光源来自四角放置的烛台，
烛光呈暖橘色，色温偏暖但亮度不足。
```

**Seedance 提示词中的光影设定**：
```
**光影设定**：
- 主光源：右侧烛台，暖橘色（色温2700K），摇曳不定
- 色调：暖色调偏暗，明暗对比强烈
- 氛围：紧张、危险、山雨欲来
```

逆光全景：烛光从背后照来，在江辰周围形成一圈光晕。

**光影设定**：
- 主光源：逆光轮廓光，江辰周围形成光晕
- 色调：冷色调渐显
```

## 六、执行流程

    第一步：确定情绪基调
        - 根据剧情阶段确定整体情绪（紧张/浪漫/神秘/危险）
        - 选择对应的光源技巧

    第二步：选择光源类型
        - 对照"光源参数与情绪对照表"
        - 确定主光源类型和位置

    第三步：套用模板
        - 根据选择的技巧类型，套用对应的 Prompt 模板
        - 填入具体参数（色温、方向、强度）

    第四步：验证完整性
        - 检查是否包含：光源 + 位置 + 效果 + 情绪 + 质感关键词
        - 确保包含"电影级画面，超真实质感"收尾

## 七、示例应用

### 示例1：ep02 P01 镜头 (当前项目)

**原描述**：
```
烛光下，江辰的眼睛瞬间瞪大，视线凝固在崔云绣怀中的那本医书上。
```

**应用光源技巧后**：
```
烛光下（光源类型），江辰的眼睛瞬间瞪大。
对江辰使用正侧光照明（光源技巧），光源来自画面右侧（方向）。
在面部形成明暗交替（光影效果），营造紧张感（情绪）。

[混合光源指导]

    复杂场景常需多种光源混合：
    - 日间室内：窗光（主光）+ 室内灯光（辅光）+ 环境反射光
    - 夜间对峙：月光（冷调）+ 火把/车灯（暖调）= 极致色温对立
    - 仙侠洞府：水晶反射光（奇幻色调）+ 丹炉火光（暖色点缀）

[Kling 3.0 灯光Prompt适配]

    Kling 3.0特有的灯光描述语法：
    - 使用 "lighting:" 前缀指定光源
    - 支持多光源叠加
    - 示例：lighting: warm golden hour sunlight from left, cool blue fill from right

[PASS/FAIL 标准]

    PASS 条件（必须全部满足）：
    - 光源选择与情绪场景匹配
    - 色温有具体数值标注
    - 6项评分平均 ≥ 7 且无单项低于 5
    - 产出三维质量标准各项 ≥ 95分

    FAIL 条件（任一满足）：
    - 光影效果与场景情绪完全矛盾
    - 色温/光比描述缺失导致无法执行
    - Prompt中光影描述歧义导致AI理解错误
    - 产出三维质量标准任一维度 < 95分

[产出三维质量标准]

    光影技术评分（0-100分）：
    □ 光型选择是否正确？（0-33分）
    □ 色温/光比参数是否完整？（0-33分）
    □ 光源方向描述是否具体？（0-34分）

    情绪表达评分（0-100分）：
    □ 光影是否服务于场景情绪？（0-33分）
    □ 色温对比是否制造合理冲突？（0-33分）
    □ 光影变化是否跟随剧情节奏？（0-34分）

    AI可执行性评分（0-100分）：
    □ 灯光Prompt是否可直接使用？（0-33分）
    □ 混合光源描述是否清晰？（0-33分）
    □ 平台适配（Seedance/Kling）是否正确？（0-34分）

    通过标准（B级辅助增强，参考 skills/templates/quality-threshold-standard.md）：各项 ≥ 90分
