```
**光影设定**：

```

```
**光影设定**：
- 时间跨度：[时间范围]

- 情绪变化：[紧张] → [平静] → [希望]

## 情绪化光影组合

### 紧张 / 悬疑

```
**光影设定**：
- 主光源：烛光/油灯，色温 2700K，摇曳
- 色调：暖橘色偏暗
- 光比：3:1-4:1
- 情绪：紧张、不安
- 特殊效果：影子晃动
```

### 浪漫 / 梦幻

```
**光影设定**：
- 主光源：逆光（夕阳/月色），色温 3000K
- 色调：暖橙/淡紫
- 光比：2:1
- 情绪：浪漫、梦幻
- 特殊效果：轮廓光、金边
```

### 危险 / 压迫

```
**光影设定**：
- 主光源：硬光（月光/荧光灯），色温 6500K
- 色调：冷蓝/冷白
- 光比：4:1-5:1
- 情绪：危险、压迫
- 特殊效果：锐利阴影
```

### 神秘 / 诡异

```
**光影设定**：
- 主光源：侧光/底光，色温变化
- 色调：蓝绿/暗紫
- 光比：5:1
- 情绪：神秘、诡异
- 特殊效果：丁达尔、投影
```

### 忧郁 / 失落

```
**光影设定**：
- 主光源：冷光（荧光/月光），色温 6500K+
- 色调：蓝调、冷紫
- 光比：3:1
- 情绪：忧郁、孤独
- 特殊效果：低调光
```

## 完整镜头示例

### 示例1：ep02 P01 镜头

**镜头描述**：
```
镜头1 [0-2s]：中景到特写，推镜头。烛光下，江辰的眼睛瞬间瞪大，视线凝固在崔云绣怀中的那本医书上。
```

**光影设定块**：
```
**光影设定**：
- 主光源：右侧烛台，暖橘色（色温2700K），摇曳不定
- 色调：暖色调偏暗
- 光比：3:1
- 情绪：紧张、惊讶
```

- 色调变化：暖橘→冷青

```
