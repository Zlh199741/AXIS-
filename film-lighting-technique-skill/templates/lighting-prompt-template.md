# 生图提示词模板 - 光源技巧版

## 模板1：人物肖像照明

### 基础模板
```
[景别]，[人物]在[场景]中。
对[人物]使用[光源类型]照明，[光源位置描述]。
[光影效果描述]。
画面[色调/氛围]。电影级画面，超真实质感。

视频提示词：[如需视频则填写，无则填"无"]
关键词：[光源关键词]
```

### 完整示例

**顶光照明**：
```
特写镜头，一个男人在书桌前打电话，是上世纪的老式拨号电话，背景是深色的书房。
场景昏暗，对男人使用顶光照明，光源垂直在头顶，在男人眼窝处形成阴影，制造压迫、神秘的感觉。
电影级画面，超真实质感。

视频提示词：无
关键词：顶光照明、眼窝处形成阴影
```

**正侧光**：
```
一个侦探站在街边，靠墙抽烟，侦探不要正对镜头，他的眼睛随意的朝其他地方看去。
主光源在人物左侧，以正侧光的形式打在人物上，人物的脸部一半清晰，一半处在阴影中。
电影级画面，超清。

视频提示词：无
关键词：正侧光、脸部一半清晰，一半处在阴影中
```

**逆光剪影**：
```
黄昏时刻，一个人在海边沙滩奔跑、玩耍。夕阳逆光照射在人身上，勾勒出人物边缘金色的轮廓，形成人物剪影。
全景，人物在画面中占比较小。画面呈现出温暖的氛围。电影级画面，超真实质感。

视频提示词：无
关键词：逆光、金色的轮廓、人物剪影
```

## 模板2：场景氛围照明

### 基础模板
```
[场景描述]。[时间]。
[光源类型]从[方向]照进[场景]。
[特殊光效描述]。画面明暗对比[强度]。
电影级画面，超真实质感。

视频提示词：[如需视频则填写]
关键词：[关键词]
```

### 完整示例

**丁达尔效应**：
```
教堂里面，光线从高处的窗户，侧着射入昏暗的室内，尘埃在光柱中飞舞，充满神圣感。
光线使用丁达尔光，显示光的路径和体积。广角镜头，大全景。画面不要太亮，呈现出朦胧、神圣的感觉。
电影级画面，超真实质感。

视频提示词：无
关键词：丁达尔光、路径、体积
```

**黑色电影**：
```
夜晚，很宽阔、很长的台阶，一个穿着风衣、戴着礼帽的人往下走。
远景，人物在画面中占比小，凸显出台阶整体的宽阔和巨大。
光照使用黑色电影风格（Film Noir），对人物使用侧顶光照明，单一光源，投射出浓厚的人物阴影。
画面昏暗，光影对比强烈，营造出悬疑、阴谋的感觉。电影级画面，超真实质感。

视频提示词：男人匆匆走下台阶
关键词：黑色电影风格（Film Noir）、悬疑、阴谋
```

## 模板3：黄金/蓝调时刻

### 黄金时刻模板
```
[场景]。[时间]正好是落日时刻/黄金时刻。
[光源]光线[柔和/温暖/逆光]，逆光勾勒出人物轮廓。
画面整体[昏暗/柔和/梦幻]。[色调描述]。
电影级画面，超真实质感。

视频提示词：[如需视频]
关键词：[核心关键词]
```

### 完整示例 - 黄金时刻
```
天台顶上，男人拉着女人的手。此时正好是落日时刻，夕阳光线柔和、昏暗、梦幻，
逆光照出两人的剪影，勾勒出他们身形的金色轮廓。画面整体昏暗、柔和、梦幻。
电影级画面，超真实质感。

视频提示词：男人单膝下跪向女人求婚
关键词：落日时刻、逆光、金色轮廓
```

### 蓝调时刻模板
```
[场景]。[时间]正好是落日后的蓝调时刻。
整个画面色调偏冷，呈现出[蓝色/紫色]的冷调。
[光源描述]，[低调照明]。营造出[忧郁/冷静/孤独]的氛围。
[景别]，[人物]在画面中显得[渺小/失落]。电影级画面，超真实质感。
```

### 完整示例 - 蓝调时刻
```
海边的步行道上，一个男人穿着衬衫，揣着西装外套，低着头漫步。
此时正好是落日后的蓝调时刻，整个画面色调偏冷，呈现出低调的蓝色和紫色。
远景，男人显得很渺小，远处是大海，男人侧面对着镜头。
画面呈现出冷静、忧郁、孤独的氛围。电影级画面，超真实质感。

视频提示词：无
关键词：蓝调时刻、色调偏冷、蓝色、紫色
```

## 模板4：动作/危险场景

### 基础模板
```
[场景描述]。[时间]。
对[人物]使用[光源类型]照明，光线质感[描述]。
阴影边缘[描述]，明暗对比[级别]，画面偏[色调]色调。
凸显出[情绪]的氛围。[景别]。电影级画面，超真实质感。

视频提示词：[动作描述]
关键词：[关键词]
```

### 完整示例 - 硬光
```
深夜的废墟中，士兵正在巡逻。对士兵使用硬光照明，光线质感硬朗，阴影边缘锋利，明暗对比大，
画面偏冷色调，凸显出危险、压迫的氛围。人物特写。电影级画面，超真实质感。

视频提示词：无
关键词：硬光、质感硬朗、阴影边缘锋利
```

## 快速填充表

| 变量 | 选项 |
|------|------|
| [景别] | 特写、近景、中景、远景、全景 |
| [人物] | 男人、女人、侦探、杀手、囚犯、士兵等 |
| [场景] | 书房、牢房、废墟、天台、海边、地铁等 |
| [光源类型] | 顶光、正侧光、逆光、伦勃朗光、硬光、烛光等 |
| [色调] | 暖色调、冷色调、黑白色调、蓝紫色调等 |
| [情绪] | 紧张、浪漫、神秘、危险、忧郁、压迫等 |
| [时间] | 深夜、黄昏、落日时刻、蓝调时刻、黄金时刻等 |

## 收尾格式（必须包含）

电影级画面，超真实质感。
```

电影级画面，超清。
```
