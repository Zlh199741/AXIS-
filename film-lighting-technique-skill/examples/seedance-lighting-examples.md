# Seedance 视频提示词中的光影设计示例

## 示例1：暖色光源 + 摇曳效果 (ep02 P01)

### 原始镜头描述
```
镜头1 [0-2s]：中景到特写，推镜头。烛光下，江辰的眼睛瞬间瞪大，视线凝固在崔云绣怀中的那本医书上。
```

### 光影设计块
```
**光影设定**：
- 主光源：右侧烛台，暖橘色（色温2700K），摇曳不定
- 色调：暖色调偏暗，明暗对比强烈（3:1）
- 情绪：紧张、惊讶
```

### 技巧解析
| 要素 | 内容 |
|------|------|
| 光源类型 | 烛光（点光源） |
| 色温 | 2700K（暖橘色） |
| 动态效果 | 摇曳不定 |
| 光比 | 3:1（明暗对比） |
| 关联技巧 | 暖色调光源 + 摇曳动态 |

## 总结：Seedance 光影设计块模板

```
**光影设定**：
- 主光源：[光源类型]，[颜色/色温]，[动态效果]
- 色调：[主色调]，[对比色]
- 光比：[明暗对比级别]
- 情绪：[核心情绪]
- 特殊效果：[如有丁达尔/投影等]
```

### 常见光源动态效果词汇

| 效果 | 适用光源 | 描述 |
|------|----------|------|
| 摇曳 | 烛光、油灯 | 烛火跳动，影子晃动 |
| 闪烁 | 荧光灯、霓虹 | 不稳定，闪烁 |
| 稳定 | LED灯、日光 | 恒定，无变化 |
| 渐亮/渐暗 | 灯光调光 | 时间流逝感 |
| 频闪 | 霓虹灯 | 故障/科幻感 |
