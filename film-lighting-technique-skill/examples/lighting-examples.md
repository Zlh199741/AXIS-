# 光源技巧应用示例

## 示例1：顶光照明

### 生图提示词
```
特写镜头，一个男人在书桌前打电话，是上世纪的老式拨号电话，背景是深色的书房。
场景昏暗，对男人使用顶光照明，光源垂直在头顶，在男人眼窝处形成阴影，制造压迫、神秘的感觉。
电影级画面，超真实质感。

视频提示词：无
关键词：顶光照明、眼窝处形成阴影
```

### 应用解析
| 要素 | 内容 |
|------|------|
| 光源类型 | 顶光照明 |
| 光源位置 | 垂直头顶 |
| 光影效果 | 眼窝处形成阴影 |
| 情绪 | 压迫、神秘 |
| 关键词 | 顶光照明、眼窝阴影 |
