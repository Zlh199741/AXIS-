# 服化道设计技能（融合工业级版）

[技能定位]
本技能是服务于顶级游戏工作室、影视特效团队、动画制作公司的**资深技术美术总监（Technical Art Director）**核心工作系统，融合Nano-Banana模型优化提示词框架、动画工业级造型逻辑、生物元素叙事设计，为短剧/动画项目生成可直接用于AI生图的标准化角色定妆参考单。

> 🔴 **角色唯一标准·电影级角色提案板（2026-05-31 取代三栏式工业资产）**：所有角色的服化道设计**统一输出电影级角色提案板**（横版16:9 / 中性灰 / 六区块），调用 `skills/cinematic-character-pitch-board-skill/SKILL.md`（配对审核 `cinematic-character-pitch-board-review-skill`）。同一角色各区块（A主视觉/B转面/C头部/D情绪/E服装）必须共享同一基底人物（五官/比例/发型/服装/配饰严格一致），由 pitch-board-review × art-direction-review 核对。主角/重要配角出完整六区块，次要/一次性配角/群演出精简提案板；三栏式工业资产已彻底废除（模板删除、校验器不再接受三栏式），存量三栏式文件需回炉重生成为提案板。

## 一、核心设计铁律（工业级标准）

> **设计本质铁律**：
> 角色设计的核心是「形状为外观骨架、元素为内容血肉、叙事为灵魂内核」，永远不把「画好看的皮囊」作为设计的终极目标。

### 六大设计铁律

| 序号 | 铁律 | 定义 | 在提示词中的体现 |
|------|------|------|----------------|
| **1** | 辨识度铁律 | 所有设计必须有且仅有 **1个核心记忆点**，做到单点极致，拒绝无意义元素堆砌 | 提炼1个核心视觉记忆点贯穿提示词 |
| **2** | 可信度铁律 | 幻想设计必须基于「功能→结构→造型」的逻辑推导，所有元素必须贴合角色人设与叙事 | 服装/道具/特征均需有人设支撑 |
| **3** | 情绪优先铁律 | 所有造型语言、元素设计、动态设计，最终都必须服务于角色的情绪与叙事表达 | 通过形状语言、光影、色彩传达情绪 |
| **4** | 落地适配铁律 | 所有设计必须匹配对应的应用场景（动画/游戏/IP/商品化），禁止脱离场景的纯自嗨式设计 | 适配短剧/动画/游戏不同需求 |
| **5** | 技术实现铁律 | 所有创意必须考虑PBR材质、拓扑约束、绑定需求的可实现性 | 添加PBR参数、拓扑参考、材质球 |
| **6** | 交叉自检铁律 | 所有输出内容必须经过 Skill 合规审计报告自检 | 确保内容质量符合工业标准 |

## 一·五、阶段0：视觉美学意图声明（强制前置·审美宪法）

> 🔴 **强制执行**：在进行任何信息收集/需求分析之前，必须先完成本阶段。
> 本阶段是角色设计的「审美宪法」——后续所有技术决策（体型/服装/色彩/材质/表情）必须服务于此声明。
> **未完成本阶段直接进入阶段1 → 输出等同无灵魂模板设计，直接不合格。**

### 五问法（必须全部回答，禁止跳过）

**Q1. 观众第一眼看到这个角色，应该有什么感受？**
→ 目标情绪词 ×3（如：压迫感 × 精密 × 冷酷）：`___` × `___` × `___`

**Q2. 视觉意象来源是什么？**（现实参照 / 文化符号 / 自然意象 / 矛盾冲撞）
→ 服装意象：`___`（如：高定裁缝×精密仪器）
→ 体型/姿态意象：`___`（如：时装周超模×冷酷机械）
→ 整体气质意象：`___`
→ 矛盾冲撞（如有）：`___`（两种意象的对抗所产生的独特感）

**Q3. 形状语言选择及情绪逻辑？**
→ 主导形状：`[圆/方/三角/S曲线/锯齿]` — 情绪逻辑：`___`
→ 辅助形状：`___` — 情绪逻辑：`___`
→ 直曲线分布意图：（哪些区域主直线、哪些主曲线，各自传达什么）`___`

**Q4. 配色情绪声明**（每个颜色的情绪贡献，不是色号清单）
→ 主色 `#___` = `___`（如：陶瓷白 = 非人温暖，高端冷感仪器质感）
→ 辅色 `#___` = `___`
→ 强调色 `#___` = `___`
→ 配色整体情绪叙事：`___`（如：冷白×青蓝 = 数字监视×高端疏离感）

**Q5. 这个角色在整套服化道视觉光谱里的位置？**
→ 视觉阶级/叙事位置：`___`（如：SSR=阶级顶端奢华终点·对比锚点）
→ 与其他角色的美学关系：`___`（如：与N卡形成最大阶级视觉反差）
→ 在整个世界观里，这个设计代表什么视觉主题？`___`

---

> ✅ 五问全部回答完成 → 进入阶段1（信息收集）
> ❌ 任何一问未完成 → 不得进入阶段1，设计宪法未确立前所有输出无效

> 🔴 **前验锁定（防后验虚填）**：五问法答案必须**在任何设计提示词输出之前**作为独立章节完整呈现给用户/审核者。
> - 正确流程：输出填好的五问法 → 用户/审核可见 → 再输出设计提示词
> - 禁止流程：先输出设计提示词 → 回头补填五问法（后验合理化）
> - 审核侧验证：五问法的答案是否**具体且与该角色唯一对应**？若答案是通用词（"酷/帅/美/独特"）→ 判定为后验虚填 → 🔴 FAIL

## 三、执行流程（融合版）

> 📖 **完整执行规则**见 [`references/execution-rules.md`](references/execution-rules.md)

> 前置铁律、读取上游产物、T0级提示词构建、变体铁律与一致性锚定、角色公式、
> 高级影棚布光、画质后缀、材质与工艺细节、T0标准校验命令、校验阻断机制与报告模板。

### 执行流程概要

| 步骤 | 内容 | 关键铁律 |
|------|------|---------|
| **第零步** | 平台输出 | 只输出 Nano Banana Pro（中文段 + 英文段分离） |
| **合规前置** | 内容合规过滤 | 高风险方案（爱死机/暗黑/赛博朋克）强制3步合规检查；禁止血液/伤口/未成年性化描写 |
| **前置铁律** | 纯白背景隔离 | 角色基础形象 + 道具 = 必须 `strictly isolated on a pure white background`；禁止场景背景/光源 |
| **第一步** | 读取上游产物 | 必须读取：导演分析、白皮书、示例文件、输出模板、assets/prompts/（如存在） |
| **第二步** | T0级提示词构建 | **7项强制要素**（缺一不合格）+ 变体铁律 + 角色公式 + 身材引擎（女性强制） |
| **第三步** | 场景与道具设计 | 🔴 已迁移至 `scene-concept-design-skill` + `prop-concept-design-skill` |
| **第四步** | 输出 | 角色提示词→追加到 `assets/prompts/character-prompts.md` |
| **第四步半** | T0标准校验 | `python tools/validators/t0-validator.py --batch --dir assets/prompts/` — 校验未通过禁止进入导演审核 |

### 🔴 主要角色标准交付：电影级角色提案板（交叉引用）

- 🔴 **所有角色统一交付物 = 「电影级角色提案板」**（2026-05-31 起为唯一角色标准）——规范与流程见 `skills/cinematic-character-pitch-board-skill/SKILL.md`（配对审核 `skills/cinematic-character-pitch-board-review-skill/SKILL.md`，校验 `tools/validators/pitch-board-validator.py` 或 `t0-validator.py --type character`）。
- 🔴 **三栏式工业资产已废弃**：角色资产不再产出三栏式纯白工业图；`assets/prompts/character-prompts.md` 统一改用提案板格式（16:9 / 中性灰 / 六区块）。三栏式模板已删除、校验器不再接受三栏式；存量三栏式文件需回炉重生成为提案板。
- 🔴 **同一基底人物**：同一角色的主视觉/转面/头部研究/情绪肖像/服装拆解必须共享同一基底人物（五官/比例/发型/服装/配饰严格一致）。
- 适用范围：主要角色必出完整提案板（六区块齐全）；次要 / 一次性配角 / 群演可出精简提案板（区块 A 主视觉 + B 转面 + F 色板）。

### 🔴 T0级提案板强制要素（速查·2026-05-31 提案板唯一标准）

| # | 强制元素 | 必须包含关键词 |
|---|---------|---------------|
| 1 | 横版大画幅 16:9 | `cinematic character pitch board, horizontal large-format 16:9` |
| 2 | 中性灰提案板背景 | `neutral gray pitch-board background #BEC1C4 to #C7CACD`（禁纯白/纯黑/场景元素） |
| 3 | 六区块版面 | 顶部细条 + 区块A主视觉立像 / B全身5视图转面 / C头部6视图研究 / D情绪肖像 / E服装配件拆解 / F色板备注 |
| 4 | 主视觉 + 转面多视图 | 区块A 85mm 全身立像 + 区块B 正/3·4正侧/纯侧/3·4背/背 五视图（turnaround） |
| 5 | HSB色板 | `HSB palette ≥4 色含 #HEX`（区块F） |
| 6 | 配饰/服装微距 | 区块E 4-6 张 100mm macro 材质拆解 |
| 7 | 金色身高刻度尺 | `gold vertical height ruler`（区块A 左侧） |
| 8 | 核心渲染参数 | PBR / AO / SSS / Unreal Engine 5 / Octane Render（至少2项） |
| 🔴9 | **同一基底人物** | A/B/C/D 五官/发型/服装/配饰严格一致；情绪/服装变体仅改 D/E/顶部细条 |

### 🔴 变体生成铁律（速查）

- 基础形象 + 变体均为**电影级角色提案板格式**（16:9 / 中性灰背景 / 六区块）
- 变体必须包含完整提案板要素（六区块/主视觉立像/转面多视图/HSB色板/服装配件拆解/身高刻度尺/渲染参数/防崩坏指令）
- 变体必须包含**一致性锚定指令**：`same character as base design, maintaining identical facial features, body proportions, hairstyle, and skin tone`
- 主角/重要配角：至少2-4个变体；次要角色：至少1个变体
- **禁止只生成基础形象**而跳过变体 → 直接判定不合格
- 🔴 女性角色强制读取 `resources/body-figure-engine.md`，英文段融入至少4项身材引擎词汇

> 📖 变体详细写法规范、一致性铁律完整条目、角色公式见 [`references/execution-rules.md`](references/execution-rules.md)

### 🔴 校验阻断机制（速查）

- ❌ 未运行 `t0-validator.py` → 不合格，拒绝进入导演审核
- ❌ 未贴校验结果 → 不合格，拒绝进入导演审核
- ❌ 校验未全部通过 → 必须修复→重新校验→直到全部通过
- 🔴 未生成变体 → 不合格：主要角色只有基础形象而无场景变体，直接拒绝
- 🔴 变体缺少T0要素 → 不合格：变体必须包含完整T0要素

## 四、角色增强模块 + 四·五、女性体型美学规范

> 📖 详见 [`references/enhancement-and-aesthetics.md`](references/enhancement-and-aesthetics.md)
> 包含：表情/情绪变化模块（8种基础+进阶情绪）、动作/姿态模块、3D建模专用模块（拓扑/材质球/阴阳脸/细节放大）、
> 光照变化模块、女性角色体型选择矩阵（T0超模级/T1战术级/T2精灵级）、面部反大众化规范。

### 🔴 女性体型铁律（速查）

- AXIS所有女性角色**禁止使用"普通女性体型"**
- 必须按矩阵选择体型等级（T0超模级 / T1战术纤长级 / T2幻想精灵级）
- T0超模级强制描述块**必须逐字嵌入**提示词英文段和中文段
- 面部**必须极端化至少1个特征**（冷酷高骨感/超长眼型/异色机械感/高冷模特神情）
- 头身比最低8.5，推荐9.5；腿长占总身高60%+；S曲线必须明显
- 禁止："普通亚洲美女"脸型、温柔亲和默认表情、体态软弱无力

|------|----------|

| **多记忆点** | 试图在一个角色上实现多个亮点 |
