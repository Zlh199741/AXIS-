# 故事卡桥接审核技能

[技能说明]
    审核 story-card-bridge 的故事卡↔集纲双向桥接产出，确保：
    1. McKee故事卡节点完整（激励事件/纠葛/危机/高潮/结局）
    2. 故事卡→集纲映射逻辑合理，无空集
    3. 集纲→故事卡提取准确，诊断有效
    4. 进展纠葛数量足够支撑中段集数

    本审核技能必须参考：
    1. skills/story-card-bridge/SKILL.md：了解桥接规范
    2. skills/short-drama-architect-skill/SKILL.md：集纲标准
    3. skills/compliance-review-skill/SKILL.md：合规检查
    4. skills/templates/quality-threshold-standard.md：通过阈值单一权威

    - 🔴 McKee 五节点完整（激励事件 / 进展纠葛≥5 / 危机两难 / 高潮非巧合 / 结局）为 P0；生成端 story-card-bridge 必须满足这些硬性字段，缺任一 → 直接 FAIL（与生成端对齐，避免"能生成必 FAIL"）。

[审核流程]

    第一步：McKee节点完整性审核
        | 节点 | 检查标准 |
        |------|---------|
        | 激励事件 | 是否不可逆？是否迫使主角行动？ |
        | 进展纠葛 | 数量≥5？压力是否持续升级？ |
        | 危机 | 是否为真正两难（非明显正确选择）？ |
        | 高潮 | 是否通过主角行动（非巧合）解决？ |
        | 结局 | 是否建立新平衡？ |

    第二步：集纲映射审核
        | 检查项 | 标准 |
        |--------|------|
        | 全覆盖 | 每个McKee节点都有对应集数 |
        | 无空集 | 没有任何集数缺少McKee节点映射 |
        | 情绪递进 | 映射后情绪强度是否逐集递进 |
        | 中段充实 | 中1/3集数是否有足够的纠葛支撑 |

    第三步：结构诊断审核（集纲→故事卡方向）
        | 检查项 | 标准 |
        |--------|------|
        | 故事脊柱 | 主角欲望/对抗力量/价值转化是否提炼准确 |
        | 缺陷诊断 | 结构缺陷是否识别准确 |
        | 修复建议 | 修复建议是否可执行 |

[评分表格式]

    三维评分规则（必须执行）：

    McKee结构完整性评分（0-100分）：
    □ 五大节点是否全部存在且定义清晰？（0-33分）
    □ 进展纠葛是否≥5且持续升级？（0-33分）
    □ 危机是否为真正两难抉择？（0-34分）

    映射合理性评分（0-100分）：
    □ 每个节点是否有对应集数映射？（0-33分）
    □ 情绪强度是否逐集递进？（0-33分）
    □ 中段（中1/3集数）是否有足够纠葛支撑？（0-34分）

    增强有效性评分（0-100分）：
    □ 桥接是否增强了集纲的叙事深度？（0-33分）
    □ 故事脊柱提炼是否准确？（0-33分）
    □ 结构诊断和修复建议是否有价值？（0-34分）

    通过标准（审核类 C 级，引用 skills/templates/quality-threshold-standard.md v1.2）：各项 ≥ 95分

[PASS/FAIL 标准]

    PASS 条件：
    - 三维评分各项 ≥ 95分
    - McKee五大节点无遗漏
    - 合规审核通过

    FAIL 条件（任一满足）：
    - McKee五大节点缺失2个以上
    - 危机非两难（明显正确选择）
    - 高潮由巧合/外力解决（非主角行动）
    - 映射后存在3集以上无叙事功能

[诊断指南]

    Q: McKee五大节点不完整？
    A: 逐一检查：激励事件→进展纠葛→危机→高潮→结局。每个节点必须有明确的事件描述。"隐含存在"不算存在。缺失2个以上=FAIL。

    Q: 进展纠葛数量不足？
    A: 标准要求≥5个进展纠葛（对应中1/3集数的加压期）。每个纠葛必须比前一个压力更大。数量<5=中段集数支撑不足=P1。

    Q: 危机不是真正两难？
    A: 真正的两难=两个选择都有重大代价（如"救爱人还是救世界"）。如果一个选择明显正确（如"救人还是不救"）=不是两难=P0。

    Q: 高潮由巧合解决？
    A: 高潮必须由主角的行动（选择/牺牲/觉醒）解决，不能靠：天降救兵、意外发现、敌人自灭、外力干预。巧合解决=P0。

    Q: 故事卡→集纲映射有空集？
    A: 每个集数必须有对应的McKee节点映射。如果某集既无激励事件、也无纠葛、也无危机=空集=该集无叙事功能=P1。

    Q: 集纲→故事卡提取不准确？
    A: 检查故事脊柱三要素：主角欲望（Want）+对抗力量（Antagonist）+价值转化（Value Change）。三要素必须从集纲中准确提炼，与原始内容一致。

    Q: 戏剧卡标注缺失？
    A: 每集至少标注1个戏剧卡类型（信息差/反差/陷阱/误会/反转等）。无戏剧卡标注=缺少叙事技巧层面的分析=P2。

    Q: 双向映射结果不一致？
    A: 正向映射（故事卡→集纲）和逆向映射（集纲→故事卡）应产生一致结果。如果正向生成的集纲，逆向提取后的故事卡与原始故事卡差异>20%=映射逻辑有误。

[常见审核案例]

    PASS案例：
    - McKee五大节点完整：激励事件→进展纠葛→危机→高潮→结局（映射到本章实际集数）
    - 危机为真正两难："暴露身份救崔云绣"vs"隐藏身份保全自己"，两个选择都有重大代价
    - 高潮由主角行动解决：主角选择暴露身份+牺牲利益，通过自身选择而非巧合
    - 双向映射一致：正向生成的集纲逆向提取后故事卡差异<10%

    FAIL案例：
    - 缺少"危机"节点，从进展纠葛直接跳到高潮，缺少两难抉择
    - 进展纠葛仅有3个，中1/3集数中有2集无实质性叙事推进
    - 高潮由"突然出现的神秘高手"解决，非主角行动驱动
    - 正向映射生成集纲，但逆向提取后故事卡缺失“结局”节点

[术语表]

    | 术语 | 英文 | 定义 |
    |------|------|------|
    | 故事卡 | Story Card | McKee结构中的叙事单元 |
    | 激励事件 | Inciting Incident | 不可逆地打破平衡的关键事件 |
    | 进展纠葛 | Progressive Complications | 持续升级的障碍和冲突 |
    | 危机 | Crisis | 主角面临的真正两难抉择 |
    | 高潮 | Climax | 通过主角行动解决的最高冲突点 |
    | 故事脊柱 | Story Spine | 欲望+对抗力量+价值转化的核心结构 |
    | 戏剧卡 | Drama Card | 叙事技巧标注（信息差/反差/陷阱） |
    | 双向映射 | Bidirectional Mapping | 故事卡↔集纲的正向和逆向转化 |
    | 价值转化 | Value Change | 从正面到负面或反之的价值观变化 |
    | 空集 | Empty Episode | 无叙事功能的集数 |

[学习路径]

    📚 第一阶段：McKee基础 (1周)
    - 掌握McKee五大节点的识别方法
    - 练习进展纠葛的数量和质量评估
    - 熟悉危机"两难"判定标准

    📚 第二阶段：映射审核 (1周)
    - 掌握故事卡→集纲的正向映射检查
    - 学会识别空集和映射断裂
    - 练习动态集数情绪曲线与McKee节点的对齐

    📚 第三阶段：结构诊断 (1周)
    - 掌握集纲→故事卡的逆向提取审核
    - 学会故事脊柱三要素验证
    - 练习戏剧卡类型标注完整性检查

    📚 第四阶段：实战应用 (持续)
    - 参与实际项目故事卡桥接审核
    - 积累双向映射不一致的典型案例
    - 掌握与short-drama-architect联动优化

[合规检查项]

    故事卡桥接审核中的合规注意事项：
    - [ ] 故事卡内容无违禁敏感元素
    - [ ] 危机/高潮设计不含过度暴力渲染
    - [ ] 进展纠葛不涉及歧视性冲突设计

    - [ ] 戏剧卡技巧不依赖低俗/色情手段制造冲突
