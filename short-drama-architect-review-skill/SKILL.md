# 爆款短剧集纲审核技能

[技能说明]
    审核 short-drama-architect-skill 产出的短剧集纲（每章集数动态规划）。
    审核员需以批判性视角审视集纲，通过逐集比对原始小说/脑洞产出、
    验证情绪循环完整性、检查卡点设计质量、逐项评分的方式，
    确保集纲质量真正达到工业爆款标准，而非仅确认格式完整。

    本审核技能必须参考：
    1. skills/short-drama-architect-skill/SKILL.md：了解集纲生成规范
    2. skills/compliance-review-skill/SKILL.md：合规检查
    3. tools/references/sensitive-word-dictionary.md：敏感词检测
    4. skills/genre-adaptive-skill/SKILL.md：题材风格适配

[文件结构]

[审核对象]
    short-drama-architect-skill 的集纲产出文件

[审核流程]

    第一步：建立整体理解
        - 读取原始小说文本或脑洞产出
        - 读取待审核的本章集纲
        - 明确审核立场：你的任务是找出问题，而非确认通过

    第二步：宏观结构验证
        - 检查故事梗概是否≤150字且核心矛盾一句话说清
        - 检查三大精彩事件是否具有足够戏剧张力
        - 检查三段式情绪周期是否完整覆盖本章动态集数：蓄能期(前1/3)→加压期(中1/3)→升级期(后1/3)

    第三步：逐集情绪循环审核
        对每一集逐项检查3-10-60情绪循环：
        - 【前3秒钩子】：是否有极致视觉奇观/肢体冲突/反常态画面？
        - 【前10秒叙事】：是否快速交代人物关系和核心矛盾？
        - 【1分钟爽点】：是否完成完整的情绪释放？
        - 【卡点钩子】：结尾是否截断在悬念/危机前0.5秒？

    第四步：跨章钩子审核（本章最后一集专项 — 邀进下一章追看驱动力）

        首先判断性质：章内大结局？还是跨章钩子？
        - 如果章末给了任何形式的情感闭合（拥抱和好、表白成功、悟出真相“原来如此”等）→ 直接判定 FAIL，章内大结局会切断追看动力。
        - 跨章钩子必须满足：
          1. 信息缺口跨越章节边界（本章内无法获得答案，必须看下一章）✔／✖
          2. 包含物理威胁+道德困境✔／✖
          3. 答案留到下一章（非本章内部解决）✔／✖
          4. 使用【跨章钩子：{}】标签明确标注✔／✖
          5. 截断在动作发生的前0.5秒✔／✖
          6. 拆分为画面/音效、卡点动作、黑屏/音效、字幕四个子模块✔／✖

    第五步：内容质量与合规审核
        - 台词是否短促有力（≤20字/句）
        - 内容是否绝对视觉化（无心理描写/内心独白）
        - 逐行扫描敏感词
        - 检查政治/色情/暴力尺度

    第六步：逐项评分并输出结果
        按照下方评分标准评分，输出审核报告

[审核维度与评分标准]

    | 审核项 | 权重 | 5分（优秀） | 3分（一般） | 1分（不足） |
    |--------|:----:|------------|------------|------------|
    | 3秒钩子质量 | 20% | 极致视觉冲击 | 有冲击但不够极致 | 平淡/缺失 |
    | 10秒叙事清晰度 | 15% | 人物关系+矛盾秒懂 | 基本交代 | 模糊/缺失 |
    | 1分钟爽点落地 | 20% | 完整情绪释放+打脸 | 有释放但不够爽 | 缺失/弱 |
    | 卡点钩子设计 | 15% | 极致悬念+截断0.5秒 | 有悬念不够极致 | 平淡收尾 |
    | 三段式情绪周期 | 15% | 完整覆盖+递进清晰 | 基本完整 | 严重缺失 |
    | 格式规范性 | 10% | 完全规范 | 基本规范 | 严重缺失 |
    | 内容质量 | 5% | 视觉化+台词有力 | 基本达标 | 冗长说教 |

[集纲结构校验]（硬门禁 — 先于评分，任一缺失直接 FAIL）

    □ 3-10-60 字段齐全：每集均含【前3秒钩子】【前10秒叙事】【1分钟爽点】【卡点钩子】四字段，缺一即 FAIL
    □ 跨章钩子四子模块：本章最后一集的跨章钩子已拆分为「画面/音效、卡点动作、黑屏/音效、字幕」四个子模块，缺模块即 FAIL
    □ 精彩台词 ≤20字：每集"精彩台词"单句字数 ≤20字（超长只允许拆句，严禁删减 — 台词零删减铁律）
    □ 核心字段齐全：第X集四字高能词标题、故事梗概（≤150字）、精彩台词、卡点钩子 均存在

[PASS/FAIL 标准]

    PASS 条件（必须全部满足）：
    - 3-10-60情绪循环：三要素全部完整且质量≥3分
    - 卡点设计：每集有卡点钩子，本章最后一集为跨章钩子（退出条件：如有章内闭合 → 直接 FAIL）
    - 三段式情绪周期：完整覆盖蓄能→加压→升级
    - 格式规范：核心字段完整
    - 综合评分 ≥ 4.0
    - 三维评分各项 ≥ 95分（审核类 C 级，引用 skills/templates/quality-threshold-standard.md v1.2）

    FAIL 条件（任一满足）：
    - 任何一集的3秒钩子缺失或质量<2分
    - 任何一集的卡点钩子缺失
    - 三段式情绪周期严重缺失
    - 格式规范性严重缺失
    - 综合评分 < 3.0
    - 三维评分任一维度 < 95分

[输出模板]

    三维评分规则（必须执行）：

        剧情连贯性评分（0-100分）：
        □ 集纲与小说原文的核心情节是否完整对应？（0-33分）
        □ 人物行为动机是否合理连贯？（0-33分）
        □ 剧情转折点是否有足够铺垫？（0-34分）

        集间叙事衔接 / 钩子—爽点因果链评分（0-100分）（集纲阶段无镜头，本维度替代原「分镜连贯性」）：
        □ 集与集之间的悬念承接是否流畅自然（上集卡点 → 本集开篇钩子）？（0-33分）
        □ 钩子→爽点的因果链是否闭合（每集3秒钩子抛出的疑问在1分钟爽点处兑现）？（0-33分）
        □ 三段式情绪强度是否逐集递进、无断裂（蓄能→加压→升级）？（0-34分）

        场景完整性评分（0-100分）：
        □ 场景是否覆盖所有核心剧情需要的地点？（0-33分）
        □ 场景描述是否具有可拍摄性？（0-33分）
        □ 场景转换是否有逻辑支撑？（0-34分）

        通过标准（审核类 C 级，引用 skills/templates/quality-threshold-standard.md v1.2 — 审核类三维各 ≥ 95）：
        - 剧情连贯性 ≥ 95分
        - 集间叙事衔接 / 钩子—爽点因果链 ≥ 95分
        - 场景完整性 ≥ 95分
        - 任一维度低于95分 → 业务审核 FAIL

[诊断指南]

    | 问题类型 | 快速检查 | 修复方向 |
    |----------|----------|----------|
    | 钩子缺失 | 检查每集开头是否有视觉冲击 | 添加极致画面/肢体冲突 |
    | 爽点不足 | 检查每集是否有情绪释放 | 增加打脸/反转/碾压 |
    | 卡点无力 | 检查结尾是否截断在悬念最高点 | 截断在动作发生前0.5秒 |
    | 周期失衡 | 检查蓄能→加压→升级是否递进 | 调整集数分配比例 |
    | 台词冗长 | 检查单句是否≤20字 | 拆分为短句 |
    | 心理描写 | 搜索"感到/内心/心想" | 转化为动作/表情 |
    | 格式缺失 | 对照模板检查字段 | 补充缺失字段 |
    | 合规问题 | 扫描违禁词表 | 替换或删除违规内容 |
