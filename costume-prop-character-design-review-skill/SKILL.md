# 服化道角色设计审核技能

[技能说明]
    审核 costume-prop-character-design-skill 的产出，包括角色模型表（Model Sheet）、场景设计稿和道具设计稿。
    确保设计质量真正达到3D建模与贴图团队的交付标准，而非仅确认格式完整。

    本审核技能必须参考：
    1. skills/costume-prop-character-design-skill/SKILL.md：了解设计规范和输出格式
    2. skills/art-design-skill/SKILL.md：确保与上游角色概念设计一致
    3. skills/compliance-review-skill/SKILL.md：合规检查
    4. resources/AI绘画终极提示词工程白皮书.md：T0级提示词标准
    5. tools/validators/t0-validator.py：T0标准校验
    6. tools/references/sensitive-word-dictionary.md：敏感词检测

    调用方 Agent：
    - agents/director.md：导演 Agent 执行审核
    - agents/art-designer.md：服化道 Agent 自审

[审核对象]
    costume-prop-character-design-skill 产出的角色模型表和场景设计稿

[审核流程]

    第一步：建立整体理解
        - 读取上游 art-design-skill 的角色概念设计
        - 读取待审核的角色模型表/场景设计稿
        - 读取 genre-adaptive-skill 确认题材风格
        - 明确审核立场：你的任务是找出问题，而非确认通过

    第二步：核心记忆点审核
        | 检查项 | 标准 | 方法 |
        |--------|------|------|
        | 辨识度 | 缩小到拇指大小仍可辨认 | 缩小全身图到1cm检查 |
        | 唯一性 | 核心记忆点有且仅有1个 | 数记忆点数量 |
        | 一致性 | 全部视图中记忆点一致 | 逐视图对比 |
        | 与概念一致 | 与art-design-skill概念设计一致 | 对比上游产出 |

    第三步：多视图完整性审核
        | 检查项 | 标准 | 评分 |
        |--------|------|------|
        | 正面全身 | 存在且比例正确 | 0-10 |
        | 45度角全身 | 存在且与正面一致 | 0-10 |
        | 侧面全身 | 存在且厚度合理 | 0-10 |
        | 背面全身 | 存在且细节完整 | 0-10 |
        | 表情集 | 至少5个基础表情 | 0-10 |
        | 服饰拆分 | 每件服饰独立 | 0-10 |
        | 比例一致性 | 各视图比例统一 | 0-10 |

    第四步：材质与技术规格审核
        | 检查项 | 标准 |
        |--------|------|
        | 材质三要素 | 每个部件有材质类型+纹理+反射率 |
        | 色卡HEX值 | 所有颜色附 HEX 色值 |
        | PBR参数 | Diffuse/Normal/Specular/AO标注 |
        | 3D可建模性 | 结构可直接用于3D建模 |
        | 尺寸比例 | 关键部位有尺寸标注 |
        | 布料可模拟 | 服饰设计考虑布料物理 |

    第五步：AI提示词质量审核
        | 检查项 | 标准 |
        |--------|------|
        | T0校验 | 通过 tools/validators/t0-validator.py 校验 |
        | 防崩坏指令 | 每条提示词包含防崩坏指令 |
        | 纯白背景 | 角色/道具提示词使用纯白背景隔离 |
        | 渲染参数 | 包含PBR/AO/Octane等渲染参数 |
        | 英文质量 | 英文Prompt语法正确、词汇专业 |
        | 微观细节 | 包含皮肤纹理/毛孔/发丝等微观描述 |

    第六步：风格一致性审核
        | 检查项 | 标准 |
        |--------|------|
        | 与概念设计一致 | 设计与art-design-skill产出一致 |
        | 题材风格匹配 | 视觉风格与genre-adaptive-skill一致 |
        | 角色间统一 | 不同角色间风格统一（同一世界观） |
        | 道具风格匹配 | 道具与角色/场景风格一致 |

    第七步：视觉意图达成度审核（审美维度·最高权重15分）

        > ⚠️ 本步是第1-6步的超越：前6步审核“有没有”，本步审核“好不好”。

        **Step 1: 检查五问法落位是否合规（口径见 aesthetic-vision-skill §二·单一权威）**
        - 五问法（📐Q1-Q5）须出现在设计文件的【人读层 / 元数据标注区】（如「📐 视觉美学意图声明」章节）→ 出现 = 允许且推荐 ✅
        - 🔴 五问法不得混入喂给生图模型的【中文描述段】/【英文描述段】正文 → 若混入则该项 FAIL（生图正文须为纯画面描述）
        - 五问是否全部回答（Q1-Q5）？
        - Q1情绪词是具体情绪词（如「压迫×精密×恐怖谷」）还是通用词（如「酷×帅×强」）？

        **Step 2: 评估Q1情绪词在产出中的可感知度**
        - 不看五问声明，直接看设计结果，第一句话能写出什么感受？
        - 把自诉的第一句话与Q1情绪词对比：是否一致？

        **Step 3: 逆向溯源设计决策**
        | 审核项 | 审核问题 | 判断方法 |
        |--------|--------|--------|
        | Q3形状语言 | 声明的主导形状在实际造型中是否可见？ | 遙罩/形态对照审核 |
        | Q4配色情绪 | 每个颜色的“情绪贡献”是否在实际配色中生效？ | 拳盒审核各色区域情绪与声明是否匹配 |
        | Q5世界观位置 | 展品与同世界观其他设计的对比关系是否在设计中有具体锐化？ | 对照同项目其他角色/道具，视觉阶级差异是否清晰 |

[评分表格式]

    请使用以下格式输出审核结果：

    ```
    ## 审核结果

    ### 三维评分规则（必须执行）

    设计完整性评分（0-100分）：
    □ 多视图是否齐全且比例一致？（0-33分）
    □ 材质/贴图参数是否完整标注？（0-33分）
    □ 表情集/动作集是否包含？（0-34分）

    3D可行性评分（0-100分）：
    □ 结构拓扑是否可建模？（0-33分）
    □ 服饰层次是否可分层？（0-33分）
    □ 技术规格是否满足3D要求？（0-34分）

    风格一致性评分（0-100分）：
    □ 设计是否与角色概念一致？（0-33分）
    □ T0提示词是否可生成一致效果？（0-33分）
    □ 不同角色间风格是否统一？（0-34分）

    通过标准：
    - 设计完整性 ≥ 95分
    - 3D可行性 ≥ 95分
    - 风格一致性 ≥ 95分
    - 任一维度低于95分 → 业务审核 FAIL

    ### 业务审核评分表

    | # | 审核维度 | 分值 | 得分 | 问题说明 |
    |---|---------|------|------|---------|
    | 1 | 核心记忆点 | 12分 | | |
    | 2 | 多视图完整性 | 17分 | | |
    | 3 | 材质技术规格 | 17分 | | |
    | 4 | AI提示词质量 | 17分 | | |
    | 5 | 风格一致性 | 12分 | | |
    | 6 | 合规检查 | 10分 | | |
    | **7** | **视觉意图达成度** | **15分** | | **最高权重审美维度** |
    | **总分** | | **100分** | **__分** | |

    ### 第7维度「视觉意图达成度」具体4档评分标准

    | 档位 | 分数 | 判断条件 | 典型表现 |
    |---|---|---|---|
    | **A 满分** | **15分** | 五问法已具体填写 + Q1情绪词3/3可感知 + Q3形状语言在造型中明显体现 + Q4配色情绪逻辑可逆向溯源 + Q5世界观位置在设计中有具体锐化 | 不看声明直接看图就能准确说出设计的情绪主题 |
    | **B 良好** | **12分** | 五问已填 + Q1有 2/3 情绪词可感知 + 有一两处声明与产出轻微脱节 | 图大体情绪对，个别细节需追问才知道 |
    | **C 及格** | **8分** | 五问已填但回答流于表面（Q1写通用词）OR 声明与产出气韵不通 | 产出技术正确但无灵魂，“有脑子但没有心” | 
    | **D 不合格** | **0分** | 五问法未完成（跳过阶段0）OR 产出与Q1声明存在完全矛盾 | 声明“压迫高冷”但设计出来温柔可爱 |

    **评分步骤**：先判断C/D级（五问法是否完成、是否流于表面）→ 再判断A/B级（情绪词可感知度 + 设计决策是否可逆溯）

    **第7维度检核不能走过场的FAIL条件**：
    - 🔴 五问法未完成 → 直接判定0分，不需进行其他评估
    - 🔴 Q1情绪词为“酷/帅/美/强/好看”等通用词 → 判定C级（8分），强制降档
    - 🔴 产出与Q1声明情绪词南辕北辙 → 判定0分，不需评估其他细节

    ### 问题清单
    | # | 维度 | 严重程度 | 问题描述 | 修改建议 |
    |---|------|---------|---------|---------|
    ```

[PASS/FAIL 标准]

    PASS 条件（必须全部满足）：
    - 业务审核总分 ≥ 80分
    - 无单项低于 5 分
    - 三维评分各项 ≥ 95分
    - T0校验通过
    - 合规审核通过

    FAIL 条件（任一满足）：
    - 多视图比例不一致导致3D建模无法使用
    - 材质标注严重缺失（缺少PBR参数超过50%）
    - 核心记忆点在缩略图中完全不可识别
    - 英文提示词完全不可用（语法严重错误）
    - T0校验未通过
    - 合规审核未通过
    - 与上游概念设计严重不一致

[合规检查项]
    - [ ] 无政治敏感内容
    - [ ] 无版权侵权风险（无明星/IP形象引用）
    - [ ] 无色情/暴力尺度问题
    - [ ] 角色设计无歧视性刻板印象
    - [ ] 英文提示词无违禁词汇
    - [ ] 视觉设计无宗教敏感符号

[诊断指南]

    | 问题 | 检查 | 修复 |
    |------|------|------|
    | 记忆点不突出 | 缩略图辨识度测试 | 增大/加对比色/简化周围元素 |
    | 视图不一致 | 叠加对比各视图 | 以正面为基准统一修正 |
    | 材质模糊 | 检查是否有三要素 | 补充材质类型+纹理+反射率 |
    | T0未通过 | 运行t0-validator.py | 按校验报告逐项修复 |
    | 风格不统一 | 对比genre-adaptive | 统一色调/材质/装饰风格 |
    | 3D不可建模 | 检查细节复杂度 | 简化装饰，增加技术标注 |
