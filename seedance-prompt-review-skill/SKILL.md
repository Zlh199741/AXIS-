# Seedance 2.0 提示词审核技能

## 🔴🔴 零·机读层唯一权威格式（审核基准 — 2026-05-31）

审核机读层时，**唯一合法格式 = 自然语言格式**（与 SKILL.md「零」+ storyboard-generation-cheatsheet「零」同口径）：
1. 机读层首行 = `[Global Spatial Anchor: ...]`（空间锚点GSA）；缺 → FAIL。GSA 内出现跨P文字引用（承接PXX / 同PXX结束位置 / 同一坐位 / 匹配剪辑承接PXX）→ FAIL（模型对其它P零记忆，继承须改写为本P绝对站位；`陈屿 终态在画面右前方` 这类本镜内终态合法）。
2. 70% 自然语言 + 30% 可执行影视词；时间段 `0·Xs秒：`（推荐）或 `0-Xs秒：`（兼容），两者均合规。
3. 台词内联唯一模板（人声锚定字段齐全）；音效独立 `音效层：`；素材 `参考@图片N`。
4. 🔴 机读层出现 6 层堆栈 `[GLOBAL]` / 焦段mm / f值 / 英文运镜(Dolly等) / `00:00·00:03` / `{}`台词 / `<>`嵌行 / `@image_N` → 必须 FAIL（这些只许在人读层）。
5. ⚠️ 不得因机读层用自然语言而误判（自然语言＝正确）；也不得因未用附件④的6层堆栈而误判。

[审核流程]

    第一步：建立整体理解
        - 读取导演讲戏本（01-director-analysis.md）
        - 读取角色提示词（assets/prompts/character-prompts.md）和场景提示词（assets/prompts/scene-prompts.md）
        - 读取待审核的 Seedance 提示词产出
        - 明确审核立场：你的任务是找出问题，而非确认通过

    第一步半：🔴 读取模板合规校验报告（2026-04-25 新增 — T0级前置阻断）
        产出方按 seedance-storyboard-skill 第七步要求，已在分镜产出完成后强制跑过
        tools/validators/seedance-template-validator.py，报告应落盘为：
        - outputs/<集数>/validation-report.json（结构化报告，优先读取）
        - outputs/<集数>/validation-report.txt（人读报告，辅助定位）

        审核动作：
        - ☐ 检查 validation-report.json 是否存在？
          不存在 → 🔴 直接 FAIL：产出方未执行第七步强制校验，退回产出侧补跑校验
        - ☐ 读取 summary.verdict 字段：
          "PASS"  → 进入第二步逐条比对
          "FAIL"  → 🔴 直接 FAIL：将 reports[].issues 中所有 severity=critical 的条目附入审核报告的"需要修改的问题"区，无需进入脑内预演
        - ☐ 读取 summary.warning 计数：
          ≥3    → 🟡 提示产出方在交付前跑 --strict 消灭 warning
          ≤2    → 继续正常流程

        若需重新手动确认，可执行：
          python tools/validators/seedance-template-validator.py <集数> --only v2 --json
        比对产出方提交的 validation-report.json 是否一致；不一致按产出方最新跑出的报告为准。

        🔴 铁律：未提供 validation-report.json 或其 verdict=FAIL 的产出，禁止进入第二步～第五步人工审核流程。

    第二步：逐条比对
        - 对每条提示词，逐句对照导演讲戏本中对应剧情点的导演阐述
        - 找出导演阐述中有但提示词中被弱化、遗漏或表达偏离的地方
        - 找出分镜师自行添加的、导演阐述中没有的内容，判断是否合理
        - 记录所有偏差，无论大小

    第二步B：🔴 成品禁用项零残留 + 运镜点名检查（方向C 单层 — 2026-06-08 改写；原"翻译审计检查"作废）
        机读层即单层成品（无翻译步骤）。逐条检查：
        - ☐ 不可执行/数字参数零残留（🔴 白/禁列表唯一权威：translation-audit-rules.md 核心原理表，与 seedance-storyboard-skill 同一张表）：
          🔴 禁止列表（命中即 FAIL）：mm数值 / f-stop / ISO / J-Cut / L-Cut / 伦勃朗光 / 蝶形光 / 丁达尔效应 / 钟面方位 / 景别英文缩写（ECU/MS等） / Dolly·Arc Shot·Pan·Whip Pan 等英文运镜词 / 180度法则 / 库里肖夫效应 / 抽象情绪词（她很伤心/温柔地/压迫感）
          ✅ 允许并要求（计入30%配额）：特写 / 近景 / 中景 / 全景 / 广角镜头 / 长焦镜头 + 缓推 / 拉镜 / 横摇 / 切镜 / 仰拍 / 俯拍 / 手持跟拍 / 慢镜头 / 虚化 / 逆光 等
          命中禁止列表 → 🔴 必须 FAIL；仅出现允许列表 → ✅ 合规
        - ☐ 🔴 运镜点名（方向C 新增·官方要求"具体"）：每个时间段是否**点名景别＋点名且具体的运镜**（如"中景，缓慢推近"），而非"镜头移动/有运镜感"含糊带过或缺失？
          含糊（只写"镜头移动"）或缺景别/运镜 → 🟡 需补充；关键情绪/卡点P 缺 → 🔴 FAIL
        - ☐ 画面坐标零残留：是否用标准位置词（画面左/右/上方/下方/中央/深处）而非钟面方位数字？发现钟面数字 → 🔴 必须 FAIL
        - 🔴 方向C：原"翻译审计表 存在性/准确性/可追溯人读层"检查**已废除**（单层无翻译审计表）。

    第二步C：🔴 设计落地全覆盖审核（2026-06-08 方向C 改写：对照导演分析+源剧本，不再对照 in-file 人读层）
        逐条P对照 `outputs/<ep>/01-director-analysis.md` 的设计意图（及源剧本），按以下7维度核对成品是否完整落地：
        - ☐ ①空间坐标锚点：角色画面位置（上/下/左/右/深处）是否在机读层有对应？
          垂直维度丢失（如"画面中下方"→"中央"） → 🔴 必须 FAIL
        - ☐ ②构图权力位置：权力位（攻击位/弱势位/主导位）是否翻译为具体画面上方/下方？
          仅保留左右丢失上下 → 🟡 需补充
        - ☐ ③物理动力学递进：动作递进链（如"施压→凹陷→切开→渗出"）是否完整？
          多步压缩为结果 → 🔴 必须 FAIL
        - ☐ ④光影叙事：光源方向+色温效果+明暗分割是否完整翻译？
          多光源场景遗漏某个光源 → 🟡 需补充
        - ☐ ⑤声音设计：声音层次+跨条衔接是否在音效行完整体现？
          跨条衔接接收端遗漏 → 🟡 需补充
        - ☐ ⑥焦段空间效果：焦段选择是否翻译为视觉效果描述？
          一般覆盖良好
        - ☐ ⑦时长与节奏：时长是否一致？剪辑节奏是否在叙事结构中体现？
          时长不一致 → 🔴 必须 FAIL

        判定规则：
        - 🔴 **情感熵修正（2026-03-29）**：情感熵T0维度标签名（"情感熵"三字）无需在机读层出现，但其包含的三个子项**视觉内容必须翻译进机读层**，逐项核查：
          ☐ **情感熵①环境熵增**：打点前环境杂质密度递增的具体描述是否在机读层有对应？ → 缺失 🔴 FAIL
          ☐ **情感熵②时间弹性→特写拆解**：打点瞬间是否有显式特写切镜句子？（标准：含"→ 切极近特写："或等效的切镜语句）→ 无显式切镜 🔴 FAIL（不接受"整体描述里含特写感"）
          ☐ **情感熵③通感模拟**：高频音效与画面的对应关系是否在音效行或叙事中有体现？ → 缺失 🟡 需补充
        - 神经劫持的**视觉执行结果**（物理丢帧描述、呼吸节奏递减表现）同样必须翻译进机读层，"神经劫持"标签名不需出现但效果必须体现
        - 任何一条P的①③⑦维度不通过 → 该条直接 FAIL
        - 任何一条P的②④⑤维度不通过 → 🟡 需补充，不单独FAIL但累计3项以上 → FAIL

    第二步D：🔴 两层必含四要素审核（2026-03-20 新增）
        对每条P逐项核查人读层和机读层是否同时包含以下四要素：

        人读层检查（📋 导演分析）：
        - ☐ 情绪钩子：是否包含4行结构（开篇钩子/前10秒/情绪高潮点/卡点钩子）？
          缺失任意一行 → 🔴 必须 FAIL
        - ☐ T0视听语言9维度：9个维度标签是否全部出现（镜头关系/剪辑节奏/光影叙事/焦段选择/声音设计/物理动力学/构图权力/神经劫持/情感熵）？
          缺失任意一个维度 → 🔴 必须 FAIL
        - ☐ 空间坐标锚点：是否包含原点 + 角色坐标（含画面精确位置：左/右/上/下/中央）？
          坐标缺失或仅有原点无角色位置 → 🟡 需补充
        - ☐ 时长：是否包含具体数值（如15s / 8s / 5s）？
          缺失时长 → 🔴 必须 FAIL

        机读层检查（🎬 Seedance提示词）：
        - ☐ 情绪钩子体现：开篇时间段（第一个0-Xs段）是否体现高冲击内容？情绪高潮时间点是否有叙事对应？
          开篇无冲击 / 高潮时间点无叙事 → 🟡 需补充
        - ☐ **A4 短剧三标承接**（2026-06-09 新增·对接 director-thinking-layer §2D.2 + seedance SKILL「八问落地追溯」）：
          **本集首条 P** 机读层第一个时间段是否承接导演分析 A4【3 秒钩子】（强冲击/反常画面已落为具体可拍内容）？
          **本集末条 P** 机读层最后一个时间段是否承接 A4【卡点】（停在揭晓前、悬念正盛，可接黑屏）？
          首条无钩子 / 末条给了完整闭环未卡点 → 🔴 必须 FAIL
        - ☐ **台词潜台词承接**（§1.9）：含台词的 P，台词原文是否零删改（铁律），且其语气/微表情/前置动作是否承接导演分析③潜台词与动作动词？
          台词被删改 → 🔴 必须 FAIL（台词零删减铁律）；潜台词无任何表演层承接 → 🟡 需补充
        - ☐ **视频单元 + 节奏**（2026-06-09 修订·对接 seedance SKILL「视频单元 + 镜头切换 + 接点分镜图」）：
          ① **单个视频（P）总时长是否 ≤15s**？>15s 未拆 → 🔴 必须 FAIL（拆成 Pxa/Pxb）。🔴 **一个视频内部含多个镜头切换是正常合规的，不得因"镜头多/切得快"判 FAIL。**
          ② **节奏是否发懒**：镜头是否为凑时长拖长致拖沓？短剧应快切（1–4s/镜常见，一个 15s 视频可装 4–6 镜）→ 无理由拖长 → 🟡 需压缩或加切换。
          ③ **视频接点是否有 @分镜图**：视频与视频之间（**非视频内部**）是否靠 @分镜图承接变动数据、而非文字"承接PXX"？台词镜是否配图？→ 缺 → 🟡 需补充。
          ④ **台词镜时长是否匹配语速档（双向查）**：语速档**须取自 `01-director-analysis.md` 每 P 的「节奏/语速档」字段**（分镜不得自行重判；导演分析缺该字段 → 🔴 退回导演阶段补，不在分镜层猜）。档位定义：慢戏 3–4 / 日常 4–5 / 快戏 5–6 字/秒。
             ▸ **太短**：时长 < 字数÷语速，说不完 → 🔴 延长/加段/拆视频，**绝不缩台词**（零删减铁律）。
             ▸ **太慢/拖**：快戏/日常戏却用慢档(3–4字/秒)估时长、或每句硬加 0.5s 留白、或把小动作另计时 → 🟡 判偏慢拖沓，按对应档压紧。
        - ☐ T0视听语言9维度体现：每个维度指导的可执行视觉/听觉设计是否存在？尤其：
          **构图权力** → 必须出现"画面上方/下方"等位置词 → 缺失 → 🔴 必须 FAIL
        - ☐ 空间坐标精确位置词：画面位置词是否出现（左/右/上方/下方/中央/深处）？有人物的P是否说明了人物画面位置？
          有人物但无位置词 → 🔴 必须 FAIL
        - ☐ 时间段标注：是否使用0-Xs格式？总时长是否与人读层时长一致？
          格式错误或时长不一致 → 🔴 必须 FAIL

        判定规则：
        - 人读层或机读层任一要素缺失 → 该条P直接 FAIL
        - 机读层构图权力/空间位置词缺失 → 直接 FAIL（不可仅标注🟡）

    第二步E：🔴 跨产物语义一致性自动化校验（2026-03-24 新增 — 根因修复）

    第二步G：🔴 画镜 Protocol A-F 合规审核（2026-04-10 新增）
        对照 seedance-storyboard-skill/SKILL.md 中的 Protocol A-F 规则，逐条P检查：

        **Protocol A — 零代词 + @引用**
        - ☐ 机读层是否完全无代词（他/她/它/男人/女人/主角/两人/他们）？
          发现任意代词 → 🔴 必须 FAIL
        - ☐ 所有 `@角色名` / `@场景名` / `@物品名` 前后是否有空格？
          紧贴标点或文字 → 🔴 必须 FAIL
        - ☐ 关键道具是否用 `@物品名` 引用且描述了空间关系？
          道具未@或无空间关系 → 🟡 需补充

        **Protocol B — 六维饱满**
        - ☐ 每个时间段是否覆盖8项维度中≥6项（运镜/光影/环境/材质/粒子/主体动作/面部锚点/声音层）？
          抽查每条P的首尾时间段，覆盖 <6项 → 🔴 必须 FAIL

        □ 忠实度（逐句比对）：将导演阐述和提示词逐句对照，核心动作、台词、镜头运动、光影描述是否被完整保留？哪些被弱化或遗漏了？哪些被偏离了？具体列出。
        □ 画面还原度（脑内预演）：想象 Seedance 根据这条提示词生成的视频，画面是否与导演讲戏本中描述的画面一致？如果有偏差，具体哪个画面元素会出问题？
        □ 动作可执行性（脑内预演）：每个连续镜头内的动作密度是否合理（1 拍 ≈ 2.5 秒）？多镜头段落的节拍是否合理分配在各镜头中？是否存在动作跳跃？具体指出。
        □ 镜头可实现性（脑内预演）：单镜头段落——镜头运动是否连续可实现？多镜头段落——每组镜头各自是否可执行，切换方式是否清晰？是否存在物理上矛盾的要求？具体指出。

        □ 视听语法（核心审查）：
            - 轴线原则：对话/对峙镜头组是否保持屏幕空间一致？越轴是否有叙事目的？
            - 屏幕方向一致性：同一连续动作的运动方向与视线方向是否一致？
            - 30度原则：同一主体连续切镜，机位变化是否足够明显？
            - 视线匹配：给出角色看向画外的反应后，是否补充了"他看到了什么"或"故意留悬念"？
            - 库里肖夫效应：是否用反应镜头传达情绪，而非在一个镜头里讲完所有事？
            - 动接动/静接静：镜头切换时机是否符合节奏逻辑？"静接动"冲击是否有情绪目的？
            - 因果逻辑：关键镜头是否遵循原因→结果或结果→原因（悬念）？
            - 光影叙事：光线是否服务于情绪表达？（暖光=安全/冷光=危险）
            - 焦段隐喻：是否体现广角/长焦的心理暗示？
            - 声音设计：J-Cut/L-Cut/声画对位是否有目的？
            如有破坏连贯性的设计（越轴/跳剪/声画对位），是否在提示词中明确标注"刻意设计"？

        □ Seedance 友好度：提示词是否采用叙事描述式？是否有否定句？是否有重复静态内容？是否有可能让 Seedance 困惑的歧义表达？
        □ 音频设计：提示词中是否包含人声锚定、环境音效、动作音效；音频描述是否与画面情绪匹配；如果有台词/对白/旁白/系统声，是否用语速、音量、气息、尾音标注情绪变化且保持固定音色？如果完全缺失音频设计，扣分。
        □ 情绪准确性：这条提示词传达的情绪基调是否与导演讲戏本中该剧情点的核心情绪一致？如果有偏差，指出导演要的情绪是什么，提示词传达的变成了什么。

        评分标准：
        - 9-10：提示词精准，脑内预演生成视频完全符合导演讲戏意图，无需修改
        - 7-8：基本到位，但有 1-2 处可能导致生成偏差的地方
        - 5-6：有明显的遗漏、偏离或可执行性问题，需要修改
        - 1-4：提示词严重偏离导演意图或无法生成有效视频

        □ 衔接自然：按顺序读完所有提示词，相邻两条之间的画面空间、时间、情绪是否能自然过渡？如果不能，指出具体哪两条之间有断裂。
        □ 节奏合理：整体节奏是否有起伏变化？是否存在连续多条节奏相同导致观感疲劳的情况？
        □ 情绪弧线：全部提示词串联起来，情绪弧线是否与导演的叙事设计一致？如果有偏差，指出哪里开始偏离。

        □ 连贯性语法一致（跨提示词检查）：
            - 轴线一致性：跨提示词的对话场景，轴线是否保持一致？
            - 屏幕方向：跨提示词的跑动/视线/动作矢量方向是否一致？
            - 空间关系：相邻场景之间的空间关系是否可理解？
            - 视线匹配：跨提示词的视线匹配是否保持？如果有变化，是否有合理的重置？

        □ 光影连续：
            - 相邻场景之间的光影/色调过渡是否合理？
            - 是否与导演设定的光影变化一致？

        □ 声音蒙太奇连续：

            - 声画对位是否有贯穿性的叙事目的？

## 🔴 新增：剧情连贯性强制审核规则（2026-03-13 更新）

### 核心问题背景
在实际审核中发现以下严重问题：
1. **Kling提示词缺少开篇剧情**：ep01的Kling提示词直接跳到"江辰爬起"，缺少"恶少轻薄+崔云绣用花瓶砸晕江辰"的核心冲突场景
2. **集数间剧情断裂**：ep01→ep02、ep02→ep03的衔接不流畅
3. **人物身份缺失**：崔云绣"清江书院才女"身份未在提示词中体现
4. **缺少视听语言标注**：部分Kling提示词没有镜头关系、剪辑节奏等专业标注

### 剧情连贯性检查清单（必须逐项检查）

#### 1. 开篇剧情完整性检查
- [ ] **首集必须有钩子场景**：检查第1集的提示词是否包含"3秒钩子"画面
- [ ] **核心冲突必须呈现**：检查是否包含剧本/集纲中的核心矛盾场景
- [ ] **人物关系必须建立**：检查开篇是否交代了主要人物之间的关系

#### 2. 集数间衔接检查
- [ ] **时间线清晰**：检查集与集之间是否有明确的时间转场说明
- [ ] **剧情承接**：检查下一集是否承接上一集的结尾
- [ ] **情绪连续**：检查集与集之间的情绪是否自然过渡

#### 3. 人物身份一致性检查
- [ ] **角色标签完整**：每个主要角色的身份标签是否在提示词中体现
- [ ] **视觉特征一致**：角色外观描述是否与character-prompts.md一致
- [ ] **行为动机合理**：角色行为是否符合其身份设定

#### 4. 视听语言标注检查
- [ ] **镜头关系**：是否有轴线、屏幕方向等标注
- [ ] **剪辑节奏**：是否有动接动/静接静等标注
- [ ] **光影叙事**：是否有色温、光源方向等标注

### 严重问题判定标准

以下情况直接判定为 **FAIL**：

| 问题类型 | 具体表现 | 判定 |
|---------|---------|------|
| 开篇缺失 | 第1集缺少核心冲突场景（如ep01缺少"轻薄被砸"） | 🔴 FAIL |
| 剧情断裂 | 集数之间无衔接，直接跳跃 | 🔴 FAIL |
| 人物消失 | 主要角色某集突然无合理理由消失 | 🔴 FAIL |
| 视听空白 | 整集提示词无任何视听语言标注 | 🔴 FAIL |
