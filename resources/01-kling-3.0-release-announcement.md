# Kling 3.0 官方特性公告

> 版本：Kling 3.0  
> 更新日期：2026-03  
> 本文档用于 AXIS 工作流参考，汇总 Kling 3.0 相较于 2.6 版本的核心新特性

---

## 一、核心新特性

### 1. 智能分镜（Smart Storyboarding）
- 支持在单条提示词中使用「镜头1、镜头2、镜头3…」标记实现自动分镜
- 系统根据镜头标记自动切分画面，无需手动拆分多条提示词
- 支持镜头间的转场指定（切、溶、淡入淡出等）

### 2. 主体参考绑定（Subject Reference）
- 使用 `@主体` 标签绑定角色形象
- 确保同一角色在不同镜头间保持外形一致性
- 支持多主体同时绑定

### 3. 多角色对话支持（Multi-Character Dialogue）
- 支持三人及以上角色同屏对话
- 每个角色可独立配置音色、情绪、语速
- 支持角色间的视线交互和空间位置关系

### 4. 原生文字生成（Native Text Generation）
- 场景中可包含文字元素（标题、字幕、标识等）
- 支持指定字体风格、大小、颜色
- 文字与画面自然融合，非后期叠加

### 5. 超长时长支持（Extended Duration）
- 新增 10 秒和 15 秒时长选项（2.6 版最长 5 秒）
- 时长选项：5s / 10s / 15s
- 超长时长适用于需要完整动作序列或对话的场景

## 二、提示词结构变更

### 2.1 Kling 3.0 标准提示词结构

```
【场景】场景描述，包含环境、光影、氛围
【主体】@角色名 + 动作描述 + 表情描述
【镜头】景别 + 运镜方式 + 时长
【音频】
  - 配音：[角色标签] 台词内容（音色描述、情绪、语速）
  - 环境音：环境音效描述
  - 音效：动作/物体音效标注
【时长】5s / 10s / 15s
```

### 2.2 智能分镜格式

```
镜头1：
  【场景】...
  【主体】...
  【镜头】...
  【音频】...

镜头2：
  【场景】...
  【主体】...
  【镜头】...
  【音频】...

[转场：切/溶/淡入淡出]
```

---

## 三、与 Kling 2.6 的主要差异

| 特性 | Kling 2.6 | Kling 3.0 |
|------|-----------|-----------|
| 最大时长 | 5秒 | **15秒** |
| 分镜方式 | 每条提示词一个镜头 | **智能分镜（多镜头/条）** |
| 角色一致性 | 手动描述 | **@主体 标签绑定** |
| 多角色支持 | 双人为主 | **三人及以上** |
| 文字生成 | 不支持 | **原生文字生成** |
| 音频设计 | 基础配音 | **完整音频系统** |

---

## 四、审核注意事项

使用 Kling 3.0 特性时，审核应重点关注：

1. **智能分镜标记格式**：必须使用「镜头1、镜头2」规范格式
2. **@主体标签**：主角必须使用 @主体 绑定，确保跨镜头一致性
3. **时长合理性**：根据场景复杂度选择合适时长，避免无意义拉长
4. **多角色对话**：三人以上对话需明确每个角色的空间位置和视线方向
5. **原生文字**：文字内容不得包含违禁词，字体风格需与画面风格一致
