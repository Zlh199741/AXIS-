# 高级 Seedance 2.0 功能指南

## 用途
帮助分镜师掌握 Seedance 2.0 的高级功能，提升提示词质量，实现更复杂的视觉叙事。

---

## 1. 高级运镜技巧

### 1.1 复合运镜

将多种运镜组合使用，创造更丰富的视觉效果。

```
示例：推拉结合 + 环绕
"镜头从全景快速向前推进，穿越人群头顶，在主角面前急停，然后环绕主角旋转 180 度，最后缓慢拉远..."
```

| 组合类型 | 效果 | 适用场景 |
|----------|------|----------|
| 推 + 拉 | 节奏变化 | 强调 + 展示环境 |
| 摇 + 移 | 空间感 | 场景转换 |
| 升 + 俯 | 压迫感 | 紧张/危险场景 |
| 环 + 推 | 聚焦 | 人物内心 |

### 1.2 主观视角（POV）

第一人称或第三人称主观视角，增强沉浸感。

```
示例：
"主观视角，主角眼中所见——狭窄的走廊，昏暗的灯光，前方不远处..."
"从反派肩后视角看向主角..."
```

| POV 类型 | 描述 | 效果 |
|----------|------|------|
| 第一人称 | 主角眼中 | 强沉浸 |
| 肩后视角 | 跟随者视角 | 旁观感 |
| 监控视角 | 俯视固定 | 紧张/悬疑 |
| 窗户视角 | 框中框 | 偷窥感 |

### 1.3 摄影机运动模拟

模拟真实摄影机的物理运动特性。

```
示例：
"手持摄像机风格，轻微晃动，跟随主角奔跑..."
"斯坦尼康风格，稳定滑轨移动..."
```

| 风格 | 特征 | 适用场景 |
|------|------|----------|
| 手持 | 晃动、不稳定 | 紧张/追逐 |
| 斯坦尼康 | 平滑稳定 | 优雅/长镜头 |
| 无人机 | 流畅俯瞰 | 场景建立 |
| 摇臂 | 大幅度升降 | 戏剧张力 |

## 2. 多参考融合技巧

### 2.1 角色 + 场景融合

同时参考多个素材，创造新组合。

```
示例：
"主角形象参考 @图片1，场景参考 @图片2，动作参考 @视频1...
角色服装保留 @图片1 中的风格，但场景切换到 @图片3 的环境..."
```

### 2.2 风格迁移

将一种艺术风格应用到不同内容。

```
示例：
"以 @图片1 的构图为基础，采用 @图片2 的油画风格..."
"保持 @视频1 的镜头运动，但替换为 @图片3 的水墨画风格..."
```

### 2.3 元素混合

将多个素材的关键元素组合。

```
示例：
"取 @图片1 的角色造型，融合 @图片2 的光影风格，
背景参考 @图片3 的建筑风格，色调参考 @图片4..."
```

## 3. 复杂场景处理

### 3.1 多人场景

处理多角色互动和空间关系。

```
示例：
"中景，六人围坐在圆桌旁。镜头从左至右逐一扫过每个人的表情——
@图片1 中的主角沉思 @图片2 中的谋士轻笑 @图片3 中的武将皱眉...
每个人有独立的动作和反应，镜头在每人身上停留 1-2 秒..."
```

### 3.2 群体场景

大规模人群的调度和视觉焦点。

```
示例：
"全景，广场上聚集了数百人。镜头从空中俯拍建立场景...
然后快速下摇聚焦到主角（@图片1），周围人群虚化...
主角抬头，视线引导镜头切到对面高楼上的另一角色..."
```

### 3.3 动态环境

处理天气、时间变化等动态元素。

```
示例：
"从阳光明媚逐渐过渡到暴风雨...
0-3秒：阳光穿过云层，暖色调
3-6秒：云层聚集，色调转冷
6-10秒：雨滴开始落下，镜头前景添加雨丝效果
10-15秒：暴风雨来临，灯光闪烁..."
```

## 4. 高级转场技巧

### 4.1 动作转场

利用动作连贯性实现镜头切换。

```
示例：
"主角伸手推门——画面模糊——切到门内的场景（@图片1）"
"剑客挥剑——剑光闪过——切到另一个场景"
```

### 4.2 匹配转场

利用相似元素实现画面过渡。

```
示例：
"圆形物体旋转——切换到同样圆形的月亮"
"画面中的红色元素——匹配到另一场景的红灯笼"
```

### 4.3 节奏转场

利用现场音效触发点与视觉节奏控制镜头切换，禁止使用音乐、BGM或配乐作为驱动。

```
示例：
"前 3 秒低密度环境音，镜头缓慢移动...
第 4 秒低频冲击音效触发，快速切到特写...
第 8 秒危机顶点，镜头急推...
第 10 秒收尾，慢动作定格..."
```

## 5. 声音蒙太奇高级应用

### 5.1 多层声音设计

同时处理环境底噪、动作音、画面内特殊音效和人声。

```
示例：
"环境底噪参考 @音频1（雨声/空间混响），禁止背景音乐、BGM、配乐...
环境音：雨声（持续），远处雷声（每 10 秒一次）...
动作音：脚步、剑鸣、喘息...
人声对白参考 @音频2..."
```

### 5.2 声音引导视觉

用声音引导镜头运动。

```
示例：
"画外音：'小心背后'——镜头急转看向后方
声音淡入：远处的钟声——镜头缓慢拉远
心跳声渐强——镜头推向主角面部特写"
```

## 6. 特殊效果技巧

### 6.1 子弹时间

慢动作与 360 度环绕结合。

```
示例：
"子弹时间（bullet time）：时间近乎静止
镜头围绕主角缓慢旋转 360 度，展示每个角度的细节
背景中：雨滴悬浮在空中、火花凝滞...
主角表情特写，汗水滴落...
时间恢复，动作继续"
```

### 6.2 视觉特效

添加电影级特效描述。

```
示例：
"镜头边缘添加暗角效果...
画面色调：青橙调（Teal & Orange）...
添加胶片颗粒感（film grain）...
光晕效果（lens flare）从画面右侧射入...
"
```

### 6.3 色彩叙事

用颜色变化传达情绪和意义。

```
示例：
"开场：黑白画面，只有主角的红色围巾是彩色（视觉焦点）
随着剧情发展，画面逐渐转为彩色
结尾：主角死亡，画面再次转为黑白"
```

## 7. 高级时间控制

### 7.1 时间伸缩

在同一镜头内控制时间流速。

```
示例：
"慢动作：主角跃起至空中——时间拉长到 3 秒
正常速度：下落过程——1 秒
快动作：落地翻滚——0.5 秒"
```

### 7.2 循环时间

创造时间循环效果。

```
示例：
"同样的场景重复三次，每次略有不同...
第一次：主角推门进入
第二次：同一时刻，主角再次推门进入（似曾相识）
第三次：慢动作，展示这次的不同选择"
```

## 8. 预算优化技巧

### 8.1 素材复用策略

减少素材数量同时保持质量。

```
技巧：
- 使用同一场景的不同角度作为多个 @引用
- 用文字描述代替额外素材
- 将相似角色/场景合并引用
```

### 8.2 动态资源分配

根据场景重要性分配预算。

```
示例：
"重要场景（P01、P03）：使用 8 张参考图
次要场景（P02、P04）：使用 4 张参考图
过渡场景（P05）：使用 2 张参考图 + 文字描述"
```

## 9. 常见问题与解决方案

### 问题 1：运镜不连贯

**原因**：运镜描述过于笼统

**解决**：
```
❌ "镜头移动"
✅ "镜头从主角面部缓慢向右平移，经过肩膀，看向窗外"
```

### 问题 2：多角色视线混乱

**原因**：未明确角色视线方向

**解决**：
```
❌ "两人对视"
✅ "主角视线从 @图片1 位置转向右侧 @图片2，两人目光交汇"
```

### 问题 3：光影不一致

**原因**：未描述光源位置变化
> 💡 **参考资源**：`resources/电影摄影-AI提示词库.md`（6种场景类型+8套打光方案可直接复用）、`resources/电影摄影-主文件(技法+设备+工作流程).md`（色温/光比与情绪映射）

**解决**：
```
❌ "画面明亮"
✅ "主光源从左侧窗户射入，冷白色调；切到室内场景后，主光源转为暖黄色台灯"
```

### 问题 4：动作无法实现

**原因**：动作密度过高或时间不合理

**解决**：
```
❌ "他起身，走向门口，打开门，跑出去，回头看，惊讶"
✅ "他起身走向门口（2秒），停顿（0.5秒），猛然拉开门（0.5秒），冲出画面（1秒）"
```

- [ ] 声音设计完整

- [ ] 素材引用正确
