**阶段**: 导演分析
**审核得分**: 9.2/10
**审核时间**: 2026-03-14

**亮点**:
1. 黄金3秒钩子设计精准："江辰被砸"场景冲击力强
2. 情绪高潮点明确：每个剧情点都有明确的情绪释放

```markdown
- 绝对客观视角：全程无内心独白
```

1. 剧情点拆分合理，每个点10-15秒
2. 空间坐标锚点清晰
3. 视线对焦描述准确

## 三、优化案例

### 3.1 案例：Kling提示词缺少开篇剧情

**问题描述**:
- Kling提示词直接跳到"江辰爬起"
- 缺少核心冲突场景"轻薄+被砸"

**问题定位**:
1. 分镜编写时遗漏了开头场景
2. 集数间剧情断裂

**修复方案**:
1. 在开头补充"轻薄被砸"场景
2. 添加集数间转场说明

**修复后评分**: 8.0/10

**经验总结**:
- 开篇必须有钩子场景
- 核心冲突必须呈现
- 人物关系必须建立

## 四、失败案例

### 4.1 案例：多次审核未通过

**问题描述**:
- 连续3轮审核FAIL
- 问题始终无法完全修复

**根本原因分析**:
1. 需求本身有问题：原小说节奏太慢
2. 标准过严：部分维度要求过高
3. 沟通不足：修改意见传递不清晰

**解决方案**:
1. 调整原小说内容
2. 重新评估审核标准
3. 明确修改清单

**最终结果**: 人工决策点介入，手动调整后通过

**经验总结**:
- 连续多次失败要考虑根本原因
- 不是所有问题都能通过修改解决
- 必要时需要调整需求

## 六、最佳实践

### 6.1 审核通过技巧

1. **严格对照清单**
   - 审核前逐项自检
   - 不确定的地方标注

2. **主动预判问题**
   - 识别潜在风险点
   - 提前准备解释

3. **理解审核标准**
   - 熟悉评分维度
   - 了解PASS标准

4. **清晰沟通**
   - 修改意见具体化
   - 避免模糊表述

### 6.2 生成优化技巧

1. **规避高风险动作**
   - 避免肢体接触
   - 减少复杂手部动作

2. **使用特写替代**
   - 表情用特写
   - 动作用细节

3. **明确光源描述**
   - 指定光源方向
   - 统一色调

4. **利用参考图**
   - 主体参考稳定
   - 场景参考准确

## 七、案例贡献指南

### 7.1 提交案例格式

```markdown
## 案例名称

**项目**:
**阶段**:
**日期**:

### 问题描述
[描述遇到的问题]

### 解决方案
[描述如何解决]

### 经验总结
[可复用的经验]
```

### 7.2 案例收录标准

- 有代表性：能代表某类问题
- 有解决方案：必须包含解决方案
- 可复用：经验有普遍意义
- 格式规范：符合模板格式
