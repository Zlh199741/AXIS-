# 导演思维（道）· 样例项目导演阐释

> 🟦 **这是示例文件，不是规则文件。** 它把 [director-thinking-layer.md](director-thinking-layer.md) 的通用框架
> 应用到**一个具体样例**上，给你看"框架落地后长什么样"。
> 🔴 **做新项目时**：本文件整篇视为可替换——换成你自己项目的前提/对立/价值曲线/戏脊即可，
> 不要把下面的"玩具/江临/崖边"当成任何新项目的设定。
> 样例作品：《在言情文里，女主选择谁，谁才是男主》（创造者-被造物 / 物化↔成人 题材）。

---

## 一、样例·控制性主题与前提（对应框架 §1.2 / §1.5 / §1B.4）

- **控制性主题 / 前提**：把人当玩具者，终将因爱而承认——**人不可替代**（"不换了"即主题落点）。
  - 前提三要素：性格＝物化他人的女儿 / 冲突＝玩具要做人 / 结局＝承认与对等。
- **导演 POV / 贯穿母题（作者论）**：全片签名＝"物化 ↔ 成人"的伦理拷问，所有场景、调度、视觉都为这一签名服务。

## 二、样例·核心对立（对应框架 §1.2 角色配器·对立面统一）

- 创造者（女儿/作者） vs 被造物（江临）——一个握有"删改/更换"的神权，一个要求被当人；**互相需要又不可妥协**，冲突不可逃避。

## 三、样例·全剧价值曲线（对应框架 §1.5 麦基正负极）

- 价值轴＝**"被当人 ↔ 被当物"**。
- EP01 物化常态（−，夹甜） → EP02 突转+发现（掌控 + → 失去 −− → 觉醒 +） → EP03 去物化对等（++）。整体一条 **V 型**曲线。

## 四、样例·复杂情节（对应框架 §1.1 亚里士多德 突转+发现）

- EP02 江临**跳崖**＝突转（她以为"玩具坏了再换"，结果失去的是唯一的人）；
- 她**"我爱他/他是人"**＝发现（从无知到知）。
- 二者**合一** ＝ 全剧情感核弹（复杂情节的最强形态）。

## 五、样例·悬念架构（对应框架 §1.7 希区柯克 + §2D.1）

- 开篇序章式预告"**江临将坠崖**"先告知观众（ep02 P00 的 3 秒钩子）——之后看他们日常甜蜜，每一帧都带悬念。
- 这同时是**短剧 3 秒钩子**与**希区柯克长悬念**的合流示例（见框架 §2D.1）。

## 六、样例·主题深化（三层亲子镜像）

- 作者→角色、母→女、神→造物，是**同一关系的三投影**；母亲画外音＝创造者无能为力的爱，是全剧情感低音。

## 七、样例·角色戏脊（对应框架 §3）

- 女儿＝"按我的剧本拥有一个完美的、听话的'东西'"
- 江临＝"让她看见我是人，不是玩具"
- 母亲（画外音）＝"我创造了你，却护不住你不受伤"

## 八、样例·道→术 交接的具体落点（对应框架 §5）

| 导演判断（道） | 下沉调用的术（分镜查 unified 库） | 导演层不写 |
|---|---|---|
| EP02 崖边·发现+突转：她伸手想接、**手停在半空没接住** | 注意力引导(剪辑节奏) + 时间弹性(拆解坠落) | 不写"快门 270°/递减帧数" |
| EP01 投喂·潜台词：她贴近、替他理衣领 | 暖粉金 + 近景 + 柔光 | 不写"伦勃朗光/光比 2:1/85mm" |
| 崖边痛感用**并置**而非脸特写讲完（马梅特） | 无修饰镜头并置（手 / 空崖 / 未发送文字） | 不写具体机位/焦段数值 |
| 末集卡点：江临纵身、镜头随之下坠——**结果切断**（§2D） | 默奇"情感＞空间"授权的跳切 + 黑屏 | 不写黑屏帧数 |
