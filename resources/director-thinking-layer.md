# 导演思维（道）— 理论根基 + 操作框架（通用·与项目无关）

> 🔴 **本文件不是我编的"伪导演思维"，而是综合多位公认权威的真实理论**（出处见文末参考书目）。
> 理论来自两组源头——**§1 单场戏戏剧根基**（亚里士多德/埃格里/斯坦尼/卡赞/麦基/马梅特/希区柯克/卢梅特）

> 🔴🔴 **但两组不是两份清单——已合并为一套贯通的「导演工作法」（§2），按三个尺度同时使用：**
> **2A 宏观整集骨架（用 §1B）→ 2B 每场戏八问（用 §1）→ 2C 镜头组接（用 §1B）。三层都做才叫导演分析，绝不止八问。**

## 0. 先厘清：导演思维到底是什么

| | 导演思维（道·本文件） | 视听执行（术·unified 库） |
|---|---|---|
| 回答 | 这场戏**在演什么**、人物**要什么**、要观众**懂什么** | **怎么拍**：景别/运镜/光影/焦段/剪辑/动画参数 |
| 本质 | 对戏剧的**诠释（interpretation）与判断** | 把诠释**翻译**成视听语法与参数 |
| 谁的活 | 导演 | 摄影指导(DP)/剪辑/动画/灯光 |
| 错误 | 把"运镜光影清单"当导演思维（匠气，无灵魂） | 把"戏剧意图"塞进机读层（参数污染） |

> 一句话：**导演思维 = 戏剧诠释 + 表演调度的判断；摄影机怎么动是它的下游，不是它本身。**

## 1. 理论根基·第一组：单场戏的戏剧根基（八大经典源头，可查可追溯）

> 每条：核心概念 → 出处 → 怎么用 → 本剧落点。

### 1.1 亚里士多德《诗学》(约公元前335年)：突转 + 发现 = 复杂情节
- **突转 Peripeteia**：命运/意图的逆转——人物追求一个目标，却因误解/局限得到相反结果，且逆转既出人意料又"事后看必然"。
- **发现 Anagnorisis**：从**无知到知**的认知翻转（认出真相/认出关系）。
- **过失 Hamartia**："错失目标"（archery 射偏），是判断之误而非邪恶。
- **复杂情节** = 突转 + 发现**同时发生**，引发**怜悯与恐惧**（净化 Catharsis）。
- 🔴 用法：每集/全剧必须有一次**突转**和一次**发现**；最强的戏是两者合一。
- 📌 本剧：江临**跳崖**＝突转（她以为"玩具坏了再换"，结果失去的是唯一的人）；她**"我爱他/他是人"**＝发现（从无知到知）。EP02 高潮＝突转与发现合一。

### 1.2 埃格里《编剧的艺术》(1946)：前提 / 人物三维 / 角色配器
- **前提 Premise**：整部作品要**证明的一句主题论点**，是全部动作的种子。合格前提含三要素——**性格 + 冲突 + 结局**（如"吝啬导致毁灭"）。
- **人物三维**：生理（年龄/外貌/缺陷）、社会（阶层/职业/处境）、心理（欲望/挫折/气质）。三维不全＝人物不可信。
- **角色配器 Orchestration**：刻意安排**对立面的统一（unity of opposites）**——双方羁绊强到**无法妥协**，冲突才不可逃避。
- 🔴 用法：先写出全剧**一句前提**，每场戏都为它取证；主要人物必须配出"无法妥协的对立面"。
- 📌 本剧前提：**"把人当玩具者，终将因爱而承认——人不可替代。"**（性格=物化他人的女儿 / 冲突=玩具要做人 / 结局=承认与对等）。对立面统一：**创造者 vs 被造物**，一个握有"删改/更换"的神权，一个要求被当人——彼此需要又不可调和。

### 1.3 斯坦尼斯拉夫斯基体系：目标 / 最高任务 / 单元 / 贯穿动作线
- **目标 Objective**：角色此刻**想要什么**（动词化，可演："激怒她/讨好她/试探她"）。
- **单元 Units**：把一场戏切成若干"目标段"，目标一变即换单元。
- **最高任务 Super-objective**：贯穿全剧的**总欲求**。
- **贯穿动作线 Through-line**：一个个目标串成不断的行动线。
- 🔴 经典比喻：**最高任务＝戏脊，各目标＝椎骨。**
- 📌 本剧：女儿最高任务＝"按我的剧本拥有一个完美的'东西'"；江临最高任务＝"被她看见我是人"。两条最高任务对撞＝全剧引擎。

### 1.4 卡赞"戏脊"(Spine)：每个角色、每场戏都有一句脊柱
- 卡赞导戏前买一本小本子，为**每个角色、每场戏**写下一句"脊柱"（如《欲望号街车》中布兰奇的脊柱），所有调度都为脊柱服务。
- 🔴 用法：开拍前，**每场戏先写一句"本场戏脊"**（不是情节摘要，是这场戏的核心动作/意图）。没有脊柱的场面调度＝散乱。
- 📌 本剧示例脊柱——EP02 崖边："**她第一次想留住一个'东西'，却发现晚了。**"

### 1.5 麦基《故事》(1997)：场景必须"转" / 期望与结果的鸿沟 / 控制性主题
- **场景必须转 Turn**：一场戏是"在冲突中、于连续时空里，使人物生活的**价值正负极**至少翻转一次"。不翻转的＝非场景（是"说明/事件"）。
- **鸿沟 The Gap**：戏剧实质＝人物**预期**与**实际结果**之间裂开的鸿沟；鸿沟越大，戏越强。
- **控制性主题 Controlling Idea**：故事意义的最纯形式——"**价值 + 致使其改变的原因**"（如"正义战胜，当主角比对手更狡诈时"）。
- **正反主题辩证**：一场场之间，正主题与反主题来回拉锯，到高潮一方胜出＝控制性主题。
- 🔴 用法：每个剧情点标出**价值正负极的翻转**（+→− 或 −→+）；全集是一条正负极曲线。
- 📌 本剧价值轴＝**"被当人 ↔ 被当物"**。EP01 多为"−（持续被物化）"；EP02 崖边由"她以为掌控(+)"突转到"失去(−−)"再到"觉醒(+)"；EP03 收于"对等(++)"。

### 1.6 马梅特《论电影导演》(1991)：场景目标 + 无修饰镜头的并置
- **场景目标**：每场戏先问"**主角想要什么**"，再问"达成它的**最小必要动作**是什么"。
- **无修饰镜头 Uninflected shot**：信息量最小的客观镜头（一只手、一把勺、一把钥匙、一张脸）。
- **并置生义（爱森斯坦蒙太奇）**："好电影＝一连串并置的镜头，镜头**之间的对比**在观众脑中推动故事。"意义来自**镜头的并置**，不在单个镜头里。
- 🔴 用法：不要靠"一个全知镜头讲完一切"，而是用**客观镜头并置**让观众自己得出意义（这正是 AXIS"绝对视觉化/库里肖夫"的理论母体）。
- 📌 本剧：崖边不必拍"她很痛苦"的脸特写讲完——并置"**她伸出的手（客观）**＋**空荡的崖（客观）**＋**未发送的文字（客观）**"，痛在观众脑里生成。

### 1.7 希区柯克：悬念 vs 惊吓（桌下炸弹）
- **惊吓 Surprise**：观众与角色一样不知情，炸弹突然爆——**15 秒**刺激。
- **悬念 Suspense**：**观众知道**桌下有炸弹、角色不知道——**15 分钟**煎熬。
- **机制＝戏剧反讽**：观众知道得比角色多，等待+恐惧由此而生。
- 🔴 用法：高价值信息**尽量先告诉观众**，让观众替角色揪心；只有"反转本身即卖点"时才藏。
- 📌 本剧：序章式预告"**江临将坠崖**"先给观众（ep02 P00 3秒钩子）——之后看他们日常甜蜜，每一帧都带悬念，这是正确的希区柯克用法。

### 1.8 卢梅特《拍电影》/ 场面调度：调度即潜台词
- **调度即潜台词**：一人坐着另一人站着＝权力；同框却不对视＝隔阂；谁靠近谁后退＝心理距离。**不着一字，观众已懂。**
- **展示而非告知 Show, don't tell**：情绪在画框里发生，不靠台词/旁白说明。
- **镜头计划 Lens plot**：所有视觉选择都服务于故事/人物/主题（《十二怒汉》全片靠调度+镜头叙事）。
- 🔴 用法：把内在状态**外化为人与空间的安排**（站位/距离/对视/朝向/道具），这是导演把"道"变"可拍"的核心手艺。
- 📌 本剧：投喂日常＝她贴近、替他理衣领（潜台词：她在乎，却叫他"玩具"）；崖边＝两米对峙、背对（潜台词：物化的代价）；和解＝从对峙到并肩（去物化＝对等）。

### 1.9 台词工艺（马梅特 + 品特 + "动作动词"）：台词是动作，不是信息
> 短剧台词密度极高、且常靠台词推爽点，单独立一条。
- **台词＝动作（动词化）**：每句台词都在"做事"——逼问/讨好/威胁/试探/羞辱/求饶，而非交代信息。写台词前先问"这句在**对对方做什么**"。（斯坦尼目标 + 马梅特"场景目标"的台词级落地）
- **潜台词＞字面（品特 / 海明威冰山）**：人物**很少直说真意**；最强的台词是"说的≠想要的"。给沉默、停顿、答非所问留位置——**没说出口的比说出口的更响**。
- **信息别塞进嘴里（去说明 anti-exposition）**：禁止"你忘了吗？三年前你害死了我爹"这类硬塞背景。背景靠动作/道具/反应外化（呼应 §1.6 马梅特"无修饰镜头并置"）。
- **短剧节奏律【与产品对齐】**：下沉市场竖屏短剧，**单句宜短、口语、带攻击性或钩子**（系统铁律：台词≤约20字/句仅指**节奏**，🔴 **绝不等于可删改台词**——CLAUDE.md 台词零删减铁律优先级最高）。
- 🔴 用法：每个 P 的关键对白，导演要标一句"**这句台词的动作动词是什么 + 潜台词是什么**"，供分镜的语气/微表情层承接（不改字）。
- 📌 示例（可剥离）：她笑着说"乖，别闹"——动作动词＝**安抚式镇压**；潜台词＝"你只是我的玩具，没有不闹的权利"。字面温柔，底下是物化。

## 1B. 第二组理论：结构学 · 蒙太奇剪辑 · 作者论（好莱坞类型片层）

> 🔴 上面 §1.1–1.8 是**单场戏**的戏剧根基；本组是**整片层**的导演思维——好莱坞商业片导演真正
> 天天在用的"宏观骨架 + 镜头组接 + 作者签名"。导演思维**远不止八条**；这是第二组核心，仍非全部。

### 1B.1 故事结构学：好莱坞"叙事八范式"（整片骨架）
导演接到本子先判**它的结构骨架**，这是整片的"道"。业界公认并存、互相兼容的主流范式：
- **坎贝尔→沃格勒 英雄之旅**（Campbell《千面英雄》→ Vogler《作家之旅》）：启程-启蒙-回归三幕、17/12 阶段（平凡世界→冒险召唤→拒绝→导师→跨越门槛→考验盟友敌人→最深洞穴→磨难→奖赏→归途→复活→带宝回归）。
- **布莱克·斯奈德 Save the Cat**：15 拍节拍表（开场画面/主题陈述/铺垫/催化剂/争论/第二幕/B故事/欢乐与游戏/中点/坏人逼近/一无所有/灵魂黑夜/第三幕/结局/终场画面），专治第二幕塌陷。
- **西德·菲尔德 范式**（《电影剧本写作基础》1979）：三幕 + 两个情节点（Plot Point I/II）+ 中点，好莱坞模板化的奠基。
- **约翰·特鲁比 22 步**（《故事写作大师班》）：以**欲望 + 道德论证**为核心（弱点→欲望→对手→计划→对决→自我揭示→新平衡）。
- 其余并行范式（按需）：迈克尔·豪格 六阶段、琳达·西格 故事脊、丹·哈蒙 故事圈（节选自英雄之旅的 8 步循环）、戴夫·托特 七情节点。
- 🔴 用法：先用其一**定全片骨架**，再用 §1.5 麦基逐场把骨架填成"会转的场景"。范式之间松散兼容，别教条。

### 1B.2 蒙太奇与库里肖夫（镜头组接生义）
- **库里肖夫效应**：同一张无表情的脸，接"汤/棺材/美女"会被观众读成"饿/悲/欲"——**意义来自两镜并置，不在单镜**。这是一切剪辑叙事的实验基石。
- **爱森斯坦 蒙太奇**（《战舰波将金号》）：镜头不是"砖块相加"而是"**碰撞**"产生新概念；其**理性蒙太奇/吸引力蒙太奇**主张用画面冲突直接在观众脑中生成抽象观念。
- 🔴 用法：高潮/转折处用**冲突性并置**（而非平铺长镜）让观众自己"算出"含义——与 §1.6 马梅特"无修饰镜头并置"同源。

### 1B.3 剪辑决策层：沃尔特·默奇《眨眼之间》"剪辑六法则"
一刀该不该剪、剪在哪，按**优先级从高到低**排（前两项远重于后四项）：
1. **情感**（是否忠于此刻情绪）— 默奇认为占 51%，比下面五项加起来还重
2. **故事**（是否推进叙事）
3. **节奏**（是否在"对"的、有趣的节奏点上）
4. **视线追踪 Eye-trace**（观众注意力焦点的位置与移动）
5. **平面性 Planarity**（二维构图的连贯/银幕方向）
6. **三维空间连续性**（实拍空间关系/轴线）
- 🔴 名言：观众最后记住的"**不是剪辑、不是摄影、不是表演、甚至不是故事——而是他们的感受**"。所以**情感永远第一**。
- 🔴 用法：宁可牺牲空间连续性(6)也要保情感(1)；这给"为了情绪可以越轴/跳切"提供了理论授权。

### 1B.4 作者论：导演是影片的"作者"
- **作者论**（特吕弗 1954 提出、萨里斯 1962 引入美国）：把导演视作如文学作者般的**首要创作意志**，其个人母题与风格签名贯穿全部作品。
- 🔴 用法：每个项目先定**导演视角/态度（POV）与贯穿母题**（本剧＝"物化↔成人"的伦理），让所有场景、调度、视觉都为这一签名服务——这正是 §2 第⑥问"控制性主题"的上位来源。

## 2. 导演工作法（两组理论合并·三尺度贯通）—— 导演分析的操作总框架

> 🔴🔴 **两组合并后的唯一操作法。** 不是两份清单，而是**一套工作法**，按尺度从大到小依次执行：
> **2A 宏观（整集骨架）→ 2B 中观（每场八问）→ 2C 微观（P与P组接）**。
> 🔴 三层缺一不可——只写八问(2B)而无骨架(2A)与组接(2C)＝又把导演思维矮化成"单场清单"，**判不合格**。

### 2A 宏观层·整集骨架（用 §1B：结构学 + 作者论 + 麦基价值曲线）—— 每集开篇做一次
1. **结构骨架选型 + 标节拍**：给本集/全剧选一个主结构范式（英雄之旅阶段 / Save the Cat 15拍 / 菲尔德三幕情节点 / 特鲁比道德论证），并标出**本集每个剧情点落在哪个节拍**。
2. **作者签名 / 控制性主题**：写出全剧一句前提（埃格里）＋控制性主题（麦基）＋导演 POV（作者论）；本集如何为它取证。
3. **全集价值曲线**：用麦基价值正负极，画出本集从首 P 到末 P 的 **± 走向**（含卡点钩子）。
> 产出：写在 `01-director-analysis.md` **文件头的「整集骨架」块**。

### 2B 中观层·每场戏（用 §1：导演八问，每个 P 必答）
> 按序答完八问；⑤发现、⑦信息差为**条件项**（无则标"本场不适用"），其余必答。

| # | 问 | 要回答 | 理论来源 |
|---|---|---|---|
| ① | **戏核/本场前提** | 这场戏在**证明**什么（一句话主题，不是情节） | 埃格里 前提 + 卡赞 戏脊 |
| ② | **目标·阻碍·赌注·战术** | 谁**要什么**（动词）、被**什么挡**、输了**失去什么**、用**什么手段** | 斯坦尼 目标 + 麦基 风险 |
| ③ | **潜台词** | 台词**字面 vs 真正在发生的**；没说出口的 | 卢梅特 调度即潜台词 |
| ④ | **转折（价值翻转）** | 哪一刻**变了**，价值正负极 **+→− 或 −→+** | 麦基 turn + 亚里士多德 突转 |
| ⑤ | **发现（认知翻转）** | 谁从**无知到知**？认出了什么真相/关系？ | 亚里士多德 发现 |
| ⑥ | **导演态度/控制性主题** | 要观众此刻**懂什么、站哪**；本场如何为全剧前提取证 | 麦基 控制性主题 |
| ⑦ | **信息差** | 此刻观众**知道而角色不知道**的是什么（要不要造悬念） | 希区柯克 悬念 |
| ⑧ | **表演与调度（外化）** | 用**可拍的身体/走位/距离/对视/道具/无修饰镜头并置**把①-⑦变成画面 | 马梅特 + 卢梅特 + 斯坦尼 |

> 🔴 每个 P 还须标 **本P对应 2A 的哪个结构节拍**（让微观接上宏观骨架）。
> 🔴 ⑧ 写"演员演什么、人怎么站怎么动、哪几个客观镜头并置"——**不写镜头怎么动**（那是术）。
> 🔴 本剧戏核轴（每场对齐）：**此刻谁在"物化"谁？谁在争取"被当成人"？**（把人当玩具 ↔ 玩具要做人）

### 2C 微观层·P 与 P 的组接（用 §1B：蒙太奇 + 默奇剪辑六法则）—— 每个 P 结尾标一行
1. **蒙太奇并置**（库里肖夫 / 爱森斯坦 / 马梅特无修饰镜头）：本 P 与下一 P **如何并置生义**（碰撞 / 对比 / 因果 / 反应）。
2. **剪辑取舍**（默奇六法则）：本 P → 下一 P 这一刀，优先级 **情感＞故事＞节奏＞视线＞平面性＞空间连续**；必要时为情感可越轴/跳切。
> 产出：写在每个 P 块的 **「与下一P组接」行**。

> ✅ 一句话记：**先用 §1B 搭骨架与剪辑（2A/2C），再用 §1 填每场戏的肉（2B）——两组合一，缺层即不合格。**

## 2D. 短剧/竖屏适配：经典戏剧 ×「3-10-60 钩子学」的和解 + lite 档位

> 🔴🔴 **为什么必须有这一节**：上面 §1/§1B/§2 是经典电影/戏剧理论；但 AXIS 的**真实产物**是受
> CLAUDE.md「**3-10-60 情绪循环 + 每集卡点截断在最高潮前 0.5 秒**」支配的下沉市场竖屏短剧。
> 这两套**看似冲突**（"麦基：场景必须翻转一次价值正负极、完成一个回合" ⟷ "短剧：结尾绝不给闭环、悬念正盛时黑屏"）。
> 本节给出**和解规则**，让高雅理论真正服务于爆款产物，而不是两层各说各话。

### 2D.1 冲突点 → 和解规则（四条）

| 冲突 | 经典戏剧说 | 短剧产物说 | 🔴 和解规则（导演照此判） |
|---|---|---|---|
| **场景要不要"转完"** | 麦基：场景必须完成一次价值正负极翻转 | 卡点：结尾不给闭环，截在揭晓前 0.5 秒 | **集内每个 P 仍要"转"（保麦基）；但全集最后一个 P 故意"转到一半"——价值翻转的"结果"被黑屏切断，把闭环留到下一集**。即：闭环照做，只是**跨集延迟兑现**。 |
| **悬念 vs 惊吓** | 希区柯克：高价值信息先给观众，制造长悬念 | 3 秒钩子：开篇先抛最炸的反常画面 | **不矛盾**：3 秒钩子＝希区柯克"先给观众炸弹"的极速版。开篇钩子先给结果/危机的"一瞥"，再回头铺因果——本就是悬念正解。 |
| **铺垫节奏** | 斯奈德 15 拍、菲尔德三幕，铺垫可从容 | 前 10 秒必须交代关系+矛盾，不许拖 | **整集骨架(2A)仍用经典范式定"转折点在哪"，但把每个节拍的"时长预算"压缩**：竖屏一集≈经典一幕的体量，节拍不删、密度加倍。 |
| **人物弧光** | 埃格里/特鲁比：弧光需完整论证 | 单集只够推进一两步 | **弧光按"集"分期兑现**：全剧前提(§1.2)不变，但每集只取证弧光的一小段，靠集与集累积成完整论证。 |

### 2D.2 三尺度里怎么落（嵌进 §2 工作法，不另起炉灶）
- **2A 宏观**：选经典范式定全集骨架后，**额外标三件短剧事**：① 本集【3 秒钩子】放哪个画面；② 本集【1 分钟爽点】是哪个 P 的价值翻转；③ 本集【卡点】＝最后一个 P 的"转折结果"切在哪 0.5 秒。
- **2B 每场八问**：第④问"转折"对**爽点 P** 要给足（转满）；对**末尾卡点 P** 要标"转折**起势已现、结果切断**"。第⑦问"信息差"是 3 秒钩子与悬念的理论依据。
- **2C 组接**：默奇"情感＞故事"在短剧里更极端——**为钩子/卡点可以牺牲时空连续性**（跳切、闪前、倒序开场都获授权）。

### 2D.3 lite 档位（避免杀鸡用牛刀）
> 🔴 不是每个 P 都值得跑完整八问 + 亚里士多德突转。按 P 的戏剧权重分档：

| 档位 | 适用 P | 必答 | 可省 |
|---|---|---|---|
| **Full（完整）** | 爽点 P、转折 P、卡点 P、情感核弹 P | 八问全 + 2C 组接 + 价值翻转标注 | — |
| **Lite（精简）** | 过渡 P、信息桥接 P、纯节奏铺垫 P | ①戏核一句 + ②目标 + ⑧表演调度 + 2C 组接行 | ③潜台词/④转折/⑤发现/⑦信息差（标"本场不适用"） |
| **Beat（节拍点）** | 纯空镜/转场/反应插入 | 一句"它在节奏上干什么" | 其余全省 |

- 🔴 **红线不变**：lite/beat 只省**分析深度**，不省**三尺度结构**（2A 整集骨架 + 2C 组接行仍对全集强制）；且**爽点/卡点 P 禁用 lite**。
- 📌 示例（可剥离）：投喂日常的中段闲笔＝Lite；崖边突转+发现＝Full；坠落后那一个空崖镜头＝Beat。

全剧超目标（戏脊总纲）
   └─ 角色戏脊（每个主要人物一句）

## 5. 道 → 术 交接（怎么下沉，不越界）

> 原则：导演层写**戏剧判断 + 可拍的表演/调度**（道），点出"该调哪一类视听"；
> **具体参数（焦段/光比/快门角度/帧数）一律不写**，留给分镜阶段查 unified 库（术）。
> 🔴 下沉时认准 unified 库的**真实 craft 名 + 三级标签**（真实标准/启发式/人工规划），别把启发式数字当硬指标。

**通用交接规律（与项目无关）：**

| 道（导演判断该写的） | 该点的"术类别"（不写参数） | 导演层**禁写** |
|---|---|---|
| 谁压制谁 / 权力关系 | 机位高度与权力（仰=压迫/俯=脆弱） | 具体俯仰角度数 |
| 此刻情绪冷/暖、安全/危险 | 光的冷暖与软硬、光比强弱 | 伦勃朗光/光比 4:1/色温 K 值 |
| 孤立感 / 被吞没 | 负空间 + 主体背景对比 | 主体占比百分比 |
| 紧张升压 / 舒缓 | 剪辑节奏（镜头时长走向）、卡点 | 递减帧数（24-12-6） |
| 痛感/冲击 | 撞击顿帧、通感高频音、撞击拖影 | 删几帧/锁多少 Hz |
| 用并置让观众自己懂（马梅特） | 无修饰镜头并置（客观物 A + 客观物 B） | 具体机位/焦段数值 |
| 内在状态外化 | 场面调度（站位/距离/对视/朝向/道具） | — |
| 主观代入 | 视线匹配 + POV（广角手持） | POV 时长秒数 |

📌 **具体落点示例（可剥离）**见伴随文件 [director-thinking-layer-example.md](director-thinking-layer-example.md) §八。

## 6. 产出要求 + FAIL 红线（三尺度都要 — 两组合并后的硬标准）

🔴 `outputs/<ep>/01-director-analysis.md` 必须含**三层**，缺任一层即不合格：

**【整集骨架块·文件头·对应 2A】**（用 §1B + §2D）：
- A1 结构骨架范式 + 本集各 P 的节拍归属
- A2 全剧前提 / 控制性主题 / 导演 POV（作者签名）
- A3 本集价值正负极曲线（首 P→末 P 的 ± 走向 + 卡点）
- A4【短剧三标·对应 §2D.2】：本集【3 秒钩子】放哪个画面 / 本集【1 分钟爽点】是哪个 P 的价值翻转 / 本集【卡点】＝末 P 转折结果切断在何处

**【每个剧情点·对应 2B】**（用 §1 导演八问）：
1. **场景戏脊**（一句·①）＋ **本P结构节拍归属**（接 A1）
2. **目标·阻碍·赌注·战术**（②）
3. **潜台词**（③·至少一处"说的≠真的"）
4. **转折/价值正负极**（④·标出 +→− 或 −→+）
5. **发现**（⑤·若有认知翻转）
6. **导演态度/为前提取证**（⑥）
7. **信息差/悬念**（⑦·若适用）
8. **表演与调度**（⑧·可拍的身体/走位/距离/道具/并置——供分镜直接提取）
9. **交给术层的一句话提示**（点出调哪类视听，不写参数）

**【与下一P组接·对应 2C】**（用 §1B 蒙太奇 + 默奇剪辑六法则）：
10. **与下一P组接行**：本P↔下一P 如何并置生义（碰撞/对比/因果/反应）＋这一刀的剪辑优先级取舍（情感>故事>节奏>视线>平面>空间）

> 🔹 **档位说明（对应 §2D.3 lite）**：上面"每个剧情点 1-9 项"是 **Full 档**要求，对**爽点/转折/卡点/情感核弹 P 强制**；
> 过渡/桥接 P 可用 **Lite 档**（必答①戏核+②目标+⑧表演调度+组接行，其余标"本场不适用"），纯空镜/转场用 **Beat 档**（仅一句节奏功能）。
> 🔴 但 lite 只省**分析深度**，**不省三尺度结构**——A1/A2/A3/A4 整集骨架 + 每 P 组接行对全集仍强制。

🔴 **FAIL**：若 P 块只有"对应 Seedance / 节拍入口"这类反向指针、无上述实质 → 判定**空壳，不合格，重写**。
🔴 **FAIL**：只堆运镜/光影/景别而无戏脊与价值翻转 → 判定"匠气"，退回补"道"。
🔴 **FAIL（合并后新增）**：缺【整集骨架块】(2A) 或 缺【与下一P组接行】(2C) → 判定"只做了八问、两组没合并"，退回补全三层。
🔴 **FAIL（短剧新增·对应 §2D）**：缺 A4 短剧三标，或爽点/卡点 P 误用 lite 档草草带过 → 退回补全。

## 参考书目（真实出处，可查）

1. 亚里士多德，《诗学》(Aristotle, *Poetics*, c.335 BC)——突转 Peripeteia / 发现 Anagnorisis / 过失 Hamartia / 净化 Catharsis。
2. 拉约什·埃格里，《编剧的艺术》(Lajos Egri, *The Art of Dramatic Writing*, 1946)——前提 Premise / 人物三维 / 角色配器·对立面的统一。
3. 康斯坦丁·斯坦尼斯拉夫斯基体系 (Stanislavski's System)——目标 Objective / 最高任务 Super-objective / 单元 Units / 贯穿动作线。
4. 伊利亚·卡赞，《卡赞论导演》(Elia Kazan, *Kazan on Directing*)——戏脊 Spine 笔记法。
5. 罗伯特·麦基，《故事》(Robert McKee, *Story*, 1997)——场景必须转 / 鸿沟 Gap / 控制性主题 Controlling Idea / 正反主题辩证。
6. 大卫·马梅特，《论电影导演》(David Mamet, *On Directing Film*, 1991)——场景目标 / 无修饰镜头 / 爱森斯坦式并置生义。
7. 阿尔弗雷德·希区柯克（《希区柯克与特吕弗对话录》）——悬念 vs 惊吓·桌下炸弹·戏剧反讽。
8. 西德尼·卢梅特，《拍电影》(Sidney Lumet, *Making Movies*, 1995) 及场面调度理论——调度即潜台词 / 展示而非告知 / 镜头计划。

**第二组（整片层·结构/剪辑/作者论）：**
9. 约瑟夫·坎贝尔《千面英雄》(1949) → 克里斯托弗·沃格勒《作家之旅》(*The Writer's Journey*, 1992)——英雄之旅三幕/12–17 阶段。
10. 布莱克·斯奈德《救猫咪》(Blake Snyder, *Save the Cat!*, 2005)——15 拍节拍表。
11. 西德·菲尔德《电影剧本写作基础》(Syd Field, *Screenplay*, 1979)——三幕范式 + 情节点。
12. 约翰·特鲁比《故事写作大师班》(John Truby, *The Anatomy of Story*, 2007)——22 步 + 道德论证。
13. 列夫·库里肖夫（库里肖夫效应）& 谢尔盖·爱森斯坦《电影形式》(*Film Form*)——并置/碰撞蒙太奇、理性蒙太奇。
14. 沃尔特·默奇《眨眼之间》(Walter Murch, *In the Blink of an Eye*, 1995/2001)——剪辑六法则（情感>故事>节奏>视线>平面性>空间连续）。
15. 弗朗索瓦·特吕弗（1954）/ 安德鲁·萨里斯（1962）——作者论（导演即作者）。
