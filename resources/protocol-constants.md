# 统一协议约束常量库

本文档定义项目中所有协议文件使用的统一常量。所有文件必须引用此常量库，确保全维度一致性。

## 1. 评分标准常量

### 1.1 阈值常量

| 常量名 | 值 | 说明 |
|--------|-----|------|
| `PASS_THRESHOLD` | 8 | 平均分通过阈值（1-10分制） |
| `MIN_SINGLE_SCORE` | 6 | 单项最低分数阈值 |
| `MAX_ROUND_FAIL` | 2 | 连续FAIL后触发根因合并的轮数 |
| `MAX_ROUND_TOTAL` | 4 | 连续FAIL后进入人工决策点的轮数 |

```markdown
| P01  | X        | X        | X        | X        | X        | X        | X        | X        | X        | X.X  | 无      |
```

| 阶段 | 维度1 | 维度2 | 维度3 | 维度4 | 维度5 | 维度6 | 维度7 | 维度8 | 维度9 |

## 2. 素材标记常量

### 2.1 标记格式（强制）

```markdown
## [epNN][character|scene][新增|变体|复用] 名称
```

### 2.2 状态定义

| 状态 | 定义 | 审核要求 |
|------|------|----------|
| `新增` | 首次出场，需服化道设计提示词 | 必须审核 |
| `变体` | 外观/状态有变化（换装/老化/受伤等） | 必须审核 |
| `复用` | 与已有素材完全一致 | 无需重复审核，标注"复用"即可 |

### 2.3 标签筛选正则

```regex
\[ep\d{2}\]\[character\|scene\]\[新增\|变体\|复用\]
```

## 5. 视听语言常量

### 5.1 知识库引用（统一）

所有skill必须引用统一的视听语言知识库：

```
resources/视听语言逻辑.txt
```

### 5.2 连贯性原则

| 原则 | 定义 |
|------|------|
| 轴线原则 | 对话/对峙/共同关注点的镜头组必须保持屏幕空间一致 |
| 屏幕方向一致性 | 同一连续动作的运动方向与视线方向保持一致 |
| 30度原则 | 同一主体的连续切镜，机位变化需足够明显（≥30度） |
| 视线匹配 | 给出角色看向画外的反应后，必须补充"他看到了什么"或"故意留悬念" |

### 5.3 蒙太奇逻辑

| 原则 | 定义 |
|------|------|
| 库里肖夫效应 | 用反应镜头传达情绪，不在一个镜头里讲完所有事 |
| 动接动 | 切镜优先卡在动作发生中段，保证动作连续 |
| 因果链 | 关键镜头遵循原因→结果，或结果→原因（制造悬念） |

### 5.4 镜头焦段隐喻

| 焦段 | 心理隐喻 |
|------|----------|
| 广角(<35mm) | 夸大前景、拉伸纵深，用于喜剧/恐惧/速度感 |
| 标准(35-70mm) | 客观叙述，无特殊心理暗示 |
| 长焦(>85mm) | 压缩空间、隔离角色，用于孤独/窒息感 |

### 5.5 光影叙事

| 光影 | 情绪表达 |
|------|----------|
| 暖光 | 安全、温馨、怀旧 |
| 冷光 | 危险、孤独、冷酷 |
| 伦勃朗光 | 明暗对照，暗示秘密或双重人格 |
| 色温对立 | 冷暖对比制造冲突 |

## 6. @引用语法规范

### 6.1 基础语法

| 类型 | 格式 | 示例 |
|------|------|------|
| 图片引用 | `@图片N` | `@图片1` |
| 视频引用 | `@视频N` | `@视频1` |
| 音频引用 | `@音频N` | `@音频1` |

### 6.2 完整引用格式

```markdown
@图片N = [素材来源] [用途说明]
```

示例：
```markdown
@图片1 = ep01/角色/林书白 参考人物外形
@图片2 = ep01/场景/教室 参考教室环境
@视频1 = ep01/场景/教室 运镜参考
@音频1 = 环境音/雷雨声 背景音效
```

### 6.3 场景宫格处理

- scene-prompts.md 中的九宫格必须拆分为独立场景图
- 每张独立场景图独立编号
- 不允许整张九宫格作为单一 @图片 引用

## 7. 精度模式常量

### 7.1 模式定义（统一命名）

| 模式名 | 别名 | 输出规范 |
|--------|------|----------|
| `标准模式` | 默认模式 | 4视图布局（面部特写 + 三视图） |
| `高精度模式` | 增强模式 | 8视图布局 + 材质清单 + 光影规范 |

### 7.2 高精度模式输出规范

**人物提示词增强内容：**
- 布局：8视图（正面、背面、左右侧面）+ 4个特写细节
- 材质：3-4种关键材质，每种标注名称和特性
- 精度指令：添加 "AAA game quality" / "高细节渲染"

**场景提示词增强内容：**
- 材质与工艺规范块：4种主要材质
- 光影规范块：主光源、辅助光、光影逻辑

### 7.3 场景宫格规格

| 场景数量 | 宫格规格 |
|----------|----------|
| ≤9 | 3×3 |
| 10-12 | 3×4 |
| 13-16 | 4×4 |

## 8. 输出格式常量

### 8.1 PASS输出格式（统一）

```markdown
✅ **业务审核：PASS**

[评分表]

整体评价：[1-2 句总结]

---
**审核详情**：
- 阶段：[阶段名]
- 审核项：[数量]项
- 平均分：[X.X]/10
- 通过时间：[YYYY-MM-DD HH:mm]
```

### 8.2 FAIL输出格式（统一）

```markdown
❌ **业务审核：FAIL**

[评分表]

**需要修改的问题**：

**问题1**：[具体问题描述]
- 位置：[如 P03 导演阐述]
- 当前问题：[具体描述现在的内容哪里不对]
- 脑内预演：[想象生成效果会出什么问题]
- 修改方向：[具体建议怎么改]

**问题2**：...

---
**修改优先级**：
1. 🔴 必须修改（单项低于 6 的）：[列出]
2. 🟡 建议修改（单项 6-7 的）：[列出]

---
**审核详情**：
- 阶段：[阶段名]
- 审核项：[数量]项
- 平均分：[X.X]/10
- 失败原因：[一句话概括]
```

### 8.3 合规审核PASS格式

```markdown
✅ **合规审核：PASS**

- 政治敏感：✅ 无

- 低俗内容：✅ 无
- 敏感题材：✅ 无

---
**审核详情**：
- 审核时间：[YYYY-MM-DD HH:mm]
- 扫描行数：[N]行
- 违规词汇：[N]个
```

### 8.4 合规审核FAIL格式

```markdown

**发现违规内容**：

| 类别 | 词汇/内容 | 位置 | 风险等级 |
|------|----------|------|----------|
| 软性色情 | XXX | P03 提示词 | 🔴高 |

**修改建议**：
- [具体修改方向]

---
**审核详情**：
- 审核时间：[YYYY-MM-DD HH:mm]
- 违规项：[N]项
- 风险等级：[高/中/低]
```

## 11. 审核工作流常量

### 11.1 阶段流转

| 阶段 | 产物文件 | 审核skill |
|------|----------|-----------|
| 阶段一 | 01-director-analysis.md | script-analysis-review-skill + compliance-review-skill |
| 阶段二 | assets/*prompts.md | art-direction-review-skill + compliance-review-skill |
| 阶段三 | 02-seedance-prompts.md | seedance-prompt-review-skill + compliance-review-skill |
| 阶段三(Kling) | 02-kling-prompts.md | kling-prompt-review-skill + compliance-review-skill |

### 11.2 门禁常量

| 门禁类型 | 检查项 |
|----------|--------|
| 入口门禁 | 文件存在、状态一致、结构符合模板 |
| 出口门禁 | 业务审核PASS、合规审核PASS、产物已写入 |
| 预算门禁（Seedance） | 图片≤9、视频≤3、音频≤3、总文件≤12 |
| 预算门禁（Kling） | 参考图≤9（角色+场景+道具多参考图输入）、输出=单条视频、音频=内置（音画同出）；"单图生视频"指输出形式，非输入限制 |
