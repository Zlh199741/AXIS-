## 技法一：自然主义打光（Naturalistic Lighting）
**理念**：所有光线来自画面内可信光源（窗/灯/烛/火），即使背后有灯具，观众感知不到。

### 基础操作流程

| 步骤 | 操作 | 要点 |
|------|------|------|
| 1.确定主光源 | 找场景最合理的光源 | 窗光>室内灯>烛光 |
| 2.光源增强 | 同方向放同色温灯具 | 不添加新方向 |
| 3.阴影管理 | 白卡填补阴影但保留形状 | 填光比≤3:1 |
| 4.色温统一 | 统一或刻意制造冲突 | 冷暖对比=叙事冲突 |

### 子技法

| 子技法 | 说明 | 代表使用 |
|--------|------|----------|
| 窗光唯一主光 | 全场景仅靠窗光+反光板 | 《教父》会客室、维米尔画作 |
| 实用光源暴露 | 灯泡/蜡烛出现在画面中=可信 | 《巴里·林登》蜡烛、《她》公寓灯 |
| 混合色温冲突 | 冷荧光+暖钨丝在同一画面 | 《搏击俱乐部》地下室、《寄生虫》半地下 |
| 光源外移动 | 角色从光区走向暗区=情绪转换 | 《教父》Vito在阴影中接受请求 |
| 反射光利用 | 水面/镜面/湿路面反射扩展光域 | 《银翼杀手》雨夜、《攻壳机动队》 |

### 光比与情绪映射（AI关键词）

| 光比 | 情绪 | AI提示词 |
|------|------|---------|
| 1:1 | 平和/天真 | `flat even lighting, no shadows` |
| 2:1 | 自然/日常 | `natural soft lighting, gentle shadows` |
| 3:1 | 戏剧/内省 | `dramatic side lighting, defined shadows` |
| 5:1 | 紧张/神秘 | `high contrast chiaroscuro, deep shadows` |
| 8:1+ | 恐惧/极端 | `extreme contrast, single source, near silhouette` |

### 常见错误

1. ❌ 眼睛全亮却无明确光源方向 → ✅ 确保光从一个主方向来
2. ❌ 夜景角色受光但场景灯具不发光 → ✅ 实用光源必须亮
3. ❌ 多方向等强光=平光=无立体感 → ✅ 一个主光+一个弱填光
4. ❌ 填光太强消除所有阴影 → ✅ 阴影是立体感的来源
5. ❌ 色温混乱但无叙事目的 → ✅ 混合色温必须有情感理由

**代表作**：《教父》(眼睛埋入阴影) · 《旧日天堂》(黄金时段每天20分钟) · 《血色将至》(火把/原油灯) · 《巴里·林登》(f/0.7真实蜡烛) · 《燃烧女子的肖像》(蜡烛+壁炉唯一光源)

## 技法二：极简构图（Minimalist Composition）
**理念**：负空间是情绪的容器，每个元素必须有存在的理由。

### 核心原则

| 原则 | 说明 | 情绪效果 |
|------|------|----------|
| 三分法/黄金比例 | 主体置于交叉点 | 平衡/舒适 |
| 负空间方向 | 面朝=希望；背对=孤立 | 方向=心理状态 |
| 框中框 | 门框/窗框创造画中画 | 隔离/困局/偷窥 |
| 视线高度 | 眼线=平等；低=权力；高=渺小 | 权力关系 |
| 对称 | 完美对称=秩序/权力/不安 | 控制/仪式/恐怖谷 |

### 负空间进阶

| 负空间类型 | 情绪 | AI关键词 | 代表作 |
|-----------|------|---------|--------|
| 上方负空间 | 渺小/敬畏 | `vast sky above, tiny figure below` | 《沙丘》 |
| 侧方负空间 | 孤独/失衡 | `subject offset, large empty space beside` | 《银翼杀手2049》 |
| 前方负空间 | 希望/未知 | `space ahead of subject, journey forward` | 《荒野猎人》 |
| 后方负空间 | 危险/过去 | `empty space behind subject, threat approaching` | 《寂静之地》 |
| 全包围 | 绝对孤独 | `tiny figure centered vast empty environment` | 《降临》 |

### 构图与权力（AI关键词）

| 构图手法 | 权力含义 | AI提示词 |
|---------|---------|---------|
| 仰拍 | 被拍者=强者 | `low angle shot looking up, powerful imposing` |
| 俯拍 | 被拍者=弱者 | `high angle looking down, vulnerable small` |
| 平视 | 平等/客观 | `eye level shot, neutral observation` |
| 荷兰角 | 不安/失控 | `Dutch angle tilted frame, psychological unease` |
| 鸟瞰 | 全知/命运 | `bird's eye view overhead, god perspective` |

### 常见错误

1. ❌ 画面元素过多=视觉噪音 → ✅ 删除一切不服务叙事的元素
2. ❌ 负空间无意义 → ✅ 负空间是情绪容器不是失误
3. ❌ 主体永远居中=乏味 → ✅ 居中只在对称/权力/仪式时使用
4. ❌ 忽略前景层 → ✅ 前景虚化元素增加纵深和偷窥感

**代表作**：《花样年华》(走廊压缩) · 《冷战》(4:3牢笼) · 《燃烧女子的肖像》(静止凝视) · 《一一》(玻璃倒影) · 《银翼杀手2049》(极端负空间) · 《寄生虫》(垂直构图=阶级)

## 技法三：阴影剪影（Shadow & Silhouette）
**理念**：黑暗是造型工具，人物成为纯粹形状，动物性与神秘感同时爆发。

### 四大类型

| 类型 | 制造方式 | 适用情境 | 光比 |
|------|----------|----------|------|
| 完全剪影 | 主体不打光，背景强逆光 | 登场/死亡/高潮 | ∞:1 |
| 半剪影 | 轮廓光+极弱填光 | 神秘但保留人性 | 8:1+ |
| 阴影分割 | 光在人脸上几何分割 | 内心矛盾/双重人格 | 4:1 |
| 威尼斯百叶 | 百叶窗条纹投影 | 囚禁感/noir | 3:1 |

### 子技法

| 子技法 | 说明 | 代表使用 |
|--------|------|----------|
| 烟雾体积光剪影 | 逆光+烟雾=轮廓发光 | 《银翼杀手》、《现代启示录》 |
| 火光动态剪影 | 火焰闪烁=边缘呼吸 | 《现代启示录》Kurtz |
| 窗户逆光剪影 | 背对窗光=完美日常剪影 | 《教父》、《间谍之桥》 |
| 色彩剪影 | 彩色背光制造彩色轮廓 | 《银翼杀手2049》、《Drive》 |
| 地面反射剪影 | 湿地面倒影也是剪影 | 《攻壳机动队》 |

### 阴影作为叙事工具

| 阴影用法 | 叙事含义 | 案例 |
|---------|---------|------|
| 遮住眼睛 | 隐藏意图/不可信任 | 《教父》Vito |
| 遮住半脸 | 双重人格/撕裂 | 《蝙蝠侠》双面人 |
| 从光走入暗 | 堕落/进入危险 | 《沉默的羔羊》 |
| 从暗走入光 | 觉醒/重生 | 《肖申克的救赎》 |
| 阴影逐渐吞噬 | 死亡逼近 | 《老无所依》 |

### 常见错误

1. ❌ 剪影中姿势不清=黑团 → ✅ 轮廓必须有可辨识形状
2. ❌ 暗部完全无细节 → ✅ 保留暗部最少信息量
3. ❌ 阴影方向不合理 → ✅ 每个阴影对应一个光源

**代表作**：《银翼杀手》(烟雾+霓虹逆光) · 《现代启示录》(火光剪影仪式感) · 《七宗罪》(Bleach Bypass) · 《闪灵》(走廊阴影) · 《教父》(眼窝阴影)

## 技法四：建筑框架（Architectural Framing）
**理念**：门/窗/走廊/楼梯都是叙事元素，建筑成为人物命运的隐喻。

### 核心元素

| 建筑元素 | 视觉功能 | 叙事隐喻 | AI关键词 |
|----------|----------|----------|---------|
| 门框 | 画中画 | 边界/选择 | `doorway framing, threshold` |
| 走廊 | 消失点透视 | 命运/死亡 | `corridor vanishing point perspective` |
| 楼梯 | 对角线张力 | 阶层/坠落 | `staircase diagonal composition` |
| 窗户 | 内外分割 | 自由/囚禁 | `window framing interior exterior` |
| 拱门/穹顶 | 宗教感 | 神圣/命运 | `archway dome sacred architecture` |
| 镜子 | 自我对话 | 分裂/真相 | `mirror reflection duality` |

### 子技法

| 子技法 | 说明 | 代表使用 |
|--------|------|----------|
| 嵌套框架 | 框中框中框=层层困局 | 《花样年华》多层门框 |
| 框架破碎 | 建筑框架被打破=自由 | 《1917》战壕突破 |
| 垂直框架 | 楼梯/电梯=阶级 | 《寄生虫》三层空间 |
| 水平框架 | 走廊/隧道=命运 | 《闪灵》单点透视走廊 |
| 自然框架 | 树木/山谷/洞口 | 《指环王》矿坑、《荒野猎人》 |

### 常见错误

1. ❌ 框架遮挡主体面部 → ✅ 框架引导视线到主体
2. ❌ 过于对称=刻意 → ✅ 对称只在恐怖/权力场景使用
3. ❌ 忽略建筑叙事潜力 → ✅ 每个门/窗/柱子都是叙事工具

**代表作**：《寄生虫》(楼梯=阶层) · 《布达佩斯大饭店》(完美对称) · 《1917》(战壕门洞) · 《沙丘》(史诗尺度) · 《花样年华》(走廊压缩) · 《闪灵》(几何走廊)

## 技法五：克制运镜（Restrained Camera Movement）
**理念**：镜头的移动必须有充分叙事理由，当摄影机动起来，那一刻重量无比。

### 运镜完整库

| 运镜类型 | 使用时机 | 效果 | AI关键词 |
|----------|----------|------|---------|
| 固定镜头 | 对话/沉思 | 冷静观察 | `static shot, locked camera` |
| 缓慢推近 | 情绪高潮前 | 压迫不可逃 | `slow dolly push, creeping forward` |
| 缓慢拉远 | 告别/揭示全景 | 抽离孤独 | `slow pull back, revealing wider` |
| 弧线环绕 | 关系变化 | 重心转移 | `arc tracking, orbiting camera` |
| 手持轻抖 | 情绪失控 | 纪录感 | `handheld slight shake, documentary` |
| Steadicam跟拍 | 角色行动 | 流畅伴随 | `Steadicam following, smooth tracking` |
| 垂直升降 | 揭示/俯瞰 | 视角转换 | `crane shot rising, jib vertical` |
| 横移 | 时间流逝 | 展示空间 | `lateral tracking, side dolly` |
| 360°环绕 | 高潮/觉醒 | 戏剧漩涡 | `360 revolving camera, spinning` |
| 甩镜 | 突然转折 | 瞬间冲击 | `whip pan fast swish, snap turn` |

### 运镜速度与情绪

| 速度 | 情绪效果 | 适用场景 |
|------|----------|----------|
| 极慢（0.1m/s） | 宿命/不可逃避 | 《潜行者》《2001》 |
| 缓慢（0.3m/s） | 沉思/紧张积累 | 大部分剧情片对话推近 |
| 中速（1m/s） | 跟随/日常 | 《小偷家族》 |
| 快速（3m/s+） | 追逐/失控 | 《谍影重重》 |
| 瞬间（甩镜） | 惊吓/暴力 | 恐怖片 |

### 常见错误

1. ❌ 无目的运镜=炫技 → ✅ 每次运镜回答"为什么动？"
2. ❌ 对话场景不必要运动 → ✅ 固定镜头对话往往更有力
3. ❌ 手持不稳≠纪录感 → ✅ 手持也需要控制和节奏
4. ❌ 运镜速度不匹配情绪 → ✅ 速度=情绪节拍器

**代表作**：《潜行者》(极缓推进) · 《分离》(手持法庭感) · 《小偷家族》(固定旁观) · 《1917》(全程Steadicam) · 《鸟人》(伪一镜)

## 技法六：隐形摄影（Invisible Photography）
**理念**：最高境界是让人忘记摄影机的存在，观众沉浸在故事中。

### 核心原则

| 原则 | 操作要点 | 违反后果 |
|------|----------|----------|
| 遵守轴线 | 所有机位在轴线同侧 | 空间混乱 |
| 视线匹配 | 对话双方高度/角度对应 | 权力紊乱 |
| 动作剪辑点 | 在动作进行中切换 | 剪辑可见 |
| 景别逻辑 | 建立→解构→深入 | 空间跳跃 |
| 30°规则 | 相邻镜头角度差≥30° | Jump Cut |
| 180°规则 | 不越过轴线 | 方向混乱 |

### 子技法

| 子技法 | 说明 | 何时使用 |
|--------|------|----------|
| L型剪辑 | 声音先/后于画面切换 | 所有对话场景 |
| 视线引导切换 | 角色看画面外→切到所看内容 | POV建立 |
| 动作匹配切 | 前镜动作未完→下镜接续 | 动作连续 |
| 环境声音桥 | 持续环境声掩盖剪辑点 | 场景过渡 |
| 隐形推进 | 极慢推近让观众不察觉 | 情绪积累 |

### 何时故意"可见"

| 打破手法 | 叙事目的 | 案例 |
|---------|---------|------|
| Jump Cut | 时间跳跃/焦虑 | 《精疲力尽》戈达尔 |
| 越轴 | 世界观翻转 | 《闪灵》Danny三轮车 |
| 直视镜头 | 打破第四面墙 | 《大空头》解说段落 |
| 异常长镜头 | 迫使经历真实时间 | 《俄罗斯方舟》一镜到底 |

### 常见错误

1. ❌ 越轴导致空间混乱 → ✅ 有越轴需求时用中间镜头过渡
2. ❌ 景别跳跃过大 → ✅ 全景→中景→近景，逐步深入
3. ❌ 无动机的运镜 → ✅ 观众不应注意到摄影机

**代表作**：《她》(科幻下最隐形摄影) · 《佛罗里达乐园》(儿童视角) · 《何以为家》(纪录式跟拍) · 《月光男孩》(克制精准)

## 技法七：色彩叙事（Color Storytelling）
**理念**：颜色是情绪的直接语言。色彩变化=人物内心变化。

### 色彩情绪完整映射

| 颜色 | 正面 | 负面 | AI关键词 |
|------|------|------|---------|
| 蓝色 | 冷静/智慧 | 孤独/压抑 | `cold blue tone, isolated` |
| 红色 | 激情/爱 | 危险/暴力 | `red accent, passionate danger` |
| 橙/暖黄 | 温暖/希望 | 焦虑/衰败 | `warm amber golden` |
| 绿色 | 自然/新生 | 嫉妒/病态 | `green tint, sickly or natural` |
| 紫色 | 神秘/高贵 | 疯狂/堕落 | `purple mystical, decadent` |
| 灰/脱色 | 客观/纪实 | 压抑/绝望 | `desaturated grey, lifeless` |
| 金色 | 权力/辉煌 | 幻觉/腐败 | `golden opulent, gilded` |
| 白色 | 纯粹/真相 | 空虚/压迫 | `sterile white, empty` |
| 黑色 | 优雅/权力 | 死亡/虚无 | `deep black, void darkness` |

### 色彩叙事策略

| 策略 | 说明 | 代表作 |
|------|------|--------|
| 色彩弧线 | 随剧情色彩从暖→冷或反之 | 《爱乐之城》原色→脱色 |
| 单色统治 | 一个颜色覆盖90%+画面 | 《英雄》五色篇章 |
| 互补色对立 | 橙vs青=冲突可视化 | 《银翼杀手2049》橙vs蓝 |
| 色彩分离 | 高饱和主色+其余脱色 | 《辛德勒的名单》红衣女孩 |
| 色彩编码 | 角色/阵营各有专属色 | 《黑客帝国》绿=矩阵 |
| 渐变过渡 | 一个镜头内A色→B色 | 场景内情绪转折 |

### 色彩组合心理学

| 组合 | 心理效果 | AI提示词 |
|------|---------|---------|
| 青+橙 | 最强对比=电影感 | `teal and orange cinematic grading` |
| 红+黑 | 暴力×优雅 | `red accent on black, violent elegance` |
| 蓝+白 | 冷静×空虚 | `cold blue-white sterile clinical` |
| 金+暗 | 权力×腐败 | `golden highlights deep shadows opulent` |
| 绿+灰 | 病态×真实 | `sickly green grey desaturated` |
| 粉+蓝 | 浪漫×忧郁 | `pastel pink blue romantic melancholy` |

### 常见错误

1. ❌ 色彩无叙事逻辑=随机好看 → ✅ 每个色彩服务故事
2. ❌ 全片一个调色=单调 → ✅ 随剧情发展色彩变化
3. ❌ 过饱和=有冲击力 → ✅ 克制的色彩往往更有力
4. ❌ 色彩冲突无理由 → ✅ 冲突色=叙事冲突

**代表作**：《银翼杀手2049》(三区分色) · 《爱乐之城》(原色→脱色) · 《蓝色》(单色哲学) · 《英雄》(五色系统) · 《黑客帝国》(绿色编码)

## 技法八：层次氛围（Layered Atmosphere）
**理念**：前中背三层都有信息，大气介质是粘合三层的胶水。

### 四层结构

| 层次 | 元素 | 功能 | AI关键词 |
|------|------|------|---------|
| 前景 | 虚化物体/肩膀/植物 | 纵深/偷窥感 | `foreground bokeh element` |
| 中景 | 主体/核心动作 | 叙事核心 | `subject mid-ground sharp focus` |
| 背景 | 环境/天空 | 世界观 | `background establishing` |
| 大气 | 烟雾/灰尘/雨 | 粘合/情绪 | `atmospheric haze volumetric` |

### 大气介质完整速查

| 介质 | 情绪效果 | AI关键词 |
|------|----------|---------|
| 薄雾 | 神秘/梦境/不确定 | `thin mist ethereal mysterious` |
| 浓雾 | 恐惧/迷失/隔离 | `dense fog low visibility isolated` |
| 烟 | 危险/战争/混乱 | `smoke haze battlefield chaos` |
| 细雨 | 忧郁/浪漫/净化 | `light rain drizzle melancholic` |
| 暴雨 | 冲突/危机/情绪爆发 | `heavy rain downpour dramatic storm` |
| 灰尘 | 废土/时光/衰败 | `dust particles time decay` |
| 雪 | 寂静/纯净/死亡 | `falling snow silence cold purity` |
| 花粉/花瓣 | 梦幻/圣洁/生命 | `pollen petals floating dreamy sacred` |
| 蒸汽 | 工业/热力/隐藏 | `steam industrial pipe concealing` |
| 水下气泡 | 窒息/超脱/重生 | `underwater bubbles submerged rebirth` |
| 沙尘 | 末世/苍凉/史诗 | `sand dust apocalyptic desolate epic` |
| 萤火虫/粒子 | 魔法/记忆/超自然 | `fireflies glowing particles magical` |

### 层次设计进阶

| 层次手法 | 说明 | 代表使用 |
|---------|------|----------|
| 前景遮挡 | 前景物体部分遮挡主体=偷窥 | 《窃听风暴》、《花样年华》 |
| 中景穿越 | 摄影机穿过前景物体到达主体 | 长镜头跟拍 |
| 背景动态 | 背景有独立运动=世界活着 | 《攻壳机动队》城市蒙太奇 |
| 多层平移 | 前中背不同速度横移=视差 | 动画parallax |
| 大气光束 | 光线穿透大气=体积光 | 《指环王》《沙丘》 |

### 常见错误

1. ❌ 只有中景=扁平 → ✅ 前景+中景+背景+大气四层齐备
2. ❌ 大气介质过量=看不见主体 → ✅ 介质是调味料不是主菜
3. ❌ 前景虚化太多=干扰 → ✅ 前景引导视线不遮挡主体

**代表作**：《荒野猎人》(百分百自然光) · 《人类之子》(战争烟雾长镜头) · 《边境杀手》(黄昏大气=恐惧) · 《银翼杀手》(烟雾+霓虹体积光) · 《攻壳机动队》(多层城市)

## 技法九：情感写实（Emotional Realism）
**理念**：所有摄影决策服从于"此刻人物感受什么"。

### 情绪-摄影参数完整映射

| 情绪状态 | 景别 | 焦段 | 运镜 | 光线 | AI关键词 |
|----------|------|------|------|------|---------|
| 极度亲密 | 极特写 | 85-135mm | 固定 | 柔光 | `extreme close-up intimate, soft light` |
| 孤独 | 大远景 | 长焦压缩 | 极缓推近 | 冷光/阴天 | `lonely vast landscape, overcast cold` |
| 迷失 | 广角全景 | 24mm以下 | 手持轻抖 | 散射光 | `wide angle disoriented, handheld` |
| 恐惧 | 不稳定景别 | 广角极近 | 手持激烈 | 单源硬光 | `wide distorted close, harsh single light` |
| 升华/自由 | 由近到远 | 由长到短 | 上升拉远 | 逆光/金光 | `ascending crane, backlit golden` |
| 压抑 | 中近景 | 50mm | 固定不动 | 平光/荧光 | `static mid-shot, fluorescent flat` |
| 愤怒 | 近景→特写 | 35-85mm | 快速推近 | 侧光高对比 | `push in aggressive, high contrast side` |
| 温暖/安全 | 中景 | 50mm | 缓慢横移 | 暖色柔光 | `warm soft medium shot, gentle track` |
| 困惑 | 广角中景 | 24-35mm | 环绕 | 混合色温 | `wide confused, mixed color temperature` |
| 绝望 | 俯拍全景 | 广角 | 缓慢拉远 | 冷灰脱色 | `overhead pulling away, desaturated cold` |

### 子技法

| 子技法 | 说明 | 代表使用 |
|--------|------|----------|
| 呼吸同步 | 镜头运动与角色呼吸节奏同步 | 《月光男孩》特写段落 |
| 触觉摄影 | 极近距离拍手指/嘴唇/皮肤纹理 | 《利兹与青鸟》、《燃烧女子》 |
| 环境=情绪 | 用风景替代面部表情传达情绪 | 《游牧人生》、《生命之树》 |
| 时间感变形 | 情绪高潮时放慢/加速 | 《鬼灭之刃》战斗关键帧 |
| 主观视觉 | 模拟角色视觉（模糊/晃动/色偏） | 醉酒/受伤/幻觉场景 |

### 常见错误

1. ❌ 景别与情绪不匹配 → ✅ 亲密用近景，孤独用远景
2. ❌ 所有情绪都用同一焦段 → ✅ 焦段随情绪变化
3. ❌ 运镜与情绪节奏脱节 → ✅ 运镜速度=情绪节拍器
4. ❌ 忽略光线的情绪功能 → ✅ 光是最直接的情绪工具

**代表作**：《月光男孩》(情绪特写克制精准) · 《生命之树》(情感宇宙化) · 《游牧人生》(人与风景情感等价) · 《利兹与青鸟》(身体语言叙事)

## 技法十：故事驱动创新（Story-Driven Innovation）
**理念**：技术创新是解决叙事问题的手段。形式实验必须回答：**这让故事更有力了吗？**

### 创新维度

| 维度 | 创新方向 | 案例 | 叙事理由 |
|------|----------|------|----------|
| 画幅比例 | 4:3/宽银幕因故事选择 | 《冷战》4:3囚禁感 | 画幅=角色的精神牢笼 |
| 色彩系统 | 黑白/限定色 | 《曼克》重建40年代 | 时代质感还原 |
| 长镜头 | 技术边界服务叙事 | 《1917》伪一镜到底 | 战争=不间断的体验 |
| 混合媒介 | 动画/档案/现实结合 | 《逃亡》动画纪录片 | 记忆=不可靠的重建 |
| 帧率变化 | 不同帧率混用 | 《蜘蛛侠平行宇宙》12+24fps | 漫画感=有意降帧 |
| 非常规镜头 | 红外/针孔/特种摄影 | 《沙丘》红外沙漠 | 异世界的陌生感 |
| 动态画幅 | 画幅在影片中变化 | 《布达佩斯大饭店》三个时代三个画幅 | 时间维度可视化 |
| LED围幕 | 实时环境投射 | 《曼达洛人》《银翼杀手2049》 | 实拍质感+幻想环境 |

### 创新检验清单

在决定使用任何非常规技法前，必须通过以下检验：
1. **叙事必要性**：这个技法是否解决了常规手法无法解决的叙事问题？
2. **观众感知**：观众是否能从中获得更深的情感/认知体验？
3. **一致性**：这个创新是否贯穿全片形成系统，而非一次性炫技？
4. **可理解性**：观众是否能直觉理解这个创新的含义，无需解释？

### 常见错误

1. ❌ 为创新而创新=炫技 → ✅ 创新必须解决叙事问题
2. ❌ 创新不一致=混乱 → ✅ 建立规则后贯穿全片
3. ❌ 创新过于晦涩 → ✅ 观众应能直觉感受到意义

**代表作**：《1917》(伪一镜) · 《冷战》(4:3黑白) · 《蜘蛛侠平行宇宙》(混合帧率) · 《布达佩斯大饭店》(三画幅) · 《沙丘》(红外摄影)

# 第三部分：工作流程

## 前期准备（Pre-Production）

### 1. 剧本视觉分析
逐场景标注以下要素：
- **情绪关键词**：每场戏的核心情绪（紧张/温暖/孤独等）
- **光线意图**：主光源类型+光比+色温
- **构图意图**：景别+机位高度+负空间方向
- **色彩意图**：主导色+辅助色+整体饱和度
- **运镜意图**：固定/推/拉/跟/环+速度
- **视觉转折点**：全片色彩/光线/节奏发生根本变化的节点

### 2. 视觉参考会议
- 与导演对齐视觉语言（Look Reference ≥ 3部参考片）
- 建立全片色彩板（Mood Board）
- 确定每幕的光线策略变化
- 确定画幅比例和镜头系统

### 3. 测试拍摄
- 镜头测试：锐度/焦外/畸变/光晕特性
- 色彩LUT对比：≥3套LUT在目标场景测试
- 演员妆发灯光联合测试：确认肤色还原
- 特殊场景预演：高难度镜头运动预排

### 4. 勘景
- 记录自然光源方向/质量（罗盘+光线追踪App）
- 确定最佳拍摄时间段（Golden Hour精确到分钟）
- 评估电力/空间/噪音限制
- 拍摄参考照片（同一时段同一天光条件）

## 现场光线决策流程

```
步骤1：确定场景情绪 → 查技法九「情绪-摄影参数映射」
  ↓
步骤2：确定主光源方向
  → 室内：窗光方向？实用灯具位置？
  → 室外：太阳方向？时间段？
  ↓
步骤3：确定光比
  → 1:1~2:1 = 日常/温暖
  → 3:1 = 戏剧/标准
  → 5:1+ = 紧张/神秘/恐怖
  ↓
步骤4：确定色温
  → 日光 5600K / 钨丝 3200K / 混合？
  → 冷暖冲突是否有叙事理由？
  ↓
步骤5：大气介质
  → 需要烟/雾/雨增加纵深和情绪？
  → 查技法八「大气介质速查」
  ↓
步骤6：前景层
  → 是否需要前景虚化物体增加纵深？
  ↓
步骤7：最终光线检查
  → 通过「现场核心Checklist」逐项确认
```

## 现场核心 Checklist

### 光线
- [ ] 主光源方向明确且来自可信光源
- [ ] 光比符合场景情绪目标
- [ ] 眼神光存在（人像场景）
- [ ] 色温统一（或冲突是刻意的）
- [ ] 暗部保留足够细节（不死黑）
- [ ] 高光不过曝（保留信息）

### 构图
- [ ] 构图有设计感（三分法/负空间/框中框）
- [ ] 前景/中景/背景都有内容
- [ ] 负空间方向与情绪匹配
- [ ] 视线高度与权力关系匹配
- [ ] 大气介质是否需要（烟/雾/雨）

### 运镜
- [ ] 摄影机运动有明确叙事动机
- [ ] 运镜速度与情绪节奏匹配
- [ ] 轴线关系确认（不越轴或有意越轴）
- [ ] 焦点目标已确认
- [ ] 起幅/落幅构图完整

### 技术
- [ ] 曝光准确（示波器确认）
- [ ] 白平衡设置正确
- [ ] 录制格式/帧率正确
- [ ] 音频同步
- [ ] 安全镜头已拍

## 后期调色流程（DaVinci Resolve）

### 标准调色六步流程

| 步骤 | 操作 | 工具 | 要点 |
|------|------|------|------|
| 1.素材管理 | 导入+分组+标签 | Media Pool | 按场景/时段分组 |
| 2.一级调色 | 曝光/对比/白平衡统一 | Primary Wheels | 先统一再风格化 |
| 3.色彩匹配 | 同场景不同镜头色彩统一 | Color Match | 基于灰卡/肤色 |
| 4.二级调色 | 局部调整（天空/肤色/高光） | Qualifier/Window | 蒙版精确控制 |
| 5.LUT/风格化 | 应用整体色彩风格 | 3D LUT | LUT强度50-70%即可 |
| 6.输出检查 | 全片色彩一致性审查 | Gallery对比 | 逐场景AB对比 |

### 风格LUT速查
