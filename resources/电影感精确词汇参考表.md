# 电影感精确词汇参考表

> **用途**：场景提示词模板 `⑤ 技术封印` 层的电影感增强参考。  
> **核心原则**：AI 模型听到 "cinematic" 只能激活 1-2 层效果；要全面电影感，必须逐层显式写入具体参数词。

---

## 一、电影感七层模型

| 层级 | 维度 | 普通图片 | 电影感图片 | 核心差异 |
|:---:|------|---------|-----------|---------|
| ① | 光比与方向 | 均匀平光 | 高对比明暗 | 有方向性的光 + 深阴影 |
| ② | 色彩分离 | 所有颜色平均 | 冷暖对立/单色主导 | 色温冲突制造情绪 |
| ③ | 景深控制 | 全清晰 | 前/背景虚化 | 强迫视线聚焦 |
| ④ | 镜头光学特性 | 无光学痕迹 | 有眩光/畸变/暗角 | 光学"不完美" = 真实感 |
| ⑤ | 大气介质 | 干净空气 | 雾/尘/雨/烟 | 光有了"体积" |
| ⑥ | 构图纪律 | 居中/随意 | 三分法/框中框/引导线 | 画面有叙事方向 |
| ⑦ | 胶片质感 | 数码锐利干净 | 颗粒/色偏/动态范围 | 有机感，非合成感 |

## 二、逐维度精确词汇

### ① 光比与方向

| 中文描述 | 英文提示词 | 效果 |
|---------|-----------|------|
| 高对比明暗法 | `high contrast chiaroscuro lighting` | 伦勃朗油画级明暗 |
| 单侧硬光 | `single hard directional key light` | 一侧亮一侧暗 |
| 逆光轮廓勾线 | `strong rim light / backlight outlining silhouette` | 发丝/肩线金边 |
| 光比参数 | `light ratio 4:1` 或 `5:1` | 数值越大越戏剧化 |
| 实际光源可见 | `practical light source visible in frame` | 路灯/台灯/烛火入画 |
| 眼神光 | `catchlight in eyes` | 人物有灵魂 |
| 顶光照明 | `top light, eye socket shadows` | 压迫、审讯、神秘 |
| 正侧光 | `split lighting, half face in shadow` | 复杂、压抑、双面性 |
| 伦勃朗光 | `Rembrandt lighting, triangle light patch on cheek` | 戏剧性、深沉 |
| 反射补光 | `bounce fill from [surface material]` | 柔和过渡，环境互动 |

### ② 色彩分离

| 中文描述 | 英文提示词 | 效果 |
|---------|-----------|------|
| 青橙对冲 | `teal and orange color grading` | 好莱坞标准电影色调 |
| 双色温撕裂 | `dual color temperature split, warm 3000K vs cool 6500K` | 内心冲突视觉化 |
| 单色主导 | `monochromatic [color] dominant palette` | 张艺谋式色彩叙事 |
| 低饱和+单色强调 | `desaturated palette with single saturated accent color` | 辛德勒红衣效果 |
| 漂白跳过 | `bleach bypass processing` | 高对比低饱和战争感 |
| 压暗色调 | `crushed blacks, lifted shadows` | 暗部有层次但整体偏暗 |
| 互补色撕裂 | `complementary color split lighting` | 霓虹夜景、赛博朋克 |
| 消色差主调 | `achromatic palette with [single color] accent` | 极简冷峻 |

### ③ 景深控制

| 中文描述 | 英文提示词 | 效果 |
|---------|-----------|------|
| 大光圈浅景深 | `shallow depth of field, f/1.4 wide open` | 背景奶油虚化 |
| 焦点转移 | `rack focus from foreground to background` | 叙事引导 |
| 深焦全清晰 | `deep focus f/8, everything sharp` | 库布里克式全景控制 |
| 前景遮挡虚化 | `out-of-focus foreground element framing subject` | 窥视感/框中框 |
| 散景形状 | `anamorphic oval bokeh` 或 `hexagonal bokeh` | 镜头个性化 |
| 微距特写 | `macro close-up, extremely shallow DOF` | 细节放大，背景消融 |

### ④ 镜头光学特性

| 中文描述 | 英文提示词 | 效果 |
|---------|-----------|------|
| 变形宽银幕水平眩光 | `anamorphic horizontal lens flare` | 一条横穿画面的蓝色光线 |
| 暗角 | `natural vignette, -0.3EV corner darkening` | 视线聚焦中心 |
| 桶形畸变 | `subtle barrel distortion wide angle` | 广角镜头压迫感 |
| 色散/紫边 | `chromatic aberration on edges` | 镜头真实感 |
| 呼吸效应 | `lens breathing effect` | 变焦时画面微缩放 |
| 实际光源引发眩光 | `lens flare from practical light entering frame` | 太阳/灯光入画 |
| 十字星芒 | `starburst / diffraction spike from point light` | 点光源向外辐射光芒 |
| RGB通道偏移 | `RGB channel offset 1-2px on edges` | 数字故障/CRT美学 |

### ⑤ 大气介质

| 中文描述 | 英文提示词 | 效果 |
|---------|-----------|------|
| 体积光/丁达尔 | `volumetric light shafts, Tyndall effect` | 光束可见 |
| 空气粉尘漂浮 | `dust particles floating in light beam` | 空间真实感 |
| 薄雾/晨雾 | `atmospheric haze, morning mist` | 空间纵深层次 |
| 湿润路面反光 | `wet pavement reflecting light sources` | 霓虹夜景光线翻倍 |
| 雨帘折射 | `rain curtain refracting neon lights` | 光的扩散与色散 |
| 呼吸白气 | `visible breath in cold air` | 温度可见化 |
| 蒸汽/热浪纹 | `steam rising / heat haze distortion` | 温差可见化 |
| 烟雾弥漫 | `smoke-filled room, light scattering through haze` | 体积光最大化 |

### ⑥ 构图纪律

| 中文描述 | 英文提示词 | 效果 |
|---------|-----------|------|
| 三分法 | `rule of thirds composition` | 基础但有效 |
| 引导线 | `leading lines guiding eye to subject` | 纵深感 |
| 框中框 | `frame within frame composition, doorway/window framing` | 窥视感 + 层次 |
| 对称构图 | `Kubrickian perfect symmetry composition` | 秩序/不安 |
| 大量负空间 | `extreme negative space, subject small in vast frame` | 孤独/渺小 |
| 荷兰角 | `Dutch angle tilted horizon` | 心理不安 |
| 单点透视灭点 | `one-point perspective vanishing point composition` | 走廊/纵深压迫 |
| 对角线构图 | `diagonal composition, dynamic tension` | 运动/不稳定 |
| 俯拍/鸟瞰 | `top-down overhead shot, bird's eye view` | 全局掌控/渺小 |
| 仰拍 | `low angle looking up, imposing perspective` | 威压/崇高 |

### ⑦ 胶片质感

| 中文描述 | 英文提示词 | 效果 |
|---------|-----------|------|
| 胶片颗粒 | `film grain texture, ISO 400-800 aesthetic` | 有机非数码 |
| 柯达暖调 | `Kodak Portra 400 warm film stock` | 皮肤暖色偏移 |
| 富士冷调 | `Fujifilm Pro 400H cool green tint` | 清冷日系 |
| 柯达电影胶片 | `Kodak Vision3 500T film stock` | 专业电影级暖调颗粒 |
| 宽银幕比例 | `2.39:1 anamorphic widescreen aspect ratio` | 电影院画幅 |
| 高动态范围 | `high dynamic range, detail in shadows and highlights` | 暗部亮部都有信息 |
| CRT扫描线 | `CRT horizontal scan lines overlay` | 复古/监控质感 |
| VHS磁带噪点 | `VHS tape noise, analog video distortion` | 怀旧/恐怖/伪纪录片 |

## 四、电影感增强行模板

在场景模板 `⑤ 技术封印` 的 **风格锚** 后追加一行：

```
电影感增强：[镜头光学] + [大气介质] + [胶片模拟] + [色彩调色]
```

### 实例

**现实层·阴天日景**（如车祸现场白天版）：
```
电影感增强：subtle barrel distortion（轻微广角桶形畸变），
atmospheric haze 3-5% visibility（3-5%薄雾大气透视），
Kodak Portra 400 desaturated grain（柯达淡彩颗粒），
desaturated teal shadows with warm highlight retention（冷青阴影+暖色高光保留）。
```

**现实层·黄金时刻**（如车祸现场夕阳版）：
```
电影感增强：anamorphic horizontal lens flare（水平蓝色光晕），
atmospheric golden dust particles（夕阳金色粉尘漂浮），
Kodak Vision3 500T film stock warm grain（柯达电影胶片暖色颗粒），
teal and orange color grading with crushed blacks（青橙调色+压暗黑部）。
```

**现实层·冷白室内**（如医院走廊/食堂）：
```
电影感增强：natural vignette -0.4EV（中度暗角），
fluorescent light flicker micro-variation（荧光灯微闪烁变化），
Fujifilm Pro 400H cool grain（富士冷调颗粒），
bleach bypass desaturated with clinical blue tint（漂白跳过+医疗蓝偏色）。
```

**现实层·暖光密室**（如副院长办公室）：
```
电影感增强：warm anamorphic oval bokeh（暖色椭圆散景），
dust particles in desk lamp beam（台灯光束粉尘漂浮），
Kodak Vision3 250D warm fine grain（柯达日光胶片细腻暖颗粒），
Gordon Willis top-light shadow palette（戈登·威利斯式顶光暗调）。
```

**虚拟层·系统空间**（如广播虚空/聊天群/控台）：
```
电影感增强：RGB channel offset 1.2px on panel edges（面板边缘RGB色散），
digital scan lines 5-8% opacity（全息扫描线），
ISO 800 digital film grain simulation（数字胶片颗粒仿真），
high saturation self-luminous elements on near-black base（近黑底+高饱和自发光）。
```
