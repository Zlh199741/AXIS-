## 1.1 《银翼杀手 2049》 Blade Runner 2049 (2017)

**导演**：Denis Villeneuve ｜ **摄影**：Roger Deakins

### 技术参数表

| 参数 | 值 | 说明 |
|------|-----|------|
| 画幅 | 2.39:1 | 超宽银幕，强化水平线压迫 |
| 主焦段 | 35-40mm Alexa 65 | 大画幅浅景深+广角空间感并存 |
| 色温主调 | 3200K暖橙 × 8000K冷蓝 | 双色温极端对立 |
| 光比 | 5:1 至 8:1 | 极端明暗对比，Deakins标志性 |
| 光源类型 | 巨型LED灯墙+实景投射 | 首创LED围幕实拍技术 |
| 胶片/数字 | Alexa 65 (6.5K) | 大画幅数字，模拟胶片质感 |
| 调色风格 | 单色调统治（橙/青/黄/白） | 每个场景一个主色统治 |
| 景深控制 | f/2.8-f/4 | 中浅景深，主体与环境同在 |
| 氛围介质 | 浓雾/工业烟/沙尘/雪 | 几乎每场景都有大气介质 |

### 标志性场景解析

**场景1：橙色废土（拉斯维加斯废墟）**
- 极端负空间，K的剪影仅占画面5%，其余全是橙色雾霾
- 单一暖橙色源（太阳穿过沙尘），无冷光补偿
- 感官剥夺→孤独→末世虚无
- T0映射：维度四（负空间压制）+ 维度七（虚无主义空镜锚点）

**场景2：华莱士总部水纹光**
- 水波纹投射在墙面/天花板，人物被光纹切割
- 单一底光穿过水池，光比8:1，面部仅一侧被水纹照亮
- 神圣感×不安感→造物主隐喻
- T0映射：维度八（光源霸权）+ 维度二（几何母题分形）

**场景3：全息女友Joi雨中场景**
- 全息投影叠加真人，双重轮廓线
- 霓虹粉紫×冷蓝雨水反射，光穿透Joi半透明身体
- 美丽×悲哀，触不可及的亲密
- T0映射：维度五（恐怖谷）+ 维度六（环境熵增）

### 可复用技巧

1. **单色统治法**：每场景只用一个主色调统治，将复杂情绪简化为色彩直觉
2. **LED围幕实拍**：用LED屏幕包围投射环境光，获得真实反射（AI等价于精确描述环境反射光）
3. **大气介质必备**：Deakins几乎不拍"干净"空气，烟/雾/尘/雪是画面层次关键
4. **负空间叙事**：85%空白/单色背景压缩主体，制造孤独感

**场景2：泰瑞公司金字塔内部**
- 巨大空间中微小人物，柱状光束穿透尘埃
- 丁达尔效应极致运用，光束成为可见实体
- 神庙+权力+造物主

1. **变形宽银幕光晕**：横向蓝/橙线状光晕=赛博朋克DNA，AI用 `anamorphic lens flare` 触发
2. **多层光源叠加**：一画面5+种光源（霓虹/车灯/探照灯/广告屏/丁达尔），信息过载
3. **永恒雨夜**：雨水反射使地面成为第二个霓虹天幕，信息密度翻倍
4. **逆光剪影+边缘光**：正面暗，边缘被霓虹勾勒轮廓
