# 视觉风格选择审核技能

[技能说明]
    审核视觉风格选择阶段的产出（assets/visual-style-guide.md），确保：
    1. 风格选择与题材类型、情绪基调、目标受众匹配
    2. 规范文档完整（色彩/光影/镜头/应用指南齐全）
    3. 提示词库可执行（能直接用于服化道设计和分镜编写）
    4. 如有混搭风格，兼容性检查通过

    按需查阅（电影摄影三件套 — 审核光影规范完整性时参考）：
    - resources/电影摄影-40+代表作视觉分析.md（比对风格参数是否与目标代表作一致）
    - resources/电影摄影-主文件(技法+设备+工作流程).md（审核光影规范参数是否专业合理）

    本审核技能可参考：
    1. skills/visual-style-selector-skill/SKILL.md：了解完整风格体系与选择流程
    2. outputs/<集数>/01-director-analysis.md：导演分析产出（题材/情绪/受众）

[审核对象]
    assets/visual-style-guide.md

[审核流程]

    第零步：强制前置校验（主 skill 确认码 + 阈值口径）
        🔴 主 skill 全文读取确认码校验（消除幻觉，确保风格体系被真实读取后才出文档）：
        - 生成方（visual-style-selector-skill）必须已全文读取主 skill，并在其「📊 Skill 合规审计报告」中逐字包含确认码：
          ```
          ✅ VISUAL-STYLE-SELECTOR-SKILL 全文读取确认：STYLE-SELECTOR-CERTIFIED-风格预设库已激活-色彩基调已加载
          ```
        - ☐ 确认码缺失 / 被篡改 / 与上方字符串不逐字一致 → 🔴 直接 FAIL：判定生成方未完整读取 visual-style-selector-skill，退回重做，不进入第一步
        - ☐ 阈值口径确认：本 skill 三维评分通过线 = C级审核类「各项 ≥ 95」，以 skills/templates/quality-threshold-standard.md 为唯一权威来源（不得硬编码其它数值）

    第一步：建立整体理解
        - 读取导演分析产出（01-director-analysis.md）中的题材类型、情绪曲线、目标受众
        - 读取待审核的视觉风格规范文档（assets/visual-style-guide.md）
        - 明确审核立场：你的任务是找出问题，而非确认通过

    第二步：逐项比对
        - 风格与题材匹配：选定风格是否适合该题材类型？
        - 风格与情绪匹配：选定风格的色调/光影是否能传达目标情绪？
        - 风格与受众匹配：选定风格是否符合目标受众的审美偏好？
        - 如有混搭：是否遵循三大黄金法则（主次分明/元素分离/基调统一）？
        - 是否使用了禁止混搭组合？

    第三步：文档完整性检查
        - ☐ 选定风格名称与子风格
        - ☐ 参考作品列表
        - ☐ 全局风格前缀（完整T0级提示词模板）
        - ☐ 🔴 全局前缀格式合规：全局风格前缀是否与 art-design 的 Nano Banana Pro「中英文分离」格式一致？
              要求：① 同时提供【中文描述段】（纯中文一整段、不夹杂英文术语）与【英文描述段】（纯英文一整段、不换行、含技术关键词与渲染参数）；
                    ② 两段语言完全分离、内容对应；③ 下游服化道可直接把前缀并入 Nano Banana 中英文分离输出而不产生中英混排
              中英混排 / 缺中文段或英文段 / 英文段内夹中文术语 → 🔴 必须修改（否则服化道阶段会继承不合规的混排前缀）
        - ☐ 色彩规范（主色调/辅助色/强调色 + Hex色号）
        - ☐ 光影规范（主光源方向/色温/强度 + 氛围光 + 特效光）
        - ☐ 镜头规范（常用焦段 + 景深处理 + 运镜风格）
        - ☐ 应用指南（角色设计/场景设计/道具设计/分镜编写各至少2条要点）

    第四步：可执行性验证
        - 脑内预演：将全局风格前缀丢进文生图工具，能否生成符合预期的画面？
        - 色彩规范是否足够具体（不能只写"暖色调"，要有具体色号）？
        - 光影规范是否有明确方向和强度参数？
        - 提示词是否与已有的T0标准兼容？

    第五步：逐项评分
        按照下方验收清单，对视觉风格规范文档评分（1-10）

    第六步：输出结果（三维百分制为唯一裁决）
        - 🔴 最终 PASS 裁决：三维评分（见下方 [三维评分规则]）各项 ≥ 95 → PASS；任一维度 < 95 → FAIL + 问题清单
          （与 skills/templates/quality-threshold-standard.md「审核类 C级 各≥95」一致）
        - 下方 [验收清单] 的 1-10 七维评分仅作问题定位的证据层，不单独裁决；当 1-10 结论与三维冲突时，以三维为准（冲突即裁决规则）
        - D级用户确认豁免：视觉风格「方案选择本身」（A/B/C 哪个方向）属用户拍板的 D级确认决策，审核不否决用户的风格偏好；
          本 skill 只对「规范文档质量（匹配度/完整性/可执行性/下游指导性/前缀格式合规）」做 C级 三维≥95 把关

[验收清单]

    视觉风格规范文档评分（1-10）

    评分维度：
        □ 题材匹配度：风格选择是否与题材类型高度匹配？（参考 visual-style-selector-skill 中的题材快速匹配表）
        □ 情绪一致性：色调/光影/氛围是否能传达导演分析中的情绪基调？
        □ 受众适配度：风格是否符合目标受众年龄层和审美偏好？
        □ 文档完整性：色彩/光影/镜头/应用指南是否全部齐全且具体？
        □ 提示词可执行性：全局风格前缀是否可直接用于文生图？有无歧义？
        □ 全局前缀格式合规度：全局风格前缀是否符合 art-design Nano Banana Pro「中英文分离」格式（中文段纯中文 + 英文段纯英文不换行、两段分离对应、无中英混排）？
        □ 混搭合理性（如适用）：主次比例是否明确？元素分离是否清晰？基调是否统一？
        □ 下游指导性：应用指南是否足够具体，能有效指导服化道和分镜？

    评分标准：
        - 9-10：风格规范精准完整，与项目调性完美匹配，可直接用于后续环节
        - 7-8：基本到位，但有 1-2 处可能导致后续环节偏差的地方
        - 5-6：有明显的缺失、不匹配或歧义，需要修改
        - 1-4：风格选择严重不合理或文档严重不完整

[三维评分规则（百分制 · C级审核类，唯一裁决 — 阈值见 quality-threshold-standard.md）]

    将上方 1-10 七维证据映射为三个百分制维度，作为最终 PASS/FAIL 的唯一裁决：

    维度一 · 风格匹配度（0-100）
        □ 题材匹配（0-33） □ 情绪一致（0-33） □ 受众适配（0-34）

    维度二 · 文档完整性与可执行性（0-100）
        □ 文档完整：色彩/光影/镜头/应用指南齐全且具体（0-34）
        □ 提示词可执行：全局前缀可直接用于文生图、无歧义（0-33）
        □ 🔴 全局前缀 Nano Banana 中英文分离格式合规（0-33）

    维度三 · 下游指导性与混搭合理性（0-100）
        □ 下游指导性：应用指南能有效指导服化道/分镜（0-50）
        □ 混搭合理性（如适用；不涉及混搭时该子项按满分计）（0-50）

    通过标准（C级审核类）：三维各项 ≥ 95 → PASS；任一维度 < 95 → FAIL
    D级用户确认类豁免：风格方案选择（A/B/C 方向）以用户拍板为准，不计入否决项；审核仅把关「规范文档质量」

[诊断指南]

    Q: 主 skill 确认码缺失，但文档看起来挺完整，能放行吗？
    A: 不能。确认码缺失 = 生成方未全文读取 visual-style-selector-skill，存在幻觉风险（风格预设/色彩基调可能凭记忆编造）。第零步 🔴 直接 FAIL，退回重做。

    Q: 全局前缀写成了「中英混排一整段」（中文里夹 best quality、masterpiece 等英文术语），算 FAIL 吗？
    A: 算。art-design 下游用 Nano Banana Pro「中英文分离」格式，混排前缀会被继承成不合规输出。要求拆成【中文描述段】+【英文描述段】两段分离，维度二该子项 <95 → FAIL。

    Q: 风格与题材不匹配如何判定？
    A: 对照 visual-style-selector-skill 的「题材快速匹配表」。如恐怖悬疑题材选了「柔和粉彩/吉卜力治愈系」，色调情绪根本相反 → 维度一题材匹配 + 情绪一致双低 → FAIL。

    Q: 混搭风格用了「禁止混搭组合」（如吉卜力 + 韩漫）怎么办？
    A: 维度三混搭合理性直接判低分。禁止组合（手绘温暖 vs 锐利暗黑完全对立）→ 要求改为单一风格或过渡风格 → FAIL。

    Q: 色彩规范只写「暖色调」没有具体 Hex 色号？
    A: 文档完整性不达标。色彩必须有主色调/辅助色/强调色 + Hex 色号，否则下游无法精确执行 → 维度二 <95 → FAIL。

    Q: 用户坚持要选一个高风险（突破方向）风格，审核必须 FAIL 吗？
    A: 不必。风格方向选择属 D级用户确认类，以用户拍板为准。审核只校验「该风格的规范文档是否完整、可执行、与之自洽」，不否决用户对风险等级的偏好。

[常见审核案例]

    PASS 案例：
    - 题材=青春爱情，选「新海诚背景 + 京阿尼人物」混搭，主次 60/40 清晰、色调统一暖粉，三大黄金法则全满足
    - 全局前缀【中文描述段】纯中文叙事 +【英文描述段】纯英文一整段不换行，两段分离对应，可直接并入 Nano Banana 输出
    - 色彩含 Hex 色号、光影含方向/色温/强度、镜头含焦段，应用指南对角色/场景/道具/分镜各≥2条
    - 生成方审计报告含确认码 STYLE-SELECTOR-CERTIFIED-…
    → 三维：风格匹配 97 ｜ 文档完整与可执行 96 ｜ 下游指导与混搭 96 → PASS

    FAIL 案例：
    - 全局前缀写成中英混排一整段（"吉卜力风格 hand-painted watercolor 温暖 best quality"）→ Nano Banana 分离格式不合规
    - 色彩只写「暖色调」无 Hex；光影规范缺色温与方向
    - 恐怖题材却选柔和粉彩，情绪相反
    - 生成方审计报告无确认码
    → 第零步确认码缺失即 🔴 FAIL；即便进入评分，维度一/维度二均 <95 → FAIL
