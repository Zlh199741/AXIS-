# 多角色场景示例

## 示例一：三方对峙（豪门争产）

### 场景信息
- 场景：豪华客厅
- 参与角色：大嫂（主导）、女主（弱势）、老爷子（仲裁）
- 场景类型：对峙

### 站位设计
```
初始站位（稳定三角）：
        老爷子（沙发正中）
         /            \
大嫂（左前方站立）  女主（右前方站立）
```

### 视线交互
| 角色 | 视线方向 | 视线类型 | 情绪含义 |
|------|---------|---------|---------|
| 大嫂 | → 女主 | 俯视+斜视 | 轻蔑、碾压 |
| 女主 | → 大嫂 | 直接对视 | 隐忍、倔强 |
| 老爷子 | 游移于两人之间 | 游移 | 犹豫、权衡 |

### 关键站位变化
1. 大嫂逼近女主（距离拉近）→ 压迫感升级
2. 女主后退半步（距离拉远）→ 示弱
3. 老爷子起身（打破三角）→ 局势转折
4. 女主站稳不退（站位稳固）→ 反转信号

## 示例二：群戏（公司会议室反转）

### 场景信息
- 场景：现代会议室
- 参与角色：男主（弱势→主导）、总监（主导→弱势）、6名员工（群演）
- 场景类型：冲突+反转

### 站位设计
```
初始站位：
  [员工1] [员工2] [员工3]
        总监（站立，画面中心）
  [员工4] [员工5] [员工6]
              男主（角落座位，画面边缘）
```

### 群演调度
| 群演组 | 数量 | 位置 | 动作 | 反应 |
|--------|------|------|------|------|
| 员工组 | 6人 | 会议桌两侧 | 低头/看手机/窃窃私语 | 总监发言时点头附和 |
| 反转后 | 6人 | 不变 | 抬头/放下手机/面面相觑 | 男主摔文件时集体惊愕 |

### 关键站位变化
1. 总监站在中心讽刺男主 → 权力碾压
2. 男主缓缓起身（画面边缘→中心移动）→ 反转前兆
3. 男主走到总监面前（距离逼近）→ 权力逆转
4. 总监后退（位置交换）→ 反转完成
