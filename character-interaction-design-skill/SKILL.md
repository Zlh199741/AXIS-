# 角色互动设计技能

[技能说明]
    本技能解决多角色互动场景的系统化设计问题，包括：
    1. 多角色站位逻辑（权力矩阵、三角构图）
    2. 视线交互设计（Eye-line交叉）
    3. 冲突动作设计（肢体冲突、物理交互）
    4. 群演调度规范（批量人物处理）
    5. 情感线互动（CP/对立/误会场景）

    适用于导演分析阶段和分镜编写阶段的多角色场景设计。

## 一、多角色站位逻辑

### 1.1 权力矩阵（Power Matrix）

| 站位 | 权力关系 | 适用场景 |
|------|----------|----------|
| 画面中心偏上 | 权威/主导 | 教训、命令、掌控 |
| 画面中心偏下 | 弱势/服从 | 求饶、认错、被压制 |
| 画面右侧 | 主动/攻击 | 进攻、表白、离开 |
| 画面左侧 | 被动/防守 | 等待、承受、接纳 |
| 前景大/后景小 | 主导 | 压迫感、掌控局面 |
| 前景小/后景大 | 弱势 | 被包围、受限 |

### 1.2 三角构图法则

```
稳定三角：
    A
   / \
  B - C

适用：三方对峙、谈判、僵持

动态三角：
    A → B
   ↙   ↘
    C

适用：追逐、逃离、转换

倒置三角（不稳定）：
    A
   ↘ ↙
    B
    |
    C

适用：危机、压迫、一边倒
```

### 1.3 站位变化设计

| 变化类型 | 设计要点 | 示例 |
|----------|----------|------|
| 位置交换 | 权力关系逆转 | 弱势者突然翻身 |
| 距离拉近 | 关系亲近/冲突升级 | 争吵逼近、暧昧靠近 |
| 距离拉远 | 关系疏远/退出 | 决裂、离开 |
| 包围/解围 | 局势变化 | 主角被围→突围 |

## 二、视线交互设计

### 2.1 Eye-line 基础规则

| 类型 | 描述 | 适用场景 |
|------|------|----------|
| 直接对视 | 视线相交 | 对峙、表白、冲突 |
| 斜视 | 30-60度偏转 | 不屑、轻视、回避 |
| 俯视 | 视线向下 | 藐视、碾压 |
| 仰视 | 视线向上 | 崇拜、求助、震惊 |
| 游移 | 视线不定 | 心虚、紧张、思考 |
| 凝视 | 视线固定 | 深情、仇恨、决定 |

### 2.2 视线交互模式

```
模式1：单向锁定
A → B（单方面压制/暗恋）

模式2：双向对视
A ↔ B（平等对峙/深情）

模式3：三角循环
A → B → C → A（三角恋/情报传递）

模式4：群体聚焦
A → B+C+D（演讲/威慑/审判）

模式5：视线逃离
A → B → 避开（心虚/害羞/尴尬）
```

### 2.3 视线冲突设计

| 场景 | 视线设计 | 效果 |
|------|----------|------|
| 情敌相遇 | 双方对视→移开→再对视 | 紧张、试探 |
| 秘密被发现 | 突然对视→震惊→躲避 | 尴尬、危机 |
| 谈判博弈 | 直视→移开→逼视 | 心理战 |
| 单相思 | 偷偷看→被发现→慌乱 | 甜蜜、苦涩 |

## 三、冲突动作设计

### 3.1 肢体冲突类型

| 类型 | 强度 | 示例 | AI生成难度 |
|------|------|------|------------|
| 推搡 | 低 | 推肩膀、推搡 | 低 |
| 拉扯 | 中 | 拽衣领、拉手 | 中 |
| 殴打 | 高 | 扇耳光、拳击 | 高 |
| 武器 | 高 | 剑砍、枪击 | 高 |
| 魔法/技能 | 高 | 仙法、幻术 | 高 |

### 3.2 冲突动作设计原则

1. **起承转合**：
   - 起：冲突起因（挑衅、误会）
   - 承：升级（推搡、对骂）
   - 转：高潮（动手、爆发）
   - 合：结果（倒下、逃离）

2. **AI友好原则**：
   - 避免肢体接触（易崩坏）
   - 用表情/动作替代
   - 用影子/声音暗示
   - 用特写放大细节

### 3.3 冲突替代方案

| 真实冲突 | AI友好替代 |
|----------|------------|
| 扇耳光 | 抬手→对方侧脸特写→音效 |
| 推倒 | 冲过去→撞到→踉跄 |
| 拥抱 | 跑向→张开手→画面定格 |
| 亲吻 | 靠近→闭眼→嘴唇特写 |

## 四、群演调度规范

### 4.1 群演分类

| 类型 | 数量 | 处理方式 |
|------|------|----------|
| 背景群演 | 10-50人 | 文字描述，不单独设计 |
| 中景群演 | 5-10人 | 群体动作描述 |
| 焦点群演 | 2-5人 | 单独设计动作 |

🔴 独立角色硬上限（对接平台文件预算 图片≤9，默认 FAIL 规则）：
- 单镜头 / 单条提示词中**独立设计动作的角色 ≤ 8**（焦点群演 + 中景需单独动作者合计）。
- **超过 8 个独立角色 → 默认 FAIL**：① AI 无法稳定处理 8+ 独立主体；② 每个独立角色需引用独立参考图，会突破平台「图片≤9」预算（角色图 + 场景图 + 道具图合计已逼近上限）。
- 合规解法（任选）：合并为群体动作描述 / 拆分为多镜头多条提示词 / 减少引用改为文字氛围描述。

### 4.2 群演调度模板

```markdown
【群演设计】
- 焦点人物：A（需单独设计动作）
- 中景群演：群体动作描述（如"众人惊恐后退"）
- 背景群演：整体氛围描述（如"人群骚动"）

【调度原则】
- 焦点人物在画面前景1/3处
- 中景群演在中景层次
- 背景群演在远景模糊处理
```

### 4.3 群体情绪设计

| 场景 | 群体动作 | 氛围词 |
|------|----------|--------|
| 震惊 | 集体后退/静止 | 震惊、寂静 |
| 愤怒 | 向前涌动/指指点点 | 嘈杂、混乱 |
| 恐惧 | 四散奔跑/抱头 | 尖叫、混乱 |
| 欢呼 | 向前挤/举手 | 热闹、沸腾 |
| 悲伤 | 低头/抽泣 | 沉重、呜咽 |

## 五、情感线互动设计

### 5.1 CP互动模式

| 类型 | 互动特征 | 典型场景 |
|------|----------|----------|
| 甜宠 | 亲近、呵护、投喂 | 摸头、递东西、拉手 |
| 虐恋 | 拉扯、伤害、复合 | 推开、挽回、拥抱 |
| 暗恋 | 偷看、靠近、误会 | 脸红、结巴、躲避 |
| 对立 | 争吵、碰撞、吸引 | 顶嘴、对视、较量 |

### 5.2 暧昧推拉设计

```
第一层：靠近
- 肢体靠近（走路并肩、坐下靠近）
- 视线接触（偷看、被发现）

第二层：接触
- 道具接触（递东西、手指触碰）
- 言语接触（调侃、关心）

第三层：突破
- 打破距离（突然拉近）
- 打破关系（表白/亲吻）
```

### 5.3 误会场景设计

```
误会构成：
1. 目睹异常（看到亲密举动/秘密）
2. 错误解读（主观臆断）
3. 情绪爆发（愤怒/伤心）
4. 冲突升级（争吵/动手）
5. 真相揭开（反转/虐心）
```

### 6.0 互动方案输出标准块（🔴 AXIS 强制格式 — 每个多角色互动场景必须按此 5 段输出，缺一不可）

**① 站位 ASCII（俯视权力矩阵，标注上=主导 / 下=弱势 / 左=被动 / 右=主动）**

```
      [上=主导]
         A
        / \
       B   C
  [左=被动] [右=主动]
```

**② Eye-line 视线交互（标注屏幕方向，锁 180° 轴线）**
- A → B：直视（A 看 3 点钟方向）
- B → A：回看（B 看 9 点钟方向）
- C → A+B：旁观斜视
- 轴线基准：[守轴 / 刻意越轴并说明叙事目的]

**③ T 轴时间轴（0.5s 精度，与分镜衔接锚点一致）**
- T+0.0–2.0s：[建立] 各方站定、对峙
- T+2.0–5.0s：[试探] 言语交锋 + 微表情
- T+5.0–8.0s：[升级] 情绪升温 + 肢体/物理动作
- T+8.0–10.0s：[高潮] 关键动作，卡点截断

**④ @素材引用预算（对接平台文件预算：图片≤9 / 视频≤3 / 音频≤3 / 总≤12）**

| 引用类型 | @素材 | 数量 |
|---------|-------|------|
| 角色独立图 | @角色A图、@角色B图、@角色C图 | 3 |
| 场景独立图 | @场景图 | 1 |
| 道具图 | @道具图 | 1 |
| **图片合计** | | **5（≤9 ✅）** |

> 独立角色 > 8 时图片必然超 9，本块判 FAIL（见 4.1 独立角色硬上限）。

**⑤ epNN 资产标记（写入 assets/prompts 时使用，遵循 CLAUDE.md 标记规范）**

## 七、诊断指南

Q: 群戏总是很乱？
A: 使用焦点人物法：只设计2-3个焦点人物的动作，其他人用群体动作描述。

Q: 角色站位没有戏剧张力？
A: 检查权力矩阵：弱势角色是否在画面下方/边缘？强势角色是否占据主体？

Q: 互动场景太平淡？
A: 加入视线变化：单一看→偷看→对视→移开，情绪层层递进。

Q: 冲突动作容易崩坏？
A: 用替代方案：肢体冲突→表情特写→声音暗示→影子效果。

[PASS/FAIL 标准]

    PASS 条件（必须全部满足）：
    - 位置逻辑和视线交互无严重错误
    - AI友好替代方案完整（无不可执行动作）
    - 每个互动场景均输出 6.0 互动方案标准块 5 段（站位ASCII+Eye-line+T轴+@素材引用预算+epNN标记）

    - 6项评分平均 ≥ 7 且无单项低于 5
    - 产出三维质量标准各项 ≥ 95分

    FAIL 条件（任一满足）：
    - 视线交互导致空间关系崩塌
    - 冲突动作无AI替代方案（直接暴力不可生成）
    - 群演管理混乱导致焦点缺失
    - 单场景独立角色 > 8（突破平台图片≤9 预算，默认 FAIL）
    - 缺失 6.0 互动方案标准块任一段
    - 产出三维质量标准任一维度 < 95分
